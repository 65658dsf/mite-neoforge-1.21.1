深层石头化 / Deep To Stone
作者：NingMeng123
GitHub：https://github.com/65658dsf
适用版本：Minecraft Java 1.21.1（资源包格式 34）

这是独立资源包，可在原版或 NeoForge 客户端启用。
仅修改贴图和物品显示模型，不改变物品与方块名称、硬度、掉落、生成、熔炼配方或其他玩法。

替换范围：
- 深板岩全部表面（含顶部）→ 原版石头。
- 深板岩圆石 → 原版圆石，同时覆盖其楼梯、台阶、墙。
- 虫蚀深板岩共享深板岩材质，也会显示为石头。
- 原版深层煤、铜、铁、金、红石、青金石、钻石、绿宝石矿石
  → 各自对应的普通矿石。
- MITE: Modern 深层银矿石、秘银矿石、艾德曼矿石
  → 本项目对应的浅层矿石贴图。没有安装 MITE 时这些贴图不生效。
- 物品栏中对应方块的图标也会随之改变。
- 粗铜、粗铁、粗金 → 对应原版普通铜矿石、铁矿石、金矿石方块外观。
- MITE: Modern 粗银、粗秘银、粗艾德曼 → 本项目对应浅层矿石方块外观。
  原版没有银矿石，因此粗银使用本项目现有的普通银矿石材质。
- 上述六种粗矿物在物品栏、手持和地面掉落时均显示为矿石方块，
  仍然是原来的粗矿物物品，不能作为矿石方块放置，熔炼和其他用途不变。

安装：
1. 将 DeepToStone-1.21.1.zip 原样放入所用游戏实例的 resourcepacks 文件夹，无需解压。
2. 在“选项 → 资源包”中启用“深层石头化”，并将它放在其他修改相同贴图的资源包上方。
3. 点击“完成”等待加载；如果已启用旧版本，可按 F3+T 重新加载资源。
   停用本包即可恢复原有显示。

原有默认材质、模组资源和其他材质包均未修改。
磨制深板岩、深板岩砖/瓦、强化深板岩、凝灰岩等保留原有外观。
深层方块使用本包固定的原版浅层贴图和当前项目浅层矿石贴图。
粗矿物复用对应浅层矿石的方块模型；其他资源包若修改对应浅层矿石，其外观也会随之变化。

素材来源：
- 原版石头、圆石及八种普通矿石贴图：本机 Minecraft Java 1.21.1 客户端，归 Mojang/Microsoft 所有。
- 银、秘银、艾德曼普通矿石贴图：当前 MITE: Modern 项目。
