# 地底世界的试炼密室与刷怪笼地牢

开发署名：NingMeng123。

本项按用户要求把 1.21.1 试炼密室与普通刷怪笼地牢接入 `mite:underworld`，属于现代内容适配，不宣称试炼密室存在于 R196。沿用现有地底地形、高度、地幔和顶部基岩。

## 生成范围

- 试炼密室使用独立结构 `mite:underworld_trial_chambers`，沿用锁定版本的原版拼图模板池、别名选择、房间规模和功能方块。起点高度为 Y168～232，拼接范围限制在 Y116～307；不再使用主世界 Y-40～-20 的起点。刷怪身份按下表替换；普通和不祥宝库使用后续新增的[地底宝库奖励](underworld-vault-loot.md)，试炼刷怪笼通关奖励及房间箱子保持原配置。
- 结构间距、分离距离与盐值沿用 1.21.1 试炼密室。群系标签只包含地底群系。其他维度不会获得这个独立结构，原版试炼密室不被替换。
- 普通刷怪笼地牢使用原版 `monster_room` 特征，每区块 36 个候选位置，Y154～300。2026-10-22 按用户要求从 12 次提高至 36 次，生成尝试次数为调整前的三倍。仍须满足原版坚实地板、顶部及侧面洞口条件，只有候选检查成功才形成房间；不保证每个区块都有地牢，实际房间数量也不保证恰好变为三倍。
- 试炼密室受存档的结构生成设置约束；普通地牢与原版相同，按生物群系特征生成。已有完成生成的区块不会补建，需要探索新区块或使用新的测试存档。普通地牢不能用 `/locate structure` 定位。

数据通过 `UnderworldDungeonWorldgenProvider` 生成。普通地牢按 NeoForge 的 `underground_structures` 生物群系特征阶段接入，参考[官方生物群系修改文档](https://docs.neoforged.net/docs/1.21.1/worldgen/biomemodifier/)。

## 普通地牢箱子

2026-10-19 小幅提高地底普通地牢箱子的远古金属材料出现率：原有 8 次奖励抽签结束后，如果箱子奖励中没有远古金属币，额外以 3% 概率补入 1 枚远古金属币。币可以拆成远古金属粒；已经抽到币的箱子不再追加。若原有每箱出币率为 `p`，调整后为 `p + (1 - p) × 3%`，并非直接增加 3 个百分点。

这是现代地底平衡补充，历史权重、原有装备及唱片抽签保持原配置。仅作用于 `mite:underworld` 中使用 `minecraft:chests/simple_dungeon` 的箱子；主世界箱子、试炼密室房间箱子和宝库奖励保持原配置。已有尚未生成奖励的地牢箱子也会使用新规则；已经开启并生成奖励的箱子不会补发。

上述地牢密度与箱子出币微调已通过隔离目录 `runData`、`build` 与 1594 项 JUnit（零失败、错误或跳过），5 份地牢生成资源与数据生成结果一致，发布包中的候选次数已核对为 12。该次微调未执行游戏内手测或服务端 GameTest；日志为 `build/verification/underworld-balance-datagen.log` 和 `build/verification/underworld-balance-build.log`。

## 普通地牢怪物池

2026-10-19 按用户要求，普通地底地牢改用以下独立怪物池，增加守卫、骑士和地底怪物的种类。百分比表示大量地牢中各类刷怪笼的选择权重，每个笼选定一种后保持固定，不在每轮刷怪时混抽。

| 怪物 | 选择权重 |
|---|---:|
| 远古骷髅守卫 | 20% |
| 怨魂 | 25% |
| 远古骷髅 | 10% |
| 蜘蛛骑士（恶魔蜘蛛载远古弓骷髅） | 15% |
| 恶魔蜘蛛 | 15% |
| 相位蜘蛛 | 10% |
| 尸鬼 | 5% |

项目现有实体只有“远古骷髅守卫”，没有单独的普通“骷髅守卫”；用户已确认使用现有守卫搭配其他地底怪。两类骷髅领主继续排除。

新地牢生成时立即选型；旧地底笼若仍是原版僵尸、骷髅、蜘蛛或旧版对应的怨魂、远古骷髅、恶魔蜘蛛，且没有自定义 NBT、装备、生成规则或多项/非默认权重的候选池，加载后也会一次性接入新池。选择使用世界种子和方块坐标，不消耗世界随机数，结果随笼保存，重进存档不会重抽。自定义笼保留原配置并继续执行下方固定映射；使用刷怪蛋指定怪物时保留指定身份，并清除本功能原有骑士乘客及候选。

蜘蛛骑士使用实际乘客关系。载具和远古骷髅分别经过正式出生初始化，骑手固定为持弓子型；两者一起加入世界，出生取消或挂载失败时不会留下孤立骑手。普通笼的激活、延迟、生成范围和附近数量上限保持原规则。试炼笼继续使用已有角色映射及完整波次、奖励和冷却。

本轮怪物池修改已通过 `build`、1611 项 JUnit（零失败、错误或跳过）及独立命名空间的 8 项服务端 GameTest。验证包含 256 个位置覆盖全部 7 类、六种旧笼身份迁移、保存重载不重抽及不推进世界随机数、主世界和自定义配置隔离、真实骑士生成及弓/盔甲初始化、刷怪蛋清理后实际生成、既有普通笼/试炼配置回归。自然生成测试在种子 0 的 `144050, 248, -143796` 找到远古骷髅守卫笼及地牢箱子。发布包已核对新池、骑手初始化、Mixin 接线和 12 次地牢候选；未打包测试资源，本轮未操作游戏客户端。

## 地底刷怪笼固定替换表

以下固定映射用于自定义普通刷怪笼和试炼刷怪笼的普通、不祥模式；目标均为已经注册的 MITE 生物。固定映射不增加随机抽签，重载后不会改变同一配置的身份。

| 原身份 | 地底刷怪笼身份 |
|---|---|
| 僵尸、尸壳、僵尸村民 | `mite:revenant`（怨魂） |
| 溺尸 | `mite:ghoul`（尸鬼） |
| 骷髅 | `mite:longdead`（远古骷髅） |
| 流浪者、沼骸、凋灵骷髅 | `mite:longdead_guardian`（远古骷髅守卫） |
| 蜘蛛 | `mite:demon_spider`（恶魔蜘蛛） |
| 洞穴蜘蛛 | `mite:phase_spider`（相位蜘蛛） |
| 史莱姆 | `mite:ooze`（灰浆怪） |
| 苦力怕 | `mite:infernal_creeper`（地狱苦力怕） |
| 蠹虫 | `mite:hoary_silverfish`（苍白蠹虫） |
| 骷髅领主、远古骷髅领主 | 远古骷髅守卫 |
| 旋风人等未列出的身份 | 保留原身份 |

领主排除也处理命令、刷怪蛋和数据包写入的当前实体、加权候选及乘客。这里限定地底刷怪笼，不改变自然生成与领主自身召唤随从的规则。

保留作者配置的其他实体 NBT、乘客、装备表、掉落概率、自定义光照范围及候选权重。普通笼保留原有激活和延迟规则；试炼保留人数倍率、同时/总数量、生成间隔、实体 UUID 跟踪、奖励和冷却。试炼替换体使用试炼自己的碰撞、视线与自定义生成限制，不叠加自然生成的暗度、特定地板或附近玩家限制。

## 手动验收

请重启开发客户端加载新代码，在测试存档中开启作弊。使用新存档或未探索过的地底区块，并开启结构生成。以下测试不需要安装 JEI 或 Jade。

### 1. 自然试炼密室

```mcfunction
/gamemode spectator
/execute in mite:underworld run locate structure mite:underworld_trial_chambers
```

记录命令返回的 X、Z，替换下方占位坐标：

```mcfunction
/execute in mite:underworld run tp @s X 200 Z
```

在附近上下寻找密室。预期：能找到原版风格完整房间、走廊、试炼刷怪笼和宝库，位置处于高层地底洞穴带；底部地幔、顶部基岩不因本功能消失。主世界执行 `/locate structure minecraft:trial_chambers` 仍使用原版生成。

### 2. 普通与不祥试炼

切换生存模式，分别触发近战、远程和小型怪物的笼。不要只看笼内模型，要观察实际生成实体。

- 原僵尸位置刷怨魂；原骷髅位置刷远古骷髅；沼骸/流浪者对应远古骷髅守卫；蜘蛛等对应替换表。
- 灯光正常的房间仍能刷怪，不需要拆掉密室灯光。旋风人继续存在。
- 怪物存活时不会无限多刷；击杀完整波次后正常掉落奖励并进入冷却。
- 在另一只尚未完成的笼附近获得不祥之兆再触发不祥试炼，检查替换、装备、波次与不祥奖励。测试命令可使用 `/effect give @s minecraft:bad_omen 120 0 true`。
- 两种领主均不应从这两类地底刷怪笼产生。

### 3. 普通刷怪笼与手动写入限制

探索 Y154～300 的新区块洞穴，寻找带苔石/圆石、箱子和普通刷怪笼的小房间。普通地牢不能使用结构定位命令直接查找。

要单独隔离验证刷怪身份，可在地底一个安全、黑暗且有地板的宽敞测试房内站定，切换创造模式，再放置：

```mcfunction
/setblock ~2 ~ ~ minecraft:spawner{"mite:underworld_dungeon_configured":1b,SpawnData:{entity:{id:"minecraft:zombie"}},Delay:0s}
```

上面的标记用于明确指定怪物、绕过普通地牢的一次性选型；不加标记的默认笼会加入新池。预期指定笼内模型和实际实体均为怨魂。把配置里的 `minecraft:zombie` 分别换成 `minecraft:skeleton`、`mite:bone_lord`、`mite:ancient_bone_lord`，预期分别为远古骷髅、守卫、守卫；可用刷怪蛋右键同一地底笼再次测试。靠近普通笼约 16 格内观察；旁边堆积过多同类会达到数量限制。自然地牢按上方 7 种类型验收，蜘蛛骑士必须实际骑乘并持弓。

### 4. 保存与其他维度

保存退出、重新进入，检查普通笼和两套试炼配置、笼内模型及下一批怪物身份。主世界用同样命令创建僵尸/骷髅笼，预期仍生成原版对应怪物。

测试中若曾加速，结束后恢复 `/tick rate 20`。2026-10-15 用户确认当前交付正常并授权提交；逐项画面、操作和真实多人结果未另行记录；自动验证记录另见 `docs/testing/underworld-dungeons-automated-results.md`。
