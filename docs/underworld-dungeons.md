# 地底世界的试炼密室与刷怪笼地牢

开发署名：NingMeng123。

本项按用户要求把 1.21.1 试炼密室与普通刷怪笼地牢接入 `mite:underworld`，属于现代内容适配，不宣称试炼密室存在于 R196。沿用现有地底地形、高度、地幔和顶部基岩。

## 生成范围

- 试炼密室使用独立结构 `mite:underworld_trial_chambers`，沿用锁定版本的原版拼图模板池、别名选择、房间规模、刷怪配置、宝库和战利品。起点高度为 Y168～232，拼接范围限制在 Y116～307；不再使用主世界 Y-40～-20 的起点。
- 结构间距、分离距离与盐值沿用 1.21.1 试炼密室。群系标签只包含地底群系。其他维度不会获得这个独立结构，原版试炼密室不被替换。
- 普通刷怪笼地牢使用原版 `monster_room` 特征，每区块 10 个候选位置，Y154～300。仍须满足原版坚实地板、顶部及侧面洞口条件，只有候选检查成功才形成房间；不保证每个区块都有地牢。
- 试炼密室受存档的结构生成设置约束；普通地牢与原版相同，按生物群系特征生成。已有完成生成的区块不会补建，需要探索新区块或使用新的测试存档。普通地牢不能用 `/locate structure` 定位。

数据通过 `UnderworldDungeonWorldgenProvider` 生成。普通地牢按 NeoForge 的 `underground_structures` 生物群系特征阶段接入，参考[官方生物群系修改文档](https://docs.neoforged.net/docs/1.21.1/worldgen/biomemodifier/)。

## 地底刷怪笼替换表

以下固定映射同时用于普通刷怪笼和试炼刷怪笼的普通、不祥模式；目标均为已经注册的 MITE 生物。固定映射不增加随机抽签，重载后不会改变同一配置的身份。

| 原身份 | 地底刷怪笼身份 |
|---|---|
| 僵尸、尸壳、僵尸村民 | `mite:revenant`（怨魂） |
| 溺尸 | `mite:ghoul`（尸鬼） |
| 骷髅 | `mite:longdead`（远古骷髅） |
| 流浪者、沼骸、凋灵骷髅 | `mite:longdead_guardian`（远古骷髅守卫） |
| 蜘蛛 | `mite:demon_spider`（恶魔蜘蛛） |
| 洞穴蜘蛛 | `mite:phase_spider`（相位蜘蛛） |
| 史莱姆 | `mite:ooze`（灰浆怪） |
| 苦力怕 | `mite:infernal_creeper`（地狱苦力怕） |
| 蠹虫 | `mite:hoary_silverfish`（苍白蠹虫） |
| 骷髅领主、远古骷髅领主 | 远古骷髅守卫 |
| 旋风人等未列出的身份 | 保留原身份 |

领主排除也处理命令、刷怪蛋和数据包写入的当前实体、加权候选及乘客。这里限定地底刷怪笼，不改变自然生成与领主自身召唤随从的规则。

保留作者配置的其他实体 NBT、乘客、装备表、掉落概率、自定义光照范围及候选权重。普通笼保留原有激活和延迟规则；试炼保留人数倍率、同时/总数量、生成间隔、实体 UUID 跟踪、奖励和冷却。试炼替换体使用试炼自己的碰撞、视线与自定义生成限制，不叠加自然生成的暗度、特定地板或附近玩家限制。

## 手动验收

请重启开发客户端加载新代码，在测试存档中开启作弊。使用新存档或未探索过的地底区块，并开启结构生成。以下测试不需要安装 JEI 或 Jade。

### 1. 自然试炼密室

```mcfunction
/gamemode spectator
/execute in mite:underworld run locate structure mite:underworld_trial_chambers
```

记录命令返回的 X、Z，替换下方占位坐标：

```mcfunction
/execute in mite:underworld run tp @s X 200 Z
```

在附近上下寻找密室。预期：能找到原版风格完整房间、走廊、试炼刷怪笼和宝库，位置处于高层地底洞穴带；底部地幔、顶部基岩不因本功能消失。主世界执行 `/locate structure minecraft:trial_chambers` 仍使用原版生成。

### 2. 普通与不祥试炼

切换生存模式，分别触发近战、远程和小型怪物的笼。不要只看笼内模型，要观察实际生成实体。

- 原僵尸位置刷怨魂；原骷髅位置刷远古骷髅；沼骸/流浪者对应远古骷髅守卫；蜘蛛等对应替换表。
- 灯光正常的房间仍能刷怪，不需要拆掉密室灯光。旋风人继续存在。
- 怪物存活时不会无限多刷；击杀完整波次后正常掉落奖励并进入冷却。
- 在另一只尚未完成的笼附近获得不祥之兆再触发不祥试炼，检查替换、装备、波次与不祥奖励。测试命令可使用 `/effect give @s minecraft:bad_omen 120 0 true`。
- 两种领主均不应从这两类地底刷怪笼产生。

### 3. 普通刷怪笼与手动写入限制

探索 Y154～300 的新区块洞穴，寻找带苔石/圆石、箱子和普通刷怪笼的小房间。普通地牢不能使用结构定位命令直接查找。

要单独隔离验证刷怪身份，可在地底一个安全、黑暗且有地板的宽敞测试房内站定，切换创造模式，再放置：

```mcfunction
/setblock ~2 ~ ~ minecraft:spawner{SpawnData:{entity:{id:"minecraft:zombie"}},Delay:0s}
```

预期笼内模型和实际实体均为怨魂。把配置里的 `minecraft:zombie` 分别换成 `minecraft:skeleton`、`mite:bone_lord`、`mite:ancient_bone_lord`，预期分别为远古骷髅、守卫、守卫；可用刷怪蛋右键同一地底笼再次测试。靠近普通笼约 16 格内观察；旁边堆积过多同类会达到数量限制。

### 4. 保存与其他维度

保存退出、重新进入，检查普通笼和两套试炼配置、笼内模型及下一批怪物身份。主世界用同样命令创建僵尸/骷髅笼，预期仍生成原版对应怪物。

测试中若曾加速，结束后恢复 `/tick rate 20`。2026-10-15 用户确认当前交付正常并授权提交；逐项画面、操作和真实多人结果未另行记录；自动验证记录另见 `docs/testing/underworld-dungeons-automated-results.md`。
