# 027 功能性方块来源与适配

开发者：NingMeng123。版本依据是本地 R196 发布包的 `reference-data/runtime-registry.json`，独立原始配方/方块快照见 `spec/functional-blocks-027.json`。新增 6 种金属砧、7 种金属箱子和绿宝石附魔台；原版铁砧沿用三种原版损伤 ID，已有熔炉、工作台、符文石、地幔不重复注册。银、秘银、艾德曼块及依赖的远古金属块由同批金属块模块添加。

## 铁砧

`amv.java:187–215`：寿命是 `1600 * 31 * 材料耐久倍率`，磨损达到 50%/80% 改变外观，100% 消失。铜、银、金寿命 198400；铁 396800；远古金属 793600；秘银 3174400；艾德曼 12697600。贴图使用原资源包 `blocks/anvil/<material>`。物品最多堆叠 1。

`va.java:58–162`：砧材料倍率不得低于待修装备材料；消耗对应金属粒，工具/实心金属甲/金属弓费用为耐久组件数乘 2，锁链甲单粒修复量为最大耐久乘 2 再除非锁链费用，钓鱼竿费用 1。源 `for` 循环只连续执行与第一份修复量相等的批次；剩余不足一份时需再取一次结果。维修保持品质和第一件的颜色，玩家制造能力按既有品质系统取出时再次校验。

`vc.java:31–51` 的砧磨损只来自材料维修。工具磨损等于实际恢复耐久；防具和金属弓乘 200；钓竿乘整数 `200/9=22`。这两个比例分别由运行快照的铁鹤嘴锄 12800 / 铁靴 64，以及秘银锹 25600 / 秘银弓 128 算出。合并两件装备没有现代额外耐久奖励，不磨砧、不支付经验；消耗一件同品质、未附魔的第二装备，第一件必须有损伤；当第一件未附魔时第二件也需有损伤，第一件已附魔时可使用完好第二件。源调用 `ye.areItemStacksEqual(...,ignore_tag_compound=true)` 忽略第二件染色，保留第一件品质、颜色、附魔和其它组件。普通合成格和砂轮不跟随放宽染色检查。

砧磨损以 `mite:anvil_damage` 组件随采集物品保存，方块实体写入版本和精确磨损；原版铁砧状态变化、重载、坠落落地均保存。坠落不能放回世界时，掉落物也携带磨损。新增砧创造栏列出完好、轻损、重损三种组件变体，物品模型随磨损切换。R196 砧是可搬移方块：最低采集强度为硬度乘 4，0 级正常移动需 128 刻；不耗手持工具耐久。原版铁砧有效硬度为 9.6，新增砧硬度为材料倍率乘 1.2。

## 金属箱子

`BlockStrongbox.java`、`TileEntityStrongbox.java`、`ary.java:34–35`：七种箱子全部 27 格，不能相邻合为大箱，物品最多堆叠 4。放置时记主人；主人和创造玩家能打开；旁人无法打开。仅非创造主人破坏会掉箱体，其它移除仍按箱子行为散落内部物品。默认并非禁止旁人破坏或保护内部资源。继承 `ank.java:281/339` 的上方实心方块及坐猫开盖阻挡，复用现代原版阻挡检查。

主人搬移无工具等级门槛、最低强度为硬度乘 4；旁人正常破坏等级依次为铜/银/金 3、铁/远古金属 4、秘银 5、艾德曼 6。七种硬度仍是材料倍率乘 1.2。原资源包 `entity/chest/<material>_single.png` 接入现代箱子动画，手持模型也使用相应材质。箱体保存 27 格物品、主人 UUID 和显示名；UUID 是对旧版按账号名识别所有者的现代适配。漏斗继续使用普通容器访问，锁只限制玩家，未额外发明自动化保护。

`ank.java:166–173` 和 `ary.checkForWormComposting` 的存放活虫堆肥同样适用于金属箱子。复用既有食物模块的服务端箱子 tick，不重复处理容器或客户端箱盖动画；满箱且无法容纳食物容器/肥料时保留原食物。验收分别驱动实际金属箱子 ticker 转换一份已保存堆肥进度，以及检查满箱汤食不会丢碗或制造额外肥料。

## 绿宝石附魔台

`vm.java:238–261`：有效书架上限 24，绿宝石基础能量为 `(1 + 书架数) * 2`，源钻石台则乘 4。因此这是较低能量的替代台，不能称为附魔增强台。`aaw.java:205–225`：超过物品附魔性后，第二段每能量加 0.5，第三段加 0.25，之后不再增加；三个槽比例为 1/3、2/3、1，前两槽附加 ±0.1 浮动。铜工具附魔性 30，在 24 书架时最高槽为 40。

方块硬度 2.4，堆叠 4；配方为一本书、两个绿宝石、四个黑曜石（运行配方 order 195，难度 2735）。使用原资源包顶面和侧面，现代原版底面与动画书。菜单、实际附魔种类、青金石消耗和经验扣除沿用 1.21.1，实现源绿宝石台能量及附魔性递减；原版钻石台仍采用新版算法。旧版经验公式、无青金石槽、把水瓶/金苹果特殊附魔，以及所有旧版附魔不是本批已完成内容，不能标成全附魔系统复刻。

## 兼容边界与验收

材料维修为 R196 金属粒和确定磨损，重命名/附魔书等非维修操作保留现代可用行为和成本；这些操作不再触发原版随机砧损坏。非 R196 的钻石、下界合金等装备维修保留现代处理。NeoForge `AnvilUpdateEvent` 取消或其它模组提供输出时不强行覆盖，维修触发原版的修理通知事件。每次菜单计算以调用栈保存自己的事件，监听者嵌套更新其它菜单后仍保持外层取消和自定义输出，`finally` 清理作用域。

单元测试验证独立数值、整数舍入与剩余批次；GameTest 覆盖真实砧菜单、低阶限制、品质丢失后拒绝取出、事件取消、磨损保存/掉落/坠落、原版铁砧阶段、主人容器/保存/真实生存破坏、内部物品守恒、24 书架与实际附魔。额外菜单数据同步源零经验费及精确耗材数，客户端零费用结果仍能点击，并正确预测剩余金属粒。客户端材质、持握与 UI 由用户手测，未将注册或自动测试冒充实机通过。
