# 当前 ITE 扩展全部机制对照

作者：NingMeng123。分析日期：2026年10月25日。对应当前同级工程 `MITE Modern ITE`，版本0.2.10，提交 `c638852c87103c64e2d9f15f6437550ec729f36d`。本篇和主报告、旧版三个审计分册共同阅读。

## 加载关系与机制归属

当前扩展不是把两个旧JAR直接装进1.21.1。`ModernIte.java` 注册配置、世界生成、内容、金属升级炉、宝石锻造、生物、疯狗、附魔、经济和一套 `MiteExtensions.Policy`。主模组继续负责基础挖掘、营养、制造事务、矿脉、日历调用、自然生成调度、装备经验和基础AI；扩展通过该策略覆盖结果，并通过事件和Mixin补充行为。

这决定了对照时不能把扩展没有自己的 `MiningRules`、作物代码或地底生成器判成缺失：这些机制实际继承主模组。也不能把旧版的父模组机制再计为Extreme原创。主模组的策略只允许注册一个提供者，当前没有多扩展策略自动合并机制。

证据：`ModernIte.java:21`、`ExtremeRules.java:31`；主模组 `api/MiteExtensions.java:35`、`:133`。

## 日历与刷怪

`ExtremeCalendar` 把128天前血月设为每32天，之后每16天；128当天是蓝月，120当天是月晕，血月前三天为丰收月。`bloodCount` 被用于怪物装备阶段；不能据此推断所有名为“血月”的其他系统都使用同一计数。

`ExtremeWorldState` 将开荒平安期保存为主世界全局状态。日历达到37000tick或历史最高日期达到第3天即永久结束。回拨时间、死亡、重登和跨维度不会重新开启平安期。结构初始守卫有延迟补生成，而不是简单丢弃。首次血月前的白天半速只改变日历推进，AI、生产、饥饿、疲劳仍按正常tick执行；历史最高日期达到32后永久恢复正常。

当前 `IteReferenceSpawns.enabled()` 恒为true，旧“参考/自定义双模式”的部分分支仍留在源码，但当前入口不选择它们。有效行为是ITE的物种、地形、光照检查和可编辑的额度、节奏，不是README历史版本描述的另一套24格统一现代限制。

设有效区块并集为C、当前显示日期为D。当前工厂默认浅层额度为：

`floor(25 × C / 256 × (血月 ? 3 : 1)) + max(100, D)`。

深层额度为上述结果乘2，深浅独立计数。C=256、D=32且平安期已结束时，普通浅/深为125/250，血月为175/350；是容量，不是每轮会实际生成的数量。光照、拥挤、栖息地、随机抽签和碰撞仍会减少实际出生数。

自然池按照维度、群系、位置、结构和日期过滤；女巫小屋、下界要塞、末地、蘑菇岛等有自己的处理，不能把所有45种怪物视为同权重全维度随机刷。`ExtremeKind` 的固有日期与通用解锁配置取较大值。脚本战斗允许自己的编队规模，但仍经过自动生成日期和平安期门槛。

`SpawnPopulation` 同时记账现存实体和本tick尚未加入实体区段的预约，替换怪物转移预约，避免同一候选被重复计算或并发召援绕过限制。命令、刷怪蛋、已保存怪物和真实死亡拟态有不同的准入路径。已有怪物不会仅因修改开始日期而被批量删除。

## 战斗与特技

怪物成功伤害同一玩家的历史次数参与渐进伤害：次数乘 `min(2, 0.5 + 当前日期/50)`。龙和史莱姆等存在豁免。玩家持适用工具近战同一怪物时，额外 `min(2, 次数×max(等级,0)×0.1)`，并与征服者的 `等级×次数×1` 加算。次数在实际成功伤害后记录，不能把取消、无敌、完全格挡的攻击也计入。

当前玩家盾牌耐久损耗在主模组预算上乘3，怪物盾牌除2向下取整，再进入耐久附魔与损坏回调。武器格挡和盾牌格挡分开：武器格挡受适用材质、附魔开关、40tick最长持续和160tick冷却控制。怪物有基于攻击意图、朝向、目标、箭矢威胁的格挡，不是站在玩家附近就无条件举盾。僵尸盗贼的门盾有独立判定和显示。

当前大力士僵尸和击飞骷髅有效近战命中将垂直速度设为 `1.6929821475097433`，标准空气约上升15格；击退僵尸采用水平击退。它们不再等同旧版或本项目更早版本的超高上抛值。攻击消耗吸收生命也可触发，未造成有效命中的攻击不触发。

压缩骷髅特性以3%抽取，死亡时默认生成6至8只同类小骷髅，苦力怕另有3%的死亡分裂。幼体体型为一半、总生命为四分之一、输出伤害一半，不再继续分裂；黑暗地狱苦力怕排除。骷髅分裂的初始虚弱、缓慢和抗性默认20tick。召援密度、预约和随从限制可能使实际分裂数少于抽取数。

## 装备经验与强化锻造

主模组单装的装备成长上限是25。安装当前ITE后，非护甲为 `15+强化等级`；护甲为 `3×材料采集等级+强化等级`。强化最高：铁/远古金属3，秘银5，艾德曼7，振金10。磨具保留旧方块和历史组件，但当前右键只提示成长上限由强化决定，不再提供旧版的额外磨炼级数。

强化不是普通附魔，也不是装备经验等级。攻击类装备的强化增益为 `1.028^(2.28×强化级)-1`，并按实际属性事件组合；护甲和工具各有自己的结算式。装备经验获取乘 `1+0.025×g×(g+1)`。品质奖励只向上提升，不会降低已有更好品质。

四档强化台使用9槽：5材料、待强化装备、斧、战锤、成品；受装备材质对应台阶限制。失败率为阶位基础35/55/65减去斧、锤材料修正；万能石替换基础概率为50再应用修正。耗时、材料和斧锤耐久由同一规则供服务端与JEI读取。

每次开始即确定本次失败结果和失败时刻，并保存进度；关界面或重载区块不能重新抽结果。成功消耗材料和完整工具预算并升1阶；失败也消耗材料和一半工具预算，目标剩余耐久保留95%或90%，**当前明确不掉强化等级**。这与旧ITE失败掉阶有实质区别。

防护宝典作用于成长词缀：用保护替换火焰/爆炸/弹射保护和荆棘等候选；已有保护成长词缀拒绝。它不直接把普通附魔书中的所有保护类型改写。制造、维修和模板升级会保存宝石、强化、磨具和冷却组件。

## 复活阵与死亡拟态

复活阵绑定单个主人和跨维度坐标，致死时先检查归属、实体状态和安全落点；真正传送成功后才消耗阵并清经验，附加恢复、抗性、抗火和虚弱。位置不可用、传送被取消时不能宣称已经成功复活。其他玩家连创造模式也不能拆主人阵；归属和皮肤档案保存、同步，旧阵可在主人登录/操作时补全。

当前死亡拟态由玩家真实死亡掉落事件以10%触发；不会在紧急守备或复活阵已经取消死亡时重复吞走背包。成功生成才把原掉落转交拟态，杀死后返还。它豁免开局日期和平安期，但仍可能被加入阶段的局部拥挤保护拒绝。其基础生命常量为10，与旧Extreme的80有明显差异。

振金私人箱继承所有者容器思路；外人实际拆除私人箱后广播和记日志。私人箱的打开权限与复活阵破坏权限是不同规则，不能一概写成“其他人任何方式都不能破坏所有私人物品”。
