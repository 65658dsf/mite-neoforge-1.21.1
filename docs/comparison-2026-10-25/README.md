# MITE 三个参考模组与当前主模组和 ITE 的全机制对比报告

作者：NingMeng123。日期：2026年10月25日。

后续配置调整：本报告的资源哈希、工厂覆盖CSV及原矿量对照表记录分析时的基线。用户随后明确采用“原默认倍率乘选定系数”的相对调整方式，例如铜4.5×0.82=3.69，并要求生成高度也对齐旧版，现已清空主世界高度覆盖以恢复来源采样及现代映射；实际配置见[默认倍率和高度调整](../overworld-ore-defaults-2026-10-25.md)。以下旧矿量模型保留原高度基线，不能用作最终新配置的矿量保证；高级候选次数和概率沿用原值。

当前主模组已经重建了R196的大部分玩法家族，当前ITE则合并了旧ITE和Extreme的选定内容，并继续修改数值、成长和交互。**它们已经形成一套现代玩法，不能描述成三个旧包的逐项原值复刻。** 差异既有未接入的有效旧玩法，也有主动改设计、修复旧版不可达代码、现代原生替代和仅在额外兼容模组下才有意义的规则。

本报告按全部已识别机制家族展开，包含生存、挖掘、矿物、世界与维度、自然生成、全部实体族、AI、战斗、农业、制造、装备、附魔、经济、物理、功能方块、界面、命令、兼容和保存。所附全文件索引负责追踪入口与资源，详细分册负责解释具体行为；不把文件存在、资源注册或配置声明当作机制已经实际启用。

下面旧ITE和Extreme两列写的是**对父层的增量或覆盖**。“承接”表示仍有父层机制，不表示不存在。当前ITE列表示“主模组加当前ITE后的最终组合”，不是扩展单独脱离主模组运行。

**单装主模组默认 `reference_rules=1`。** 因此打包文件里的 `base_cap=100`、`blood_cap=200`、`hostile_interval_ticks=5` 是保留的custom配置，不能拿来当默认实际刷怪表现。装ITE后 `IteReferenceSpawns.enabled()` 恒true，但策略允许用ITE自己的数值控制，不能再套“reference就忽略所有可编辑值”的单装解释。

普通刷怪笼的15个额度只计真正成功加入世界的生成，取消或失败不扣额，计数保存后不会因重载刷新。依据为主模组`SpawnerBalanceRules`和`R196SpawnerMixin`的实际生成回调；这与R196原随机间隔、现代试炼刷怪笼和ITE拆笼挑战是不同机制。

## 影响体验最大的确定差异

1. **资源分布已经明显放宽。** 铜银矿倍率4.5、铁及深板岩铁3/5、钻石3等，叠加现代高度、地底新矿及不同掉落，不能把现在的资源压力按R196原地图估算。
2. **刷怪由组合策略决定。** 单装主模组reference与当前ITE策略的额度、组次、节奏和日期下限不一样；旧Extreme的猛烈血月公式也没有原样成为当前唯一规则。
3. **生命上限和装备上限发生结构变化。** R196玩家20生命；当前加ITE能84。主模组装备经验25级，装ITE改材质/强化上限。玩家等级无限不代表生命、饥饿和挖掘都无限增长。
4. **成长结算和ITE新血月没有完全共用周期。** 主模组 `MonsterGrowthRules.completedBloodMoons` 固定 `elapsed/32-elapsed/128`，跳过128倍数；当前ITE128天后每16天血月。ITE装备档位使用扩展血月计数，但普通怪生命/攻击基准仍走本体公式周期。第144天血月不能直接解释成所有通用成长也完成一次新基准结算。
5. **当前极难怪并不等到65天统一出现。** 工厂通用门槛为3天；65是旧fallback/历史README。流浪女巫等更晚物种规则仍生效；龙头僵尸、骷髅暴君等另有33日门槛。
6. **强化失败、磨具和宝石系统已重做边界。** 当前不掉强化等级，磨具不再加成长上限，强化过程保存结果；与旧ITE原随机交互不是同一风险成本。
7. **死亡拟态和怪物特技多处改设计。** 当前拟态既稀有又搬运掉落；部分旧不可达技能被修复，还有龙息、套桶、召援等新增。
8. **农业、经济与基础战斗不是纯旧版封闭环境。** 现代村民原报价保留并追加旧货单；现有职业/补货/结构/战利品、现代护甲/攻击冷却和第三方武器都会改变整体经济与战斗。
9. **主模组大量历史缺口已经补齐。** 女巫诅咒、牲畜真实需求、源状态效果、火球预判、自动换持、永久水源等不能再引用旧“待实现”文档判缺失。
10. **内容相似不代表身份和技能相同。** 当前41个Extreme保留身份中已有明确改写；另有3个旧身份没有独立注册，现代原生替代需分别说明。
