# 动物繁殖冷却与 R196

开发署名：NingMeng123。2026-10-24 按用户追加要求，以原版 MITE R196 为来源。

R196 `nk.java:45-54` 明确区分两个计时：新生幼体 `Age=-64000`，成功繁殖的父母 `Age=16000`。`pk.java:68-69` 和 `rp.java:101-102` 对双方父母调用 `setGrowingAgeAfterBreeding()`；`nk.java:70-91` 在服务端逐 tick 将正数减至 0。按 20TPS，父母冷却为 **13 分 20 秒**，来源幼体成长为 **53 分 20 秒**。服务器暂停或降低 TPS 时，现实耗时相应变化。

生产常量和普通动物成功繁殖入口采用 R196 的 16000 tick。现代动物同样使用 16000 tick 的父母冷却；现代兔子的幼体成长继续采用其原生负龄。父母冷却与幼体成长分别计时。

本轮另修复了实际存档边界：为兼容现代特殊动物，原代码会把成年动物从 0 设置为 6000 的操作映射到来源冷却 16000。然而读入存档也从新实体的默认 0 开始，所以恰好剩余 6000 tick 时重载会错误延长为 16000。现在 `AgeableMob.readAdditionalSaveData` 的读档阶段保留原始 Age，继续兼容真正繁殖入口的 16000，也不改变正在运行的 `6001→6000→5999` 倒计时。

`SourceBreedingCooldownGameTests` 对牛、猪、羊、鸡和兔子执行真实进入求偶、成功繁殖并插入幼体；逐一检查双方父母的 16000、15999、6001、6000 存档重载和完整倒计时归零，以及归零后再次进入求偶。幼体的负龄作为独立条件验证。现有 `GameplayBalanceGameTests` 的 6000 边界和牲畜幼体来源测试继续保留。
