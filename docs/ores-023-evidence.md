只有铜、银、金、铁、秘银、艾德曼，以及主世界普通装饰中的蠹虫石，启用深度增大尺寸。地底蠹虫石的第三个参数没有传 `true`。钻石、青金石、红石也没有深度放大；不能根据稀有度推断。

`abw` 的两个实际世界构造器都把地底的 `underworld_y_offset` 设为 120。`acu.genMinable` 对地底除沙砾外的候选乘 8，艾德曼再乘 2。`afq.getRandomVeinHeight` 用 `16+120=136` 作为部分矿石抽样范围；**采样结果不再加 120**。红石是 `aqc`，蠹虫石是 `aqs`，并非 `apr`，因此它们不走 75% 的金属矿石分支。

## 额外调用链

`acq.a(World,Random,int,int)` 在常规装饰后，为所有主世界生物群系运行 `generateSilverfishBlocks`。它扫描本区块 256 列的地表高度，`maxHeight=max(64,全部高度)`，`veinSize=max((sumHeight-8192)/256/8,2)`，候选为 `veinSize-1`，高度为 `nextInt(maxHeight)`，不走十分之一门控，也不按深度扩大。此路径不能被只替换 `acu.b()` 的实现漏掉。

`acx` 是 Extreme Hills 和 Extreme Hills Edge（原始 biome 3、20），在父类完成后额外尝试 `3+nextInt(6)` 个单块绿宝石，旧层 `4+nextInt(28)`，仅替换石头，没有通用矿脉尺寸采样。

`aep.a(ado,int,int)` 是下界的填充路径：石英 16 次、基础大小 13；金矿 2 次、基础大小 8，使用原始金矿 metadata 2；蠹虫石 `2+nextInt(7)` 次、基础大小 8，metadata 3。三者均替换下界岩、起始层为 `10+nextInt(108)`（10～117），不走十分之一门控，不按深度放大。新 R196 存档满足金矿 `earliestMITEReleaseRunIn>=139` 和下界蠹虫石 `>=0` 的开关。

下界金矿采用原始 `BlockGoldOre` 的下界岩子类型，其掉落仍是整块矿石，可映射到新版 `minecraft:nether_gold_ore`；不能沿用原版金粒产出。下界蠹虫石是实际启用方块，需要独立现代 ID；原始 `EntityNetherspawn` 的战斗与行为必须记录后续覆盖状态。

## 尺寸和矿脉形状

`afq.generate` 在检查起始替换方块之后才消耗随机数。先通过一个随机长度的乘法循环调整 `scale`，上限 4；深度选项再乘 `1-relativeHeight+0.5`。小尺寸分支还有取消与翻倍，向零截断后，预算 1 或 2 再随机变为 0 或 3，最终上限 32。

`afq.growVein` 是递归六面随机生长。每个已放置节点最多尝试 16 次；随机轴和方向后，携带剩余预算向邻格递归。不可替换位置不消耗后续随机数。它不是新版原版矿物特征的椭球生成器，仅相同的候选数和 `veinSize` 并不代表相同结果。

所有浮点运算须保留原来的 float/double 转换。例如乘法循环里的 `0.7f` 先提升 double，与字面量 double `0.7` 结果并不保证一致。附带的原字节码样例记录 RNG 后续 `nextLong`，同时检验结果和消耗顺序。

## 方块和掉落数值

`aqz` 的注册常量与 `apr` 构造器给出：银矿硬度 2.5、最小采集等级 2；秘银 3.5、等级 3；艾德曼 4.0、等级 4。铜 2.5、煤 1.2、金 2.4、其他普通矿石 3.0。红石继承 `akc.stone` 的等级 2；钻石等级 4、绿宝石等级 3，石英、青金石、铜银铁金煤等级 2。采集等级采用本项目 R196 材料等级体系。

`aqz.getExplosionResistance` 直接返回硬度字段 `cG`，旧 `b(float)` 不修改数值；不要把旧注册链中的抗爆参数当作生效参数。深板岩版本是现代适配，额外硬度倍率需要在实现规格另行说明。

已执行的 `reference-data/runtime-registry.json` 也核实各矿石与蠹虫石最大堆叠为 4；新增矿石与沿用原版 ID 的矿石应一起接入堆叠规则。蠹虫石最小采集等级为 0、硬度 0.75，其正常破坏生成生物而不掉方块。

`apr.dropBlockAsEntityItem` 对金属矿石掉整块矿石。煤、钻石、绿宝石、石英掉各自矿物，青金石和红石每次 `3+nextInt(3)`。自然矿石可由时运额外复制一次，每个原始单位概率 `fortune*0.1`；每单位最多两份。玩家放置后的整块金属矿石抑制时运，避免反复放置复制。`aqz` 计算经验时只数原始掉落，额外复制不增加经验。

采集经验：钻石 30、绿宝石 20、石英 10、青金石每原始单位 5；煤、红石及整块金属矿石为 0。爆炸使钻石、绿宝石、石英变碎片，煤不掉落；其他金属矿石仍掉方块。技能相关分支只有在世界明确启用技能且玩家缺少挖矿技能时才生效。

`RecipesMITE.addFurnaceRecipes`：一块铜、银、铁、金、秘银、艾德曼矿石分别得到一锭；青金石、红石矿各 4 个对应粉末，石英、绿宝石、钻石矿各 1 个宝石。`asg` 的实际加工时间为 200 刻，铜银铁金等热级 2、秘银 3、艾德曼 4。炉温机制必须在服务端验证；普通冶炼 JSON 并不自动提供这一机制。艾德曼矿物品的 `zh.isHarmedByLava()` 为 false，其他矿石不能按稀有度擅自获得此性质。

023 的数据生成按固定 1.21.1 客户端 JAR 核实并覆盖原版矿物加工配方 ID；不会再为同一原版矿石输入新增重复的 `mite:` 冶炼条目。红石、青金及各深层矿石在普通熔炉和高炉均产 4 粉，其余源矿产物各 1 个；石英的原版 ID 例外为 `minecraft:quartz` / `minecraft:quartz_from_blasting`。普通熔炉保持源 200 刻；保留现代高炉的 100 刻加工，并为新增银/秘银/艾德曼的深浅矿石各接入现代高炉配方。100 刻是现代设备适配，不属于 R196 源行为。JSON 的经验银行为 0，取出时由统一源产物经验规则按实际数量支付。023 初始阶段尚未实现完整炉温、炉种和燃料层级；当前已由 [024 熔炉体系](furnaces-024-evidence.md) 接入服务端热级检查，不能再将此历史限制视为当前行为。

## 现代高度适配

保留 1.21.1 原版主世界地形、洞穴、biome 和 -64～319 高度。原始主世界 0～64 层映射为 `-64+2*y`，64 以上保持原值；因此秘银起点 -64～0，艾德曼仍只在地底，钻石 -64～0，铜保留最高起点 128。此规则只决定起点，并不替换地形生成器。

地底已在 022 明确为 -64～319，矿物起点使用 `ModernUnderworldTerrain.fromLegacyY`（`ceil(y*384/256)-64`）。艾德曼的来源抽样 0～135 映射到 -64～139；部分金属可抽样至旧 255，对应新版 319。不能重复叠加地底的 120 偏移。

深度尺寸仍用抽样得到的旧层号；每个后续生长节点相隔现代一格。候选次数不按体积倍增；这是明确的稀缺性适配。现代随机特征与地形不同，因此不承诺旧版本同种子矿石位置一致。生成仅作用于新存档或新区块，不覆写玩家已探索区块。

## 原字节码样例的复现

```powershell
python tools/reference/export_ore_rules.py --java <Java17至23的java.exe路径> --verify-spec
```

该工具先核对 1,186 个覆盖类的 SHA-256，再通过只读 Java Guard 执行原 R196 `afq`。禁止文件修改、外部读取、进程、网络和本机库加载。`Unsafe` 仅分配无构造器的世界载体；不创建 Minecraft 客户端、服务器或真实世界存档。

高度样例直接运行原方法；尺寸样例运行原 `generate`，仅在 `growVein` 入口捕获预算，不替换原尺寸代码。形状样例在内存中的原 `adr`/`ads` 块数组上实际运行原完整递归生长，输出每个方块位置及后续 RNG。所有样例位于规格中的 `source_oracle`，与生产纯算法分离。

来源开关、地下偏置、下界子类型、额外山地路径已核实。旧矿物可出现的最终极限受地形、替换条件和脉形状影响，表中范围是起点范围，不应向玩家保证每层必有该矿物。

## 023实现与现代入口

主世界移除22个原版矿物/泥土/砂砾/虫石placed入口，下界移除4个金矿/石英入口，并通过[NeoForge 1.21.1官方Biome Modifiers](https://docs.neoforged.net/docs/1.21.1/worldgen/biomemodifier/)在三个维度各添加一次R196候选批次。主世界三个原版噪声预设仅将`ore_veins_enabled`改为false，密度路由、洞穴、含水层、表面规则及高度保持原版；避免现代大型铜/铁矿脉叠加。

绿宝石沿用原版1.21.1实际生成该矿的10个山地群系，读取生成期地表对应的三维群系，不将地下洞穴群系误判为地表。保留现代化石结构，将其独立煤/钻石覆盖层转换骨块；其余现代结构与远古残骸保留，完整现代战利品/交易进度另属后续平衡。

普通熔炉保留来源200刻周期，现代高炉采用100刻适配。源矿物产出及经验接入统一取出入口：金属一矿一锭，红石/青金一矿4粉。`asi.java:193..213`已确认炉下漏斗每次成功抽取会在炉朝向前方生成产物经验，速度缩放0.2；023仅为矿物恢复此分支，覆盖NeoForge物品能力和原版容器路线，失败转移无奖励，生产历史不再次奖励。食物既有自动化经验策略此次未修改。

新增深板岩金属矿保留源硬度，没有新增深板岩硬度倍率；原版对应矿石的采集硬度同样按源矿类别取值。深板岩银、秘银、艾德曼现已使用独立的现代深板岩矿图，普通变体仍使用对应原包矿图。023 初始阶段尚未复刻独立 Netherspawn/HoarySilverfish/Copperspine AI 和完整炉温、燃料、熔炉等级；现代银鱼不能代称这些独立 AI。炉温、燃料和熔炉等级现已由 [024 熔炉体系](furnaces-024-evidence.md) 实现，当前矿石与对应粗矿均须满足实际设备和燃料热级。

## 2026-10-19 用户要求的现代粗矿适配

以上掉整块矿石的段落记录 R196 源行为。当前版本按用户要求，将铜、铁、金、银、秘银、艾德曼的普通采集产物改为对应粗矿，普通与深板岩变体共用同种粗矿；精准采集、爆炸和下界金矿保留原矿石产物。粗矿沿用源时运概率；自然矿与玩家放置的矿石均可获得时运额外粗矿，因为粗矿不能重新放置为矿石，不再适用整块矿石的防复制限制。仍掉整块矿石的下界金矿继续保留放置抑制。新增 `mite:raw_silver`、`mite:raw_mithril`、`mite:raw_adamantium`，粗矿配方包含普通熔炼和高炉类型，实际设备仍须满足对应矿石的热级，一粗矿炼一锭。这是当前授权的现代适配，不作为 R196 原始掉落的证据。

新增深层矿图与粗矿图的制作、16×16 导入方式和完整提示词见 [现代矿石材质记录](art/modern-ore-textures.md)。
