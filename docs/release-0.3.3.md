# MITE: Modern 0.3.3

November 10, 2026. Developed by NingMeng123.

## Changes

- Fixed flowing water and lava incorrectly becoming additional source blocks when falling. Downhill water now drains properly after its feeding source is removed.
- Standardized all 25 vanilla wall crafting recipes to produce 8 walls from 6 matching material blocks, including deepslate, tuff, sandstone and nether brick wall families.
- Updated generated wall recipes and recipe-book entries to use the consistent output quantity.

Build file `MITE-Modern-0.3.3.jar`.

Requires Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series.

## 中文更新日志

- 修复流动水和流动岩浆在下落时异常生成额外液源的问题。移除上游水源后，下坡残留水流会正常消退。
- 原版全部 25 种围墙的合成产量统一为六个对应材料制作八个墙，涵盖深板岩、凝灰岩、砂岩、下界砖等围墙系列。

构建文件为 `MITE-Modern-0.3.3.jar`。
