# 女巫诅咒手动测试

开发者：NingMeng123。来源与逐项公式见 [R196 证据](witch-curses-source.md)，结构化规则见 `spec/witch-curses.json` 和 `spec/witch-curse-products.json`。

当前实现包含全部 16 种诅咒、女巫索敌施咒、延迟生效、未知效果发现、世界保存、解除、物品栏状态和暗角。2026-10-16 用户反馈“可以提交了”，确认当前交付正常并授权提交；未另行提供逐项操作或多人结果。不自动操作或重启游戏。

## 快速准备

在开启作弊的测试存档中执行：

```mcfunction
/summon minecraft:witch ~3 ~ ~ {NoAI:1b,PersistenceRequired:1b}
/mite curse apply @s cannot_run
```

第二条是管理员测试命令：从目标玩家周围 64 格内选择最近的存活女巫作为真实施咒者，直接施加指定诅咒。支持 Tab 补全类型；不带延迟立即生效，末尾加 `6000` 可测试原版延迟。测试命令允许创造模式，女巫自然索敌施咒仍排除创造和旁观玩家。

```mcfunction
/mite curse status @s
/mite curse clear @s
/mite curse apply @s cannot_run 6000
```

`status` 仅供管理员诊断，会输出类型、是否生效、是否已知、剩余游戏刻和施咒者 UUID；不会把效果标记为已知。每人只能有一个待生效或已生效诅咒，切换测试前先 `clear`。自然施咒时没有待生效提示。

## 每种效果

以下均使用 `/mite curse apply @s <类型>`，测试结束后 `/mite curse clear @s`。

| 类型 | 检查方法与预期 |
|---|---|
| `equipment_decay` | 用同一无附魔工具执行同样操作，耐久消耗为无诅咒时两倍；耐久附魔继续工作。 |
| `cannot_hold_breath` | 空气储备最多 90 游戏刻，入水后显示约 3 格气泡并较快开始耗氧；陆地不显示气泡条。水肺效果与水下呼吸附魔保留原规则。 |
| `cannot_run` | 有足够食物时按疾跑键也无法疾跑，尝试后显示具体诅咒。 |
| `cannot_eat_animals` | 肉、奶、含动物原料的混合食物不能食用；纯植物食物仍可食用。 |
| `cannot_eat_plants` | 面包、种子、植物食物和含植物原料的混合食物不能食用；纯肉仍可食用。 |
| `cannot_drink` | 水、药水、奶等饮品不能喝；祛魔瓶可喝，投掷药水仍可投掷。 |
| `endermen_enemy` | 附近末影人即使未被直视也可能敌视你，戴雕刻南瓜不能消除这部分额外检测。 |
| `clumsiness` | 比较相同等级/工作台/配方：最低制造品质按等级减 20 计算；需要付费的品质经验翻倍，制造耗时按来源公式翻倍后再套用等级与设备修正。 |
| `entanglement` | 在草等植物中水平移动输入减为 0.4 倍，藤蔓内为 0.2 倍；普通空气/地面不减速。 |
| `cannot_wear_armor` | 已穿装备掉到地上，不能通过右键、护甲槽、Shift 转移或分配器正常穿上；头部南瓜等也受限制。 |
| `cannot_open_chests` | 普通、陷阱及 MITE 金属箱不能打开；其他工作设备仍可用。 |
| `cannot_sleep` | 不能入睡；不会解除已有其他睡眠门槛。 |
| `fear_of_spiders` | 多次近战攻击蜘蛛，大约四分之三被阻止；弓箭攻击不受这项限制。 |
| `fear_of_wolves` | 同上，目标换成狼。 |
| `fear_of_creepers` | 同上，目标换成苦力怕。 |
| `fear_of_undead` | 同上，目标换成骷髅、僵尸或其他亡灵；按实际亡灵标记判断。 |

蛋糕与同时含动植物原料的食物会同时受到两类禁食影响。产品来源独立于营养数值，例如面包虽然不补植物营养，也属于植物制品。现代新增食物的分类属于明确的现代适配。

## 展示、保存与解除

1. 施加 `cannot_run` 后先打开物品栏：应显示“诅咒／效果未知”，仅悬停不能揭示。关闭背包并尝试疾跑，再打开背包，应显示名称与说明。低画质也有暗角，生效提示约 100 游戏刻后淡出。配方书打开或小分辨率时状态改用紧凑图标。
2. 保存退出再进入、死亡重生、往返地底/下界：诅咒及已经发现的效果保留；已生效诅咒不重复首次生效提示或发现粒子。
3. 用 `6000` 延迟施加，待生效期间不应显示诅咒或限制动作。可用 `/tick rate 200` 加速，完成后 `/tick rate 20` 恢复。`/time set` 只改昼夜，不会跳过这个游戏刻倒计时。
4. 喝牛奶不解除诅咒。喝 `mite:bottle_of_disenchanting` 解除本人的待生效或已生效诅咒，并正常返还空瓶。
5. 击杀真正的施咒女巫后，该女巫对所有玩家的诅咒均解除；击杀别的女巫不会解除。女巫区块卸载或玩家下线不解除，女巫不自然消失。
6. 测自然施咒时另外召唤一个有 AI 的女巫，转生存让她发现玩家。施咒发生在有效目标筛选的 25% 尝试中，与药水是否命中无关；同一女巫对同名玩家的诅咒类型固定。

多人可由 OP 对玩家名字施加同一女巫的不同测试诅咒，再分别测试发现、重连和女巫死亡后的共同解除。
