# Jade 动物生病原因

开发署名：NingMeng123。

准星指向牛、哞菇、猪、羊或鸡时，Jade 会显示其生病原因：饥饿、缺水、活动空间不足，以及对应食物、水分或自由度的百分比。多个不足会同时列出；健康动物不增加提示行。

判定沿用已有机制：三项数值中任一项低于 25% 即为生病，恰好 25% 达标。自由度不足可能由拥挤或长期缺少露天活动引起，提示描述当前不足，不把过去的数值变化猜成某一种环境原因。

三项都达标后仍有原有的 3600 游戏刻恢复期，提示改为“恢复中”和剩余秒数。在正常 20 TPS 下完整恢复需要 3 分钟；服务器变慢时实际等待会更久。再次出现不足会重置恢复计时，尚有不足时不显示正在倒数的假象。

提示读取 `Livestock032View` 已经同步的三项需求与恢复计时，与病态贴图使用同一数据，不扫描环境、不添加网络请求、不修改存档或生病机制，也不调整圈养动物的逃跑行为。哞菇沿用相同的健康规则，但保留原有贴图。

Jade 仍为可选扩展，可在其插件设置中关闭“MITE 动物生病原因”。该扩展标记为客户端功能，服务端无需再安装 Jade，只需正常运行 MITE 并同步动物数据。接口依据：[Jade 客户端功能文档](https://jademc.readthedocs.io/en/1.x/plugins20/plugin-config/)，并核对本地 Jade 15.10.6 API。
