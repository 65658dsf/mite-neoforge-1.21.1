# 模组菜单设置

作者：NingMeng123。更新：2026-10-19。

支持用户提供的 **Mod Menu (NeoForge Edition) 1.21.1-1.0.2**。它通过 NeoForge 的 `IConfigScreenFactory` 打开 MITE 设置，无需将菜单模组设为必需依赖；NeoForge 原生模组列表的配置入口也可用。

## 使用

进入模组列表，选择 **MITE: Modern → 配置**：

- **矿石生成倍率（主世界 / 地底）**：上方按钮明确切换两个维度。每个矿物只需编辑生成倍率：`1` 为原始倍率，`2` 双倍、`0.5` 一半、`0` 关闭；“还原”回到 `1`。原始候选次数、通过率与当前期望矿脉尝试数只读显示，不需要自行计算。支持搜索矿石名称或 `namespace:id`，远程服务器显示对应维度的只读倍率。
- **怪物成长基准与公式**：生命与攻击分别配置初始基准、每日增长百分数、血月基准公式和周期内公式。显示血月参与基准递推的完整步骤、默认生命每日 `0.5%` 和本体攻击每日 `0.25%`。可试算任意原始属性及日期，查看最近一次血月的结算输入、新基准和当前属性；两阶段公式通过语法及实际运行校验后才可保存。详细变量、函数和血月规则见 [怪物随日期成长](monster-day-scaling.md)。
- **附魔设置（默认目录与注册表）**：主菜单即可打开，读取内置默认目录和上次记录的附魔信息，直接显示实际默认等级与已有覆盖。进入世界后再次读取 `Registries.ENCHANTMENT`，补入其他模组和数据包新增的附魔，并更新原始等级，不覆盖你的上限或禁用设置。按名称或 `namespace:id` 搜索，逐项禁用或配置最高等级；显式上限为 `1–255`。
- **其他玩法与高级设置**：总体/生命/攻击成长倍率、生存近战距离倍率及固定减少值、高低差修正、主世界和地底试炼结构生成开关，以及附魔 ID 高级覆盖项。

矿石界面只保留首页的 **矿石生成倍率（主世界 / 地底）**。其他玩法与高级设置中不再显示主世界/地底的旧倍率和生成参数分组，避免同一配置出现多个编辑入口。原有 TOML 字段、保存值和服务端导出继续兼容，高级候选次数及通过率仍可在 TOML 中设置，专用页只读显示这些基准。

附魔默认目录由实际注册数据生成，并在进入世界时读取实际注册表补全，不使用手写附魔白名单。矿石页使用生成规则提供的配置集合，注册表提供实际方块名称和 ID。主世界提供铜、银、铁、金、秘银、青金石、钻石、艾德曼八种矿物；地底复用原有十一组配置，包含同样八种矿物及碎石、红石、虫蚀石头。主世界艾德曼已接入实际生成批次，但保留原始默认候选数 `0`，因此默认仍不生成；需要开启时，在高级 TOML 中将其候选数设为正数，之后由倍率控制。

上述可配置矿石的深层变种也各有独立条目，显示真实的 `minecraft:deepslate_*_ore` 或 `mite:deepslate_*_ore` 名称和 ID，可以搜索“深层”或 `deepslate`。普通矿石与深层矿石分别控制石头和深板岩中的生成；地底保留原有碎石和虫蚀石头配置入口。

每个专页的“保存”应用本页有效草稿；取消或 Esc 放弃修改。矿石页同时保存主世界和地底两份倍率草稿，切换维度、翻页、搜索与调整窗口保留输入，包括无效草稿；任一维度有错误都不能保存。附魔页同样保留翻页和搜索前的输入。怪物页的生命/攻击、血月/周期内四项公式共同校验，切页不能绕过错误。远程多人游戏可查看服务器同步的专页参数，无法改写服务端玩法。

## 导出到服务端

先保存各设置页的修改，回到玩法设置首页，点击**右上角“导出配置”**。会在客户端游戏目录的 `exports/mite-时间戳/` 下生成独立的 `mite-common.toml`；成功页显示完整路径，提供“打开导出文件夹”和“复制文件路径”。每次导出创建新目录，保留先前导出和原始配置。

停止服务端，把导出的文件复制到服务端的 `config/mite-common.toml`，然后启动服务端。导出包含全部玩法设置：矿石实际生成参数及旧倍率、怪物基准与四项公式、成长倍率、武器攻击距离、试炼结构开关、附魔上限和禁用 ID。新增配置字段会从真实配置定义中自动纳入导出。附魔目录缓存仅用于客户端显示，无需复制到服务端。

导出使用本地有效设置，不包含未保存草稿；公式曾在重载时被拒绝的情况下，导出最后一份通过校验的完整成长配置。文件生成后会重新读取并验证内容。连接远程服务器时，当前页面显示服务器只读配置，导出按钮禁用；断开连接后可导出自己的本地配置。

## 附魔离线配置与自动补全

无需进入存档，主菜单的附魔页就能编辑内置目录中的附魔及此前发现的模组附魔。未覆盖项显示目录记录的实际原始上限，已有上限覆盖显示你配置的等级；仅打开、翻页或保存不会把显示的默认值写成覆盖。

进入世界会重新读取全部附魔的注册 ID、名称和原始等级，自动补入此前没有的新附魔。已有上限覆盖和禁用 ID 独立保存在 `config/mite-common.toml`；目录更新只修改元数据，不改写玩家设置。离开世界后，更新过的目录保留在 `config/mite-enchantment-catalog.json`，下一次在主菜单也可配置这些附魔。

在等级框输入 `1–255` 会指定显式上限，输入 `0` 清除该上限覆盖；“还原”清除上限覆盖并重新启用该附魔，显示当前目录的原始等级。未改过的条目继续沿用各自原有规则。缓存中暂时未在当前世界注册的附魔、手动写入但尚未发现的 ID 都会保留，名称处悬停可查看来源；未知原始等级不会假定为 1。

## 矿物参数含义

主界面每矿物只编辑生成倍率，原始次数和通过率作为只读参考。实际计算为：

```text
期望矿脉尝试 / 区块 = 基准候选次数 × 生成倍率 × 通过率 / 100
```

例如默认地底铜矿为 `320 × 1 × 10% = 32` 次矿脉尝试/区块，铁矿为 `480 × 1 × 10% = 48`；主世界铜矿为 `40 × 1 × 10% = 4`。铜矿倍率 `2` 或 `0.5` 分别让相应维度的候选数变为双倍或一半，概率过滤只执行一次。倍率范围 `0–100`，非整数候选数量按小数部分随机舍入。倍率为 `1` 时保留原始生成随机序列。

这不是矿石方块所占百分比，也不是最终生成块数。候选通过后仍受矿脉大小、地形、可替换方块及高度等条件影响。修改仅影响后续新生成区块。

主世界倍率位于 `[overworld_ores]`，地底复用原有 `[underworld_ores]`。高级候选与概率字段分别位于 `[overworld_generation.<矿物>]` 和 `[underworld_generation.<矿物>]`，保留已有文件中的自定义值；通过倍率页保存或还原不会改写这些高级字段。界面显示原始默认参考以及当前有效基准，避免将已有自定义基准误认为原始默认。

同一配置节中的 `deepslate_<矿物>` 为深层矿石的独立倍率，例如 `deepslate_silver = 0.5`。旧配置没有这些字段时，默认值 `-1` 表示继续继承原有普通矿物倍率，确保已有自定义倍率不会因升级而改变。打开倍率页时显示当前实际倍率；保存后按界面显示的值分别写入普通和深层配置，因此之后两者独立调整。高级候选数、通过率和高度仍由同一矿物原有规则提供。

普通和深层倍率相等时仍使用原来的单批候选，不会重复生成矿脉，并保留原有随机序列。倍率不同则共享较小倍率对应的候选，仅为差值增加限定石质的候选；差值矿脉不能跨入另一石质。将某一变种设为 `0` 只关闭该变种，另一变种仍可生成。

旧 JSON 的八矿物 `*_frequency_overworld` / `*_frequency_underworld` 对应各自维度的高级 `candidates`，`*_chance_*` 对应 `chance_percent`。这里的频率单位是每区块实际候选次数，地底已经包含原始数量扩展，不会再额外乘 `8`。保留当前模组的默认候选量与 `10%` 概率，不自动导入旧 JSON 示例中的 `100%`。主世界艾德曼默认 `0` 次，单独调整倍率不会将零候选变为正数。

## 生效范围

配置位于实例目录的 `config/mite-common.toml`。单机存档共用该实例配置。专用服务器使用服务器自己的文件；登录和配置重载时同步不可写快照，断开后恢复本地配置。

- 矿物参数改变新区块的候选矿脉和通过概率，不改写现有矿石。默认参数保持原有生成随机序列。
- 怪物生命和本体攻击使用可编辑公式成长。默认生命每日增加当前参考生命的 0.5%，本体攻击每日 0.25%；血月后以结算属性重设基准，蓝月不重设。已有怪物更新生命时保持伤势比例。
- 总体和分项成长倍率相乘并传入公式的 `rate`。默认公式下设为 0 可关闭对应增长；忽略 `rate` 的自定义公式不受该倍率控制。
- 怪物设置保存及文件重载均会校验语法和代表性运行；非法组合不发布。对未来未采样日期的异常另有逐次运行保护和默认公式回退。
- 试炼开关阻止新区块中的结构起点，保留已有结构并允许完成跨区块部分。禁用类型也从 `/locate` 排除。
- 近战距离先乘倍率，再扣固定方块数，最低 0；客户端选取和服务端检查相同，创造距离保留原值。默认同高普通原版/MITE 剑仍为 2.25 格；安装 Better Combat 时，简易刀剑使用各自配置的基础距离，例如振金长柄刀 3.5 格、振金弯刀 2.75 格，再应用高差及本设置，不按耐久分类统一截成 2.25 格。该设置不改变伤害。
- 禁用附魔阻止常规附魔台、铁砧、战利品、交易等新获取路径和常规效果；上限约束已有物品的有效等级。保存的附魔数据保留，重新启用后可恢复效果。已装备附魔属性在服务端下一 tick 刷新。

第三方模组若绕开原版/NeoForge 附魔 API、自行读取原始存储执行私有效果，仍可能需要专门适配。

## 配置示例

```toml
[overworld_ores]
copper = 1.0
deepslate_copper = 1.0

[underworld_ores]
copper = 1.0
deepslate_copper = 0.5

[overworld_generation.copper]
candidates = 40.0
chance_percent = 10.0

[underworld_generation.copper]
candidates = 320.0
chance_percent = 10.0

[underworld_generation.mithril]
candidates = 32.0
chance_percent = 5.0

[monsters]
growth_multiplier = 1.0
health_growth_multiplier = 1.0
damage_growth_multiplier = 1.0
health_base = 0.0
damage_base = 0.0
skeleton_reference = 20.0
health_daily_percent = 0.5
damage_daily_percent = 0.25
health_formula = "base + reference * rate * days"
damage_formula = "base + reference * rate * days"
health_blood_moon_formula = "base + reference * rate * days"
damage_blood_moon_formula = "base + reference * rate * days"

[combat]
weapon_reach_multiplier = 1.0
weapon_reach_reduction = 0.25
height_reach_penalty = true

[structures]
underworld_trials = false
overworld_trials = true

[enchantments]
disabled = ["minecraft:mending"]
max_levels = ["minecraft:sharpness=7", "mite:vampiric=3"]
```

未出现的字段保留默认值；附魔 ID 以当前世界实际注册 ID 为准。示例中的矿物字段仅用于说明格式，并不列出整个生成器。

两项血月公式默认空值时，沿用对应周期内公式，兼容旧版自定义设置；界面显示实际表达式，保存时明确写入两阶段公式。血月公式决定下一周期的 `base` 与 `reference`，周期内公式使用新基准计算当前属性；蓝月不执行血月结算。
