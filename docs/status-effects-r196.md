# R196 状态效果与生物活性

开发署名：NingMeng123。依据本地 R196 发布包和项目固定的 Minecraft 1.21.1 / NeoForge 21.1.259 源码。

本次规则作用于玩家、29 种 MITE 来源生物，以及 `R196VanillaMobRules` 映射的原版身份和来源拆分身份。现代独有实体保持原有效果算法；没有改写全局药水注册模板或药水物品组件。现代护甲、抗性、抗火的明确适配继续由现有伤害管线处理。

- 中毒按剩余时长每 `max(100 >> amplifier, 1)` 刻造成 1 点伤害，允许致死。来源为 `ni.java:85–86,126–140`、`of.java:659–665`。使用原生 `MobEffectInstance.tick` 的时长和隐藏效果生命周期、NeoForge 的毒伤类型与正常可取消伤害事件；无限时长沿用现代实例的实体 tick 时钟。Java 位移的放大器低五位语义也保留。
- 力量和虚弱分别使用每级 `+.4/−.4` 的 `ADD_MULTIPLIED_BASE`，级数为 `amplifier+1`。来源 `ni.java:18,31,228–229` 和继承的 `ox.g()`：先把武器等 operation0 加值并入基数，再处理 operation1。两种效果共享同一基数相加，不能把它们改为两个独立乘区。
- 来源非玩家保留 `ni` 的速度、缓慢两个乘区；普通缓慢每级 −20%，自由行动折扣缓慢乘区。玩家遵循 `ni.java:219` 跳过这两个原生属性修正，改用 `of.java:1741–1758`：速度与缓慢先相加，只有净负修正受自由行动抵消，最终倍率限制为 0–4。护甲速度附魔仍读取最高装备等级，单独相乘。移除效果、脱下装备、效果升级与实体重载均刷新修正，不残留原生 −15% 模板。
- 玩家蜘蛛网继续有现代物理摩擦，另施加来源独立的 −75% 移动能力项，并与速度、缓慢一起经过自由行动。该项也作用于未装备自由行动的普通玩家；不影响黏液块等其他阻滞向量。
- 来源非生物活性实体拒绝中毒、再生、凋零（`of.java:504–506`）。名单包括来源亡灵、末影人、岩浆怪、铁傀儡、雪傀儡，以及地狱犬、火元素、土元素、黏土魔像；分别见 `tg.java:392`、`tl.java:162`、`rv.java:41`、`sb.java:118` 和对应来源类的覆写。食尸鬼和隐形潜伏者按其真实生物活性处理，不能仅凭中文名称列为亡灵。蜘蛛原生毒免疫等更严格的原有规则继续生效。

实现入口为 `SourceStatusEffects`、`SourceStatusEffectInstanceMixin`、`SourceStatusEffectLivingMixin` 与已有附魔效果/装备刷新入口；服务端维护真实属性并通过原生属性同步发送给客户端。保存重载会从实际效果重新生成修正。由于原生 NBT 加载直接写入效果表，升级时会先通过正常 `removeEffect` 路径移除受管非生物活性实体已保存的中毒、再生和凋零，再刷新属性；其他效果以及现代独有实体的效果全部保留。显式运行期强制添加仍使用原版管理员入口。

验证入口：`SourceStatusEffectRulesTest` 的独立算术向量、`SourceStatusEffectGameTests` 的真实效果 tick、实际持剑属性、重载、移除、原生非生物与新增非生物身份矩阵，以及现代独有实体对照。原 `SourceEnchantmentCombatGameTests` 脱下自由行动后的期望改为来源普通缓慢 −20%。上述验证均已执行通过，构建与运行结果见[本轮统一验证](testing/r196-parity-implementation.md)；客户端画面与真实多人仍待手测。
