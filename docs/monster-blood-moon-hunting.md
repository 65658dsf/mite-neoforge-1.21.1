# 怪物只在血月当夜主动捕猎

开发者：NingMeng123。2026-10-23 按用户要求，怪物主动攻击动物、村民等非玩家生物，仅在主世界实际血月夜启用。使用 `LunarCalendar.State.bloodNight()`；普通白天、普通夜晚、血月日期的白天、蓝月及其他维度均不触发。

共同目标选择器覆盖使用原版最近目标任务的怪物，包括尸壳、溺尸、流浪者及灾厄村民。脑 AI 的主动目标变更使用 NeoForge 的 `BEHAVIOR_TARGET` 入口约束。本模组的僵尸／尸鬼／土元素村民或动物目标、蜘蛛捕鸡、吸血蝙蝠、地狱犬、胶质生物与蠹虫的非玩家猎物也使用同一门槛；原版僵尸主动袭击村民现在同样只在血月夜发生。

监守者咆哮后直接写攻击记忆、凋零侧头独立选取和发射、恼鬼复制召唤者目标，也接入同一限制。猪灵受伤后的真实求援单独记录来源，未受伤同伴可以正常反击；主动捕猎疣猪写入的怒气不会取得这一豁免。

血月结束时，在下一次实体 AI 与接触攻击前清除当前主动猎物、待恢复 UUID、对应重选队列和导航。主动捕猎来源会随实体持久数据保存，保存后跨越血月或重载不能继续原有捕猎。旧版只保存 UUID 的被动猎物，也不会在非血月夜重新恢复。

玩家索敌、玩家骑乘目标的原有处理以及受到攻击后的反击保持有效。动物自身的捕食与宠物护主不属于怪物主动捕猎。史莱姆和胶质生物的碰撞伤害入口也执行血月限制，避免没有目标任务的碰撞伤害绕过它。

## 验证

`MonsterHuntingGameTests` 检查实际血月与普通夜／血月白天／蓝月的边界、血月结束即时停止、旧 UUID 和新持久数据重载、原版怪物共同目标任务、来源反击与同类求援、蝙蝠和史莱姆实际伤害、蜘蛛的一次成功捕鸡抽签。原有视线、范围、UUID 和吸血机制夹具的有效捕猎步骤显式处于血月，操作完恢复世界时间；异步范围用例只在断言的同步片段切换时间。

相关回归类：`MonsterTargetMeleeGameTests`、`NativeArachnidGameTests`、`UndeadBatMobGameTests`、`ElementalCubeSilverfishGameTests`、`PiglinHuntingGameTests` 和 `WitherHuntingGameTests`。测试辅助类为 `BloodMoonHuntingTestClock`，同步恢复世界时间、最高日期和临时停用的日期成长设置，避免血月夹具影响其他回归。本文件描述验证范围，实际执行结果以本轮统一构建与定向 GameTest 日志为准。
