# R196 作物生长与病害

开发署名：NingMeng123。依据本地 R196 实际启用的类、继承关系及物品调用链；独立来源索引见 [crop-source-evidence.md](crop-source-evidence.md) 和 [crop-source.json](../spec/crop-source.json)。

## 普通食用作物

小麦、胡萝卜、马铃薯、洋葱采用 R196 年龄 0～7 的规则。甜菜根接入同一套生长、病害与收获原因校验，同时保留新版年龄 0～3。2026-10-31 按用户要求移除生长温度限制和温度减速。火把花、瓶子草及第三方作物不批量套用旧作物成长公式。

- 需要耕地。能直接见天，或所在位置未扣天光的原始亮度至少 8，才是合法作物位置。生长则要求作物上方的实际亮度恰为 15；夜晚、阴雨和遮蔽会影响它。
- 中心耕地湿度为零时，生长率直接为零。其余九宫格计算以 1 起步，耕地贡献干燥 1、湿润或施肥 3；非中心贡献除以 4。
- 同种活作物出现在斜对角，或者东西和南北两个轴向均有同种活作物时，生长率除以 2；只除一次。病而未死的作物仍算活株，死株不算。
- 中心施肥再乘 1.5，再乘全局 0.25；各生物群系均使用原最适温度下的生长倍率，不再因寒冷或炎热减速、停长。
- 四向没有同类活株乘 0.5；只有一个邻居且邻居没有另一株同类时乘 0.75；其他情况乘 1。
- 生长使用按约一小时成熟校准的随机检定，一次增长一个阶段；水分、施肥与布局继续影响生长率。每次实际增长后抽一次 `nextInt(256)`，零时失去肥力；普通土也保留这次来源抽样。

这些是随机刻规则，不是每秒增长概率。NeoForge 生长事件可允许或阻止正常增长；数据包和其他模组明确提供的土壤支持、灌溉票据仍受尊重。

## 旱死、病害与治疗

检查顺序为合法性、干旱、已有病害、血月暴露、日常感染、生长。

- 生长率为零且附近没有认可的灌溉源时，每次作物随机更新有 5% 概率枯死。未成熟株保留当前年龄并留下死株；成熟株按干旱收获原因掉落后消失。温度不再使生长率归零。
- 日常感染基础概率小麦/胡萝卜/洋葱为 0.0005，马铃薯为 0.001；乘温度最优范围 1.0～1.2 的线性修正、潮湿生物群系的 1.5 倍，以及 `1 - 实际光照 / 16`。潮湿使用生物群系降水量严格大于 0.85 的判断。完整日光仍有很低的感染概率。
- 活病株每次更新先有 1/64 概率死亡；成熟株病死时年龄减一。未死亡则一半概率尝试三轴各 ±1 格的传播，可以跨普通作物种类感染，包括洋葱。
- 骨粉直接对准活病株只清除病态，不增加年龄；健康株不能催熟，死株不能救活。骨粉点击耕地、瓜茎和蓝莓不会启用源码里存在但默认调用链不可达的催熟分支。
- 病、死状态保存在原生方块状态中，由正常区块同步及保存处理。原资源包病死材质用于视觉区分；健康株保留新版材质。

血月继续复用已交付的感染入口，并保留原作单人与独立服务器的实际启用差异，不再叠加第二次血月感染判定。

## 收获与意外破坏

| 状态或原因 | 来源掉落 |
|---|---|
| 健康年龄零，玩家破坏 | 一份种子或种植用根菜 |
| 健康中间阶段 | 无；马铃薯例外为一个毒马铃薯 |
| 成熟小麦，玩家正常收获 | 一个小麦，不附带新版种子产量 |
| 成熟胡萝卜、马铃薯、洋葱 | 75% 两份，25% 三份 |
| 活病株 | 无；活病马铃薯例外为一个毒马铃薯 |
| 死株、作物爆炸 | 无 |
| 支撑失效、流水冲毁、非牛践踏 | 普通种子/食物不回收；活中期或活病马铃薯保留毒薯例外 |
| 牛践踏 | 不执行作物掉落 |
| 真实积雪覆盖 | 普通年龄零可返种，成熟保留产物；年龄零瓜茎按源码在死亡检查前返种 |
| 西瓜普通破坏 | 固定四片，时运不增加，精准采集返回整块 |
| 西瓜、南瓜爆炸 | 一个对应种子，包括无衰减 TNT 和有衰减爆炸 |

掉落表在数据生成中维护。普通作物的原因过滤与农业附魔走统一入口，后续 `BlockDropsEvent` 的取消和清空不会被病害事件重新添加物品。瓜类爆炸选择独立战利品表，仍经过原生全局战利品修改器。
