证据：`EnumQuality:6-13`、`CraftingResult:36-46`、`yc:595-598`。品质直接改变最大耐久，未发现品质直接乘攻击力、工具采集效率、材料附魔能力或基础护甲值的调用；磨损后保护变化通过既有耐久机制体现。最大耐久为 `max(round(base * durabilityMultiplier), 1)`。

材料上限来自 `EnumEquipmentMaterial:5-21`：皮革/木/燧石/黑曜石/石英为优良；锈铁为劣质；铜/银/绿宝石为优秀；金/钻石为精良；铁/古代金属为大师；秘银/艾德曼为传奇；地狱岩/玻璃为普通。多材料物品先取所有材料的最低上限，若它低于普通就采用这个最低值，否则取最高上限（`yc:1237-1252`）。这不表示 R196 存在这些材料的全部现代装备品种。

默认品质为 `min(materialMaximum, average)`（`yc:1255-1257`）。设置到物品堆时，`ye:928-955` 将超过材料上限的请求降到上限，并在没有存储品质时补默认值。锈铁因此默认劣质；不能让玩家普通品质下限把它变成普通锈铁。

## 可选范围、费用与时间

令等级为 `L`、总经验点为 `XP`、配方未调整难度为 `D`、笨拙诅咒是否生效为 `C`。

1. 原始最低品质 `minQ = clamp(2 + (L - (C ? 20 : 0)) / 10, 0, 2)`。`/10` 是 Java 整除，向零截断，不是向下取整。技能开启且缺适用技能时，再将下限压到至多劣质（`uf:2184-2196`）。实际输出还要受材料上限限制。
2. `XP <= 0` 或技能开启但缺技能时，最高品质就是最低品质。其他情况，从材料最高品质降序寻找高于普通的第一档，其候选费用不超过当前总经验；找不到则退回最低品质（`uf:2199-2216`）。不是按等级固定解锁品质，也不是按背包经验球数量判断。
3. 调整难度 `Dq = D * 2^max(q - 2, 0)`；原始代码逐次用 float 乘 `2F`。粗劣/劣质不会更快、更便宜。`quality_override` 优先于玩家选择（`CraftingResult:29-46`）。
4. 候选经验费 `round(Dq / 5F)`，笨拙在 round 后将整数费用乘 2（`uf:2219-2225`）。只有品质高于普通且未获 XP 豁免时实际扣费；普通以下、无品质物品、豁免配方都扣 0（`wd:279-287`）。费用是经验点，不是整级。
5. `bex:450-503` 先从 `Dq` 算基础 tick，再施加诅咒、等级和工作台修正；不得对最终 tick 简单乘品质倍数。基础值：`Dq<25` 用 25；`Dq>100` 用 `round(pow(Dq-100F, (double)0.8F))+100`；其余 `round(Dq)`。最后 `int(max(baseTick*(C?2:1)/((1F+L*.02F)+benchBonus),25F))`。工作台加速见 016 规格。

等级和总经验应来自本项目已复刻的 R196 经验状态。正确正等级累计曲线是 `5L²+15L`；CFR 对 `uf.<clinit>` 的后置递增反编译有误，不能使用其表面的 `5L²+25L`。详见 [经验适配](experience-adaptation.md) 和 `ExperienceRules` 中的字节码证据。品质纯规则 API 接收真实 `level/totalXp`，不另造经验曲线。

## 点击、结果更新与完成

`wd:174-210` 中左键启动，右键向上切换一档，超过当前最高则回到当前最低。只有一档或存在固定 `quality_override` 时右键不改变品质。初次出现新结果时选择最低可用品质（`wd:312-331`）；选择改变时清进度（`wd:250-259`），不是保留已完成百分比。经验变化使当前选择不再可用时，`MITEContainerCrafting:67-69` 重新校验、收缩到合法范围并停止旧制造。预览物品、预计耗时、费用必须同步更新。

`MITEContainerCrafting:85-97` 完成一次后取出结果、发送完成信号，再将进度归零；**只要实际品质经验费 >0，就停止连续制作**。本项目保留已验收的普通左键单次、Shift 左键连续操作；付费品质仍遵循 R196 完成一次后停止，以免意外连扣经验。免经验维修不触发这个付费停止条件。

原作 `ka:861-868` 收客户端完成消息并依照包内整数扣经验。现代适配必须改为服务器计算并扣费，不能复刻信任客户端费用的实现缺陷。扣除应与一次成功产出绑定；切换品质、取消、关闭界面、材料不足或权限变化均不得提前扣费。`ye:720-750` 的原版结果提示包含品质切换说明及扣费后的等级变化；现代界面可直接显示经验点和当前总经验，使收费更明确。

## 用户指定的品质预览适配（2026-10-13）

用户要求“即使经验不足也能切换到更高的品质，但是无法制作”。当前实现因此把**可选预览范围**与**实际制造资格**分开：预览从原最低品质到材料最高档，不因经验不足隐藏高档；制造资格继续按上面的 R196 经验公式检查。原始 `range/maximumQuality` 仍用于资格与维修，新增 `selectionRange` 仅用于选择。

铜镐在 0/499/500/999/1000 点经验下都可预览普通、优良、优秀；优良仍需 500 点，优秀仍需 1000 点。经验不足时预览和费用标红，点击结果不能开启制造，也不扣原料或经验。运行中失去资格会停止并清零进度，保留已选预览；补足经验后须重新点击开始，不自动继续。材料上限和维修/染色的固定品质不变。上文关于原 R196 缩小可选范围、自动回退预览的描述保留为原作证据，不再作为当前界面行为。

## 修理和改变外观（来源规则）

- **双装备合并修理**：两个同 ID、各 1 件、都损坏、未附魔、同品质；有染色则必须双方染色一致。按完整最低制造难度计算品质能力门槛；不足设失败状态 1，禁止取出。成功输出固定原品质、免经验，计时基础难度为完整最低制造难度的一半，然后仍应用品质难度倍率。证据 `aaf:288-321`。
- **线/筋修补皮革**：同样按装备完整最低制造难度验品质资格，超过能力无结果；固定原品质、免经验、基础难度 `50 * 实际消耗数量`。证据 `aaf:323-353`。具体耗材数量、耐久修复算法是维修系统内容，不能只因品质公式存在而宣称已接入该配方。
- **皮革染色**：`zw:45-60,100-101` 复制护甲、固定输入品质、免经验，基础难度 100。颜色变化不能重设品质、修耐久或重新收制造品质费。原作通用制造规则仍会拒绝损坏的非维修原料；染色不是 repair。
- **铁砧维修**：`va:85-96` 也要求输入品质不超过按完整制造难度计算的能力；具体铁砧成本、材料和附魔合并规则见制造系统规格。不得用普通工作台免经验规则代替铁砧自身费用。

## 存储、掉落与边界

`ye:122-123/169/366/451` 保存、读取、复制和比较品质；`ey:182/199` 网络同步品质；熔炉、漏斗等转移链 `ank:214-215`、`any:146-147`、`aok:169-170`、`aot:130-131`、`vm:220-221` 保留品质。现代 Data Component 应负责相同的存储/传输语义，转移、重连和读档不得变回普通。

品质还参与生物装备生成/掉落：`ye:855-883` 为未附魔且普通以上的木/皮装备降一档后施加随机损伤；`og:838-839` 过滤部分自带低品质重损手持装备，并对远古亡魂的自带高品质装备额外处理。这些属于生物装备来源和掉落调用链，具体接入状态应在交付中独立说明，不能因为玩家制造品质完成就默认怪物流程全量复刻。

不存在原版自动合成器对应行为。现代自动化品质策略、1.21.1 新装备的材料映射、未登记最低制造难度时的处理属于现代适配，必须明确记录，不可用推测数值冒充 R196 来源。

本批纯规则实现为 `EquipmentQualityRules`，复用 016 的 `Quality` 枚举；其 15 个单元测试采用上表及字节码顺序对应的独立字面量。技能/诅咒参数用于精确表达源规则，不表示这两套玩法已上线。运行接入与游戏验证由本批服务端、客户端及测试实现负责。
