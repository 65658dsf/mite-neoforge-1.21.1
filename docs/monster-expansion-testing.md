# 怪物毁田、血月进度与天气测试

开发署名：NingMeng123。本批包含用户确认的现代扩展，原始 R196 行为与新增规则在各系统规格中分开记录。

## 测试前

由用户重启测试客户端。使用新的、开启作弊的测试存档，先测早期行为，再跳到后期；最高到达日期会持久保存，调回时间不会回退怪物或装备成长。不要用长期游玩的存档测试高日期。

## 怪物主动破坏耕地

1. 执行 `/gamemode creative`、`/time set 18000`、`/gamerule mobGriefing true`。创造模式便于让怪物没有玩家攻击目标。
2. 在平坦、能正常走到的位置准备一小片耕地，混合空耕地和种有小麦的耕地；在其 4～6 格外生成普通僵尸。不要给它 `NoAI`。
3. 等待搜索与行走。没有活体攻击目标的地面怪物会寻找半径 8 格、上下 2 格范围内可达的耕地，到达后工作 40 tick（正常速度约 2 秒）破坏一格；搜索间隔约 10～15 秒。湿润和施肥的耕地也能被主动毁坏。
4. 耕地应变为泥土，上方作物按踩踏规则处理，不凭空掉落泥土或成熟小麦。把农田围到无法到达，怪物不应隔墙破坏。
5. 切生存让怪物获得攻击目标，它应优先追击。执行 `/gamerule mobGriefing false` 后不应继续毁田；动物与飞行怪物不使用此地面任务。

详细边界见 [毁田说明](monster-farmland.md)。

## 第三个血月后的永久解锁

在独立测试存档中，先用 `/time set 2303999` 检查第 96 天末刻，再用 `/time set 2304000` 到第 97 天。之后用 `/time set 13000` 回到普通夜晚，主世界依然可以自然刷出已解锁的地底生物；保存退出重进后保持。

在离玩家至少 24 格、远离世界出生点的合格黑暗区域观察。洞穴蜘蛛、远古骷髅及远古骷髅领主进入原主世界候选，原有僵尸与普通骷髅继续存在；远古骷髅和吸血蝙蝠各保留 1/6 的守卫／巨型替代。寒冷、沙漠、石质顶底等生物栖息条件继续生效，稀有生物不保证短时间全部出现。普通刷怪笼的领主排除规则继续保留。

详细种类和权重见 [入侵说明](blood-moon-invasion.md)。

## 血月白昼降雨、夜间干雷与白昼红天

执行 `/gamerule doDaylightCycle false`、`/gamerule doWeatherCycle false`、`/time set 750000`，等待约 5 秒让原版天气渐变完成。第 32 天白昼应为雷暴，天空、云与空气雾偏血红；`/weather clear` 会在下一次正常天气更新后恢复血月雷暴。

再用 `/time set 762000`，等待约 5 秒，检查夜间雨幕、雨声消退，但仍能出现真实闪电和雷声；露天炼药锅此时不再接雨。夜间沿用月相日历的 13000～23000（包含端点），黎明 23001 起恢复降雨。

边界命令为 `/time set 756999`（白昼降雨）、`/time set 757000`（开始停雨）、`/time set 767000`（夜间干雷）、`/time set 767001`（黎明恢复降雨）。`/time set 767999` 检查当天最后一刻仍为白昼降雨段。`/time set 768000` 离开血月后，应恢复原来的冻结天气；分别在血月白昼和夜间保存重进，随后跳出血月，检查恢复没有丢失。第 128 天是蓝月，不套用血月天气覆盖和白昼红天。

入夜雨量消退后，月盘与光晕保留血月颜色，恢复晴天的可见度。光影可能替换原版天空，需用户检查实际画面。具体规则见 [天气说明](lunar-weather-adaptation.md)。

## 血月装备成长

使用 `/summon minecraft:zombie` 或原版生物蛋生成新怪物。带自定义 NBT 的召唤指令可能跳过原生初始化，不适合统计默认生成概率。旧怪物不会因日期变更自动换甲。

- `/time set 1518000`：第 64 天，第二次血月白昼，启用皮革主档。成功穿甲的怪物可抽到更高材质，极少数可达艾德曼；正常也会有不穿甲的结果。
- `/time set 6000`：调回普通日，已经解锁的材质档位和分布保留，穿甲与空手补装备概率为同日期血月的一半。
- `/time set 2286000`：第 96 天第三次血月，主档为锁链；第 320 天第八次血月进入艾德曼主档，第 352 天第九次起进入振金主档。血月四个护甲部位独立抽取是否穿戴和材质，可以缺件、混搭，低阶概率保留。
- 普通日第 64 天起与同一最高日期血月共享材质阶段，穿甲率 40%～49%、空手补装备率 35%～48.5%；血月每部位穿戴率为 80%～98%、空手补装备率 70%～97%。普通日一次穿甲成功后补同材质空槽；工具四类等权，混搭时优先参考本次生成的第一件护甲，皮革与锁链使用锈铁工具。当前精确表见 [怪物装备生成](blood-moon-equipment.md)。
- 检查来源自带主手、显式装备、普通骷髅弓与溺尸三叉戟保持。未穿甲怪物也可以持械。旧版本已生成怪物不补发工具，新结果保存重进或跨维度不重抽。
- 保存前后检查同一怪物，已穿甲和未穿甲的结果都不重抽。已有明确指定的护甲不覆盖；固定套装的特殊怪不被此规则降级，蜘蛛和苦力怕不增加隐形护甲。

普通日历进度、每次血月档位、逐部位穿戴率、空手补工具率与各材质实际概率见 [装备概率表](blood-moon-equipment.md)。少量刷怪不能可靠估计稀有概率，精确分布由数值和生成路径测试验证。

测试加速可用 `/tick rate 100`，结束恢复 `/tick rate 20`。同时恢复原来的游戏模式、时间和游戏规则。
