## 来源与身份

[mobs-source-031.json](../spec/mobs-source-031.json) 覆盖实际主注册的 85 个身份：60 个 Living、58 个可构造 Living、2 个抽象注册、25 个非 Living。其中新增生物是连续 ID 512–540 的 29 种，没有把未注册 AI、父类、粒子类或废弃条目当成新生物注册。受保护 null-world oracle 查询 78 个明确变体，构造失败 0；667 个物品腐蚀 getter 也均来自实际原类。

公开规格保存 3985 个来源方法索引的签名、行号和正文校验值，不发布完整反编译正文。完整正文留在忽略的 `.reference`，提取工具不会把它写入公开规格或运行资源。注册、默认属性、实际调用条件、生成完成后的装备/变体、最终掉落和死亡经验分别记录，不能把其中一种查询当成其他系统的结论。

## 本批实现系统

- 新增身份、源基本属性、尺寸、经验、装备、少量材料掉落及相应保存状态；装备品质与耐久继续使用此前复刻的统一系统。默认怨魂全套锈铁，远古骷髅全套远古锁链，普通/远古骷髅领主分别使用对应板甲。普通原版骷髅新增来源 25% 木棒近战变体及持久化子型。
- 鬼魂类的伤害接受条件、经验/视觉影响与光源行为；蜘蛛的库存蛛网、毒/麻痹、燃烧蛛网与相位躲避；狼与地狱犬的不同生物学和驯服规则；苦力怕的来源属性与爆炸相关参数。
- 原生普通蜘蛛与洞穴蜘蛛也共用来源蛛形父规则：共享保存的投网/死亡库存、500/200 刻投网、严格 2–6 格边界和每刻 1/10 跃击、鸡猎物、仅普通蜘蛛的户外明亮中立。洞穴蜘蛛实际损血后固定施毒 480 刻。普通蜘蛛保留来源 1% 持弓骷髅骑乘，地下世界对应远古骷髅；只有普通蜘蛛执行来源困难模式群组增强，新四种来源蜘蛛与洞穴蜘蛛不会错误继承这个回调。
- 元素体的材料/热量状态、黏土硬化、工具与魔法防护；四种胶体的尺寸、攻防、接触、腐蚀、进食与死亡分裂；蠹虫的来源身份与受伤增援；蝙蝠的猎物、飞行/吊挂、吸血、进食暂停、暗翼伤害接受条件和视觉效果。
- 来源生成池、生成资格、月相/时间/深度影响、维度间高度适配；保留 1.21.1 地形与洞穴生成器，生物生成接入它，不使用旧版地形生成器。
- 从原材质包提取 44 张去重生物 PNG。模型使用正确原布局：人形/蜘蛛/骷髅/胶体为 64×32，怨魂和旧蝙蝠为 64×64。旧蝙蝠模型独立重建；隐形潜行者身体透明度 0.05，火元素不绘制不透明身体、保持源火焰显示。只有来源蜘蛛及元素体具有这里引用的发光层，蝙蝠没有新增发光层。

这份分组描述的依据是对应生产文件和来源规则；具体实现是否通过验收要继续看构建和测试记录，不用“已注册”替代每个机制的验证。

## 明确的现代适配

1. **世界形状。** 主世界保持现代地形、-64 起始高度与深层洞穴。旧逻辑使用的深度、地下世界缓冲区及移位分别映射；飞行、吊挂、寻路、光照与生成不能简单对所有 Y 判断统一加一个常数。
2. **父类与渲染。** 使用现代实体生命周期、同步、声音和动画接口。重建旧 UV 或明确复用经对照相同的现代网格；新生物纹理独立位于 `assets/mite/textures/entity`。原版对应生物仍可使用现代材质。不同材料弓继续具有骷髅持弓姿势。
3. **拆分身份。** 旧的骷髅子型、僵尸村民、豹猫驯服型与马种类对照现代拆分实体。自然生成的下界来源骷髅在正常来源资格检查后可转为现代凋零骷髅；直接使用原版骷髅蛋/命令的旧 type1 状态仍保存、同步并具有正确尺寸和外观。
4. **制造与持有物。** 生成装备采用来源附魔概率和磨损公式，附魔候选使用现代注册表。现代消失诅咒继续生效；副手/身体槽装备沿用明确的装备返还规则，不丢弃现代槽位内容。
5. **碰撞与寻路。** 通过现代碰撞、视线和寻路接口表达来源资格。现代方块形状、实体宽高和服务端事件影响实际通路，不能承诺与 1.6.4 每一步路径或同种子每次随机位置一致。
6. **视觉状态。** 暗影/暗翼的服务端影响同步为独立持久化视觉强度；客户端按来源每刻 0.01 衰减，显示黑色覆盖最多 0.9，并置于 HUD 之前。显示上限不等于机制资源上限。
7. **现代事件。** 使用 NeoForge 原生生成与掉落事件，用户或其他模组可正常取消相应事件。来源替代生成完成逻辑仍保留 NeoForge 的生成原因元数据。
8. **骑乘循环终止。** 普通蜘蛛骑手完整生成并拒绝非持弓子型；原作命令召到下界时每次固定 type1，旧循环不能终止。本批最大 64 次后给最后一个已获准生成的普通骷髅来源 type0 弓装备。地下世界 64 次全部非弓时跳过骑乘。取消生成不会被重抽绕过；这项命令路径安全适配明确区别于来源正常可达循环。

## 不包含或需要继续验证的内容

- 本批不宣称 Minecraft 1.21.1 的所有新增生物 AI、结构生成、袭击、交易、试炼刷怪笼和战利品进度都已完成 MITE 平衡。守望者、旋风人、猪灵、现代袭击等没有 R196 对应类的行为应单独评估，不能凭相似外观替代成某个旧生物。
- 生物注册、生成和基础属性的覆盖不等于逐条完成全部原版生物 AI。来源未改动行为、现代父类保留行为和本批显式改动应分别核对；完整 Boss、村民经济和新增结构成长门槛仍属于独立系统。
- 现代自然生成仍受实际生物群系、玩家附近区块、难度、光照和来源池权重影响。一次没看到某种生物不能证明它未注册；命令/蛋能召出也不能证明其自然生成条件正确。
- 来源中没有启用的旧模式与本批未提供的现代模式不能算成默认规则。没有对应原物品/宿主方块的旧 subtype 要保留身份差异，不将相近的现代方块说成完全相同的来源内容。
- 其他模组的实体、维度、召唤流程、装备事件和自定义伤害类型需要真实组合测试。JEI、Sodium、Jade 等已有测试扩展并不是本模组的前置；第三方实体不能按名字套用某个来源身份。
- 本批没有迁移 1.6.4 世界/旧实体 NBT，也不保证同种子同出生位置。只在现代模组自己的版本化保存数据上验证重连、重启及跨维度保留。
- 自动 GameTest 可覆盖固定参数、攻击/掉落/保存路径，但不能代替用户确认 UV、透明度、发光层、火焰、视觉衰减与多人观察同一个实体的显示一致性。

来源事实与提取方式详见 [证据记录](mobs-031-evidence.md)；具体手测见 [031 手测清单](testing/031-mob-spawning.md)。

## 原生生物材料和装备掉落

29 种来源原版生物的死亡材料改为独立来源算法，并衔接有明确旧 subtype 的现代拆分身份。普通僵尸稀有池是金属粒，僵尸村民是种子/作物；铁傀儡环境死亡不给铁、近期玩家击杀给铁粒。牛、羊、鸡的肉/皮/毛与着火分支按源码处理；剩余羽毛和蛛网库存保留。骷髅来源子型的箭/煤/骨/头骨只生成一次，其他装备返还保留实际品质、磨损与来源概率。

死亡物仍进入 NeoForge 原生捕捉和取消事件，已实现的箭附件回收不重复生成。现代鞍、马货物、身体/副手装备和带电苦力怕头颅保留；没有来源的新生物不套用任意旧掉落池。女巫药水效果的六个 source metadata 已通过独立只读 JVM 查询确认，时长也使用来源值。

掉肉读取源 `min(food,water,freedom)>=.25`；本批仅有初值、保存与供农业模块调用的接口，尚未完成这些资源的完整养殖代谢。屠宰附魔尚未注册时其增量为 0，后续附魔系统接入；不将当前掉落覆盖表当成完整农业验收。详见 [原生掉落规格](../spec/native-mob-loot-source-031.json) 与 [行为证据](mob-behavior-031-evidence.md)。
