# 016 工作台与制造设备

开发者：NingMeng123。版本基准为本地 MITE R196；本批使用独立方块 ID，保留 1.21.1 地形与现代容器。

## 来源与等级

`arv.java:10,64–77` 的工具材料共有九类：燧石、铜、银、金、铁、远古金属、秘银、艾德曼、黑曜石。旧燧石/黑曜石各有四种木材外观，本批各合并为一个方块；原木/木板配方允许现代对应标签。

`awy.java:168–191` 以材料的 durability 比较工作台加工能力，不使用矿物采集等级。服务端现在也进行该校验。

| 工作台 | 加工能力 | 制作该台需要的能力 |
| --- | ---: | ---: |
| 燧石 | 1 | 无 |
| 黑曜石 | 2 | 无 |
| 铜 / 银 / 金 | 4 | 1 |
| 铁 | 8 | 4 |
| 远古金属 | 16 | 8 |
| 秘银 | 64 | 16 |
| 艾德曼 | 256 | 64 |

升级台需求来自 `RecipeHelper.java:73–83`：查找 durability 严格较低的最强材料，明确排除黑曜石。铜、银、金处于同一加工档，并非三个顺序阶段。普通金属工具和已接入耐久系统的金属护甲需要同种材料能力或更高能力；粒锭兑换不要求金属台。钻石/下界合金护甲的 16/32 为明确的现代材料能力映射，皮革不套用金属门槛。

## 配方与回收

`RecipesMITE.java:113–131`：

- 燧石/黑曜石台：上排“燧石或黑曜石块、线或筋”，下排“木棍、原木”。也可竖排同材料小刀、原木。
- 金属台：上排“对应锭、皮革”，下排“木棍、木板”。铜台及以上即使形状可放 2×2，也必须在满足加工能力的工作台制造。
- 燧石/黑曜石台可拆出相应小刀；`wd.java:130–131` 另退原木。本批用专用配方保留该返回物，因木种外观合并统一退橡木原木。

计时、饥饿暂停和受伤回退见 [制造计时](timed-crafting-016.md)。本批工具和材料的实际配方由服务端统一验证，包含普通点击、Shift、配方书、数字键和自动合成器路径。

## 禁用原版工作台与现代自动化

用户明确要求禁用原版工作台，因此旧 `minecraft:crafting_table` 不再代表燧石台：关闭其配方、创造栏显示、交互和正常放置。保留注册 ID 以读取已有存档；破坏已放置的旧台会掉落一个新 `mite:flint_crafting_table`。不批量改写已有世界。

原版合成器的制作配方使用新燧石台替代旧工作台，其他材料保持现代配方。自动合成器的无设备门槛配方可使用自身基础加工能力；有门槛的配方必须邻接满足能力要求的工作台。邻接指六个正交相邻方块，不搜索玩家背包、远处设备或其他维度。每批计时期间持续检查设备和输入，完成前不消耗材料；中途取消或重启重新计时。

## 实现边界

本批复刻九种材料等级及其基础制造/回收规则，不声称重现旧 GUI、四种旧木材外观或完整铁砧体系。使用现代 3×3 容器和配方书；旧客户端信任的制造完成信号不迁移，实际完成由服务端时钟决定。
