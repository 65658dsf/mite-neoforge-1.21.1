# 怪物自带装备死亡掉率

开发者：NingMeng123。2026-10-18 按用户要求，怪物自带的秘银及以上装备（秘银、艾德曼、振金）固定不掉落，包含武器、工具、防具、链甲、弓、盾及对应的 Simply Swords 兼容武器，不论是否附魔或带有副词条。拾取装备的掉率保持原有规则。

来源怪物和现代原生怪物均经过同一材质门槛，秘银及以上自带装备直接拒绝，不进行三分之一或附魔减半的随机抽签；抢夺不能突破该限制。按真实装备定义识别材质，改名、损耗、品质与附魔不会改变结果，也不会误禁秘银锭等材料。

低于秘银的自然装备先执行原来的掉落条件，再独立按三分之一概率保留；带有普通附魔时再按二分之一保留，总计六分之一。这样也覆盖来源主手武器在近期玩家击杀时直接掉落的分支，并让抢夺、品质及大摔落修正后的整体概率一起降低。原本必掉的低阶自带武器变为约 33.33%，附魔后约 16.67%；没有其他修正的 8.5% 基础掉率分别变为约 2.83% 和 1.42%。各装备槽分别判定，已有附魔、品质和磨损继续保留。独立装备副词条不算普通附魔。

掉落率大于 1 的原生保证掉落标记（包括实际拾取的装备）无论材质、是否附魔均完整绕过新增判定；通过抢夺临时提高到 100% 的自然装备仍需经过材质门槛和新增判定。消失诅咒、近期玩家击杀条件、死亡掉落事件取消等既有条件仍有效。新增规则只适用于 `MobCategory.MONSTER`，非怪物分类实体沿用原规则。规则即时适用于旧怪物当前穿戴的自带装备，无需重新生成怪物，也不改变其现有装备。

缴械与拾取换装同样不能抛出自带秘银及以上装备，避免绕过禁掉规则。这两条路径只应用固定材质门槛，不叠加死亡的三分之一或附魔减半概率；原有缴械和拾取换装效果继续生效，拾取／保证掉落的旧装备照原规则抛出。

普通骷髅和长亡骷髅的双手武器原本已随切换交换各自掉落率。长亡守卫的私有备用武器现也独立保存并交换该标记，防止换武器后把自带武器误当成拾取物，或降低拾取武器的掉率。旧档缺少备用掉率标签时，优先保留主手已有的必掉保障；其余按自然默认值恢复，新存档分别保存两把武器的掉率。

低于秘银的怪物自带主手若品质低于普通且磨损超过 70%，附魔与未附魔都先接受原有的 75% 磨损阻断，再分别应用六分之一或三分之一。这样同品质、同磨损的附魔装备不会因旧附魔豁免而更容易掉落。拾取装备和非怪物分类继续保留原规则。

实现入口：`MobEquipmentDrops.keep`、`R196MobEquipment.dropEquipment`、`MobEquipmentDropRateMixin`、`QualityMobEquipmentMixin`。出生装备概率与日期附魔独立处理，见 [装备生成](blood-moon-equipment.md) 和 [日期附魔](mob-enchantment-progression.md)。秘银及以上禁掉的验证见 [高阶装备禁掉验证](testing/monster-high-tier-drops.md)；此前附魔减半验证见 [装备平衡验证](testing/monster-equipment-balance.md)。以下为此前三分之一版本的历史验证。
