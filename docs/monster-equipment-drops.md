# 怪物自带装备死亡掉率

开发者：NingMeng123。2026-10-18 按用户要求，将怪物自带装备的死亡掉率降为此前的三分之一，拾取装备的掉率保持原有规则。

来源怪物和现代原生怪物均先执行原来的掉落条件，再独立按三分之一概率保留自然装备。这样也覆盖来源主手武器在近期玩家击杀时直接掉落的分支，并让抢夺、品质及大摔落修正后的整体概率一起降低。原本必掉的自带武器变为约 33.33%；没有其他修正的 8.5% 基础掉率变为约 2.83%。各装备槽分别判定，装备数量、已有品质和磨损仍沿各自原有流程处理。

掉落率大于 1 的原生保证掉落标记（包括实际拾取的装备）完整绕过新增判定；通过抢夺临时提高到 100% 的自然装备仍需经过三分之一判定。消失诅咒、近期玩家击杀条件、死亡掉落事件取消等既有条件仍有效。新增规则只适用于 `MobCategory.MONSTER`，非怪物分类实体沿用原规则；换装时抛出的旧装备与缴械不属于本次死亡掉率调整。

普通骷髅和长亡骷髅的双手武器原本已随切换交换各自掉落率。长亡守卫的私有备用武器现也独立保存并交换该标记，防止换武器后把自带武器误当成拾取物，或降低拾取武器的掉率。旧档缺少备用掉率标签时，优先保留主手已有的必掉保障；其余按自然默认值恢复，新存档分别保存两把武器的掉率。

实现入口：`MobEquipmentDrops.keep`、`R196MobEquipment.dropEquipment`、`MobEquipmentDropRateMixin`。出生装备概率、材质分布与装备词条成长不受此规则调整。
