# 怪物装备日期附魔成长

开发者：NingMeng123。2026-10-18 用户指定的现代平衡扩展。

新生成怪物使用主世界记录的最高到达天数；下界、地底和其他维度共享该日期，回调时间不会降低成长。只在出生装备生成时处理，旧怪物、存档加载、跨维度和重复加入世界均不重抽。

| 最高日期 | 日期附魔概率 | 日期附魔强度 |
| --- | ---: | ---: |
| 1 | 0% | 5 |
| 65 | 16% | 9 |
| 129 | 32% | 13 |
| 257 | 64% | 21 |
| 301 | 75% | 23 |
| 401 及以后 | 75% | 30 |

日期概率为 `clamp((highestDay - 1) / 400, 0, 0.75)`；日期强度为 `clamp(5 + floor((highestDay - 1) / 16), 5, 30)`。强度传入原生附魔算法，最终附魔种类和等级仍受装备附魔能力、兼容性及随机结果影响。

来源装备生成器只进行一次附魔抽签：概率取原有局部紧张度概率与日期概率的较大值，强度也取原强度与日期强度的较大值。原先关闭来源附魔的装备在后期也可按日期概率获得附魔。当天没有日期加成时，原有随机调用顺序保留。

其他现代怪物保留原生附魔结果；出生流程结束后，只对仍未附魔且可附魔的自然装备补一次日期抽签。因此这类装备的总附魔概率包含原生成功结果和失败后的日期补充。来源生成器已经处理过的物品不会再抽第二次；已附魔物品不追加或重写附魔。原品质、名称和损耗保留。命令明确指定的装备、掉率大于 1 的拾取／保证掉落装备不参与出生补充。

怪物自带的秘银、艾德曼、振金装备不论附魔与否都固定不掉落。低于秘银的附魔自带装备死亡掉率额外减半：未附魔按原掉落结果保留三分之一，附魔保留六分之一；拾取装备保持原掉率。这里判断的是普通附魔，装备成长的独立副词条不触发这项减半。消失诅咒和原有死亡条件继续有效。

实现入口：`MobEnchantmentRules`、`MobEquipmentEnchantments`、`R196MobEquipment.generated`。验证结果与包文件见 [装备平衡验证](testing/monster-equipment-balance.md)。
