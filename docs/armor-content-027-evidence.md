# 027 装备、马铠及锁链材料

开发者：NingMeng123。

`item-catalog-015.md` 装备类别实际为61个叶条目：七种材料的板甲/链甲各四个部位，共56件；另有五种马铠。金板甲四件继续复用原版 ID，本批新增57个装备 ID。铁链甲四件原版装备也接入来源配方，但不伪造为目录新增条目。新增七种锁链材料，加上继续可放置的原版铁链，一共八种锁链材料，均对应材料分类中真实存在的叶项。

## 数值与取得

普通板甲基础耐久为`部件数×材料耐久×2`，链甲不乘2；品质倍率继续使用017的0.5/0.75/1/1.5/2/2.5/3/3.5。锈铁最大品质为劣质，默认耐久也按劣质品质0.75计算。例如铜胸甲普通64、秘银胸甲普通1024/传奇3584、艾德曼胸甲普通4096/传奇14336。马铠没有玩家品质、没有耐久，也不能附魔。来源金属装备和锁链不会被普通火焰烧毁，非艾德曼仍会被岩浆损伤；艾德曼装备/马铠/锁链对岩浆也免疫，分别沿用`akc.isHarmedByFire/isHarmedByLava`，不能用同时屏蔽火焰与岩浆的现代FIRE_RESISTANT属性冒充所有金属。

铜/银最高优秀，金最高精良，铁/远古金属最高大师级，秘银/艾德曼最高传奇；品质中文显示沿用现有017语言条目。材料附魔能力依次为铜30、银30、金50、锈铁0、铁30、远古40、秘银100、艾德曼40。

70个源形状配方包括56个装备配方、7个四粒环形锁链配方、7个锁链→四粒逆拆配方。锈铁链甲确有四件配方，锈铁板甲和锈铁锁链材料均没有来源制造配方；不为它们补猜测配方。锈板的维修最低难度使用源显式override，不以“无配方”判定为无法维修。手工、计时、品质、快捷操作和相邻工作台自动合成继续走既有系统，普通点击完成一件，Shift连续的旧规则不变。

默认生物五个生成装备阶段接入 `og.java:898–969` 的来源映射：皮革、锈铁链甲、铜链甲、锈铁板甲、铜板甲。仅改默认装备来源，保留当前现代生成概率和怪物算法；特殊R196生物另属后续生物批次。

五种马铠保护值为铜4、银4、远古5、秘银6、艾德曼7。它们使用真正的1.21.1 `AnimalArmorItem`、马的BODY槽、原生装备属性、存档及实体纹理。源码中五件马铠都没有制造配方；铜/银/远古有可确认的结构箱来源，秘银/艾德曼仅有注册，未发现默认生存取得调用链，保留创造/命令取得，绝不添加猜测配方或更高阶战利品。

## 结构箱适配

`spec/armor-loot-027.json` 保存每个旧权重池、总权重、数量及现代战利品表映射。对应旧主世界地牢、地底地牢、废弃矿井、铁匠铺、沙漠神殿、丛林神殿、下界堡垒。保持新版非装备箱子内容和现代钻石/下界合金装备，只替换来源已管理的人形甲、铁/金马铠与锁链材料；再使用旧池中的装备候选权重、完整分母及旧抽取次数。原池的非装备候选作为空结果，不能把仅装备候选重新归一化为必出装备。

装备磨损按 `ye.applyRandomItemStackDamageForChest`：正常0–6成，锈铁3–9成离散均匀抽取，保持最低最后一点。使用当前战利品上下文随机数替代旧 `Math.random`，便于可复现测试。

适配范围仅为装备池，不复刻旧箱子的随机槽位覆盖、独特书籍/签名物品、10/20日工具材料重抽或旧地图结构。旧非装备重抽可能改变早期旧版装备实际条件概率；本批采用可追溯的基础分母，避免扩大旧非装备/结构机制范围。地底世界是否生成对应结构仍由世界生成批次负责，装备池本身已能按维度选取，不伪称存在所有原版结构。

## 现代适配边界与验证

用户确认盔甲属性可以结合高版本特性，因此此处的人形装备减伤已改为 Minecraft 1.21.1 的护甲、盔甲韧性与原生附魔体系。此前将来源平减量直接写入护甲属性、剥离韧性及按来源 profile 代替真实 NPC 属性的实现已替换。完整现代数值、公式、存档影响和手测步骤见 [护甲防御与盔甲韧性的现代适配](modern-armor-defense.md)；本文件中的原始材料防御仍是可追溯的 R196 提取结果，不把现代适配覆盖写成旧版原值。

皮革、铁、金、铁链甲、钻石和下界合金保留 1.21.1 的基础护甲；钻石和下界合金保留每件 2、3 点韧性，下界合金另保留每件 0.1 击退抗性。新增板甲整套护甲为铜/银 13、锈铁 9、远古金属 18、秘银 22、艾德曼 24；其中远古金属、秘银、艾德曼每件韧性为 1、3、4。链甲低于对应板甲，铜银同级。低阶甲韧性为 0，遵循明确的现代平衡，而非遗漏。

玩家与人形怪物使用真实装备属性结算，包括未知来源 profile 的盔甲、原版海龟壳、混搭和额外属性。保护类附魔使用原版 EPF，抗性和抗火恢复原版减伤、免疫行为；保护附魔不再额外放大护甲属性，避免重复计算。现代破甲使用真正的 `ARMOR_EFFECTIVENESS` 数据函数；MITE 穿甲每级扣 1 点现代护甲，最低为 0，不再直接减平减防御或给无甲目标增加原始伤害。现代弩的穿透仍表示穿透多个实体。

来源品质只改变最大耐久；玩家护甲与韧性共同乘 R196 磨损系数，最后一点耐久失效且保留通常受击下的可维修性。受管怪物生成装备即使已有严重损伤也保留完整护甲、韧性；不再按玩家磨损比例削弱怪物的穿戴防御。玩家耐久分摊继续使用旧材料防御和来源损耗预算，保留可取消的 `ArmorHurtEvent`，这与现代实际生命减伤相互独立。普通 NPC 不新增常规受击盔甲消耗。

特殊物种的来源天然防御先独立处理，再结算现代人形装备。马的 BODY 槽、来源马铠及其专用受伤规则保留。普通无天然防御的人形怪物没有额外的一点伤害保底，原生吸收生命可以完整吸收命中。现代护盾、伤害冷却、伤害事件、经验/食物消耗仍走原生事务。

现代锻造纹饰和穿戴行为保留；银甲毒抗在服务端实际施加效果前生效，不修改共享食物/药水模板，并保留效果强度、可见性、隐藏效果和治疗方式。银甲毒抗覆盖率维持前述来源规则，未与本次现代护甲数值混算；无限时长毒保持无限时长。

目录身份、来源基础耐久、70 个配方、品质维修、银甲毒抗、五种马铠、附魔标签及地牢战利品测试继续保留。新增现代防御集成测试验证真实玩家/僵尸健康值、各材质护甲与韧性、NPC 严重磨损和实体 NBT、未知 profile 混搭、额外属性、原版保护/抗性/抗火/破甲、穿甲、可取消磨损、品质/网络/维修后的属性刷新及原生吸收生命。纯 R196 防御算术测试只证明来源提取，不代表本次适配后的运行时公式。客户端图标、穿戴 UV、Jade 和 HUD 仍需实际手测，不把无窗口测试写作客户端通过。
