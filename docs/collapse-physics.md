# 泥土与灵魂沙坍塌

开发署名：NingMeng123。原作：Avernite。来源为本地 R196 发布包，规则与 class 校验值见 [坍塌规格](../spec/collapse-physics.json)。

## 默认规则

R196 原规则给原版 **泥土、灵魂沙** 接入 `BlockUnderminable`。2026-10-17 根据用户反馈补充 **草方块、粗泥土、灰化土、缠根泥土、菌丝体**：原先挖掉土层后，这些未纳入范围的地表覆盖层仍然悬空，导致自然地形的坍塌表现不完整。新增范围限于完整土壤方块，仍使用同一套受扰动触发、支撑复核、连锁和持久化。落块保留原 BlockState，草皮落地仍为草方块，不额外改写掉落或材质。

耕地和土径是非整格耕作方块，本次不加入；泥巴、灵魂土、苔藓、黏土也不扩张。沙子、沙砾、铁砧仍走此前已有的物理规则。

R196 的 `allow_new_sand_physics` 默认为 false，且没有启用写入。关闭的是实验性斜坡合法性检查；已启用的泥土坍塌仍会执行。实际效果是：**受扰动后垂直下落**，不会横移滑坡，也不会在生成世界后把所有浮空土层自动拆掉。

| 触发 | 行为 |
| --- | --- |
| 生存玩家挖掉支撑 | 实际移除成功后立即检查正上方和同高度四个水平邻居；创造挖掘不触发。拆火把家族是原作明确的例外。 |
| 玩家放置 | 放置事务通过取消检查后立即尝试掉落；包含创造玩家。实际放置位置来自已提交的 snapshot，支持点击侧面等偏移位置。 |
| 实体踩踏、接触 | 检查脚下或碰到的已纳入土壤；不限定玩家，创造玩家站上去也会触发。没有额外改写实体自身的普通跌落伤害。 |
| 连锁 | 一块开始下落后，为正上方安排检查；挖掘/接触式坍塌成功时，再为同层四个正交邻居安排检查。延迟 **2 tick**，不会直接扩散到对角线。每块仍须满足下方可落条件。 |
| 爆炸移除支撑 | 原爆炸事务完成后，只为正上方安排 2 tick 检查。没有把任意普通 `removeBlock` 都变成爆炸或玩家挖掘。 |
| 树叶腐烂、末影人取块、蠹虫出块、怪物挖掘 | 实际移除成功后直接检查正上方。怪物挖掘的落块危险识别也包含泥土和灵魂沙。 |
| 普通邻居变化、世界生成、指令直接改块 | 不自动发起坍塌。这样保留 R196 天然悬空地形与明确的触发边界。 |

## 支撑与落地

石头、木板、玻璃、树叶、台阶、栅栏、门、活板门、床和梯子等可以支撑，不能将“不是完整立方体”统一当作没有支撑。源开着的门、活板门仍是固体；栅栏门只有关闭时是固体。两层及以上雪、睡莲、花盆和移动活塞也有独立保留规则。

空气、水、岩浆、植物、火把、按钮、压力板、拉杆、地毯、红石线等允许落入。一层雪可以被碾碎；骷髅头有明确可压碎规则。铁轨虽然允许开始下落，却不能被碾碎；落地无法放置时，落块转为物品。花盆虽然硬度为零，原作显式禁止替换，不能套用零硬度碾碎。

已纳入土壤落块的附加碰撞：悬空物体按正常掉落事务撞落，紧贴实心地面的物体被碾碎时不掉物品；落块压到玻璃材料支撑会破坏玻璃并继续掉落，包含染色玻璃、玻璃板、信标等对应材料族。保留方块的 `canEntityDestroy` 否决和正常掉落事件。

使用原版 `FallingBlockEntity.fall` 创建落块，保留原版重力、速度、落地、超时、保存重进和试炼密室天然来源。根据本轮用户要求，**所有已纳入土壤落块启用原生直接砸伤**：第一格缓冲，此后按原生累计下落距离每格 **1 点生命值伤害**，单次最多 **20 点**。这比原先仅可能埋住后窒息的行为更完整；落块必须实际落到目标所在位置，伤害遵守原生非创造/非旁观目标筛选、护甲与伤害事件取消。普通沙子、沙砾和铁砧不会被这条土壤增强规则重新配置。

## 存储、联机与现代高度

- 所有判断由服务端执行。原作 metadata 的待坍塌位改为带版本的区块 Data Attachment，检查仍使用原版保存的方块计划刻；保存退出后不会丢掉待处理状态。
- 只查询已加载区块，不为扩散强制加载邻区。使用各维度的最低建造高度，负数层正常坍塌；没有旧版写死的 Y=0 地板。
- 灵魂沙的原生气泡柱计划刻与坍塌检查分开处理，原生 20 tick 计划不会把坍塌推迟，也不会被提前到 2 tick 执行。
- 方块被换成另一种方块时清除待检查标记，避免旧检查误伤后来放回的土块。落块生成被 `EntityJoinLevelEvent` 取消时，恢复源方块及其天然禁掉落标记，不开始上方连锁。
- 保留现代落块的保存与区块生命周期，不复制 R196 在附近区块未加载时直接向下瞬移放块的旧优化。
- 落块伤害设置使用原生 NBT 字段保存；修复前已在半空的土壤落块在重新读档时补上砸伤，试炼密室天然禁掉落来源仍保留。

## 手动测试

重启测试客户端，用独立测试区域检查。需要观察慢动作时可以 `/tick freeze`，再 `/tick step 1t`；测完 `/tick unfreeze`。持续加速用 `/tick rate 200`，恢复正常用 `/tick rate 20`。

1. **挖支撑**：用石头撑住泥土，再在生存模式挖掉正下方石头，泥土应变成落块。相同结构换灵魂沙或草方块、粗泥土、灰化土、缠根泥土、菌丝体也应生效。用创造模式挖支撑则不立即触发，之后站上土块仍能触发。
2. **连锁**：先建一排泥土及下方支撑；通过指令去掉大部分支撑，留下一个用于生存挖掘。指令本身不会触发；挖掉最后一个支撑时，周围已经悬空的土块应逐步跟着掉落。邻块下方若有石头，应停住。
3. **放置和踩踏**：玩家把泥土放在空中时应立即下落，创造放置也一样。用 `/setblock` 建立悬空泥土则不会自行下落；走到上面应触发。
4. **特殊支撑**：台阶、栅栏应能托住；水不能托住。落向地面火把会碾碎火把，落到铁轨则保留铁轨并转为泥土物品。较高处落到玻璃棚后应击穿并继续掉落；普通沙子仍保留原来的火把阻挡规则。
5. **负高度与存档**：在 Y<0 区域重复测试；可在两刻连锁等待期间暂停、保存退出后重进，确认继续处理且没有重复物品。试炼密室天然块的掉落限制仍须保留。
6. **怪物及爆炸**：让挖掘怪挖开土层支撑，或炸掉泥土下的支撑，检查上层会跟随坍塌，怪物不会把泥土误当作没有下落危险。
7. **落块砸伤**：在非创造模式下让土壤从较高处落到玩家或牛身上，比低处掉落受伤更多；约一格的短落差不应凭空砸伤。保存半空落块再进入也应继续生效。沙子维持原有行为；试炼天然土壤砸伤后仍不应因此多掉方块物品。

## 来源边界与验证

核心源码：`BlockUnderminable.java:15–98`、`BlockFalling.java:38–80`、`jw.java:159–174`、`nn.java:954–963`、`sr.java`；默认实验开关、支撑覆写与相关调用均已核对实际启用链。

R196 爆炸还含独立的 2.5 倍低抗性预处理射线，可把部分草地/耕地改成泥土。这属于爆炸土壤转换，并非“爆炸移除支撑后坍塌”；本批未扩张现有爆炸范围来猜测实现该射线。
