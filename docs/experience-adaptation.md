# 正等级经验曲线与现代接口适配

开发者：NingMeng123。原始依据见 [R196 玩家规格](r196-player-rules.md) 的字节码修正记录。

## 当前独立功能

正等级 0–200 使用 R196 累计曲线 `T(L)=5L²+15L`，0–199 级的下一等级需求为 `20+10L`。关键累计值：1 级 20、2 级 50、5 级 200、10 级 650、35 级 6650、200 级 203000。

`Player.totalExperience` 在本模组中代表当前累计经验，等级和进度从它产生。正经验、直接设置等级、设置级内点数、等级消耗均同时维护三字段；不会每 tick 用原版未扣除成本的历史总经验把等级补回来。

死亡惩罚和负等级另行实现。本功能的游戏运行范围暂为 0–200 级、0–203000 点经验；减到不足 0 时清零。数学规则层保留原始负经验公式供后续功能使用，不表示已经启用负等级玩法。

## 现代行为的明确选择

| 入口 | 行为 |
| --- | --- |
| 经验球、命令加减点数 | 对整数总经验加减，使用宽整数计算避免溢出，跨级更新生命/食物的既有等级来源 |
| `/experience query ... points` | 返回当前等级内的整数点数，不是累计总数；不用浮点进度反算 |
| 设置级内 points | 限制在当前等级的合法级内区间 |
| 添加/设置 levels | 保留进度比例，用 `oldPoints * newCost / oldCost` 的整数除法计算新级内点数 |
| 附魔台、铁砧 | 保留现代设备的等级成本与物品规则；扣级经过统一经验入口，累计数同步减少 |
| 经验修补 | 保留新版经验球先维修、余量再进入玩家经验的顺序；本功能不更改维修效率 |
| 200 级 | 正经验硬封顶 203000，进度为 0；安全的下一等级跨度返回 1，使原版调用不会除零；命令设置正级内点数被拒绝 |
| 设置超过 200 级 | 命令明确报错，不把截断后的结果宣称为设置成功 |

203000 的硬封顶是现代安全适配。旧 R196 在 200 级后以 `Integer.MAX_VALUE` 作下一阈值；总经验恰好达到该值会使原版等级扫描无法终止，并且原版经验加法可能溢出。这里不照搬这些异常行为。

## 事件、保存与同步

点数入口先发送 NeoForge `XpChange`，若跨级再发送一次聚合的 `LevelChange`；等级入口发送 `LevelChange`。取消时保持三字段不变，修改事件数值后重新计算一致的结果；跨多级采用一次聚合事件属于现代适配，不模拟原版逐级循环。原版直接 setter 不发送这些事件，本模组保持此语义。取消经验事件不代表取消整笔附魔或铁砧物品操作。

保存继续使用原版 `XpTotal`、`XpLevel`、`XpP`，额外写入 `mite_experience_version=1`。无标记旧存档按已显示的等级与进度比例迁移，避免早期测试命令造成的 `XpTotal` 脱节改变玩家当前等级。已标记存档以累计整数为准恢复。客户端接收现有经验数据包，不另建可由客户端申报经验的接口。

实际验证状态与证据另记于逐功能测试记录；本设计文档本身不是测试通过证明。
