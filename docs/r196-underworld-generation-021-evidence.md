# R196 地底世界生成证据与移植边界

维护：NingMeng123。原作：Avernite。版本基准为本地 `MITE 1.6.4 R196.zip`，SHA-256：`fb7ad265d05749e0cd1e54938f6c36ecbe9ea1d4d90d4a04c519615e1e0218c3`。

本页只记录地底维度的地形、菌丝和已存在生物的生成部分；传送门、符文、地幔热量与下界地核的验收见本阶段总册。本轮不生成新矿物。主世界继续采用 Minecraft 1.21.1 地形、洞穴和 Y−64..319；本实现没有替换主世界生成器。

## 反编译歧义的解决

`aet.placeRandomCobwebs` 的 CFR 文本把带 `++random_number_index` 的赋值内联进数组表达式，表面上导致 Y 和 Z 共用最后一个索引。实际字节码偏移 57..104 清楚显示依次抽取 X、Y、Z，三个索引分别递增。实现以字节码为准。

此差异由真实 R196 类执行的区块 SHA 检查检出；不是通过修改测试期望迁就移植实现。包含蛛网的种子 0、区块 `(−11,1)` 有 2 个蛛网，作为回归案例保留。

## 独立字节码金值

`spec/r196-underworld-terrain-fixtures.json` 来自 `tools/reference/UnderworldTerrainExport.java` 执行归档 R196 的 `ChunkProviderUnderworld.generateNetherTerrain`、`aet.placeRandomCobwebs` 和 `adr` 缓存转换构造器。未调用 Minecraft 入口，也未调用世界、客户端或服务器构造器；只用无构造器的载体提供原函数所需世界标量。载体不运行游戏刻。

执行前由 `tools/reference/export_underworld_terrain.py` 核对全部 1,186 个归档类的 SHA-256；Java 只读 guard 禁止文件修改、进程、网络、原生库加载和新线程。输出由外层 Python 保存。复现需既有 `.reference` 归档及其已下载的 1.6.4 依赖，不会下载新依赖：

```powershell
python tools/reference/export_underworld_terrain.py --java <Java-17至23的java.exe路径>
```

金值覆盖 5 个种子与 5 个坐标组合，共 25 个区块、1,638,400 个方块，包括负坐标、远坐标、负种子、最大 long 种子、水和蛛网。每个区块以 `(local_x*16+local_z)*256+world_y` 顺序计算完整 SHA-256，另外保存 6 种材料数量及实际 `ChunkPostField` 的菌丝锚点坐标和种子，共 39 个锚点记录。地幔规范代码为无符号 255，其余沿用旧空气/石头/基岩/水/蛛网代码。

`R196UnderworldTerrainTest` 的 25 个金值案例全部一致；另有材料边界和并行区块生成测试。该验收只覆盖基础地形和锚点，不包括矿物、地牢或后续实体装饰后的完整世界。

## 现代适配与本轮范围

原作把噪声数组、随机表和菌丝缓存放在可变静态字段。本移植使用不可变的每维度种子状态及每次生成的局部数组，避免异步区块生成串用结果。旧随机表在一次 JVM 中只初始化一次，本移植按当前存档种子确定；金值对应每个存档独立初始化的 R196 行为。

主世界的现代高度无需改变。地底保留独立的旧 256 层坐标体系，`seaLevel=144` 仅向现代引擎描述地底水面，不把矿物的源 Y 范围自动加上 120。将来矿物可接入 `mite:underworld` 生物群系的普通特征阶段；目前该生物群系没有矿物特征。

水平范围使用现代存档世界边界。原作在旧 `isChunkWithinBlockDomain` 范围外返回空区块，本轮没有复制该独立旧边界的空区块行为；这是坐标边界的现代适配，不能将上述区块金值一致扩大解释为现代整张地图与旧版完全一致。

当前原版可用刷怪子集沿用已核实权重：蜘蛛 80（1..2）、爬行者 100（1..2）、史莱姆 100（1..4）、末影人 10（1..4）、洞穴蜘蛛 40（1..2）、蝙蝠 100（8..8）。它们的完整 R196 战斗行为不属于本生成器的完成声明。源史莱姆确实还限制 Y<40（`EntityCubic.java:366–386`），没有擅自把其限制平移到上层洞窟。

尚未实现的长亡者、远古骷髅君主、吸血蝙蝠等源实体不以原版实体冒充。原地底 16 次地牢尝试依赖长亡者/长亡者守卫刷怪器及未完成的古代金属装备、钱币、唱片战利品，留待对应实体和战利品一并接入；本轮不生成原版随机僵尸地牢代替它们。

独立维度注册、真实生成地幔/基岩边界、主世界和下界生成器保持、地底蝙蝠高层生成由 `UnderworldGenerationGameTests` 覆盖。最终全量服务器测试及人工画面验收状态以本阶段总册为准；本页不把未进行的人工测试写成通过。
