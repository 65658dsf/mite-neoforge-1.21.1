# 1.21.1 现代内容适配规格

开发署名：NingMeng123。原作：Avernite。状态：**设计已记录，功能待实现；本文件不是已完成清单**。

机器可读设计值见 `spec/modern-adaptation.json`。两处发生差异时，以 JSON 中的现代设计值为准；JSON 不得作为 R196 原始数值证据。后续实测调整须一起更新两处和验收用例。

## 证据边界

2026-10-12 实际读取了[官网](https://avernite.ca/MITE/)、[配方页](https://avernite.ca/MITE/crafting_recipes/)和[提示页](https://avernite.ca/MITE/hints/)。官网说明渐进式采集、生存与金属加工路线；配方页列出钻石装备属于原作移除的配方。因此保留钻石装备是本移植的**现代设计偏离**，不能称为直接复刻。网站用于解释意图；R196 压缩包内方法、常量和有效调用链才是版本行为证据。

材料标识先覆盖 `flint, copper, silver, gold, iron, ancient_metal, mithril, adamantium`。**这一排列不是硬度或强度顺序**；原始硬度、耐久、炉温、配方时长及挖掘级别均由原始规格提取，不在此猜数值。现代设计只引用材料名和加工能力；不得使用 enum ordinal 比较材料。

1.21.1 注册表差异清单仍待工具生成。下表覆盖需主动适配的机制族，并不冒充已经逐项审核全部新版注册项。每个新增物品、方块、附魔、交易、结构和战利品表最终必须分配到一个机制族，并标明保留或修改理由。没有归类的条目视为未验收。

## 成长阶段与通用入口

阶段是验收路线的命名，不是材料硬度表，也不是全服解锁开关：

| 阶段标识 | 实际要求 | 代表能力 |
| --- | --- | --- |
| gatherer | 原版 R196 开局条件，待提取 | 采集、燧石与简易加工 |
| base_metal | 能按 R196 配方取得铜/银/金等目标材料 | 基础金属工具 |
| iron | 能取得铁并使用满足该配方的工作台/铁砧 | 盾牌、弩、基础机械 |
| ancient | 获得远古金属并满足其原始使用条件 | 对应原作工具；不默认比铁硬 |
| mithril | 能取得秘银并使用秘银加工设备 | 钻石装备装配、精密机械、修补与鞘翅维护 |
| adamantium | 能取得艾德曼金属并使用相应加工设备 | 下界合金与重型现代装备 |
| end | 满足已核实的末地进入和探索条件 | 末地探索所得能力 |

所有配方通过一个服务端规则入口：输入快照、配方 ID、工作台能力集合、炉温、可空操作者、累计有效 tick、输出空间。无效请求返回稳定的失败原因和本地化提示；不能只改显示配方或客户端 UI。

修改玩家背包配方、工作台、配方书、shift 点击、拖动、自动合成器和专用加工菜单时，都使用同一份材料/设备规则。每个输出只有一次提交点：再次核验条件，原子扣料、扣经验、应用损耗，再写入输出。失败不产生输出或部分扣费。

### 先进装备的来源适配

保留原版装备 ID、外观、附魔与使用方式。通过制作材料、既有设备、交易和战利品入口调整成本；**不添加装备激活标记、隐藏禁用状态或额外装配机器**。获得的完整装备能直接使用和赠送；多人合作允许共享已经生产出的装备。

结构中的钻石/下界合金成品分别改为对应原版材料掉落：钻石工具/护甲替换为其原版配方钻石用量减 1（最少 1）；下界合金成品替换为 2 下界合金碎片。不会凭空引入秘银或艾德曼。现代结构及其它战利品保留；替换仅影响确实越过加工路线的成品，且记录具体 loot table 与 pool。装备交易仍出售成品，额外消耗该阶段材料，支付见下表；随机怪物装备/钓鱼等同样纳入来源审计。

三叉戟保留溺尸战斗获取，鞘翅保留末地船获取；挑战与维度进入成本本身就是它们的路线。它们不因为玩家缺少隐藏的阶段标识而失效。铁砧、锻造和修理保持名称、耐久、附魔、纹饰等合法组件；新配方不能顺便免费修满被升级的装备。

## 装备、附魔与移动

以下成本和 tick 均为**本项目设计值**；20 tick 为一秒游戏时间。每行默认经验成本为 0，只有显式列出的情况例外。原版伤害、护甲、附魔互斥等未指定字段暂保留 1.21.1 规则，随后通过独立平衡验收判断，不可错误套用材料 enum 顺序。

| 对象 | 阶段与设备 | 配方或装配成本 | 时间与限制 |
| --- | --- | --- | --- |
| 钻石工具/武器/护甲 | mithril；秘银工作台 | 制作沿用该物品原版钻石/木棍用量，另加 1 秘银锭 | 每件 400 tick；使用秘银采掘能力上限，不能仅凭原版钻石 tier 绕过艾德曼矿门槛 |
| 下界合金锭 | adamantium；艾德曼工作台 | 4 下界合金碎片 + 4 金锭 + 1 艾德曼锭 → 1 锭 | 600 tick；远古残骸采用原作最高炉级和烈焰棒加工能力，炉温数值引用原始规格 |
| 下界合金装备 | adamantium；锻造台相邻 1 格内有艾德曼铁砧 | 原版升级模板 + 钻石装备 + 下界合金锭 | 600 tick；升级保留组件，消耗模板；采掘能力等于艾德曼能力，抗火保留 |
| 盾牌 | iron；铁工作台 | 6 任意木板 + 2 铁锭 + 1 皮革 → 1 盾牌 | 200 tick；保留主动格挡和斧破盾规则，盾牌不能代替装备的原作格挡判定而造成双重减伤 |
| 弩 | iron；铁工作台 | 3 木棍 + 2 线 + 2 铁锭 + 1 绊线钩 → 1 弩 | 300 tick；保留装填、穿透、多重射击；每发独立扣弹/损耗，不复制特殊材质箭 |
| 三叉戟 | 战斗获取；铁砧维修能力按材料映射 | 保留溺尸来源；每次 1 海晶碎片恢复最大耐久的 10%，向上取整 | 维修 200 tick；默认耐久不变；忠诚、引雷、激流保留，特殊附魔不绕过免疫 |
| 鞘翅 | end；秘银铁砧用于常规材料维修 | 保留末地船来源；每次 1 幻翼膜恢复最大耐久的 10%，向上取整 | 维修 200 tick；原版飞行和火箭推进保留，胸甲槽取舍保留 |
| 重锤 | adamantium；艾德曼工作台 | 1 沉重核心 + 1 旋风棒 + 2 艾德曼锭 | 600 tick；砸击额外伤害上限 20 点，基础伤害另计，服务器计算落地后清除累计状态 |
| 经验修补 | mithril；保留修补附魔 ID | 图书管理员出售修补书固定基础成本 16 绿宝石 + 4 秘银锭；可按下述规则从其它来源取得 | 1 经验点恢复 1 耐久；使用经验点而非经验等级，无额外充能组件 |

修补仍可从 1.21.1 的原版允许来源获得；钓鱼或探索所得修补书视为合法探索收益，不新增装配封锁。其实际恢复效率统一为 1 耐久/经验点，并按实际恢复量扣经验；剩余经验交还玩家。玩家使用铁砧应用修补时，除原版经验成本外需要满足秘银铁砧加工能力，因此钓到书不会自动开放所有装备的低成本维修。天然带修补的弓/钓竿等保留可直接使用的完整物品，作为明确允许的早期探索奖励；它们不会给高阶挖掘工具提供金属或设备。

保留全部现代附魔 ID 与可获得途径。经验修补以外的耐久保护、效率、时运、精准采集、保护、穿透、密度等必须分别交叉测试采集与战斗原始公式。不允许铁砧合并变相取消原作已核实的“不能叠加附魔等级”规则：若 R196 确认该限制，保留两件合法附魔的并集，同名附魔取最大值，不执行原版同级+1；应用不同附魔与现代装备升级仍保留。

## 交易、结构与资源循环

| 机制 | 默认现代设计 | 必须验证的风险 |
| --- | --- | --- |
| 村民职业与交易 | 全部现代职业保留；原作村庄生成条件单独从 R196 提取。原版供需与涨价保留；钻石装备交易保留原绿宝石价格，第二支付槽加 2 秘银锭；修补书见上表 | 治疗折扣不得使任何资源成本归零；每笔至少 1 个对应支付物，特殊非绿宝石材料不受折扣；不新增原版不存在的下界合金交易 |
| 交易经济 | 普通物品沿用原版每次交易数量；每个交易项每日最多补货 2 次；禁止复制职业重置已经发生过的交易进度 | 绿宝石交易不能直接产出铜/秘银/艾德曼材料；新玩家接触已发展的村庄允许交易，但设备成本依旧成立 |
| 结构与战利品 | 保留现代结构、探索路径和战利品用途；高阶成品按前述材料映射替换；R196 限制资源逐表核查 | 城市、堡垒、试炼密室、藏宝图、沉船、废弃传送门、袭击奖励逐表审核，不能只拦箱子开箱 |
| 含材料的战利品 | 秘银、艾德曼不额外加入现代战利品；既有铁/金/钻石资源保留，早期采掘门槛由加工能力保障 | 拆铁块、盔甲熔炼、金粒、猪灵交易、钓鱼和考古必须进入来源图 |
| 傀儡和袭击农场 | 保留原版触发和可自动化行为；非玩家/驯服生物最近 100 tick 内造成伤害而死亡的铁傀儡改掉 3–5 铁粒；玩家归因掉落待与原作核实 | 击杀归因由服务端记录，禁止通过离线假玩家免费绕过；不对铜/金等其他农场猜测套同公式 |
| 刷怪与经验农场 | 保留现代刷怪笼、试炼刷怪笼和战利品机制；经验按已提取的原作实体规则，新增敌对生物先归类再定值 | 放置处刑、摔落、火烧、宠物归因、区块加载不能复制经验或绕过免疫 |
| 新食物与作物 | 保留现代食物、蜜蜂、蜂蜜、海带、浆果、甜菜等；每个食品须映射到原作营养维度 | 未映射食品不冒充已完成营养适配；自动农场遵守温湿度、病害与离线生长上限 |
| 探索与便利物品 | 保留潜影盒、收纳袋适用的原版功能、指南针、望远镜、船/矿车及饰纹 | 内嵌容器、装备复制与成就奖励不得丢失组件或绕过堆叠/重量等已核实限制 |

交易及经济设计值是初始基线；存在闭环盈利时应增加具体来源成本或修改交换比率，不通过随机失败、每日弹窗、隐藏世界锁解决。结构初次进入不需要整座结构关停；获取到的合法装备立即可用。

## 自动化与无操作者规则

| 设备 | 制造/安装成本与阶段 | 默认行为 |
| --- | --- | --- |
| 漏斗 | iron；铁工作台；5 铁锭 + 1 箱子 | 保留原版运输间隔；受保护输出槽须经处理器提交成功后才可取出 |
| 活塞、投掷器、发射器、观察者 | iron；铁工作台；保留原版材料及数量 | 配方时间均 200 tick；保留红石功能，不让推拉/投掷形成免费挖掘或工具磨损豁免 |
| 高炉/烟熏炉 | iron；铁工作台；保留原版配方材料 | 配方时间 300 tick；高炉 2 倍速度不提高可达炉温，烟熏炉限食物；燃料与热量取已核实原始规则 |
| 自动合成器 | mithril；秘银工作台；原版配方中的 5 铁锭替换为 5 秘银锭，其余材料不变 | 制造 600 tick；其自身只提供 iron 制作能力；相邻工作台不能免费给它更高能力 |

自动合成器完整保留基本功能，但 v1 对**有经验成本**的配方返回 `NO_OPERATOR_XP`，不制作该配方；不添加额外经验储罐或新方块。它不读取附近玩家经验，也不通过经验瓶无主代扣。品质固定为原作 `average`；已确认 `hasQuality()` 的工具、防具等输出保留该品质，普通物品不增加品质组件，不进行玩家技能/等级加成。经验成本必须汇总配方和物品制作回调：原作铸币由 `ItemCoin` 单独扣经验，不能只检查 `crafting_experience_cost` 后把金币当成免费自动生产。

每个上升沿至多开启一次工作；输入不满足时该脉冲不缓存。进入工作后所需输入移到持久化内部预留区，耗时等于对应人工配方，持续供电不产生重复作业；忙碌时其它脉冲忽略，不累计队列。自动合成器不得加工需要更高工作台、熔炼炉或铁砧的配方。

下列行为必须固定：

- 区块卸载暂停，读档恢复累计有效 tick；不得按真实时间补产，也不得主动强加载区块。
- 缺燃料或输出阻塞暂停且不消耗后续资源。完成后的输出只保存一份，直到可向外发出；不能重复结算。
- 工作开始后改输入不影响预留区；移除设备只掉落预留材料和已完成输出各一次，未完成产物不掉落。
- 数据包重载后重新查配方和限制；缺失或变更导致现有预留配方无效时，退回预留材料至设备可回收区，时间归零，绝不掉落两份。
- 人工取消和自动化失败使用同一回滚入口；输入、经验、品质、输出状态由服务端持久化，客户端只显示进度。

## 世界、维度与保留内容

主世界完整保留 **1.21.1 原版 noise generator、biomes、caves 和世界高度**，保持新版山地与洞穴的丰富性，不用 1.6.4 地形代码替换现代生成器。包含蘑菇岛等现代群系，是“保留现代主世界”的明确适配选择，不能套用官网旧版删除规则。只通过矿物配置、结构出现门槛、loot 和群系修饰接入 R196 资源；现代生成器注册项不被整包替换。地下世界是独立新增维度，不覆盖主世界。

旧高度条件分别归类为绝对条件、距基岩深度、距海平面深度、维度局部坐标；只有标记为分布范围的旧规则才映射现代高度。不得将全部 `y` 常量统一加减 64。矿石替换标签必须同时考虑石头、深板岩和相应维度基岩；铜矿/粗金属/时运产量统一进材料收支表，禁止旧矿和现代矿双倍注册。

地下世界单独注册维度，已核实的传送关系与原始高度缓存见 `docs/r196-world-rules.md`；完整噪声边界仍须专项校验，不得使用普通下界生成器充当复刻。进入地下世界沿用原作门的位置规则，不增加未经要求的秘银阶段锁。传送保存往返维度与位置，落点安全检查限制搜索范围，失败不扣材料或留下半个传送门。主世界/地下世界/下界/末地的规则按独立维度配置，不以一个全局高度条件控制。

## 实现状态与发布门槛

本文件及 JSON 的全部功能状态是 `planned`。现代 1.21.1 逐注册项差异、R196 硬度/炉温/配方/营养与免疫数据仍需核实；涉及它们的功能不能凭本设计表宣布完成。完整验收要求见 `docs/acceptance.md`，阶段依赖见 `docs/roadmap.md`。
