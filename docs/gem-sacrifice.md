# 宝石献祭声音、粒子与冷却

维护者：NingMeng123。日期：2026-10-22。

## 当前规则

青金石、石英、绿宝石、钻石右键献祭各消耗1个完整物品，本体分别给予25、50、250、500经验；碎片、蓝色染料和石英方块不属于献祭物品。创造模式也消耗物品，支持副手，不回复生命。方块本身的正常交互优先，未消费交互的原生使用路径才进入物品献祭。

第一次献祭即时完成，成功后四种宝石共享10 tick冷却（20 TPS时0.5秒）。换槽、换宝石、换手或重复使用包不能绕过，冷却内拒绝不会延长或排队补用；在献祭处理前被拒绝或`RightClickItem`已取消时，服务端不扣物品、不加经验、不启动冷却。不声称后续第三方经验事件都具备事务回滚。冷却由原生`ItemCooldowns`服务端检查并同步客户端，不只依赖客户端点击节流；客户端预测遭服务端否决时可能短暂显示本次预测冷却。

成功时服务端播放玻璃破碎声：`minecraft:block.glass.break`，音量0.25，音高`0.8 + random * 0.4`。同时在嘴前按头部朝向发出5个被消耗物品的破碎粒子，使用扣除前的单个物品副本；使用者和附近玩家收到同一服务端效果，不在客户端预测阶段重复播放。

## R196证据与现代适配

本地`.reference/r196/decompiled/ItemRock.java:32–44`经`uf.java:664`调用客户端表现；`bcw.java:1578–1585`实际使用`random.glass`及上述音量、音高，而不是食用声或经验球声。`bcw.java:1448–1462`发出5个当前物品的`iconcrack`粒子，并按头部朝向旋转位置和速度。`bdc.java:317–336`定义客户端墙钟节流，成功右键调用点`atv.java:1143–1147`采用500毫秒；现代改为四种献祭物品共享的服务端10 tick冷却，不把这个时长强加到其他物品交互。

旧包没有自定义玻璃OGG，现代原版声音索引的`block.glass.break`仍映射`random/glass1`、`random/glass2`、`random/glass3`，因此直接复用同名原版音效，不重复打包原版音频。已核对本地现代OGG的SHA-1与原版资源索引一致，但不宣称与旧包不存在的OGG做过逐字节比较。

## 极难版石英

Modern ITE的新配置默认每颗石英35经验，保留`quartz_max_exp_level=55`：等级必须低于55；54级可使用，55级起拒绝并显示需要低于该等级的动作栏提示。等级上限为0或`quartz_exp=0`时显示配置禁用提示。受限时不消耗石英、不加经验；旁观者或其他模组已取消的交互不误发提示，纯配置查询也不发消息。

用户已亲测55级以下可以正常使用，因此本次不是取消等级上限，而是补齐拒绝原因提示。已有TOML的有效`quartz_exp`自定义值继续优先；若旧配置仍为50，需要在模组设置改为35，不自动覆写用户配置。本体单独安装时仍为50经验且没有这个等级限制。
