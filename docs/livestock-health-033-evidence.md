## 生病是什么

R196 没有独立的牲畜随机感染、传染、疾病进度或治疗药物系统。玩家看到的 sick 外观由 **EntityLivestock.isWell() 返回 false** 直接控制：食物、水分、自由度任意一项 **低于 0.25** 即不健康；三项都 **至少为 0.25** 即恢复。

这里的健康状态不是实体当前生命值。受伤但三项需求足够的动物仍是健康外观；满生命但缺水、缺食物或拥挤的动物可以显示病态。

实际启用范围是鸡、牛、蘑菇牛、猪、羊。马、狼、猫、蝙蝠、鱿鱼及新版没有对应来源的动物不继承 EntityLivestock，不能直接加上这套病态判定。

## 判定、同步与恢复

| 行为 | R196 实际规则与来源 |
|---|---|
| 判定 | `EntityLivestock.isWell`：服务端取三项需求最小值 `>= .25`；客户端读同步 watcher |
| 即时更新 | `setFood`、`setWater`、`setFreedom` 每次修改都调用 `setIsWell`；不存在额外康复计时 |
| 被动更新 | 每 100 个实体原始 tick，以 `nextInt(10)>0` 的 90% 概率更新三项需求 |
| 食物 | 附近适用食源 `+.1`，否则 `-.005`；牛/蘑菇牛是短草、蒲公英，其他牲畜是草方块、短草 |
| 水分 | 附近可用水源 `+.1`；否则淋雨 `+.01`；否则 `-.005` |
| 自由度 | 室外且不拥挤 `+.1`，否则 `-.005`；实际实体包围盒扩张 `(2,.5,2)` 查询 Mob，包含自己，数量 `>2` 拥挤；室内总是拥挤 |
| 手动喂食 | 合法喂食 `+.5` 食物；正常成年无繁殖冷却、未恋爱等原有进食条件仍适用 |
| 手动饮水 | 口渴时使用水容器，增加 `.25 × 标准容量` 水分；一碗 `.25`，一桶 `1` |
| 保存重进 | 三项需求写入 NBT，加载时经 setter 重建同步病态；不能只保存外观布尔值后遗漏资源 |

“每 5 秒生一次病”不正确：正常 20 TPS 下每 5 秒只是一次 90% 需求更新机会，只有越过阈值才切换状态。恢复所需时间由缺失资源及环境决定，不能设固定康复秒数。

## 生病影响及不应扩大的限制

- **肉类掉落**：鸡、牛/蘑菇牛、猪、羊的来源肉类掉落均要求 `isWell()`。皮革、羽毛、羊毛及鞍具遵守各自原有掉落条件，并非全部清空。
- **生产**：只有更新后健康的成年牲畜增加生产计数。`produceGoods()` 仍每 100 tick 调用；鸡在生病时可以消耗先前积累的计数继续掉一次蛋或羽毛，不能把已有库存清零。
- **挤奶**：`ItemVessel.tryEntityInteraction` 检查牛现存奶量，不检查 `isWell` 或是否满血。生病牛已有的奶仍可以挤；缺奶后无法靠病态期间的生产补足。
- **繁殖**：`EntityLivestock.bX()` 只在健康时调用父类进入恋爱状态。它没有主动取消已经进入的恋爱状态。
- **喂食和诱引**：满生命、食物不饿、但因缺水或自由度不健康时，拒绝额外食物和诱引；受伤或食物饥饿时仍可能接受。治疗缺水与拥挤不能只反复塞小麦。
- **幼体成长**：食物或水分 `<.05` 时阻止幼体年龄正向增长；并非任意一项 `<.25` 都停长，自由度不足本身不冻结成长。
- **回血、移动及伤害**：`of.c` 的非玩家自然回血每 1000 个 offset tick 恢复最大生命的 10%，没有 `isWell` 门槛。来源没有病态持续扣血、病态移动减速或生命上限下降；不能添加这些限制冒充还原。
- **羊毛**：来源剪毛及 `pn` 吃草后 `rz.n()` 恢复毛、加食物没有 `isWell` 条件；不能把羊生病解释成绝对不能剪毛或长毛。

## 病态外观实际调用链

`bgl` 构造器注册的渲染器如下。四个病态选择函数直接读取 `isWell()`，幼体也使用同一判断。

| 实体 | 渲染类与选择方法 | 健康 / 病态纹理 |
|---|---|---|
| 鸡 | `bge.a(rq)` | `textures/entity/chicken.png` / `textures/entity/chicken/sick.png` |
| 牛 | `bgf.a(rr)` | `textures/entity/cow/cow.png` / `textures/entity/cow/sick.png` |
| 猪 | `bhi.a(ry)` | `textures/entity/pig/pig.png` / `textures/entity/pig/sick.png` |
| 羊 | `bhk.a(rz)` | `textures/entity/sheep/sheep.png` / `textures/entity/sheep/sick.png` |
| 蘑菇牛 | **独立 `bhf.a(rw)`，没有健康分支** | 始终 `textures/entity/cow/mooshroom.png` |

猪鞍具仍为独立图层。羊的染色羊毛仍为独立图层，病态替换的是身体贴图，不能把毛色直接替换或隐藏。蘑菇牛虽然继承病态玩法，却没有来源病态外观；给它新增病态贴图只能列为现代适配，不能声称 R196 已有。

四张 sick PNG 均存在于用户提供的资源包，已将解包文件与原 ZIP 条目逐张核对相同 SHA-256。JSON 记录原 ZIP 条目、相对路径、PNG 尺寸及 SHA-256；实际打包选择应保留清晰的资源出处。

## 字节码交叉验证

- `EntityLivestock.isWell:()Z`：偏移 48 读取 `0.25f`，50 为 `fcmpl`，51 为 `iflt`；边界 `.25` 属健康。
- `EntityLivestock.setIsWell:(Z)Z`：布尔真写 watcher 字节 `-1`，假写 `0`；客户端非零即健康。
- `bge.a:(Lrq;)Lbjo;`、`bgf.a:(Lrr;)Lbjo;`、`bhi.a:(Lry;)Lbjo;`、`bhk.a:(Lrz;)Lbjo;`：偏移 1 调用 `isWell`，4 跳转病态分支；前三者病态索引 1，羊病态索引 2。
- `bhf.a:(Lrw;)Lbjo;`：偏移 0～6 直接返回纹理索引 0，无 `isWell` 调用。

JSON 保存源文件和 class 校验、方法签名与方法体摘要哈希及 Code 属性哈希。没有把完整反编译源码复制到公开文档，也没有启动旧版世界。

## 032 基线覆盖及本批缺口

032 已实现三资源、阈值、同步、保存、饥渴/自由度 AI、生产、繁殖入口、进食诱引、成长及肉类掉落门槛。本次来源审计发现的明确缺口是 **鸡/牛/猪/羊按服务端健康状态切换病态外观**，以及把上述跨系统边界加入独立回归验收。客户端专用类须与公共服务端代码隔离。

来源验收应分别覆盖 `.24999` / `.25`、三个资源各自致病与恢复、受伤但健康、满血但病态、幼体、羊毛与鞍图层、既存牛奶/鸡生产计数、保存加载及多人同步。手测不能仅通过“等待一次掉蛋”断定所有疾病规则正确。
