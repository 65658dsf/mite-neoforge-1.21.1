# 特殊亡灵装备材质成长

开发者：NingMeng123。日期：2026-10-16。

## 适用范围和装备下限

新生成的下列生物保留来源装备配置，按现有日期成长规则提高材质：

| 生物 | 防具下限 | 武器下限 |
| --- | --- | --- |
| 骷髅领主 | 生锈铁板甲 | 生锈铁剑、战斧或战锤 |
| 怨魂（玩家所称冤魂） | 生锈铁板甲 | 生锈铁剑、战斧或战锤 |
| 远古骷髅 | 远古金属锁链甲 | 远古金属剑或弓 |
| 远古骷髅守卫 | 远古金属锁链甲 | 远古金属剑，或弓与备用短剑 |
| 远古骷髅领主 | 远古金属板甲 | 远古金属剑、战斧或战锤 |

这些生物原有的固定防具槽始终有装备。每件防具、主武器和守卫备用短剑分别抽取材质；抽中低于或等于原始档位时保留原物品。板甲继续使用板甲，锁链甲继续使用锁链甲，武器保留原有类别，因此可以出现不同材质混搭。

## 与现有成长规则共用的数据

- 普通日使用存档记录的最高天数，与同一天数的血月共享材质档位与分布：第 64 天启用，第 320 天进入艾德曼主档，第 352 天进入振金主档。固定装备下限不变，不把普通怪物的半概率应用于这些固定槽。
- 主世界血月日期使用现有血月档位及材质分布，从第二次血月开始，第八次血月进入艾德曼优势档。铜、银继续视为同一级。
- 日期进度对整个新生实体只记录一次，装备实际结果写入原生装备 NBT。已存在的怪物不会随着经过天数、重载或跨维度自动更换装备。
- 只选择最终物品后调用一次来源装备生成器，沿用其品质、附魔、磨损和掉落处理。这里成长的是材质；不额外创造精良、传奇等品质抽签。
- 弓沿用已有材质映射，振金档使用振金弓。近战武器和板甲可升级至振金；没有注册振金锁链甲，锁链甲保留艾德曼上限。
- 下界的特殊凋灵型骷髅分支以原有铁剑为材质下限，也能升级；保留原有劣质品质及无固定防具配置。
- 材质成长不通过实体加入世界事件扫描并替换装备；原生带 NBT 的召唤、刷怪笼数据、存档加载及后续拾取装备均保留原生顺序和显式数据。日期附魔在新装备创建时处理，见 [日期附魔成长](mob-enchantment-progression.md)。

实现入口是 `SpecialMobEquipment`，只在上述生物原本创建来源装备的位置调用；普通怪物仍由 `BloodMoonEquipment` 管理。

## 手动测试

请在独立测试存档先测试早期，再测试后期。最高历史日期会保存，单纯调回时间不会降低已经解锁的进度。

1. 新存档早期，分别用以下不带 NBT 的命令生成目标，检查上表的装备下限：

   ```mcfunction
   /summon mite:bone_lord
   /summon mite:longdead_guardian
   /summon mite:ancient_bone_lord
   /summon mite:revenant
   /summon mite:longdead
   ```

2. `/time set 7674000` 到第 320 天夜间（第八次血月），重复生成多只目标，应能观察到高阶材质混搭，且没有皮革或普通铁甲替换远古金属装备。弓型守卫依旧能切换近战短剑。
3. `/time set 8466000` 到第 353 天夜间，重新生成目标，普通日期也应经常出现高阶防具及近战武器，并可能带有日期成长附魔。
4. 记录一只目标的装备，保存退出再重进，并继续推进日期。原有个体的装备、磨损和附魔应保持原值；新生成的个体才重新抽签。
5. 用带显式 `ArmorItems` 或 `HandItems` 的原生命令生成测试目标，指定物品、名称和耐久应保持原生行为。
