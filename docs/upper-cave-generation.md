# 高层细矿洞与地下含水区域调整

维护者：NingMeng123。日期：2026-10-22。

本项按用户反馈改善前期探索：保留 Minecraft 1.21.1 的地形生成器、山脉、生物群系与世界高度，在较高层增加接近旧版观感的狭窄自然通道，并减少地下含水区域。它是现代平衡调整，不是复刻 R196 的完整洞穴算法或同种子布局。

## 高层自然通道

`mite:upper_legacy_caves` 使用原生 `minecraft:cave` carver，通过 NeoForge `add_carvers` 附加到 `#minecraft:is_overworld` 群系，保留原有洞穴切割器。新增的是可分叉的自然细通道，不是带木架、铁轨、刷怪笼和箱子的废弃矿井；本项不提高废弃矿井结构生成率。

| 参数 | 当前设置 |
|---|---|
| 起点高度 | Y8～96，包含两端 |
| 起始概率 | 0.28 |
| 纵向比例 `yScale` | 0.4～0.7 |
| 水平半径倍率 | 0.65～0.9 |
| 垂直半径倍率 | 0.8～1.0 |
| 地板裁剪 `floor_level` | -0.9～-0.5 |

上述概率是原生切割器的起始检查，不表示每区块必有洞口，也不表示每个候选都能成功形成通道。高度限制的是路径起点；弯曲、上下延伸和分叉后的实际洞壁可能超过该区间。通道仍受原生地形、可替换方块及含水层判定约束，不保证固定宽度或全部干燥。

## 降低高层大洞占比

`UpperCaveNoise` 在已有数据生成入口中，对 `final_density` 中的 `minecraft:cave_cheese` 噪声节点增加正偏置，并把两处入口引用改为独立的 `mite:upper_cave_entrances`。该入口函数从原生 `overworld/caves/entrances` 复制，仅给内部的 spaghetti-3D 整体密度分支增加小幅正偏置，使高层噪声通道收窄；该分支内部的噪声、粗糙度和厚度参数原样保留。另一分支的 `minecraft:cave_entrance` 宽入口及自然洞口不增加偏置，不全局覆盖原版入口资源。

调整作用于 `overworld`、`amplified` 和 `large_biomes` 三个预设，按实际世界 Y 计算：

| 高度带 | cheese 噪声正偏置 | spaghetti-3D 分支正偏置 |
|---|---|---|
| Y≤-24 | 0 | 0 |
| Y-24～8 | 从 0 线性增加到 0.5 | 从 0 线性增加到 0.035 |
| Y8～80 | 0.5 | 0.035 |
| Y80～112 | 从 0.5 线性减小到 0 | 从 0.035 线性减小到 0 |
| Y≥112 | 0 | 0 |

重点是 Y8～80，边缘渐变避免直接切出水平分界。原生近地表路径可能绕过 cheese 分支，spaghetti-3D 也可能形成较大的空腔，不能把浅层大洞全部视为 cheese；因此只对这两个有明确目标的分支分别调整，而不对整个最终密度统一加值。新增原生 carver 提供额外细通道，不是关闭全部现代洞穴；深层大洞、其他噪声通道以及原生 carver 仍可出现。表面规则、气候路由和世界高度不因此替换为旧版。原有 `ore_veins_enabled=false` 继续生效，与本次洞穴平衡分开记录。

## 地下含水区域减少 60%

仅实际主世界的随机地下含水层启用减水。按世界种子和空间位置，把地下划为 64×40×64 的一致区域，独立抽样排除 60% 的可削减地下含水候选、保留 40%，地表水保护候选豁免；相邻区块使用相同规则，不随探索顺序或重进存档重新抽签，也不推进原生生成随机流。

修改点位于原生 aquifer 计算末尾的蓄水分支：只有本来有水的地下候选才可能变为空蓄水状态。原生地表水提前返回分支保持不变；此外沿用原生中央近似地表位置的 `preliminarySurfaceLevel + 8` 采样，保护地表水附近的含水层候选，避免削减海河水体。这是原生采样保护，不是完整的几何连通性搜索。内陆地下候选仍可削减，即使原生泛洪计算采用全局海平面作为水位；全局和局部岩浆均不削减。下界、末地、独立地底世界及其他维度不启用这项地下减水，即便它们复用同一噪声设置。

**60% 指可削减地下含水候选的抽样削减，不是每个洞穴各自删水 60%，也不是保证某个种子或有限样本的水方块体积恰好减少 60%。** 实际水量还取决于原生含水层、洞穴形状、区域交界和地表补水；地下仍会遇到含水洞穴。泉眼、玩家放水、桶操作和既有临时水规则不由本项重写。

## 生效与兼容范围

- 只影响尚未完成对应世界生成阶段的新区块；已有完整区块不回填小洞，不抽干既有水体。旧新区块交界处可能看出生成规则差异。
- 本体负责生成调整。Modern ITE 更新其依赖的 MITE: Modern 本体后即可继承，不需要在 ITE 中重复注入切割器或含水层规则。
- 新通道依赖主世界群系标签，cheese 偏置来自上述三个噪声预设。第三方自定义群系、维度和高优先级世界生成数据包仍按其实际标签与资源覆盖关系生效，不保证套用全部调整。
- 这不是矿石增产规则，不改矿物候选次数、高度配置或废弃矿井战利品。

## 复测要点

1. 使用同种子的新测试世界，在普通、巨型生物群系和放大化预设中对照 Y8～96 的自然通道；应可找到狭窄、弯曲和分叉路径，而不是只增加大型空洞。
2. 在 Y8～80 观察大洞占比降低，但不要求完全没有大洞；同时检查深层现代洞穴和地表山脉仍存在。
3. 探索多个未生成过的地下区域，检查仍有干洞和含水洞；海洋、河流及地下岩浆应正常，其他维度不套用减水。
4. 重进存档并从不同方向加载同一片新区块，确认生成结果稳定；回到已有完整区块，确认洞穴、水体和玩家建筑未被重写。
5. 安装 Modern ITE 并更新本体，在新区域检查相同行为；不要把旧区块没有变化判定为更新失效。

独立单元测试覆盖两类偏置的高度边界、其他 JSON 字段不变、负坐标区域划分和减水抽样；黄金比较在移除唯一 cheese 包装、还原两处入口引用与原有矿脉开关后，对照锁定版本的完整原版噪声设置。独立入口函数移除唯一 spaghetti-3D 分支包装后，也必须与完整原版入口 JSON 相等。`UpperCaveGenerationGameTests` 用于验证真实生成路径。自动测试不代表已完成客户端观感、前期探索难度或真实多人验收，运行结果另按实际日志记录。
