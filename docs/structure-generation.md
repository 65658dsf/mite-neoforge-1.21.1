# 村庄与相关结构生成

开发署名：NingMeng123。原作：Avernite。基准为本地 `MITE 1.6.4 R196.zip`，SHA-256 `fb7ad265d05749e0cd1e54938f6c36ecbe9ea1d4d90d4a04c519615e1e0218c3`。本批保留 Minecraft 1.21.1 的地形、洞穴、负高度和现代建筑模板。

## 已接入的规则

| 内容 | 实际行为 |
| --- | --- |
| 村庄解锁 | 主世界显示日期至少第 60 天，且全服至少完成过一次能采掘黑曜石的工具制作。正常路径包括铁镐、铁战锤及更高材质的对应工具。持有、拾取、战利品、合成预览和未完成的制作不解锁；自动合成器没有操作者，也不记录玩家制作进度。 |
| 日期 | 使用源显示日期 `(max(time,0)+6000)/24000+1` 的无溢出等价式，第 60 天从原始时间 `1410000` 开始。不能替换成原始时间除以 24000 再加一。 |
| 共享与保存 | `data/mite_structure_progress.dat` 持久化五个 `village_conditions` 位，所有玩家和维度共用。拾取小麦、胡萝卜、马铃薯、洋葱分别记录 1/2/4/8；前四位合计 15 仍不解锁，合格工具制作记录 16。死亡或换维度不会重置。已有现代存档在玩家登录时，依据其合格工具的真实 `ITEM_CRAFTED` 统计补记，背包物品不作为迁移依据。 |
| 村庄候选 | 区域间隔 40 区块，分离距离 20，salt 10387312；保留现代平原、沙漠、热带草原、雪原、针叶林五类村庄及其群系。 |
| 天然居民 | 村庄模板不生成村民、僵尸村民、猫或铁傀儡。普通实体生成、治愈僵尸村民、玩家后续建立村庄和铁傀儡召唤不受模板过滤影响。牲畜等现代模板内容保留。 |
| 农田 | 原模板每片相连的种植田格抽取一次种类：死小麦 1/2，死胡萝卜、死马铃薯、死洋葱各 1/6；每格原作生长阶段 2～6。覆盖现代处理器产生的瓜藤和附着瓜藤，死苗沿用既有不生长、不掉作物规则。 |
| 村庄制造与奖励 | 普通工作台改为燧石工作台；盔甲匠、工具匠、武器匠的奖励箱统一为源铁保险箱及 56 项奖励池。每箱抽取 3～8 次，总权重 302，随机槽位允许后项覆盖前项。装备平均品质，随机损耗为最大耐久的 0/10～6/10。天然保险箱无主人，生存模式不能直接打开；破坏可取得内容，箱体本身不掉落。 |
| 神庙与小屋 | 沙漠神殿、丛林神庙、女巫小屋采用 40/20、salt 14357617 的候选网格。前两者候选区块西北角距世界出生点水平距离至少 2000 格；女巫小屋不受该距离限制。 |
| 废弃矿井 | 源世界种子与区块随机流下 0.5% 候选，再受丘陵群系和 `nextInt(80)<max(abs(chunkX),abs(chunkZ))` 限制。坐标原点区块不会出现；80 区块之外距离抽签总能通过，但频率、群系及现代结构条件仍须满足。第 10 天前支撑处不生成火把，第 10 天起两侧各 5%，保留抽样消耗与现代支撑结构。 |
| 要塞 | 仅三座，围绕坐标原点，源候选半径约 10240～18432 格，再做 112 格优选群系搜索；无日期或制作门槛。使用源半径公式，不能只把现代结构集 distance 改成 512。建筑、地下高度和末地入口继续使用现代实现。 |

## 与旧版不同的明确适配

- 保留新版建筑布局、水渠、床、职业站和非铁匠类箱子。原作农田矩形田块映射为现代模板相连田格；随机处理器改变种类、高度或跨区块裁剪时仍使用原田块身份。干草块、西瓜块、南瓜块等装饰保持原样。
- 源奖励耐久使用全局 `Math.random`；现代实现改用结构奖励种子，仍保持离散均匀的七种损耗。不会承诺旧版同种子、同建筑或同箱子内容一致。
- 矿井丘陵映射为现代丘陵、山地、林地坡面、高原等明确群系标签，并保留恶地矿井变体。普通平原、森林、沙漠和地下洞穴群系本身不构成丘陵资格。
- 现代下界要塞布局、新版独立结构、已完成的地底世界试炼密室与怪物房保留。本批没有把所有结构的战利品都改成 R196。
- 不提供旧版竞赛模式。管理员 `/place structure` 可绕过自然生成门槛，但放置村庄时仍适配村庄内容；直接 `/place template` 保留独立模板原样。

## 生成、定位与线程边界

自然结构入口和 `/locate` 使用相同门槛。未解锁的村庄定位直接返回无结果，不扫描并预先锁死大批候选区块；可变日期、制作位与出生点距离不写入原版永久候选缓存。服务端主线程预先载入共享存储并发布不可变快照，生成线程只读快照。时间指令、睡眠、出生点指令及新世界首次寻找出生点都会及时发布快照；停服时清理实例缓存。

**只影响尚未生成结构的新区块。** 已建成的村庄不会被拆除，已完成结构生成的空区块也不会在解锁后补出村庄。旧存档测试时应向未探索区域定位和移动。

## 手动测试

重启测试客户端后，建议使用独立测试存档，开启指令。以下内容由玩家手动确认；自动化通过不能替代客户端观感检查。

1. 新存档未制作合格工具时，先执行 `/locate structure minecraft:village_plains`，应找不到；执行 `/time set 1416000` 后仍找不到。用工作台实际制作一次铁镐，再定位应可找到符合现代群系的村庄。仅 `/give @s minecraft:iron_pickaxe` 不应解锁。可用 `/give @s mite:iron_crafting_table` 准备测试工作台，以及 `/tick rate 200` 加速制作；测完用 `/tick rate 20` 恢复。
2. 传送到定位村庄，检查无人、农田为死苗、工作台为燧石工作台，现代房屋和水渠仍存在。铁匠类房屋是铁保险箱；用生存模式直接打开应被拒绝，用合格工具拆除应掉箱内物品且不掉箱体。没有铁匠房的村庄可换一座测试。不要把仅有一两件奖励当作错误，随机写入同一槽可覆盖已有奖励。
3. 保存退出、重新进入后再定位新的村庄，验证制作进度仍保留；多人环境可由另一位没制作工具的玩家尝试定位，应该共享解锁。死亡和去地底世界后返回也不应清空进度。
4. `/locate structure minecraft:desert_pyramid` 和 `/locate structure minecraft:jungle_pyramid` 的自然候选应在世界出生点 2000 格之外。`/locate structure minecraft:swamp_hut` 无该距离限制。条件从世界出生点计算，不能只看结构到当前玩家的距离。
5. `/locate structure minecraft:stronghold` 通常会给出距离原点约 1 万～1.8 万格的位置。矿井使用 `/locate structure minecraft:mineshaft`，在丘陵、山地或恶地等适配群系查找。观察新矿井的火把日期规则时要使用尚未放置过结构的区域；已生成火把不会随改时间消失。
6. 用 `/locate structure minecraft:trial_chambers`，并检查地底世界既有密室、怪物房仍可正常生成。管理员需要直接检查村庄内容时，可在测试区域执行 `/place structure minecraft:village_plains`；此指令不验证自然解锁条件。
