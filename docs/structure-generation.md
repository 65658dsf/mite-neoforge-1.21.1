## 与旧版不同的明确适配

- 保留新版建筑布局、水渠、床、职业站和非铁匠类箱子。原作农田矩形田块映射为现代模板相连田格；随机处理器改变种类、高度或跨区块裁剪时仍使用原田块身份。干草块、西瓜块、南瓜块等装饰保持原样。
- 源奖励耐久使用全局 `Math.random`；现代实现改用结构奖励种子，仍保持离散均匀的七种损耗。不会承诺旧版同种子、同建筑或同箱子内容一致。
- 矿井丘陵映射为现代丘陵、山地、林地坡面、高原等明确群系标签，并保留恶地矿井变体。普通平原、森林、沙漠和地下洞穴群系本身不构成丘陵资格。
- 现代下界要塞布局、新版独立结构、已完成的地底世界试炼密室与怪物房保留。本批没有把所有结构的战利品都改成 R196。
- 不提供旧版竞赛模式。管理员 `/place structure` 可绕过自然生成门槛，但放置村庄时仍适配村庄内容；直接 `/place template` 保留独立模板原样。

## 生成、定位与线程边界

自然结构入口和 `/locate` 使用相同门槛。未解锁的遗迹定位直接返回无结果，不扫描并预先锁死大批候选区块；可变日期、探索计数、制作位与出生点距离不写入原版永久候选缓存。主世界化石走独立 Feature 入口限制，怪物房入口保持不变。服务端主线程预先载入共享存储并发布不可变快照，生成线程只读快照。时间指令、睡眠、出生点指令、完成制作、探索行为、进入地底及新世界首次寻找出生点都会及时发布快照；停服时清理实例缓存。

自然补怪执行实际命中的结构 `spawn_overrides`。主世界和地底试炼密室按组件范围、远古城市按完整结构范围抑制空列表对应类别的自然生成，范围覆盖原版、MITE 和 ITE 追加候选。下界要塞保留地狱砖地面加完整结构包围盒的原生判定。试炼刷怪笼和监守者使用各自的专用生成入口。

**只影响尚未生成结构的新区块。** 已建成的结构不会被拆除，已完成结构生成的空区块也不会在解锁后补出结构。旧存档测试时应向未探索区域定位和移动。

废弃传送门和掠夺者前哨站解锁后，与村庄一样通过聊天栏发送带当前日期的提示：废弃传送门为金色，前哨站为红色。服务端约每秒检查一次，只有结构生成已开启、对应生成集合存在且全部条件满足时才发送。每名玩家各收到一次，记录随玩家保存，重登、死亡重生、跨维度及回调日期不会重复；首次进入已解锁世界的玩家会补收到提示。已有村庄和末地提示记录不妨碍接收这两条新提示。

## 在 MITE 进度页查看条件

进度界面顶部标题及书本页签标题统一为 **MITE**。原有成长进度继续保留，“结构解锁”分支列出全部 21 类受限遗迹。分支在登录时可见，尚未解锁时也能提前查看；悬停图标可阅读开启结构生成、全服共享、具体日期、制作和探索条件，以及只在新区块生效的说明。怪物房和两种试炼密室不列为新解锁条件。

每个条件使用独立进度项，原生提示会显示已满足条件的数量。服务端约每秒更新一次，并在登录时同步；世界日期与共享制作、地底访问记录都使用实际生成门槛。条件全部满足后节点完成；如果管理员回调日期或关闭对应结构生成，结构节点会恢复为未完成，原有解锁聊天提示仍按玩家保存记录去重。结构分支不额外发送原版进度聊天或弹窗，避免与现有解锁消息重复。

悬停遗迹图标还会显示服务端同步的日期、条件勾选和每项累计当前值／目标值。距离保留两位小数，例如沉船目标为 `500.01` 格；客户端只展示计数，生成资格始终由服务端判定。

## 手动测试

重启测试客户端后，建议使用独立测试存档，开启指令。以下内容由玩家手动确认；自动化通过不能替代客户端观感检查。

定位神庙、矿井等结构前，先按“结构解锁”进度完成新增探索条件；只修改日期不会代替这些条件。

1. 新存档未制作合格工具时，先执行 `/locate structure minecraft:village_plains`，应找不到；执行 `/time set 1416000` 后仍找不到。用工作台实际制作一次铁镐，再定位应可找到符合现代群系的村庄。仅 `/give @s minecraft:iron_pickaxe` 不应解锁。可用 `/give @s mite:iron_crafting_table` 准备测试工作台，以及 `/tick rate 200` 加速制作；测完用 `/tick rate 20` 恢复。
2. 传送到定位村庄，检查无人、农田为死苗、工作台为燧石工作台，现代房屋和水渠仍存在。铁匠类房屋是铁保险箱；用生存模式直接打开应被拒绝，用合格工具拆除应掉箱内物品且不掉箱体。没有铁匠房的村庄可换一座测试。不要把仅有一两件奖励当作错误，随机写入同一槽可覆盖已有奖励。
3. 保存退出、重新进入后再定位新的村庄，验证制作进度仍保留；多人环境可由另一位没制作工具的玩家尝试定位，应该共享解锁。死亡和去地底世界后返回也不应清空进度。
4. `/locate structure minecraft:desert_pyramid` 和 `/locate structure minecraft:jungle_pyramid` 的自然候选应在世界出生点 2000 格之外。`/locate structure minecraft:swamp_hut` 无该距离限制。条件从世界出生点计算，不能只看结构到当前玩家的距离。
5. `/locate structure minecraft:stronghold` 通常会给出距离原点约 1 万～1.8 万格的位置。矿井使用 `/locate structure minecraft:mineshaft`，在丘陵、山地或恶地等适配群系查找。观察新矿井的火把日期规则时要使用尚未放置过结构的区域；已生成火把不会随改时间消失。
6. 用 `/locate structure minecraft:trial_chambers`，并检查地底世界既有密室、怪物房仍可正常生成。管理员需要直接检查村庄内容时，可在测试区域执行 `/place structure minecraft:village_plains`；此指令不验证自然解锁条件。
7. 用独立新存档验证废弃传送门：未进过地底时，即使 `/time set 738000`，`/locate structure minecraft:ruined_portal` 仍无结果；实际进入地底并返回后，第 32 天起可以寻找。已访问地底但 `/time set 737999` 时仍锁定；下界废弃传送门使用相同条件。
8. 用独立新存档验证前哨站：`/time set 1050000` 后，仅制作弓或仅制作秘银装备仍无法定位 `minecraft:pillager_outpost`。两项均实际完成后可在新区域寻找；`/time set 1049999` 时仍锁定。仅给予、拾取或预览对应物品不会解锁。保存重进并换另一名玩家检查共享进度。
