# 方块材质的破坏门槛

开发署名：NingMeng123。基准：MITE 1.6.4 R196；本页记录规则与验收入口，不代表用户已完成游戏内测试。

`uf.java:775–833` 在手持物对目标无效时退回空手；`akc.java:324–325` 的判断是材质 `requires_tool` **或者**方块最低采集等级大于零。空手强度因此为零，方块本体不能被破坏，不能仅仅取消掉落。工具的实际生效条件继续沿 `xj.java:126–142` 的材料/目标匹配与采集等级比较。

`ToolHarvestRules` 同时保护客户端/服务端的破坏进度和最终 `BlockEvent.BreakEvent`。现有矿物、金属储物块、金属门、原木及非主人保险箱的专属门槛继续生效；创造/旁观权限与不可破坏硬度仍使用已有入口。高等级、急迫和单独调用服务端 `destroyBlock` 均不能绕过工具资格。

原版可空手采集的方块允许空手或持普通物品破坏，包括整块玻璃、玻璃板、潜影盒和滴水石锥。方块的工具加速标签及材料等级继续参与工具效力判定。原木仍需合格的斧类，石类、砂岩、陶瓦等继续检查有效工具及采集等级。冰和雪可以空手破坏，掉落由各自的原版规则决定。普通玻璃、染色玻璃和玻璃板仍需精准采集才会掉落自身，遮光玻璃空手即可掉落自身。

不能把所有现代“适合用镐”标签当作来源的“必须用工具”：R196 的按钮、铁轨、活塞、煤炭块、萤石、红石灯、花盆及寄生石等没有材质工具要求。它们保留空手资格；此区别由实际构造器及 `reference-data/runtime-registry.json` 的 `aqz.min_harvest_level` 核对。便携方块先走便携规则，不能被普通石质门槛挡住。

`SourceMiningGameTests` 遍历原版可空手采集的默认方块状态，检查空手和木棍的实际破坏进度，并用生存玩家验证玻璃的服务端移除与掉落。硬质方块用例覆盖高等级玩家的空手、木棍与错误工具，检查无破坏进度且最终破坏事件被取消。砂岩用例验证合格的燧石斧仍可正常采集。

生存模式下，空手和手持木棍或镐均可打碎玻璃。用附有精准采集的镐打碎普通或染色玻璃时会掉落玻璃本身。石头、圆石和下界岩需要合格的镐，原木需要合格的斧类。按钮、铁轨、萤石、煤炭块保留空手采集资格。
