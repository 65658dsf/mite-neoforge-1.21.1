# R196 特殊作物与菌类

开发署名：NingMeng123。规则基准为本地 `MITE 1.6.4 R196.zip` 中的实际默认启用代码，未把新版附加作物套成旧版作物。

### 茎的细节

- 南瓜最佳温度为 0.6～1.0，西瓜为 1.0～1.4，超出范围后按一度容差线性降速。只有西瓜在高湿环境有 1.2 倍修正；全局生长倍率为 0.25。
- 中心耕地湿度为零时增长率为零。施肥倍率 1.5，每次确实进入生长/结瓜处理后有 1/256 概率损失肥力；不会重复使用普通 CropBlock 的倍率。
- 增长率为零并且耕地周围没有源代码认可的水/冰/雪水源时，每次更新有 5% 概率枯死；这不是简单的“耕地湿度为零就死亡”。
- 成熟茎还有一次 1/2 结瓜门槛，旁边已经有同种果实便不会再结；成功生成果实时有 10% 概率耗尽并枯死。
- 枯死茎仍留在地上，颜色按原版 R196 黄色褐色公式计算，不能用骨粉复活；移除果实不会把死亡状态清空。
- 植物状态直接保存在原版方块状态中，包含客户端同步与存档；现代连接茎也带有相同死亡位。使用原版新版本模型，不引入另一套同步账本。
- 不开放骨粉催熟茎。`aqq.fertilizeStem` 虽含增加二至五阶段的辅助方法，但实际 `xl.tryFertilize` 只分派给草方块及 `anr` 普通作物；`aqq → BlockGrowingPlant → BlockPlant → aqz` 不属于 `anr`。`aof.fertilize` 的相应染料分支同样没有默认物品调用链，不能把这个未启用方法当成实际玩法。正常骨粉入口不消费物品，直接调用现代 `performBonemeal` 也不推进茎。
- 蓝莓 `BlockBush` 与茎采用同样的 `BlockGrowingPlant` 父类链；其名为 `fertilize` 的一至二阶段方法也不属于默认骨粉分派对象，因此同样禁用。普通甜浆果仍保留现代自己的骨粉行为。
- 种子回收按源码：只有玩家破坏年龄零、健康的茎才返还一粒，生长后、枯死后以及支撑物损坏均不返还种子。

### 蘑菇与肥料

“户外”使用既有 `R196OutdoorChecks` 的短路径可达露天判断，并不等同于头顶直接可见天空。

- 主世界的蘑菇都需要避开直接天空。褐蘑菇的合法底材为石头、砂砾、泥土、耕地或菌丝，原始光照不超过 13；放置要求处于室内。
- 红蘑菇的底材为草方块，放置要求处于户外附近，但周围三乘三内的可通行格不能直接见天。因此它是靠近露天处的遮阴草地植物，不能把它理解成无遮蔽太阳下的蘑菇。
- 褐蘑菇培养菌丝要求底下是湿润且施肥的耕地、室内、原始光照不超过 13；培养发生在自然随机更新中。
- 巨型褐蘑菇要求菌丝、室内；巨型红蘑菇要求草方块、户外附近。前两次有效处理只保存进度一和二，第三次才调用现代巨型蘑菇配置特征。生成失败时保留阶段三，可再次尝试。
- 不使用骨粉催生蘑菇。粪便点击合适的蘑菇或红蘑菇下方草方块，有 50% 概率推进一次巨型化，正常消耗一份；直接点击下方菌丝的上表面经过 `apk.fertilize` 路径，没有额外 50% 门槛。
- 点击耕地上的褐蘑菇仍交给耕地施肥处理，两个事件处理器不会同时消费粪便。所有处理遵守取消事件、物品禁用、冷却、旁观者与放置权限。
- 蘑菇巨型化进度使用 `mite_growth=0..3` 方块状态保存；新放置蘑菇从零开始。菌丝允许巨型蘑菇的茎/菌盖作为上方方块，不会在巨型化后错误失效。

## 现代适配及范围

- 保留 1.21.1 的原版主世界生成器与高度，所有位置扫描使用真实世界高度；仙人掌坐标哈希允许负数 Y，使用 R196 同步消耗顺序构建种子 RNG 表，不读取旧版固定高度数组。
- 现代恶地继续支持仙人掌种植，作为没有旧版直接对应物的生物群系适配；沙漠是旧版主要生境。保留现代红沙、新增甘蔗底材、相邻霜冰水合，以及 NeoForge 土壤扩展。可可支撑继续接受现代 `JUNGLE_LOGS` 标签中的丛林木头与去皮方块，叶冠限制仍按旧版。
- 巨型蘑菇调用现代原生配置特征和 NeoForge `BlockGrowFeatureEvent`。新增的生长判定保留 `CropGrowEvent` 的前后钩子，方便其他模组对正常生长作允许或否决。
- 甜浆果、发光浆果、火把花、瓶子草及其他新版新增植物保留现代行为；它们没有 R196 源机制。本轮不修改森林生成、树苗或大型植被生成。
- 蘑菇、甘蔗、茎、可可、下界疣和仙人掌继承源植物爆炸不掉落规则。具体作物收获、果实产出和统一积雪处理由普通作物生命周期模块记录；此模块不独立重写天气积雪生成。

## 验证入口

- `SpecialPlantRulesTest`：最佳温区、湿度、甘蔗两次概率边界、枯死茎颜色、独立 48 位 LCG 对照的仙人掌种子表与负坐标。
- `SpecialPlantGameTests`：真实茎死亡/存档/拒绝骨粉且不消费、蓝莓拒绝骨粉且不消费、结瓜死亡和拆瓜保留死亡、甘蔗实际天空条件（石头与叶子阻挡、玻璃透天）、可可叶冠/收获/骨粉、褐蘑菇培养与三步进度、菌丝萌发/浸水腐化、真实粪肥事件单次消耗、下界疣实际 1/40 更新及跨维度自毁。
- 测试结果由主任务统一运行记录；此文档不把尚未执行的用例写成通过。
