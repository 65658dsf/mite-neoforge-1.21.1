# 玩家近战、触及与空手反伤

开发署名：NingMeng123。来源基准为本地 R196，本文只记录这三项已选实现；旧工具格挡不在本次范围内。

## 等级近战

`uf.java:558–563` 的近战等级修正为：正等级 `0.005 × 等级`，零及负等级 `0.02 × 等级`。原公式没有独立裁剪，但 `uf.java:520–538` 的自然等级最高为 200，因此原作近战等级倍率最高为 2。2026-10-18 按用户补充要求，现代实际等级继续增长，近战收益最多按 200 级计算；保留负等级修正。

`uf.java:1041–1072` 的实际顺序是：正的攻击属性 → 暴击 1.5 倍 → 等级倍率 → 银制打亡灵 1.25 倍 → 木棒/短木棒/战锤打骷髅 2 倍 → 加附魔伤害 → 悬浮在液体中且伤害大于 1 时压缩为 `1 + (伤害−1)/2`。技能默认关闭；未把默认关闭的格斗技能当成必需条件。`nn.java:2294–2345` 中 `getBlockRestingOn` 实际忽略参数并转到 `getBlockRestingOn3`，后者在不着地时直接返回空，因此悬浮判定实际等价于未骑乘、未着地且处于水/熔岩。

保留新版攻击冷却与 NeoForge 暴击事件。`SourceEnchantmentPlayerMeleeMixin` 读取已冷却/暴击的基础伤害与独立附魔项，把 R196 材料修正延后到等级之后，按上述顺序计算。附魔增伤不会再被等级、暴击或材料乘一次。新版横扫保留，使用同一个最终主攻击基数，每个副目标仍须满足本次近战触及；横扫额外击退延后到该目标实际损失生命或吸收后执行，避免超距或受伤免疫拒绝伤害时仍被横扫推动。

## 触及

来源：`uf.java:1971–2039`、`yc.java:937–958`、`Raycast.java:461–484`。

| 操作 | 生存基础值 | 判定点及加成 |
|---|---:|---|
| 方块采集/使用 | 2.75 | 方块中心到眼睛下方 0.625 或 0.25 两点之一；仅对当前方块有效且满足采集等级的工具加触及 |
| 近战 | 1.5 | 眼睛到实体碰撞点；加主手触及及双方脚下高度差修正 |
| 实体交互 | 2.5 | 眼睛到实体碰撞点；加高度差，不加工具触及 |

高度差在 `[-0.5,0.5]` 内为零；超出部分每格增加/减少 0.5，修正限制在 `[-1,1]`。`sq.java:433–435` 使船的交互距离固定 2.5；`uj.java:289–291` 使火球近战触及另加 2。创造模式三种操作的基础距离为5格，覆盖高度及这些特殊目标修正，近战最终距离再加当前等级奖励。

方块工具触及沿用 `MiteTools.Definition`。木棍、骨头近战加 0.5，但并非有效挖掘工具。现代石、钻石、下界合金工具按对应 R196 工具类别取同一触及值。现代三叉戟和重锤按近战武器保护主手。三叉戟在无 Better Combat 与安装后的中立距离分别为 2.75 和 3.25，重锤分别为 1.75 和 2。方块工具触及仍按当前方块有效性判断。有效性同时核对 `SourceMiningRequirements` 的真实材质门槛，现代通用 Tool 组件声称“能挖”不能绕过高阶金属块要求。新版副手使用方块时检查副手工具，挖掘和普通近战只看主手；Better Combat 双持攻击使用当前实际挥击的手。副手没有实体交互触及加成。

客户端保留新版碰撞/遮挡射线，按 R196 的 16 格选择射线先选最近碰撞，再用共用规则过滤。可交互但不可近战的实体仍能被选中，实际点击会按操作再次判断。服务端包分开验证攻击、普通交互和具体交互坐标；具体坐标必须有限且处于目标碰撞箱。服务端没有可信客户端射线时，普通交互/近战使用目标可选碰撞箱的最近点作为现代延迟容差，不添加原版额外一格距离。方块开始挖掘、完成采集、右键使用均重新验证当前手持物，防止中途换工具或移远后完成。远距离伪造方块坐标在读取区块前拒绝。

外部模组主动修改的原版范围属性以相对 1.21.1 默认值的增量保留；旧存档中可能显式保存的 `mite:tool_reach` 属性会扣除，避免与新目标规则叠加。R196 工具默认不再持有无条件的两种范围属性。

持相同近战武器的敌对生物使用玩家等价距离计算，在全部配置修正后额外缩短 0.2 格，并与原有更短的怪物限制取交集。怪物寻路、准备挥击及最终命中均检查该限制，普通空手与远程攻击不受影响。

### 等级近战距离

2026-11-14 起，玩家按当前 `experienceLevel` 每满5级增加0.1格近战距离，50级及以上增加1格，负等级奖励为0。升级或消费经验、死亡等原因导致降级时，奖励随当前等级实时重算。安装与未安装Better Combat均适用，生存、冒险、创造等玩家模式使用同一等级奖励。

等级奖励在原有距离倍率和固定扣减完成后相加。最终近战距离为 `原有最终距离 + min(max(floor(当前等级 / 5), 0), 10) / 10`。武器表记录0级基础距离。

### Better Combat 玩家距离

本体普通剑在安装和未安装 Better Combat 时均采用低版本同高中立距离 2.25 格，简易刀剑长剑在两种模式下均为2.5格。人物额外范围、高差和距离设置继续参与计算。其余武器按是否安装 Better Combat 读取各自的类型表。MITE 匕首两种模式均为 2 格，来源镰刀分别为 2.5 和 3.25 格。简易刀剑长柄刀分别为 2.75 和 3.5 格，弯刀为 2 和 2.1 格，长矛为 3 和 3.75 格。2026-11-14 按用户要求，巨剑、巨斧、巨锤两种模式均为3.25格，环刃均为2.8格，钗均为2格。没有显式范围组件时，类型预算与解析出的原始范围取较小值，因此第三方缩短动作距离仍生效。完整伤害、攻速及双距离表见[装备与武器平衡](equipment-balance-2026-10-24.md)和[简易刀剑平衡表](equipment-balance-simplyswords-2026-10-24.md)。

所有带主手攻击伤害的近战武器与工具在两种模式下均显示本模组的“有效近战距离”。提示读取当前悬浮物品的有效属性、对应模式类型表和距离配置，支持旧存档属性组件和连续切换悬浮物品。基础数值按生存模式同高规则计算，世界内提示加入当前查看玩家的等级奖励，无玩家上下文时显示0级基础值。实际攻击继续考虑目标高差等修正。武器长度独立于普通实体交互范围，弓弩和盾沿用各自的提示路径。

此前触及实现的验证记录为 50 项相关 JUnit 通过；Simply Swords 存在、Better Combat 缺席及存在两种组合，各 20 项专项 GameTest 通过，包括铁剑/铜剑真实攻击包、简易刀剑长武器的命中边界、属性组件、配置、高差及怪物限制。238 把受管理简易刀剑武器与 Better Combat 实时注册数据逐一对照，补齐原生材料战镰缺少 JSON 时的战镰预设长度。客户端提示事件检查在无 Better Combat、有 Better Combat、两个扩展均缺席的组合中分别通过 18、18、9 项，覆盖新物品、旧属性组件及切换悬浮目标。客户端检查跳过需要游戏窗口的上游属性排版和简易刀剑按键说明，仅验证真实 `ItemStack.getTooltipLines` 最终事件及新增距离文本数值，未进行画面或人工操作验收。

简易刀剑范围优先遵循物品的显式实体范围属性。没有该组件时，先解析绝对范围或 `range_bonus`，再与当前模式的类型预算取交集，外部增量只计算一次，资源包缩短范围同样生效。Better Combat 当前招式的 `rangeMultiplier` 和体型范围继续作为独立限制；短招式不会借用更长的基础距离。两套距离在生存模式都先应用倍率、再扣固定值，随后加入当前等级奖励。创造模式的 MITE 近战基础上限为5格，最终加上同一等级奖励，并继续参与Better Combat对应范围限制的校验。

客户端在 Better Combat 的扩展范围计算后应用设置，同时扩大候选实体查询及选择射线，最终候选再按对应武器的 MITE 距离规则过滤。服务端在真实 Better Combat 请求内保存交换主副手前选定的武器和招式，同时验证眼睛到目标可选碰撞箱的 MITE 距离、肩部射线起点到目标碰撞箱的 Better Combat 距离；双持和连击不会借用另一只手或另一招的范围。普通原版攻击包和直接调用 `Player.attack` 不会借用已完成请求的招式范围。空手或没有武器攻击配置时继续使用原规则。Better Combat 持械怪物复用同一基础距离规则，简易刀剑长兵器同样保留长度差异。

同时修正 Better Combat 2.4.0 的碰撞箱分离轴零值判断：平行轴的叉积可能为 `(0.0, -0.0, 0.0)`，其 `Vec3.equals(Vec3.ZERO)` 为假，原算法随后把两个零长度投影错误判断为分离，造成已经重叠的挥砍箱漏选目标。兼容 mixin 仅按 `lengthSqr() == 0` 跳过零轴，保留原有非零轴、角度、射线遮挡和实际距离限制。真实客户端回归覆盖四个正方向及两个斜向的范围内、范围外目标。

伐木附魔的额外垂直原木属于服务端已经验证的内部采集。主原木仍须正常触及；每个附加位置只在原事务成功、原木类型、附魔次数、手持物及世界权限通过后取得精确位置的单次许可。许可在进入真实破坏事件前消耗，并在返回/取消/异常时清空；网络开始/停止包、普通手动破坏及事件重入均不能复用。附加采集继续经过原版破坏事务、保护事件、掉落和独立工具磨损。

## 弱击和手部损伤

`yc.java:1527–1529`、`of.java:2234–2236`：工具基类 `xj`、木棍和骨头保护主手。拿着普通物品、弓或方块不等于保护。现代工具通过既有耐久工具注册适配；副手木棍和盾不保护挥击的主手。

`uf.java:2540–2542`：没有保护主手，且生命严格小于 2、食物能量耗尽、或攻击属性严格小于 1 时只能弱击。食物能量沿用既有 R196 饱食/营养资源，不把原版饱和度误当能量。`of.java:607–616`：弱击保留普通击退的 0.6 倍，NPC 再取原版 R196 0.8 倍、土元素再取 0.4 倍；不进入生命损失、吸收、护甲磨损或受伤免疫事务。现代击退事件及抗性保留。允许攻击尝试的耐力消耗继续由既有 `EnduranceMeleeMixin` 负责。

`og.java:1502–1520`（已核对字节码）的目标回调发生在主伤害返回后、附魔触发前，即使目标免疫或仅被弱击仍执行。无保护主手时：普通生物仅在以攻击者为目标且攻击者非弱击时有 12.5% 手伤；史莱姆/岩浆怪/胶质怪先取 100%；随后若正以攻击者为目标且攻击者非弱击，概率又被独立的 `else if` 覆盖为 12.5%。烈焰人与火元素始终为 100%。手伤为 1，岩浆怪为 2，胶质怪按种类为 2/3/3/4；与体型无关。即使概率为零也消耗一次目标随机数。

`nb.java:179–183` 将手伤标为不可格挡、绕过普通护甲，保留防护附魔/药水；`mite:hand_damage` 使用同一正常伤害管线，护甲不因手伤磨损。`EntityGelatinousCube.java:377–381` 还在手伤之后腐蚀主手物品，该回调已从旧的“hurt 成功才腐蚀”位置移到实际主近战回调，覆盖免疫目标及弱击；普通史莱姆沿用胃液、四类胶质怪沿用各自化学类型。

弱击沿用原生击退事件、抗性及玩家友伤规则；只有实际改变了速度时才标记原生 `hurtMarked`，由 `ServerEntity.broadcastAndSend` 将速度同步到受击玩家自己的连接。不会为同步而扣生命或添加受伤免疫帧；取消及完全抗性不产生错误速度包。
