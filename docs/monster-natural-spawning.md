# 怪物自然刷新率

开发者：NingMeng123。更新：2026-10-20。

MITE 玩法设置首页的“怪物自然刷新率”从当前实体注册表发现怪物，包含原版、MITE 及未被扩展接管的其他模组怪物。MITE 的蝙蝠和恐狼使用现有物种注册元数据识别，避免漏掉原生类别为环境生物或动物的敌对生物。列表不维护另一份怪物 ID 白名单。

安装 ITE 时，`modern_ite` 的实体由 ITE 设置页中的“ITE 怪物自然刷新率”管理，MITE 页不重复列出。两页共用搜索、分页、百分数校验、还原及草稿保留逻辑；联机读取各自服务端同步值，客户端不可保存。

## 数值含义

每行显示当前生成器和生物群系注册数据中的基础池权重；ITE 页读取其实际 `spawnWeight`，包含原有四项刷新频率覆盖。没有独立池条目的变种显示“由原有条件或变体规则决定”，不伪造统一的默认概率。

- `100%`：保持原权重；`50%`：该物种权重减半；`200%`：该物种权重翻倍。
- `0%`：禁止后续自然生成该最终物种，保留已有怪物。
- 范围为 `0–10000%`，TOML 内保存为 `0–100` 倍；小数倍率参与小数抽签，不会因整数舍入直接消失。
- 倍率调整相对抽选权重。若池中两种怪原权重均为 100，其中一种设为 50%，它的抽选份额是 `50 / (50 + 100)`，并非绝对刷新概率 50%。全部怪物同时翻倍不会增加全局刷怪额度。

原有的日期、维度、深度、光照、户外限制、族群、人口密度及怪物上限继续执行；倍率不会为没有自然入口的 Boss 创建新入口。自然调度覆盖主世界、下界、末地和 MITE 地底。第三方维度未新增抽选倍率接入。刷怪笼、试炼地牢、刷怪蛋、指令以及其他非 `NATURAL` 原因保持原有规则。

## 变种和替换

地狱爬行者、巨型吸血蝙蝠、长亡灵守卫、下界凋零骷髅和僵尸村民分别按最终身份的倍率计算；ITE 自然猪人转为猪人领主的分支同样受 ITE 设置控制。仅把父种设为 0 不会顺带关闭仍启用的变种，变种设为 0 也不会从父种转换途径漏出。

原有父种池权重为 `w`、变种概率为 `p`，配置父种倍率 `a` 和变种倍率 `b` 时：

```text
该族候选权重 = w × ((1 - p) × a + p × b)
该族选中后变种概率 = p × b / ((1 - p) × a + p × b)
```

两边都为零时不参与抽签。未修改设置时使用原整数抽签和原变种随机流程，保留默认随机序列。新自然怪入世界时再按最终实体 ID 校验零倍率；已有自然怪及其跨维度复制通过持久标记识别，不会因修改刷新率而被移除。

## 文件与导出

MITE 的已修改项位于 `config/mite-common.toml`：

```toml
[monster_spawning]
rates = ["minecraft:zombie=0.5", "mite:giant_vampire_bat=2.0"]
```

ITE 项位于 `config/modern_ite-common.toml`：

```toml
[GameMechanics.MobSpawning]
natural_spawn_rates = ["modern_ite:zombie_chaos=0.5"]
```

省略的实体沿用倍率 1；未知或暂未安装的实体 ID 保留。保存各页后回到 MITE 首页，点击右上角“导出配置”，安装 ITE 时会把两份配置写进同一导出目录。将成功清单中的全部 TOML 文件放进服务端 `config/`，重启服务端即可使用。
