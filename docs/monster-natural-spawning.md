# 怪物刷新权重

开发者：NingMeng123。更新：2026-10-22。

MITE 玩法设置首页的“怪物刷新权重”从当前实体注册表发现怪物，包含原版、MITE 及未被扩展接管的其他模组怪物。MITE 的蝙蝠和恐狼使用现有物种注册元数据识别，避免漏掉原生类别为环境生物或动物的敌对生物。列表不维护另一份怪物 ID 白名单。

安装 ITE 时，`modern_ite` 的实体由 ITE 设置页中的“ITE 怪物刷新权重”管理，MITE 页不重复列出。两页共用搜索、分页、数值校验、还原及草稿保留逻辑；联机读取各自服务端同步值，客户端不可保存。

## 直接修改生成权重

从“模组设置 → 怪物刷新权重”进入物种列表，直接填写怪物的候选池权重。页面仅提供权重输入；ITE 的物种在“ITE 设置 → ITE 怪物刷新权重”中操作。分页、搜索和调整窗口大小均保留草稿，保存后下一次自然刷怪抽签立即使用新值。

- 权重为 `0–1000000` 的整数，留空或还原表示继承原有候选池权重；同一物种在不同原有候选池中都采用所填数值。
- 权重用于同一候选池中的相对比较。例如同池两种怪物权重分别为 50 和 100，其抽选份额分别为三分之一和三分之二；权重 50 不表示固定 50% 的刷新概率。
- 权重 `0` 关闭该候选池条目，也会关闭由该候选转换出的分支；已有怪物不会被清除。
- 无独立自然候选的变种或 Boss 不会因填写权重获得新的自然生成入口，其候选权重不可编辑；变种继续遵守原有转换路径。原有日期、维度、光照、距离和总量限制继续生效。
- 多个原始权重会继续列出供参考。未修改权重、或填写与当前候选原始值相同的数值时，保留原有整数抽签及随机序列。

所有权重草稿一起验证、保存和同步，任意一项无效时不会部分保存。已有怪物、刷怪笼、试炼、刷怪蛋和指令生成不受候选权重影响。

旧版配置文件中的倍率仍兼容读取，但设置页不再提供倍率编辑。未编辑的物种保留其旧设置；填写或还原某个物种的权重时，会同时清除该物种的旧倍率，让新输入的权重按当前数值生效。

## 上限与刷怪节奏

进入“模组设置 → 怪物刷新权重 → 上限与刷怪节奏”，可以修改自然刷怪总量和调度参数。页面支持分页、还原默认值、数值校验；切换页面或调整窗口大小时保留未保存草稿，点击保存后统一应用。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| 普通日期基础上限 | 105 | 每 289 个有效区块的怪物额度，0 禁止对应日期的自然怪物补充（启用日增后仍会增长） |
| 血月基础上限 | 140 | 血月日期使用的基础额度，与普通上限分别设置 |
| 每日上限增量 | 0 | 从第 2 天起按历史最高到达天数累加，可设小数；0 保持固定上限 |
| 上限封顶 | 0 | 对单人区域的基础额度与日增之和封顶；0 不设额外封顶 |
| 刷怪尝试冷却 | 1 tick | 每个维度两次敌对高度轮次共同的尝试间隔，20 tick = 1 秒；缩短冷却会立即重算正在等待的间隔 |
| 地下轮次通过率 | 10% | 每次敌对刷怪调度时地下轮次的基础通过率 |
| 地表轮次通过率 | 17% | 每次敌对刷怪调度时地表轮次的基础通过率 |
| 血月通过率倍率 | 2 | 在血月日期乘到轮次通过率上，最终概率不超过 100% |
| 非主世界通过率倍率 | 0.25 | 下界、末地和 MITE 地底的轮次通过率倍率 |

本体额度为 `floor(min(基础额度 + max(历史最高天数 - 1, 0) × 日增量, 可选封顶) × 有效区块数 / 289)`，普通和血月各自选用相应基础额度。最终取整前保留小数日增，因此每天增加 0.5 会积累成完整额度。多人区域使用原有有效区块并集；地表和地下继续共用维度内额度。

冷却限制的是调度尝试，地形、光照、现有人口、抽签和其他准入条件仍可能使某次尝试没有生成怪物。主世界原有的临时增速、减速和暂停继续作用于通过率。修改上限只影响后续自然补充，降低上限不会清除已经存在的怪物；提高上限时原有局部密度检查也会采用相应额度，避免旧的 105/140 限制挡住新上限。

安装 ITE 时，怪物额度、日期增长、血月额度倍率和局部密度由“ITE 设置 → ITE 刷怪规则”管理，MITE 页的基础额度设置不覆盖 ITE 规则。该页还可调整生成尝试和刷怪笼近场加速参数；共同的自然刷怪冷却与轮次通过率仍在 MITE 的“上限与刷怪节奏”中设置。原有平安期、生成日期和其他限制继续生效。

单机和本地主机保存后，下一次自然刷怪调度直接使用新值，无需退出存档或重启游戏。专用服务器的设置仍以服务器为准，连接服务器的客户端只读查看同步值；服务器热重载配置后更新运行规则并同步在线玩家。上述参数与物种权重一起写入 `config/mite-common.toml` 的 `[monster_spawning]`，并包含在现有配置导出中。

## 数值含义

每行显示当前生成器和生物群系注册数据中的基础池权重；ITE 页读取其实际 `spawnWeight`，包含原有四项刷新频率覆盖。没有独立池条目的变种显示“由原有条件或变体规则决定”，不伪造统一的默认权重。

- 空白：使用当前候选池原始权重；同一物种的原始值可因生物群系或结构而不同。
- 正整数：用该数值覆盖已有自然候选的权重，数值越大，在同池中的相对份额越高。
- `0`：该候选及其转换分支不再参与自然抽签。
- 全部怪物权重同时翻倍不会增加全局刷怪额度。

原有的日期、维度、深度、光照、户外限制、族群、人口密度及怪物上限继续执行；权重不会为没有自然入口的 Boss 创建新入口。自然调度覆盖主世界、下界、末地和 MITE 地底。第三方维度未新增抽选权重接入。刷怪笼、试炼地牢、刷怪蛋、指令以及其他非 `NATURAL` 原因保持原有规则。

## 变种和替换

地狱爬行者、巨型吸血蝙蝠、长亡灵守卫、下界凋零骷髅和僵尸村民继续沿用原有父候选与变种转换路径；ITE 自然猪人转为猪人领主的分支也保留原有条件。父候选的权重为 0 时，该候选整族不再进入抽签。有其他独立候选入口的物种仍可从自己的入口生成。

未修改设置时使用原整数抽签和原变种随机流程，保留默认随机序列。旧文件的物种倍率继续按原有最终身份规则兼容，只有编辑或还原该物种时才清除。已有自然怪及其跨维度复制通过持久标记识别，不会因修改权重而被移除。

## 文件与导出

MITE 的已修改项位于 `config/mite-common.toml`：

```toml
[monster_spawning]
weights = ["minecraft:zombie=25", "mite:ghoul=40"]
```

ITE 项位于 `config/modern_ite-common.toml`：

```toml
[GameMechanics.MobSpawning]
natural_spawn_weights = ["modern_ite:zombie_chaos=30"]
```

省略的实体沿用各候选池自己的原始权重；未知或暂未安装的实体 ID 保留。旧文件中的 MITE `rates` 和 ITE `natural_spawn_rates` 仅用于兼容，未编辑的条目继续保留。保存各页后回到 MITE 首页，点击右上角“导出配置”，安装 ITE 时会把两份配置写进同一导出目录。将成功清单中的全部 TOML 文件放进服务端 `config/`，重启服务端即可使用。
