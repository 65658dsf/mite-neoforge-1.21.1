# 怪物首次发现玩家与遮挡后的追击

开发者：NingMeng123

日期：2026-10-27

## 玩家规则

普通露天场景中，怪物主动发现一个新玩家时，必须先通过自身到玩家的真实视线检测。刚出生就被石头、泥土等完整不透明墙隔开的怪物，不能仅凭挖掘能力、玩家在高处或附近蝙蝠看见玩家而首次锁定该玩家。

按用户追加规则，地下的地面近战怪物可以尝试发现尚未见过的玩家，但必须先验证一条完整可步行、终点确实能攻击的路线。绕一个有出口的矿洞拐角可以建立追击，完全封闭的墙、残缺路径或需要先拆墙才能通过的推测不能建立该首次仇恨。已经看见的玩家仍按原规则追击。

怪物已经看见并锁定玩家后，玩家再躲到墙后，保留原来的目标记忆、绕路、挖掘和追击规则；本轮没有把“当前看不见”改成立即丢失目标。视线材质策略继续沿用本体现有定义，包括普通玻璃、门等视觉透明例外，以及持弓骷髅的树叶/可射击部位判断。

## 修复位置

`SourceMonsterTargeting.SourceTarget.initiallySuitable` 通过 `requiresInitialSight` 决定首次发现是否需要视线，再统一执行一次 `targetVisible` 检查。默认实现保留来源规则，`Nearest` 对玩家强制要求自身视线，短路跳过挖掘和蝙蝠豁免，避免重复射线及不必要的蝙蝠扫描。高处玩家候选也统一经过这一入口，修复原先户外挖掘分支只检查位置、未检查可见性的旁路。普通僵尸、骷髅、凋灵骷髅及复用该目标选择器的来源变种使用相同规则。

修复只约束主动发现玩家，不改变 `SourceTarget.canContinueToUse`、受击后的 `Revenge`、同类协作仇恨、已接受目标的队列转接和存档目标恢复。玩家隔墙攻击怪物后仍可触发反击，已有合法仇恨也不会因这项首次发现规则被清除。非玩家猎物继续采用原有来源规则。

## 地下发现的开销限制

`CavePlayerDiscovery` 只在当前没有目标、使用地面导航且具备本体近战追击任务的受管怪物上运行，排除苦力怕、女巫和持弓者。僵尸、近战骷髅及复用这些任务的变种可参与。怪物与玩家都须满足地下候选条件，隐藏候选距离至多 24 格；每次只探测一人，从最近者开始轮换，避免一个无法到达的最近玩家永久挡住其他玩家。

地下资格读取已加载区块的 `MOTION_BLOCKING_NO_LEAVES` 高度图：地表高度需至少高于眼位四格；无天空维度按地下处理。不限定 Y<63，因此高处山体中的矿洞也可参与。这是廉价的覆顶高度近似，并非识别人造结构或矿洞群系；高屋顶等也可能满足资格，最终仍须完整路线证明，不能穿封墙锁定。

每只怪物至少间隔 40～49 游戏刻才再探测。所有维度共享每服务器 Tick 最多两次实际隐藏发现搜索；预算不足仅作 2～6 刻短退让并错峰，保留短期等待次序，不记录为不可达，也不会在目标为空时触发挖掘任务。正常可见玩家的发现不受这一预算限制，已有目标的完整 AI 继续运行。

新探测复用 `MeleePursuitPaths` 的共享失败缓存和十刻成功路径短缓存，发现后的追击入口可以复用原路线。首次隐藏发现另外检查整条剩余路线的身体碰撞、地面支撑和真实攻击终点，防止成功缓存远处刚被封墙或拆桥后仍错误锁定。检查本身不赋予目标、不启动导航、不改变方块。`probeStats(ServerLevel)` 与 `probeStats(PathfinderMob)` 提供真实搜索、缓存复用、预算退让和下次探测时间等只读计数。

## 验证

`MonsterTargetMeleeGameTests` 在 `mite_targeting` 命名空间新增六项 `initial_player_sight` 批次测试，怪物与玩家的头顶列明确保持露天，独立验证普通视线规则：

1. 聪明且可挖掘的普通僵尸，从出生起被石墙隔开时不能首次锁定玩家；露脸后真正赋予目标，再藏回墙后保留记忆。
2. 持弓骷髅与持剑凋灵骷髅使用相同首次视线与后续记忆流程。
3. 亡魂、古尸和骷髅领主继承首次发现规则。
4. 玩家处于普通六格垂直搜索范围之外时，户外挖掘与弓手高处候选仍须可见。
5. 玩家侧的蝙蝠确实看得见玩家时，墙后的女巫仍不能首次被动锁定；女巫亲眼发现后的追击记忆继续生效。
6. 真实玩家伤害仍可建立隔墙反击，已接受的队列仇恨仍可转入目标选择器。

测试使用真实注册的生存模式 `ServerPlayer`，等待原生实体查询可观测后再断言，并核对执行已安装目标选择器后的 `getTarget()`，避免把“夹具尚未被实体查询看到”误当成视线修复。这些用例已随 52 项专项服务端测试全部通过，完整结果见[验证说明](testing/multiplayer-path-performance.md)。

`CavePlayerDiscoveryGameTests` 使用独立 `mite_cave_discovery` 命名空间，补充四项：隐藏矿洞的真实绕路及成功路径复用、成功缓存第六节点以远突然封墙后的拒绝锁定与失败复用、不可达最近玩家后的候选轮换、24 只怪物固定顺序下的全服限流与队尾可达怪恢复。最后一项另验证已索引的玩家切回生存模式后，即使隐藏搜索名额已用完，正常看见仍能立即锁定。夹具等待区块进入原生实体 Tick 状态，再检查寻路与地形变化；四项均已随本轮专项测试通过。

原有村民目标的挖掘视线豁免、弓手树叶和玻璃视线、60 次遮挡记忆、有效路线的 600 次上限及保护/目标恢复测试继续保留。
