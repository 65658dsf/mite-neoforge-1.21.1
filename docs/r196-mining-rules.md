# R196 采集、触及与开局掉落规则

分析与开发署名：NingMeng123。本文核对本地 R196 发布包反编译结果；结构化规则见 `spec/r196-mining-rules.json`。本文是证据，不表示对应玩法已经实现。材料、物品及方块注册数值分别见装备规格与 `reference-data/runtime-registry.json`。

## 采集门槛与速度

材料要求工具的条件为 `requires_tool || block.minHarvestLevel > 0`。没有有效工具时强度为 0，而非“挖得慢但仍会掉落”。手持物品返回的强度不足 1 时会重新按空手计算，普通物品的默认强度正是 0。工具有效需要同时满足材料/方块类别匹配和采集等级；砂岩模型的半砖对斧头有特殊例外。金属工具采集等级等于材料的最小采集等级，其他非零材料减 1。证据：`akc.java:324-325`、`yc.java:559-560`、`uf.java:774-803`、`xj.java:61-62,125-138`；`aqz.java:2284` 确认 `aqz.V` 是 ID 24 的砂岩。

基础工具强度为 `baseEfficiency * materialEfficiency`。默认基础效率 4；木/燧石/黑曜石/锈铁/铜/银/金/铁/远古金属/秘银/艾德曼/钻石倍率分别为 1/1.25/1.5/1.25/1.75/1.75/1.75/2/2/2.5/3/2.5。短斧再乘 0.5；斧头挖砂岩也乘 0.5。不能把材料硬度、工具采集等级、材料效率混成一个数字。证据：`xj.java:43-103`、`ya.java:18-19`、`ItemHatchet.java:17-18`。

玩家强度按以下顺序计算：

1. 硬度 0 直接返回 1；可搬运方块使用 `4*hardness`，并将该值设为最终最小强度。
2. 有效手持物品强度上追加效率附魔 `enchantmentLevel²+1`，只有等级大于 0 时追加。
3. 蜘蛛网若没有有效工具，乘 0.2。急迫乘 `1+(amplifier+1)*0.2`；疲劳乘 `1-(amplifier+1)*0.2`，此处没有先钳制到正数。
4. 在水中且没有水下速掘、没有站地面、没有食物能量，各自独立除以 5。食物能量判断是 `satiation+nutrition != 0`。
5. 乘 `1+level*0.02`，再与可搬运方块的最小强度取最大值。

证据：`uf.java:774-828,558-566,1735-1736`。可搬运例外必须按实际方块的 `isPortable` 覆写核实，基类默认 false；不能把全部木制方块视为可搬运。

硬度为负或强度不大于 0，采集进度为 0。否则相对硬度为 `hardness/strength`；严格小于 `0.0029296875` 时瞬间破坏，等于该边界仍走普通计算。一般每次破坏进度为 `strength/hardness/512`。这与现代原版的速度系数不同。证据：`uf.java:831-862`。

旧服务端 `jw.tryHarvestBlock` 先记录强度是否大于 0，随后移除方块，再以该标志决定是否掉落；不能把这个方法解释成完整的恶意客户端拒绝逻辑。现代实现需要同时验证开始、进度、最终破坏与掉落。证据：`jw.java:106-159`。

## 耐久、触及与放置

工具基础最大耐久为 `int(4 * componentCount * materialDurability * 100)`，品质在 Item 层另按倍率四舍五入，最少 1。镐的 componentCount 是 3，短斧为 1。破坏耗损为 `max(int(hardness*100*baseDecay), int(100*baseDecay/20), 1)`；硬度 0 返回 0。有效破坏才耗损，可搬运、创造模式、非正硬度或工具强度不超过 1 都不消耗。证据：`xj.java:35-40,145-151,171-180`、`yc.java:590-605`、`yn.java:22-28`、`ItemHatchet.java:32-43`。

生存基础方块触及距离为 2.75，仅对目标方块有效时追加物品触及奖励；普通工具默认 +0.75，短斧 +0.5。创造扩展触及为 5。近战基础 1.5，交互基础 2.5，另有最多正负 1 的高度差修正和实体自己的调整方法；两者不能统一改成方块距离。证据：`uf.java:1967-2007`、`yc.java:941-953`、`xj.java:31`。

没有食物能量时，非创造玩家不能放置正硬度方块。成功放置消耗 `min(hardness(metadata=0),20) * enduranceModifier` 饥饿；这里旧版明确使用 metadata 0，不是刚放置状态的 metadata。证据：`aqz.java:1844-1850`、`uf.java:2405-2412`。

## 砂砾与树叶

砂砾的村庄道路变种、爆炸及非玩家采集，直接采用基类掉落。其他玩家采集，时运最多按 3 计算；以 `3/(12-2*fortune)` 概率进入特殊掉落，否则掉砂砾。特殊分支有 2/3 进入燧石分支，其中 1/16 是整块燧石，15/16 是碎片。剩下 1/3 进入矿物分支，依次以 2/3 命中铜粒、银粒、金粒、黑曜石碎片、绿宝石碎片、钻石碎片、秘银粒；所有前项均失败才给艾德曼粒。它们是连续条件概率，不是同权随机表。下界砂砾将铜/银/秘银/艾德曼转成金粒，将黑曜石/绿宝石/钻石转成下界石英碎片。证据：`aoo.java:16-57,61-85`。

树叶普通掉落：玩家放置的树叶不掉；沼泽先有 1/2 概率无掉落；随后依次尝试 1% 树苗、5% 木棍、0.5% 对应水果，前项成功就返回。因此非沼泽、非放置树叶的木棍概率为 4.95%，支持水果的种类水果概率为 0.47025%。橡树叶在丛林出橙子，其他群系出苹果；丛林树叶出香蕉。这里讨论普通掉落方法，精准采集在上层先分流，不能据此禁止精准采集树叶方块。证据：`aoz.java:192-214`、`jw.java:144-149`。
