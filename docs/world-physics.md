## 掉落物抗爆与碎裂

`ss.java:548–658` 在普通实体爆伤前独立处理掉落物。每个被爆炸实体查询选中的掉落物先获得抛掷速度，再判断是否损坏；此流程不套用实体视线衰减。距离使用 `dx²+(dy/2)²+dz²`，强度为 `blockPower / distanceSquared^0.75`。运动计算将距离平方至少取 1；损坏计算保留源代码在零距离的强度上限行为。

- 非装备的全金属物品、所有金属粒和锭、红石粉免疫损坏。装备即使全金属也不因此免疫。`yc.java:1079–1088` 的材料判断已与运行注册快照和既有现代 ID 映射结合，生成 `src/main/resources/mite/explosion-materials.json`；不在运行时按名称猜测第三方材质。
- 已启用的装备磨损预算为 `force×64`，工具再乘 100，护甲再乘 2，其它耐久物品不加倍率，最低 1。实际扣耐久继续经过已有品质、耐久附魔和物品损坏事件；掉落状态不套玩家护甲最后一点保护。
- 普通非耐久物品在强度小于 0.2 时保留；达到 0.2 后消失。每个完整燧石、绿宝石、钻石分别留下 1 个燧石碎片、绿宝石碎片、钻石碎片；碎片获得独立抛掷速度。
- 携带的源方块物品按源抗性与 `force×2` 比较，通过后每件执行其爆炸掉落表，不把该方块临时放到世界里。现代床和门的原版分离物品身份映射为其对应方块爆炸掉落。
- 独一唱片实际毁坏时调用现有 `onDestroyed`，释放世界唯一标记。源 `ss.handleExplosion` 与其独立 `attackEntityFrom` 的下界之星保护存在差别；本实现服从实际 `handleExplosion` 的强度判定，不凭后者推断额外免疫。

实际入口为 NeoForge `ExplosionEvent.Detonate`。处理完的掉落物从原版实体清单移除，防止再吃一次普通爆伤或叠加第二份击退。没有显式映射的第三方物品保留其原生行为。
