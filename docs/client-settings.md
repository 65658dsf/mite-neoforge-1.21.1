# R196 客户端设置限制

开发者：NingMeng123。原始机制依据本地 Minecraft 1.6.4 MITE R196 发布包，现代适配目标为 Minecraft 1.21.1 NeoForge。

## 已核实的 R196 行为

R196 将亮度固定为最低档 `gamma = 0.0`。这不是只在第一次启动时使用的默认值：读取配置、修改选项、查询选项、保存配置、游戏主循环和设置界面均明确限制亮度。夜视效果仍正常改变光照，不因亮度固定而失效。

## 1.21.1 适配范围

亮度选项在 `OptionInstance` 的初始化、读取和设置入口统一固定为 `0.0`，原版视频设置中的亮度控件禁用并提供限制提示。这样既能处理已有 `options.txt` 的较高亮度值，也能让后续设置和真实渲染读取同一个固定值。仅修改文件而未正常保存时，不承诺客户端立即重写磁盘文件；运行中的有效亮度始终为 0，正常保存选项时才将 0 写回文件。

对 Sodium 0.8.13 的亮度控件增加可选 `isEnabled` 适配，使其同样显示为禁用。Sodium 仅为可选兼容对象，不作为模组前置；未安装 Sodium 时仍使用原版选项限制。已有夜视效果继续正常生效，其他光照或光影模组自行绘制的额外效果不在亮度选项限制的保证范围内。

普通客户端仍可调整以下设置：

- 视距：R196 可修改、加载和保存，见 `aul.java:195-196,400-401,542,603-604`。
- 粒子：R196 支持全部、较少、最少，见 `aul.java:201-202,353-354,406-407,544`。
- 云：R196 可开关，旧版还按视距决定是否渲染，见 `aul.java:207-208,433-434,552,595-596`；现代版本保留新版云与视距选项。
- 声音、视角、灵敏度、GUI、画质、平滑光照和按键：保留新版选项，不将旧默认值视作强制值。R196 的设置、加载和重绑定入口见 `aul.java:151-165,227-233,382-392,427-431,508-510`、`auy.java:58-102`。

旧版 `--ds` 不是普通客户端设置：`net/minecraft/client/main/Main.java:112,175` 通过启动参数启用专用服务器客户端模式，该模式才会禁用视频设置并改变视距、云、全屏、画质及垂直同步（`avw.java:38-39,56`、`aul.java:595-612`）。本次不迁移该旧运行模式，也不将它的限制应用于普通客户端。

R196 另有新建世界仅生存/极限、禁作弊/奖励箱以及 LAN 固定生存无作弊等限制，来源为 `avb.java:82-84,190-220` 和 `awj.java:25-26,36-38,46-57`。现代版本保留已授权的创造、作弊与管理员测试流程，使 `/time`、`/tick`、`/summon` 等测试指令继续可用；亮度和困难难度固定不改变这些入口。

## 用户手动验收

1. 替换新版模组 JAR 后重新启动客户端，打开原版视频设置。亮度应为最低且无法拖动，悬停可看到限制提示；进入实际世界后也不应恢复较高亮度。
2. 安装 Sodium 0.8.13 时，在 Sodium 视频设置中重复检查亮度控件。亮度同样应显示为最低并禁用；没有安装 Sodium 的客户端也应能正常启动。
3. 完全退出游戏，在该客户端实例的 `options.txt` 中将 `gamma` 一行改为 `gamma:1.0`，再启动游戏。界面和实际渲染仍应使用最低亮度。正常保存设置或退出游戏后，检查文件中的值是否已写回 `gamma:0.0`。不要在客户端运行时修改该文件来验证加载行为。
4. 在允许指令的测试世界前往黑暗区域，可用 `/time set 18000` 配合未照明场景观察。先确认最低亮度，再使用 `/effect give @s minecraft:night_vision 60 0 true`：夜视应正常提亮场景；使用 `/effect clear @s minecraft:night_vision` 后恢复正常黑暗。
5. 分别调整视距、云、粒子、声音和视角，正常保存并重启，确认它们仍可修改和保存，不会因亮度锁而被一起恢复。
6. 退出当前世界，再进入另一个世界或重新连接服务器，确认亮度始终为最低，困难难度沿用现有锁定行为。创造模式和已允许的管理员测试指令仍可正常使用。
