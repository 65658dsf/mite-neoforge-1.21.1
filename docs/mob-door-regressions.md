# 蜘蛛、骷髅、苦力怕与金属门交互回归

开发者：NingMeng123。

## 修复内容

1. 蜘蛛：R196 `on.bl` 把速度属性写入前进输入，`of.bg` 对旧 AI 使用固定 `0.1` 地面加速度。现代 `Mob.setSpeed` 同时写入加速度和前进输入，原来把 `1.0/0.8` 同时用于两处，造成异常加速。现在保留原作属性及存档值，转换控制器输出为固定加速度与原前进输入。普通、洞穴、恶魔、树林、黑寡妇、相位蜘蛛一起生效，已有存档不需要修改属性。
2. 骷髅：源射击 AI 缺少现代客户端所需的攻击与使用物品状态，材质弓又不符合原版模型对普通弓 ID 的判断。现在同步举弓、拉弓、释放、停止状态，统一识别所有 `BowItem`，模型继承原版动态姿势。保留原有射击间隔，不通过提前射箭制造动画。
3. 苦力怕：旧爆炸参数 `0.715` 被误当作现代方块破坏半径。现在使用现代实际半径，保留带电、自定义 NBT 和地狱变种倍率，生物伤害继续独立使用源规则。详见 `creeper-explosion-fix.md`。
4. 金属门：真实放置流程验证未发现门注册或上下半损坏。无法空地放置和徒手开启来自原作规则，但先前没有解释。现在添加手持物品说明与失败操作提示：铰链侧须有上下两块坚实侧框，铜门及所有氧化、涂蜡变种按用户要求恢复右键开关，也可使用红石；其他新增金属门使用红石开启。左右侧框均可，仍自动选择合法铰链侧。

金属门依据为 R196 `anz.java:189-205,237-283`，侧框仍按原作保留；铜门手动开关是用户指定的现代适配。石头和木板可作侧框，泥土、沙子和玻璃等不符合原作侧框条件。原版木门保留现代操作。

## 手动测试

重新启动测试客户端后，在测试世界分别检查：

1. 蜘蛛：原版蜘蛛、洞穴蜘蛛及四种 MITE 蜘蛛在平地追击时不再异常滑冲，仍能正常跳跃、攀墙；相位蜘蛛的瞬移仍是独立能力。
2. 骷髅：在生存模式让普通和新增骷髅索敌，观察举弓、弓弦拉满、射击后重新拉弓；用墙遮住后应停止拉弓，重新露头后恢复。材质弓也应显示相同动作。
3. 苦力怕：在普通土地区域引爆普通、带电和地狱苦力怕，普通应形成正常爆坑，后两者范围更大。不要在试炼密室里判断方块掉落，因为密室天然方块仍受禁掉落规则保护。
4. 门：先铺地基，在目标门位左或右搭两格高石柱，旁边保留两格高空间，再放置铜、银、金、远古金属、秘银或艾德曼门。铜门及氧化、涂蜡变种可右键上下半开关；其他材质门给侧框或门位相邻方块接拉杆、按钮或压力板，验证通电开启、断电关闭。空地放置不满足侧框时仍显示提示。

## 火焰附加动物掉落修复

旧掉落逻辑只看动物是否正在燃烧，而新版火焰附加在伤害与死亡掉落之后才点燃；这使未燃烧的动物被一击击杀时仍掉生肉。现沿用原版动物战利品的判定：已着火，或直接攻击者主手附魔属于 `minecraft:smelts_loot`，则按熟肉处理。箭矢等间接攻击不会因射手后来手持火焰附加剑而被误判。原有养殖状态、掉落数量及事件取消逻辑保留。

手测：用火焰附加 I/II 的剑一击击杀未着火的成年牛、猪、羊、鸡，应掉对应熟肉；用普通剑对照仍掉生肉。

铜门手动开关与火焰附加补丁：全量 1,192 项 GameTest 和构建通过。新增 6 项熟肉掉落测试覆盖八类动物、火附 I/II、普通剑、燃烧补刀、未燃烧箭、环境归因、取消掉落及无效伤害；铜门覆盖全部八种变体的上下半手开与原生风弹/红石交互。用户已完成客户端手测并授权提交 GitHub。
