# 燧石开局材料与短斧适配

开发者：NingMeng123。版本依据为本地 MITE 1.6.4 R196 发布包；原始规则、现代适配及字面验收向量另存于 [结构化规格](../spec/r196-flint-start.json)。本文记录实现范围，不代替构建、GameTest 或客户端实测报告。

## 可获得路线与配方

本轮新增 `mite:flint_chip`（燧石碎片，上限 64）、`mite:sinew`（筋，上限 16）和 `mite:flint_hatchet`（燧石短斧，上限 1）。整块燧石继续使用 `minecraft:flint`。碎片上限来自 `ItemShard.java:8`，筋使用 `yc.java:468` 的默认上限；物品声明分别见 `yc.java:333,376,182`。

| 配方 ID | 输入与摆法 | 输出 | R196 来源 |
| --- | --- | --- | --- |
| `mite:flint_from_chips` | 2×2，每格 1 碎片 | 1 燧石 | `aae.java:12,22–44` |
| `mite:flint_chips_from_flint` | 任意单格 1 燧石 | 4 碎片 | `aae.java:12,44` |
| `mite:sinew_from_leather` | 任意单格 1 皮革 | 4 筋 | `RecipesMITE.java:41` |
| `mite:flint_hatchet` 及其变体 | 1 燧石、2 木棍、1 筋或线 | 1 短斧 | `aal.java:10`、`aai.java:51–113` |

短斧的基础 2×2 摆法为 `FS / BS`：`F` 为整燧石，`S` 为木棍，`B` 为筋或线。两个木棍须上下相连，燧石位于上方木棍的左侧或右侧；骨架可平移、水平镜像。绑定物须恰占一个空槽，在 3×3 网格中可以放在骨架外；其他槽须空着。它不是无序合成，也不支持旋转骨架。

原匹配器先从输入中移除筋或线再匹配骨架（`aai.java:51–94`；字节码偏移 306 读取线、314 读取筋）。本实现把全部有效形状裁掉空白边框、合并水平镜像，生成 **13 个普通有序配方**：基础 ID 保持 `flint_hatchet`，其余为 `flint_hatchet_binding_1` 至 `_12`，统一使用组 `mite:flint_hatchet`。连同 3 个材料转换，共 16 个配方及对应配方解锁进度，由 `MiteRecipeProvider` 生成。

每个已占用槽每次消耗 1 件；原 `aae` 的配方成分对象里存有数量 4，不代表每格消耗 4。实际默认消耗来自 `CraftingResult.java:11`，取料见 `wd.java:105,118`。现代实现使用普通有序配方，手动合成、配方书与自动合成器共用 `RecipeManager`。未迁移的制作时间、经验、品质或职业条件不会暗中套用；R196 服务端 `professions` 默认关闭且随后强制设为 false（`is.java:86–87`），不能仅凭短斧配方的 MASONRY 标记就新增职业封锁。

树叶掉木棍、动物掉皮革等保留 1.21.1 来源与掉落规则。原树叶的种类、沼泽、玩家放置及连续概率分支（`aoz.java:191–214`）没有移植。当前路线为砂砾取得碎片或整燧石、碎片合并、皮革拆筋或使用线，再以两根木棍合成短斧；本轮不增加空手原木封锁。

## 砂砾掉落的部分迁移

R196 `aoo.java:16–57` 在普通玩家采集、非道路、非爆炸路径中令 `D = 12 - 2×min(时运,3)`。先以 `3/D` 进入特殊掉落，其中 `2/3` 进入燧石分支，再以 `1/16` 掉整燧石，其余掉碎片。原矿物分支的总概率为 `1/D`，包含金属粒和矿物碎片；本轮暂回落为砂砾，未注册或伪造那些矿物。

| 时运 | 整燧石 | 碎片 | 当前砂砾（含暂回落矿物分支） |
| --- | --- | --- | --- |
| 0 | 1/96 | 15/96 = 5/32 | 80/96 = 5/6 |
| 1 | 1/80 | 15/80 | 64/80 |
| 2 | 1/64 | 15/64 | 48/64 |
| 3 或更高 | 1/48 | 15/48 | 32/48 |

现代实现把时运夹在 0 至 3；丝触保留原版砂砾输出，R196 上层也在 `jw.java:144–149` 提前分流丝触。事件已取消、非玩家、创造/旁观或 `doTileDrops=false` 时不改掉落。没有普通砂砾/燧石输出的掉落表不被重新添物；其他模组额外添加的不同物品保留。仅替换普通砂砾/燧石输出为一次新抽取，爆炸等非玩家来源继续使用现代规则。这不是完整 R196 砂砾掉落表、下界砂砾或村庄道路迁移。

## 短斧数值与磨损

R196 平均品质短斧的耐久为 `4×1×1×100 = 400`（`xj.java:35–40`、`ItemHatchet.java:32–33`、`EnumEquipmentMaterial.java:7`）。普通有效目标的工具强度为 `4×0.5×1.25 = 2.5`；基础斧伤害 3，短斧减 1，燧石材料加 1，得到工具攻击加值 3，再加玩家基础攻击 1，得到无其他修正的总攻击 4（`ya.java:23–24`、`ItemHatchet.java:22–23`、`akc.java:351–356`、`xj.java:218–220`、`uf.java:93–96`）。品质会影响原作耐久，当前仅采用平均品质基准。

普通有效方块的磨损按原 Java `float` 顺序计算：

```java
baseDecay = 1.0f * 4.0f / 3.0f;
decay = 100.0f * baseDecay;
cost = max(max((int) (H * decay), (int) (decay / 20.0f)), 1);
```

纯公式在 `H == 0` 时返回 0；实际破坏入口只处理服务端、可损坏工具、非创造/旁观、`H > 0` 且工具基础速度大于 1 的情况。不得改成每块扣 1，或先把最终乘除合并后再取整。证据为 `ItemHatchet.getBaseDecayRateForBreakingBlock` 字节码偏移 5–10 的先乘后除，以及 `xj.getToolDecayFromBreakingBlock` 偏移 13–39 的乘法、两次转整数与取最大值。

普通原木的原始硬度为 1.2（`EnumMaterialHardness.java:7` → `BlockHardness.java:16` → `arj.java:13`），所以每根扣 160。无耐久附魔等修正时，400 耐久的短斧完成第 1、2 根后分别损伤 160、320，第 3 根完成时损坏。有效目标硬度 0.8 扣 106，极小正硬度的最小扣损为 6；硬度 0 不扣损。攻击磨损为 `max((int)(100f*(1f*4f/3f)),1) = 133`，原证据见 `xj.java:154–167`；当前通过现代成功攻击后的 `postHurtEnemy` 扣损，保留现代伤害、创造及耐久附魔处理。

现代短斧使用 `#minecraft:mineable/axe` 的有效目标和 `#minecraft:incorrect_for_wooden_tool` 的掉落限制，默认工具速度为 1，采用已完成的等级、饥饿和基础进度规则。原作有效材料、材料等级与空手回退没有在本轮完整映射；尤其原砂岩是特殊有效目标，强度 1.25、磨损基数 2.5，不属于当前普通斧标签规则的还原范围。

`MiningProgress.effectiveHardness` 仅对 **注册命名空间为 `minecraft` 且属于 LOGS 标签**的方块采用挖掘有效硬度 1.2，短斧磨损复用同一入口。将现代新增原木、木质块、去皮变体及下界菌柄等该标签成员归入同阶段，是明确的现代扩展；其他模组命名空间方块不受这项映射影响。注册硬度、爆炸抗性及地形不变。

短斧在玩家默认属性下满蓄力总攻击 4、攻击速度 1 次/秒；后者来自现代基础 4 加修饰 −3，是现代冷却适配，不是 R196 攻击间隔。实现继承 `Item`，只声明 `AXE_DIG`，不提供斧头右键剥皮、刮蜡等能力。保留附魔能力 0 和无材料修复映射；**现代两件工具合并修复仍可用**。R196 `aaf.java:263–320` 的受损、品质、附魔、染色检查及无额外奖励的剩余耐久合并规则留待维修系统，不能把“没有修复材料”解释成“不可修复”。

## 验收边界与后续工作

结构化规格保存固定期望：13 种形状、全部 3,048 种四原料网格布局中仅 100 种有效、两次取料的数量守恒、砂砾各时运分支、耐久及磨损边界。对应自动测试入口为 `FlintRecipeGameTests`、`FlintToolRulesTest` 及 `FlintGravelRulesTest` 等；是否实际通过由本轮测试记录单独报告。

本轮未完成品质、职业模式、制作时间和经验成本、完整工具等级和空手限制、R196 便携方块免磨损与采集下限、触及距离、完整材料/矿物、树叶生态、旧版修复公式及战斗体系。R196 `xj.java:177` 的便携豁免当前未接入：现代斧标签中的便携方块仍可能消耗耐久。本功能是下一步工具门槛之前的可获得路线，不等于全量制造或采集复刻。
