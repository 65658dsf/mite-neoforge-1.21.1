# 装备材质升级

作者：NingMeng123。适用 Minecraft 1.21.1 / NeoForge 21.1.259。

## 模板与操作

新增物品`mite:equipment_upgrade_smithing_template`，中文名“升级模板”，位于MITE材料分类。使用原生锻造模板物品及槽位说明，使用独立的32×32透明像素纹理：铜银金属框、金色扣件及中央青色钻石，不复用原版模板贴图。纹理为`assets/mite/textures/item/equipment_upgrade_smithing_template.png`；生成来源及提示词见[贴图记录](art/equipment-upgrade-template.md)。

按以下九格布局有序合成1个模板，共消耗4个铜锭或银锭、2个铁锭、2个金锭和1颗青金石。四个角各自接受铜锭或银锭，支持全铜、全银和任意铜银混搭，其他材料不能替换或换位。中央不再接受钻石，模板现有纹理不变。

| 铜锭或银锭 | 铁锭 | 铜锭或银锭 |
| --- | --- | --- |
| 金锭 | 青金石 | 金锭 |
| 铜锭或银锭 | 铁锭 | 铜锭或银锭 |

升级模板没有复制配方，只能使用上述材料逐个制作。原先“模板、7个铁锭和石头”的复制配方及其配方书解锁已移除，JEI不再显示复制入口。

制作模板使用MITE合成耗时，整批难度为400，最低要求铁工作台；燧石、铜、银、金工作台不能制作。0级、无诅咒时铁工作台需140 tick（7秒），更高阶工作台、经验等级和笨拙诅咒继续按现有规则改变实际耗时。JEI仅在铁及更高阶工作台显示该配方及对应基准耗时；普通点击、Shift快速取出和自动合成器使用同一套耗时与工作台要求，等待完成后才消耗材料并产出1个模板。这是制作模板本身的耗时；使用模板升级装备也需要完成下一节所述的锻造周期。

在锻造台依次放入升级模板、待升级装备和目标材质锭。界面显示材料槽中的锭数和本次升级用量，放足后才会出现成品预览。金属锭每组8个，原矿每组4个。升级为远古金属装备时，每件消耗2个远古金属锭，涵盖工具、武器、板甲、锁甲、马铠、盾牌、钓竿、胡萝卜钓竿和已安装的兼容武器。其他目标材质按整件制造成本收费，例如秘银头盔5锭、胸甲8锭、护腿7锭、靴子4锭，普通镐3锭、剑2锭。完成后，多余的锭留在材料槽中。

除上述远古金属固定2锭的规则外，2026-10-22经用户确认的制造成本规则继续适用：带金属粒的制造成本统一向上取整成锭，例如2锭1粒收3锭、3锭4粒收4锭；锁甲按每环4粒计算，头、胸、腿、靴分别收3、4、4、2锭。钓竿及胡萝卜钓竿收1锭；盾牌和强化弓各1锭。马铠没有制造配方，按用户选择保留1锭，不声称它存在普通制造配方。可选简易刀剑按各武器实际配方中的锭与粒计算，不使用耐久所映射的工具类别估价；ITE金属棒按3锭4粒向上取整收4锭。

左键结果开始锻造，Shift点击完成后放入背包，右键结果取消。服务端完整计时后再一次性消耗1个模板、1件原装备和规定数量的锭，普通领取、直接快速转移、快捷栏换位、丢弃、双击收集和创造复制都不能提前拿走产物。重复点击不加速、不重置或排队。更换锻造台输入格中的物品、改变其数量或组件、关闭菜单、离线、死亡、跨维度或拆掉锻造台会取消进度。饥饿暂停进度，受伤按工作台规则回退。

锻造期间可以拿起、拆分或整理背包里的物品，进度会继续。普通领取时若光标正拿着其他物品，或Shift领取时背包已满，进度会保留在100%，腾出空间后即可交付。

锻造难度取目标装备现有制造难度，并按继承品质调整，玩家等级加速与笨拙诅咒减速继续适用，最短25 tick。锻造台没有金属工作台档位，因此不额外套用某一档工作台速度加成；缺少制造难度的目标使用100基础难度兜底。不会重新抽品质或额外扣制造品质经验。服务端进度同步到锻造箭头，JEI专用装备升级页显示完整锭数及0级普通品质基准耗时，并隐藏对应的旧原生单锭展示。其他模板、原版纹饰和简易刀剑符文升级不被本规则改写。

## 铜装备工作台升铁

铜工具、武器和四件板甲不再使用模板锻造，直接在具备铁装备制造能力的工作台升级；安装简易刀剑时包括其15类铜武器，安装ITE时包括铜棒。使用完整铁制同类物品的配方，将第一根木棍替换为原铜装备，剩余木棍和全部金属材料保留。例如铜镐：

| 铁锭 | 铁锭 | 铁锭 |
| --- | --- | --- |
| 空 | 铜镐 | 空 |
| 空 | 木棍 | 空 |

没有木棍的板甲、剪刀和ITE金属棒在铁配方空位加入原铜装备，不减少完整铁配方成本。工作台里的金属粒仍按原配方逐格使用，不把工作台配方也强行换成整锭。使用同一配方ID替换原铜模板路线，不保留单锭模板捷径；铜盾、铜钓竿、铜锁甲和铜马铠仍按其已有模板路线处理。

铜升铁沿用工作台的材料门槛与加工时间，保留原装备名称、附魔、品质、成长UUID/等级/经验/副词条及磨损比例，不重抽或二次收费。

## 材质路线

铜、银、锈铁、金 → 铁 → 远古金属 → 秘银 → 艾德曼 → 振金；其中上一节明确的铜升铁路线改走工作台，其余仍走模板锻造。

每次只升一阶，保持原装备类型：剑仍是剑，头盔仍是头盔，锁甲与板甲不互相转换。配方根据现有物品目录生成，缺少下一阶同类装备时不生成跨阶替代品。最高阶不能继续升级，不接受降级、同档换材质、错锭或缺槽。

范围包含已有金属工具与武器、板甲、锁甲、马铠、盾牌，以及存在相邻材质的强化弓、钓竿和胡萝卜钓竿。强化弓只提供远古金属→秘银：目录没有艾德曼强化弓，不从秘银直接跳到振金。木、石、燧石、黑曜石装备和箭矢没有新增转换。

安装Simply Swords时，已有15种兼容武器族沿同一金属路线逐级升级；未安装时配方由模组加载条件跳过，不解析不存在的物品。下界合金等级武器随原版同等级装备移除；原有符文升级改用对应秘银武器作为底材，其余原生材料不变。钻石及独特武器保持原有规则。

## 数据继承

升级保留名称、描述、普通附魔（包括原有诅咒及经验修补）、铁砧惩罚、染色、纹饰、盾牌旗帜、自定义组件、装备品质，以及成长UUID、等级、级内经验和全部副词条。成长数据不合并、不重抽；旧的高阶副词条与未知附魔ID照常保留。原来没有成长数据的白板装备不会凭空获得等级或副词条。

结果从目标装备的默认组件开始，使用新材质的攻击、护甲、采掘、耐火、基础耐久和堆叠属性，防止旧材质的显式属性覆盖目标。品质保留且只计算一次。损伤保留原来的磨损比例，四舍五入到新最大耐久，最多为新最大耐久减1；剩余1耐久的输入升级后仍可使用。马铠本来没有耐久，不额外添加耐久或成长。

盾牌负荷随同一面盾保留，升级后按新材质的次数及累计伤害上限继续结算。装备成长等级不因换材质立即提高；例如5级铜剑升为铁剑后仍为5级，可继续按铁质上限练到10级。

本批调整升级模板及上述铜升铁工作台路线。下界合金装备及对应锻造路线已移除，原有振金工作台升级配方继续保留。
