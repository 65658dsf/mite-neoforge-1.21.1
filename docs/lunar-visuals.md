# R196 月相的客户端显示

开发者：NingMeng123。原作机制及图片来自本地 `MITE 1.6.4 R196.zip` 和 `MITE Resource Pack 1.6.4.zip`。

最新用户要求另增加[血月白昼降雨与夜间干雷](lunar-weather-adaptation.md)：主世界血月白天的雨天天空、云及空气雾色变为暗红，夜间停雨但保留雷声和真实闪电。原有夜间 lightmap 和月盘公式不变，雨量消退后血月月盘和光晕恢复晴天可见度。

## 来源与启用条件

| 规则 | R196 来源 | 迁移行为 |
| --- | --- | --- |
| 8 张月相图及首日相位 | `aei.java:99–113`，`abw.java:1944–1955` | 使用公共 `LunarCalendar` 的相位；首日为相位 1，满月相位为 0 |
| 月盘颜色、大小、雨天透明度 | `bfl.java:762–800` | 主世界按全天事件着色，月盘半径始终为 20，透明度为 `1 - rain` |
| 血月、蓝月光晕 | `bfl.java:801–820` | 使用半径 160 的原版光晕图，透明度 `.25 × (1 - rain)`，天体角从 `.77` 到 `.785` 淡出 |
| 月晕（moon dog）圆环 | `bfl.java:821–849` | 使用半径 80 的原版圆环图；天体角 `.18→.28` 淡入、`.6→.785` 淡出；最大透明度 `.5 × (1 - rain)` |
| 普通、特殊月亮亮度和天气衰减 | `abw.java:1952–1958` | 普通为 `phaseBrightness × .5 + .75`，血 `.6`，收获 `1`，蓝 `1.1`；仅高于 `.75` 的亮度在雨中向 `.75` 衰减 |
| 月亮升起时的光照混合 | `abw.java:1969–1975`，`bfe.java:534–536` | 对天空光贡献插入源公式；不改变火把的亮度输入 |
| 夜间光照颜色 | `bfe.java:598–612` | 在现代 gamma 处理后、光照图转换为字节前插入源夜间色偏，并按天空光、方块光和月亮升起程度衰减 |
| 血月干旱地区的降雨显示与声音 | `bfe.java:958–988,1043–1097` | `renderSnowAndRain` 的气候门槛及 `tickRain` 的粒子/雨声共用服务端相同的 `LunarWeather.precipitation` |

特殊月盘颜色和光晕由全天事件标志控制；地面光照色偏由夜间标志控制。不能将二者统一限制为晚上，否则日出附近的源光晕会被过早截断。夜间边界使用公共日历，包含未偏移时间 `13000` 和 `23000`；边界处月亮升起因子为 0。

## 颜色与光照数值

| 事件 | 月盘 RGB | 额外图层 RGB | 满天空光、无方块光、深夜的光照 RGB 倍率 |
| --- | --- | --- | --- |
| 普通 | `(1, 1, 1)` | 无 | `(1, 1, 1)` |
| 血月 | `(.6, .2, .1)` | 同月盘 | `(2, 1.4, 1)` |
| 收获月 | `(1, .8, .45)` | 无 | `(1.48, 1.32, .84)` |
| 蓝月 | `(.66, .74, 1)` | `(.33, .37, .8)` | `(1, 1.1, 1.25)` |
| 月晕 | `(1, 1, 1)` | `(.4975, .6275, .85)` | `(1, 1, 1)` |

光照倍率使用 `min(moonAscension, .2) × skyLight/15 × clamp(1 - 2 × blockLight/15, 0, 1)`。因此没有天空光的地下空间不被血月染红，方块光达到 8 时也不再施加夜间色偏。月晕没有独立的地面颜色；它当天的普通满月亮度仍有效。

升起因子先将时间变为 `(dayTime + 6000) % 24000`：不超过 5000 时为 `1 - adjusted/5000`，至少 19000 时为 `(adjusted - 19000)/5000`，其余为 0。天空光贡献与月亮亮度的混合权重为 `clamp(moonAscension, 0, .2) × 5`。

## 原图与接入位置

以下文件逐字节提取自 `MITE Resource Pack 1.6.4.zip` 的 `assets/minecraft/textures/environment/`，在模组内使用 `mite` 命名空间，不要求玩家另外安装旧版资源包。

| 目标文件 | 尺寸 | SHA-256 |
| --- | --- | --- |
| `assets/mite/textures/environment/moon_phases.png` | 128×64 | `a6b22cc9fabbb51964fde3605016be83f97735fa9bdb422b2575976651387a00` |
| `assets/mite/textures/environment/halo_256.png` | 256×256 | `a56b03b076b6abe6624814dafa0ed04101d3ed192806db428d3128c4a8643095` |
| `assets/mite/textures/environment/ring_128.png` | 128×128 | `65cad5ba4deba74e862d6d0a4215f2602840f061c75f86252dc9ce4f003022d5` |

`LunarSkyMixin` 包装 NeoForge 21.1.259 的 `LevelRenderer.renderSky` 中第 3 个 `BufferUploader.drawWithShader` 调用，即月盘绘制。保留现代月盘顶点和 4×2 图集 UV；在同一加法混合阶段追加源光晕/圆环，最后恢复白色和天气透明度。直接取得该绘制点真实的 `PoseStack`，包含原生 `Y=-90°`、`X=celestialAngle×360°` 及其他模组追加的太阳路径倾斜，使月盘和光晕共享姿态；不复制整个天空渲染器。

`LunarLightTextureMixin` 每次更新取得一份日历/天气快照，用于全部 256 个光照图单元。已对照当前 NeoForge 合并类的字节码：`getBrightness` 的第 1 次调用是天空光，第 2 次是方块光；`Vector3f.mul(float)` 的第 3 次调用是最终乘 255，此时整数局部变量 0、1 分别为天空光和方块光。夜间色偏在此处施加。

`LunarPrecipitationMixin` 处理现代渲染的两个气候检查层次：先允许血月全天通过 `Biome.hasPrecipitation()`，再通过公共规则把原本 `NONE` 的降水转换为当前位置的雨或雪。实际降雨强度仍来自当前天气状态。

针对当前 Iris 1.8.14，月盘包装的 Mixin 优先级设为 900。实际转换字节码确认 Iris 的 `shouldRenderMoon` 条件位于外层，关闭月盘时同时跳过本模组的月色、光晕和圆环；不会留下独立光晕。该顺序与真实 `PoseStack` 由无窗口组合审计核对，不引入 Iris 的编译或运行前置。

迁移保留 1.21.1 的天空、云高度、流体/状态遮挡、夜视、黑暗效果、gamma 和现代光照图基础算法。原作低光亮度表微调、完全黑暗单元的最低亮度以及旧闪电视点衰减属于旧渲染器基础算法，不由本次月相补丁覆盖。所有新增图层和光照变化仅作用于主世界。会完全替换原版天空或光照图的光影包可能使用自己的显示逻辑，需要另行核对实际画面。

## 验证与手动检查

`LunarVisualsTest` 用独立写出的源数值验证月盘颜色、三个大小、两个光晕的淡入淡出、雨量衰减、升起时间、各个光照通道、火把/天空遮挡及跨维度隔离。它不启动游戏。

数据运行的可选 `LunarVisualAudit` 通过 `Class.forName(name, false, loader)` 触发 Mixin 转换但不请求目标静态初始化，再检查导出的实际字节码中 `renderSky`、光照图、雨粒子与雨声路径确实可达新增处理器，同时校验三张 PNG 的尺寸和 SHA-256。开关为 `mite.lunarVisualAudit=true`，必须同时启用 `mixin.debug.export=true`；报告可由 `mite.lunarVisualAuditOutput` 指定，默认 `build/verification/lunar-visual-audit.json`。审计不创建 Minecraft 实例、不建世界、不调用 OpenGL、不操作游戏窗口；通过只能证明代码注入和资源证据，不能代替画面验收。

手动验收在有权限的主世界进行，先关闭光影包，并临时设置：

```mcfunction
/gamerule doDaylightCycle false
/gamerule doWeatherCycle false
/weather clear
```

然后分别设置以下绝对时间，面向天空观察月亮，并在无遮挡平地和火把旁比较环境颜色：

| 命令 | 预期 |
| --- | --- |
| `/time set 186000` | 第 8 天普通满月，白色月盘，没有额外光晕 |
| `/time set 90000` | 第 4 天新月，月盘暗面，无特殊光晕，月光比满月暗 |
| `/time set 570000` | 第 24 天收获月，金黄色月盘，环境偏暖，无额外光晕 |
| `/time set 762000` | 第 32 天血月雷暴夜，月盘和光晕按雨量遮蔽，低方块光、可见天空处偏红 |
| `/time set 3066000` | 第 128 天蓝月，蓝色月盘和蓝色大光晕 |
| `/time set 2874000` | 第 120 天月晕，白色满月外有较小的蓝灰色圆环，地面没有额外色偏 |

在非血月事件日逐渐推进时间可以观察日出附近的光晕淡出；切换 `/weather rain`、等待雨量渐变完成后，应看到月盘和光晕随天气一起隐藏。当前血月白天降雨、夜间干雷，可用 `/time set 750000` 检查白昼暗红天空、云和空气雾，`/time set 762000` 检查夜间雨幕和雨声消退而雷声、闪电、血月颜色保留；干旱地区白昼也应出现降水画面与适用的雨声。普通日干旱地区保持原有气候。

切到下界、地底世界和末地检查没有额外月盘或月相色偏，再返回主世界核对仍显示当天事件。验证后恢复原有 `doDaylightCycle`、`doWeatherCycle` 和时间/天气设置；上述检查会改变测试存档时间，推荐使用专用测试存档。
