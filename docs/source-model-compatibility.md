# 特殊僵尸与地狱苦力怕模型兼容

开发与验证：NingMeng123，2026-10-26；配套版本 0.2.14。

## 修复设计

用户反馈大力士僵尸、恶魂僵尸、红色食尸鬼、地狱苦力怕和黑暗地狱苦力怕在启用资源包后外观或动画异常。此补丁同时更新 `mite` 本体和 `modern_ite` 扩展；扩展使用新的本体客户端模型接口，需要本体 0.2.14 或更新版本。

FA+Creepers 2.1 为原版苦力怕提供随机普通、骷髅、岩石与泥巴模型，其中岩石和泥巴使用 64×64 图集。两个地狱变种的自有身体和黑暗变种的红眼遮罩是 64×32，直接使用标准 CEM 几何会把脸或眼睛移到身体。它们现在保留原六部件、原 UV、原皮肤和发光层，以隐藏的标准苦力怕采样基础形态的动作，并将实际可见部件的累计矩阵映射到原模型。只固定这个隐藏驱动，原版苦力怕继续保留资源包的随机外观。

带电覆盖层同样保留原 64×32 图集及两像素膨胀，并由相同动画驱动；避免本体正确而覆盖层仍使用随机 CEM。原膨胀、闪白、爆炸、属性和 AI 没有改动。

扩展中的三个僵尸借用标准僵尸动画，仍绘制原几何与皮肤。大力士保留已验证的 64 高逻辑 UV、空帽层和双臂上勾拳；红色食尸鬼保持 64×32。恶魂僵尸保留空的僵尸头／帽节点，通过动画头部挂点绘制独立恶魂头，龙头僵尸共用此无头身体的挂点处理。累计矩阵映射排除隐藏的原版方块，使用直接 ZYX 分解以避免摆臂偏移。

未安装 EMF、未加载相关 CEM 或无法完整映射时继续使用原生动作。没有复制或修改任何第三方资源包文件。

## 验证与复核

主工程执行 `build compileGametestJava`；扩展使用相同本体 JAR 构建，在隔离客户端实际渲染上述五种实体。审核覆盖原方块／UV、待机与行走的六骨骼角点、恶魂独立头层、大力士双臂上挑、苦力怕膨胀、八个 UUID 的皮肤稳定性、暗处头部红眼和带电覆盖层。

客户端组合按用户启用顺序放入 Fresh Animations 1.10.4、AL's Creepers Revamped 1.4、FA+Emissive 1.6、FA+Creepers 2.1，以及 EMF 3.3.12、ETF 7.2.6；另在无第三方模组／资源包的目录检查原生回退。运行只创建一次性测试世界，不操作用户正在玩的游戏。实际结果及 JAR 哈希保存在交付目录中的验证记录。

手动复核时同时替换两个旧 JAR，保留现有资源包后重启。生成上述五种实体，检查苦力怕面孔与红眼在头部、三个僵尸原皮肤与专属头部正常，再观察行走、上勾拳、膨胀和带电外观。自动样本不替代用户存档、光影与多人实玩。

本体 1763 项 JUnit、扩展隔离副本 38 项 JUnit 及双方构建通过；启用用户 FA 组合、未安装 EMF 的两份 GPU 审核均为 `passed`，`failures` 为空。两种带电层与身体六骨骼变换一致，黑暗地狱苦力怕八个 UUID 的原生 UV 保持，独立头部发光对照通过。2026-10-26 用户授权将当前模型补丁提交到 GitHub，未另行提供逐项光影、原存档与真实多人验收记录。
