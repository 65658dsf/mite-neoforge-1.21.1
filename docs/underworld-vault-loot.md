# 地底试炼宝库奖励

开发署名：NingMeng123。适用 Minecraft 1.21.1。

按用户要求调整 `mite:underworld` 的普通和不祥宝库。这是现代内容平衡，不是 R196 原有宝库数值。主世界宝库、密室箱子、试炼刷怪笼完成后的奖励不在本次调整范围内。

## 内容变更

- 加入远古金属粒、秘银粒和艾德曼粒；三种材料均以粒作为奖励。
- 普通、不祥奖励中原有的钻石斧和钻石胸甲分别替换为远古金属斧、远古金属胸甲，保留原条目的附魔等级、随机附魔函数和其他设置。钻石、钻石块继续作为材料奖励。
- 移除宝库中的唱片、旗帜图案和盔甲纹饰锻造模板。
- 提高绿宝石、钻石及不祥宝库附魔金苹果的获得率。保留沉重核心每次开启 7.5% 的概率。
- 材料箭覆盖已注册的全部十种；保留原有剧毒箭和不祥宝库缓慢 IV 药箭。

## 实现与存档

结构化源为 `src/main/resources/mite/underworld-vault-loot.json`，由 `UnderworldVaultLootProvider` 读取锁定的原版 1.21.1 表，生成十份独立 MITE 战利品表；修改源后运行 `runData`。运行时数据包可以覆盖生成后的 MITE 表，源配置文件本身不是服务端热重载配置。

`UnderworldVaultLoot` 仅在地底服务端读取/保存宝库配置时，将原版普通和不祥根表映射到 MITE 根表，八种原版预览表也同步映射。自定义奖励表和自定义预览保持作者设置。沿用原生钥匙、激活范围、检测器、已领奖玩家、待弹出物品、状态和延迟；不重置已开过的宝库。已有未开启宝库不需要重新生成，客户端重启加载新代码后即可使用；已排队的奖励保持原结果。

## 用户手测

请自行重启测试客户端加载最新代码；本轮没有操作游戏窗口。建议使用测试存档，打开作弊。

1. 定位地底密室，使用自己的存档返回坐标前往；无需为本次奖励修改重新生成房间：

   ```mcfunction
   /execute in mite:underworld run locate structure mite:underworld_trial_chambers
   ```

2. 用试炼钥匙开启尚未领取过的普通宝库，用不祥试炼钥匙开启不祥宝库。确认预览和实际奖励正常，没有钻石装备、唱片、旗帜图案或纹饰模板，原生开锁和弹出动画仍正常。稀有条目不保证少数几次就出现。
3. 如需快速检查内容，可反复执行下面的奖励命令；这些管理员命令直接引用表，在任何维度都能使用，与宝库仅在地底替换的规则不同：

   ```mcfunction
   /loot give @s loot mite:chests/underworld_trial_chambers/reward
   /loot give @s loot mite:chests/underworld_trial_chambers/reward_ominous
   /loot give @s loot mite:chests/underworld_trial_chambers/arrows
   /loot give @s loot mite:chests/underworld_trial_chambers/arrows_ominous
   ```

4. 检查三种金属粒、各材料箭以及带附魔的远古金属斧/胸甲，箭可以正常使用。少量随机抽取只用于检查内容；精确掉率由独立有理数审计验证。
5. 保存退出再进入，确认已领取过的宝库仍不能由同一玩家重复开启，未领取过的宝库正常使用。主世界宝库继续使用原版奖励。

自动验证记录见 [地底宝库验证](testing/underworld-vault-loot-automated-results.md)。2026-10-15 用户反馈“没有问题了提交吧”，确认本批交付正常并授权提交；逐项画面和真实多人结果未另行记录。
