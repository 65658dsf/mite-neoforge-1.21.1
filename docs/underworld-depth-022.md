# 022 地底负数高度与地幔可达性修复

维护者：NingMeng123。原作：Avernite，MITE 1.6.4 R196。

用户实测发现021地底世界沿用旧版Y0..255和多层不可挖基岩，无法适应当前存档高度，生存玩家也无法正常下掘到地幔。本轮将**新生成地底区块**改为Y−64..319，并把内部基岩层转换为可挖石头，保留底部地幔和顶部基岩。主世界和下界仍使用各自的1.21.1生成器。

本轮是明确的现代高度与可达性适配。R196旧地形算法和独立字节码金值保持不变，不能把现代扩展后的地图称为与旧版逐方块一致。来源证据继续见[021来源规格](underworld-021-evidence.md)及[原地形金值说明](r196-underworld-generation-021-evidence.md)。本页与[022结构化规格](../spec/underworld-depth-022.json)记录现在采用的适配。

地形转换先运行已校验的R196地形，再按下列离散映射扩展高度：

```text
sourceY(modernY) = floor((modernY + 64) × 256 / 384)
modernFirstY(sourceY) = ceil(sourceY × 384 / 256) − 64
```

`ModernUnderworldTerrain`处理现代绝对Y与数组索引，原`R196UnderworldTerrain`保留来源坐标。菌丝搜索范围、生成器高度、列查询、调试信息及地底热伤使用现代边界；蘑菇检查当前维度的实际最小/最大高度。下界Y0地核、Y123..127屋顶地幔及下界热伤门槛保持原规则。

这不是矿物高度规则。后续矿脉必须分别核实来源分布、材料阶段和现代深度，不能把所有矿物Y乘1.5、加120或直接套洞穴缓存偏移。现有`mite:underworld_ore_replaceables`仍只允许石头、深板岩，不允许替换地幔、地核或基岩；本轮没有添加矿脉。

## 传送与已有存档

主世界↔地底X/Z不缩放，涉及下界的X/Z仍按8倍换算。普通门找门与符文门安全落点都使用目标维度实际高度。地底自动建门的旧高度70后备位置映射到41，下界后备高度70保持不变；不可变边界、容器和已有门仍受到保护。普通自动回程门保存的反向路由不因高度变化被重新覆盖。

新生成地底区块保存`mite:underworld_layout_version=2`，此前没有标记的区块读取为0。本轮**不自动重生成、不清除或补写旧区块**，也不删除任何存档、玩家物品或门。旧区块仍保存旧地形；扩展维度高度不会让其缺失的负数区段自动变为新地形。版本标记为后续兼容提供识别依据，不代表已实现旧存档地形迁移。

手测建议新建测试存档。需要保留旧存档时，先自行备份，再到此前未生成的地底区域验证；新旧区域交界可能有高度不连续。不要以旧区域仍有基岩层判定新生成器未生效。此次修复也不承诺已经生成的整片地底区域会自动改变。

## 手动复测

请自行重新启动客户端加载新代码，保持`/tick rate 20`。下列步骤使用开启作弊的新测试存档，游戏窗口由用户自行操作。先观察新地形：

```mcfunction
/gamemode spectator
/execute in mite:underworld run tp @s 0 176 0
```

查看上层石质洞穴、水域和菌丝，再向下穿过岩层到负数高度。预期Y−64..−60出现发光地幔，地幔上方不再有内部不可挖基岩阻断；顶部基岩位于Y316..319。地底仍无天空、降雨及可见太阳。

要复测实际可达性，给出测试工具后，在洞穴中切生存，沿阶梯逐步下挖。石头可以挖掉，到地幔时才遇到不可挖边界。重点检查途中不再遇到旧Y3、32、72、96一类封闭基岩层。可携带食物并临时给予抗火，便于单独检查通路；热伤测试时清除抗火效果。

```mcfunction
/give @s mite:mithril_pickaxe
/give @s minecraft:cooked_beef 64
/effect give @s minecraft:fire_resistance 1200 0 true
/gamemode survival
```

在挖出的自然地幔表面搭标准黑曜石门：外框4×5，内空洞2×3。**底框直接放在地幔上**，底框Y必须≤−56；不需要也不要用命令补放地幔。点燃后生存模式持续站在门内约4秒，预期进入下界。走出门、等待一秒后再次进入，预期回到地底来源门。主世界底部基岩门进入地底及高位地底门回主世界也应保持正常。

最后在地底保存退出并重进，复查所在位置、自然地幔、挖掘通道、工具损伤及门路由仍然保留。旧存档另行检查玩家建筑与容器不被此更新改写。
