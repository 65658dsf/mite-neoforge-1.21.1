# 034：MITE 独立创造分类

开发者：NingMeng123。

按用户要求，把新增的 MITE 内容从原版创造分类迁到独立 MITE 页，沿用现有“食品与容器”的入口方式。按用户补充要求，不再设置“建筑与装饰”独立页，将其内容并入“材料与矿物”和“功能方块”，共六页；“食品与容器”页仅展示 MITE 新增食品与容器，不展示原版物品。此次属于现代界面整理，不改变 R196 物品配方、属性和取得条件。

## 分类

| 创造分类 | 内容举例 |
| --- | --- |
| MITE 材料与矿物 | 金属粒、金属锭、链、碎片、钱币、矿石、地狱沙砾、金属块、花草、凋零灌木、虫蚀方块 |
| MITE 工具与杂项 | 手斧、斧、镐、锹、锄、鹤嘴锄、镰刀、剪刀、小刀、钓鱼竿、胡萝卜钓竿、祛魔瓶、唱片 |
| MITE 武器与装备 | 木棒、短木棒、短剑、剑、战斧、战锤、强化弓、箭、投掷球、护甲、马铠 |
| MITE 食品与容器 | MITE 新增食品、加工原料、蓝莓灌木、碗装食品、各金属桶及石桶 |
| MITE 功能方块 | 工作台、炉体、铁砧、金属箱子、绿宝石附魔台、符文石、门、栏杆 |
| MITE 生物刷怪蛋 | 现有 29 种 MITE 生物刷怪蛋 |

六页按上表顺序排列；标签较多时使用创造菜单的分页箭头。沿用 `mite:foods` 注册身份，没有另建重复食品页。页内新增物品按注册名稳定排序。

分类范围是全部 `mite` 注册物品，以及复用 `minecraft:wooden_sword` ID 的木棒。普通原版共享材料和装备维持其原版身份。食品页不再加入原版食品和空容器；原版苹果、面包、碗及原版桶仍可在相应原版分类与全局搜索找到。禁用的木斧、木镐、原版工作台仍不展示。

两种符文石各保留 16 种符文，六种新增铁砧各保留完整、破损、严重破损三个组件状态。无独立物品的地幔、地核和盆栽等不生成空气占位。每个新增物品只归一个 MITE 分类；全局搜索继续汇总它们及其组件变体。

## 手动测试

1. 保存并自行重启测试客户端，在测试存档切到创造模式，打开物品栏。用标签分页箭头找到六个 MITE 分类，检查中文名称、图标和翻页是否正常；不再出现“建筑与装饰”独立页。
2. 分别查看铜镐、秘银剑、银甲、金属粒、矿石、工作台、炉体、钓竿和刷怪蛋，确认可从上表对应分类拿取。在“材料与矿物”检查金属块、花草、凋零灌木和虫蚀方块，在“功能方块”检查门和栏杆，确认合并后的归属。
3. 查看原版的材料、工具、战斗、自然方块、功能方块等分类，确认其中没有新增的 MITE 物品；木棒在 MITE 武器与装备页。
4. 在“功能方块”确认两种符文石均有 16 个符文，新增各材质铁砧均有三个损坏状态；拿取并放置，外观应对应。
5. 在“食品与容器”确认 MITE 新增食品、蓝莓灌木和金属桶都在，石桶也归该页；确认没有原版苹果、面包、碗及原版桶。到相应原版分类或全局搜索中查找这些原版物品，确认仍能拿取。再搜索“秘银”“铜镐”“木棒”等，确认 MITE 内容仍能搜出。
6. 确认木斧、木镐和已禁用的原版工作台没有重新出现在创造菜单或搜索中。
