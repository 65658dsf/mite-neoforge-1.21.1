# 023 R196 矿石与矿脉手动验收

开发者：NingMeng123。本批不操作你的客户端；请自行重启开发客户端或替换模组 JAR 后重启。以下仅用于新建、开启作弊的测试存档，避免把旧区块当成本批生成结果。

## A. 注册、材质与深板岩变体

在 JEI 搜索“银矿石”“秘银矿石”“艾德曼矿石”，确认三类矿石及各自深板岩变体有名称、材质、方块模型和物品模型，没有黑紫缺失材质。普通矿石保留用户指定资源包中的原图；深板岩变体使用独立的 16×16 深色矿图，分别保留原矿银白、极浅冰蓝和近黑暗靛矿点，应能从石质底色区分深浅变体。新增粗银、粗秘银、粗艾德曼采用原版粗铁轮廓与棕灰石质基体，矿点色与普通矿石一致，使用透明背景的 16×16 物品图，在背包与 JEI 中均应正常显示。材质提示词与导入说明见 [现代矿石材质记录](../art/modern-ore-textures.md)。原版铜、铁、金、煤、红石、青金、钻石、绿宝石和下界石英继续使用现有物品 ID，不应出现重复同名矿石。另有蠹虫下界岩 `mite:infested_netherrack`，专属 Netherspawn 生物待后续阶段。

新增方块的测试命令：

```mcfunction
/give @s mite:silver_ore
/give @s mite:deepslate_silver_ore
/give @s mite:mithril_ore
/give @s mite:deepslate_mithril_ore
/give @s mite:adamantium_ore
/give @s mite:deepslate_adamantium_ore
```

## B. 实际采集与工具门槛

先用创造模式摆好矿石、领取工具，再切换生存模式采掘。铜/银矿石需要铜级或更高的镐；秘银和绿宝石需要铁级或更高；艾德曼和钻石需要秘银级或更高。资格不足时不能积累有效挖掘进度，也不能删除方块或消耗工具耐久；资格满足后应正常采集。

```mcfunction
/give @s mite:copper_pickaxe
/give @s minecraft:iron_pickaxe
/give @s mite:mithril_pickaxe
/gamemode survival
```

按用户要求采用现代粗矿掉落：铜、铁、金、银、秘银、艾德曼矿石普通采集分别取得对应粗矿，普通与深板岩矿石共用对应粗矿；下界金矿保留原有矿石产物。精准采集应保留对应的原矿石方块。无时运、无精准采集时：煤、钻石、绿宝石、石英各 1 个，青金和红石各 3–5 个。十二种深浅金属矿石的时运按每原始单位 `0.1 × 时运等级` 概率额外增加一份粗矿，自然矿与玩家重新放置的矿石都生效。粗矿不能重新放置为矿石，因此无需沿用整块矿石的防复制限制；仍掉整块矿石的下界金矿保留该限制。分别检查自然矿石、创造模式放置及精准采集后重新放置的矿石。

钻石原始每单位采集经验 30、绿宝石 20、石英 10、青金 5，煤/红石/金属矿石普通采集为 0。青金普通一次为 15–25 点；时运额外复制单位不增加经验。测试精准采集应取得原矿石，采矿经验为 0。

可以在一次性测试区域用 TNT 测试：煤不掉落；钻石/绿宝石/石英变成对应碎片；金属保留矿石方块；青金/红石仍为 3–5 个。爆炸之后正常手挖宝石仍应取得完整宝石。

本批已接入确认的熔炼产出与经验：铜 10、银 15、金 20、铁 10、秘银 40、艾德曼 100；钻石 30、绿宝石 20、石英 10、青金每粉 5，煤/木炭/红石 0。用输出槽手动领取检查经验。按 R196，炉子下方漏斗成功取出矿物产物时，每件立即在炉子朝向前方生成对应经验球；漏斗已满或禁用时不生成经验，保存后不能再领取这批已发过的历史经验。此处恢复的是矿物漏斗奖励，食品此前的处理范围保持不变。023 初始阶段只接入产出与经验；当前完整炉温、燃料和熔炉等级已由 [024 熔炉体系](../furnaces-024-evidence.md) 实现，验收时须同时检查设备与燃料热级，普通冶炼配方本身不能绕过热量门槛。

将红石与青金各放入1块普通矿石、1块深层矿石，分别检查熔炉与高炉，每块应产出4个粉末。其他矿石每块产1个对应产物，金属为锭，煤为煤，宝石为宝石。新增银/秘银/艾德曼的六个深浅矿石及三种粗矿均有普通熔炼和高炉类型配方，各产一锭；粗矿的热级与对应矿石相同，银须热级2设备，秘银须黑曜石或下界岩熔炉，艾德曼须下界岩熔炉。普通熔炉完成一次为200刻，高炉100刻属于明确保留的现代设备适配；JEI不应出现同一原版矿石输入重复增加的MITE冶炼配方。

## C. 主世界现代地形和进度

新建正常主世界，在洞穴中检查现代山地、大洞穴、负高度及深板岩仍然存在。矿脉只能替换对应石质，不能填满空气洞室或覆盖基岩。负高度矿石应采用对应深板岩外观；本批不会把主世界整体换成旧版地形。

先用旁观模式观察新生成区块，再切生存模式抽样采掘。主世界不应出现自然生成的艾德曼矿石。新增矿物不会追补已经生成的旧区块；测试旧存档时应前往未生成区域。现代化石结构仍保留，其附带煤/钻石矿物填充改为骨块，不应另外形成绕过本批矿脉分布的矿物来源。

## D. 地底世界实际矿脉

通过主世界底部黑曜石门正常进入 `mite:underworld`，或用测试命令进入旁观模式后观察：

```mcfunction
/gamemode spectator
/execute in mite:underworld run tp @s 8000 160 8000
```

检查此前的 Y -64..319 地底高度、地幔与挖掘通路仍然正常；在新生成岩层中寻找铜、银、铁、秘银及艾德曼等矿脉。艾德曼应能在地底自然找到。选择一处矿脉，记录坐标后切换生存模式，使用符合等级的镐开采。不要用 `/setblock` 摆矿石替代自然矿脉验收。

## E. 下界与保存

从地底底部地幔门进入下界，检查下界金矿、石英及已有下界砂砾；现代下界地形、生物群系和远古残骸仍保留。退出存档、重进后复查记录的矿脉和已放置矿石，确认方块、掉落和进度标记正常。
