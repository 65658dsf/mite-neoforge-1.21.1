# JEI 工作台分组与左侧设备显示

开发者：NingMeng123。2026-10-17。

## 显示行为

同一条台上合成配方不再为每种能制作它的工作台重复生成顶部分类。按最低加工能力分组，将全部适用工作台注册到 JEI 左侧设备栏；背包 2×2 保留独立分类。顶部分类的工作台名称与图标代表该组最低可用工作台。

| 配方举例 | 左侧可用工作台 |
| --- | --- |
| 铜镐 | 铜、银、金、铁、远古金属、秘银、艾德曼 |
| 铁镐 | 铁、远古金属、秘银、艾德曼 |
| 秘银镐 | 秘银、艾德曼 |
| 艾德曼镐 | 艾德曼 |
| 原木加工木板 | 全部九种工作台 |
| 制作铁工作台 | 铜、银、金、铁、远古金属、秘银、艾德曼 |

铜、银、金的加工能力均为 4，因此共用一个分类。加工能力依次为 1、2、4、8、16、64、256；不同门槛仍分组，避免在艾德曼工具配方旁错误显示燧石工作台。

制作时间展示 0 级、默认品质下各适用台的最快至最慢范围；时间相同则只显示一个值。鼠标停留在时间一行可查看每种工作台的具体时间。实际制作的品质、玩家等级和其他状态仍由服务端规则计算。

原始每台索引用于校验，JEI 注册使用合并后的只读展示索引。背包与工作台配方、不同来源的有效配方、奶酪批次数量和迷之炖菜花朵效果不会合并丢失。熔炉分类和动态修理、染色等原有页面继续使用各自逻辑。JEI 仍是可选扩展，不新增自动填料。

## 手动测试

1. 重启测试客户端进入存档，对铜镐按 R：对应合成配方只有一个工作台分类，左侧应有上表列出的七台；不能出现燧石、黑曜石工作台。
2. 对铁镐、秘银镐、艾德曼镐和木板依次按 R：检查左侧工作台集合与上表一致。对铁工作台按 R：可从铜／银／金台开始制作，不要求先有铁台。
3. 对铜、银、金、铁、艾德曼工作台分别按 U：仍能查看这些台支持的各档配方。左侧每个工作台悬停显示正确名称，点击和用途查询正常。
4. 悬停配方的制造时间，检查各台时间；切换配方页、关闭重开、退出重进后，配方不因合并而丢失或重复。
5. 奶酪保留各数量批次、迷之炖菜保留不同花朵页面；熔炉、动态修理和染色页面可正常查看。背包合成仍仅 2×2，木板不能在背包制作。
