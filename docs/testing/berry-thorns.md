# 浆果灌木刺伤

开发者：NingMeng123。

2026-10-16：本批构建、1455 项 JUnit 和 1574 项服务端 GameTest 全部通过。用户手动测试后反馈“好了提交吧”，授权提交；不补写逐项手测结果。

MITE 蓝莓灌木恢复原版浆果灌木的接触刺伤和减速；原版甜浆果灌木继续使用同一套原版规则。两种都刺伤是用户明确指定的调整，R196 蓝莓灌木原本没有这项刺伤。

生长阶段大于 0、玩家在灌木中水平移动时造成 1 点基础伤害；幼苗、站立不动或只做垂直移动不刺伤。护甲和保护附魔正常减伤，创造模式不受伤。狐狸和蜜蜂保持原版豁免。

## 手动检查

1. 重新启动客户端。在可生存的泥土或草方块上准备两种灌木。蓝莓仍要求适合其生长的生物群系，使用已有野生灌木最方便。也可在适宜位置用 `/setblock ~2 ~ ~ minecraft:sweet_berry_bush[age=3]` 和 `/setblock ~-2 ~ ~ mite:blueberry_bush[age=3]` 放置成熟灌木。
2. 切为生存模式并脱下护甲，分别在两种灌木中移动，应减速并受伤；不要在创造模式判断伤害。新种的阶段 0 幼苗只减速，静止不动不持续刺伤。
3. 穿戴护甲及保护附魔后重复，应正常减伤；低于半颗心的实际伤害可能不会立即在 HUD 显示半颗心变化。

自动测试使用实际灌木回调和服务端玩家，覆盖两种灌木的生长阶段、移动与静止、减速、护甲与附魔、狐狸和蜜蜂豁免。客户端由用户手动验收。
