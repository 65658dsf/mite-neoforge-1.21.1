# JEI 铁砧维修与适用设备

开发者：NingMeng123。2026-10-17。

## 展示行为

全部材质的装备维修合并为一个“铁砧”分类，标题直接使用普通铁砧名称，不加“装备修理”或“及以上”。对装备按 R 查看修理方法，对铁砧按 U 查看其支持的装备；配方窗口外侧使用与工作台相同的 JEI 原生竖排设备栏，配方本体保持紧凑的两输入和一输出布局。同一装备的同一种修理方式不会因多个铁砧而重复。

| 装备 | 左侧合格铁砧 |
| --- | --- |
| 铜／银／金装备 | 铜、银、金、普通铁、开裂铁、损坏铁、远古金属、秘银、艾德曼 |
| 铁／锁链装备 | 普通铁、开裂铁、损坏铁、远古金属、秘银、艾德曼 |
| 远古金属装备 | 远古金属、秘银、艾德曼 |
| 秘银装备 | 秘银、艾德曼 |
| 艾德曼装备 | 艾德曼 |

铜、银、金铁砧加工能力均为 4；铁的三种损耗状态均为 8。后续门槛为 16、64、256。这些只是维修能力数据，不再生成多个顶部分类。侧栏设备任选一种即可，设备不作为原料消耗。若同时显示多种材质的维修配方，侧栏只列它们共同适用的铁砧；按某一装备查询时，列出该装备的全部合格铁砧。

每种可识别装备显示同物品合并修理；有金属粒原料的装备再显示一粒修复示例。页面标明原料、恢复耐久、铁砧损耗和不消耗经验，不能把一粒示例误认为全部修满。默认品质受物品实际品质上限限制。实际修理仍要求玩家具备对应品质的制作能力；该门槛不根据查看者当前经验过滤 JEI 页面。

木棒、燧石／黑曜石工具、皮革装备没有金属粒修理，但保留同品质装备合并。金属盾、强化弓、金属钓竿也按各自真实维修规则显示。普通弓、未被材质维修规则识别的现代装备继续使用原有页面。

装备合并要求相同品质、右侧无附魔，盾牌底色与纹样一致；保留左侧品质、附魔及颜色，不凭空增加原版修理奖励。原料修复会消耗铁砧耐久，装备合并不消耗。计算复用 `MaterialAnvilRules.previewRepair`；服务端 `plan` 继续验证玩家能力、脱魔瓶及附魔书优先规则。

只隐藏被本次页面覆盖、且带有 JEI 已确认生成修理 UID 的旧原版修理页，避免继续提示铁锭等错误原料。附魔书、未覆盖装备和未知模组操作保留；不隐藏整个铁砧分类，也不修改原版铁砧标签。JEI 仍是可选扩展，不新增自动填料。

JEI 在方块注册之前发现插件，统一类别 ID 为 `mite:equipment_repair`，不在静态初始化时读取未绑定的方块。每条配方通过不可见的 `RecipeIngredientRole.CATALYST` 登记自身可用铁砧，U 查询只匹配该砧支持的配方。可选 JEI Mixin 仅对本模组统一维修分类提供动态侧栏数据，复用 JEI 原生外侧竖排的背景、悬停和点击；不自绘九宫格，也不改变其它分类。

## 手动测试

1. 替换测试模组 JAR、重启测试客户端进入存档。对铜镐按 R：顶部应只有一个本模组维修分类“铁砧”，窗口外侧左栏应竖排显示九种铁砧，包含铜／银／金及三种原版铁砧；金属粒页用铜粒，不能再提示铜锭修复。
2. 对铁镐、秘银镐、艾德曼镐按 R：适用铁砧分别为上表的六种、两种、一种；各材质仍在同一个“铁砧”分类内。对对应铁砧按 U：能看到支持的维修装备，不会列出更高材质的维修配方。
3. 查看铜镐的一粒修复和装备合并页面：恢复耐久及铁砧损耗不同；按示例实际维修后核对产物。木棒、燧石工具、皮革装备只有合并修复；盾、强化弓、金属钓竿有对应修复说明。
4. 查看附魔书用途、普通弓和下界合金等原有铁砧页面，确认保留；已有工作台／熔炉页面仍可查看。
5. 对高品质装备在经验不足和足够时分别实际修复：JEI 始终能查看默认示例，实际输出依旧受玩家品质能力限制；可制作时维修本身不扣经验。
