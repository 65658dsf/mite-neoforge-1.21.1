## 本批范围

本批是食物部分的第一步：双饱食/营养共用底座、三种微量营养和糖抵抗、来源食品的食用数值与效果。已有 49 个食品 ID：33 个保留 R196 来源值，16 个适配（15 个现代食品及 1 个小麦种子用户规则）；蛋糕另从方块处理。小麦种子有效 S/N=0/0、只补 1 点原版饱和度，不补 P/F/V，原 R196 的额外脂肪 2000 不应用。

新增可食用入口包括蘑菇、糖、种子、下界疣和鸡蛋。鸡蛋默认吃，Ctrl＋右键投掷；种植和原生方块/实体交互继续优先。所有目录内手持食品均为 32 tick，蛋糕六片即时食用。普通金苹果为再生 I 1200 tick；附魔金苹果为再生 II、抗性 I、抗火 I 各 1200 tick，不额外保留原版伤害吸收。腐肉是 80% 中毒 I 400 tick，生鸡肉为 30%；红蘑菇中毒 I 200 tick及恶心 V 1200 tick。

**本批没有新增奶酪、面粉、面团、洋葱、蓝莓或各类新汤，也没有替换食品配方、熔炼/炉温与自然取得链。** 这些将按食品类别继续实施，本底座不等于食品全量复刻完成。详细数值见 [食品目录与适配](../foods-018-evidence.md)，代谢证据见 [玩家规则](../r196-player-rules.md)。

## 准备

请自行重启测试客户端加载新 Java 代码。F3+T 不会更新逻辑。使用允许命令的测试副本，保存随身物品，留足背包空位；开发客户端可领取物资：

```mcfunction
/reload
/function mite:test_food_018
/gamemode survival
/experience set @s 35 levels
/experience set @s 0 points
/tick rate 20
/mite food set reserves @s 0 0
/mite food set saturation @s 0
/mite food status @s
```

35 级容量为 20，方便直接核对食品完整增量。0 级容量仍为 6，超过容量会截断。物资函数只发物品，不清包、不改世界或玩家状态，不进入发布 JAR。下列诊断命令需要管理员权限/作弊：

| 指令 | 作用 |
| --- | --- |
| `/mite food status @s` | 查看 S、N、原版饱和度、三种微量营养、糖抵抗及阶段 |
| `/mite food set reserves @s S N` | 分别设置饱食与营养，按当前容量限制；S 降低时可将已有原版饱和度钳位，不改微量营养 |
| `/mite food set saturation @s value` | 设置 0–20 的浮点原版饱和度，实际值限制在当前 S 内 |
| `/mite food set nutrients @s P F V` | 设置蛋白、必需脂肪、植物营养素；每项 0–160000 |
| `/mite food set resistance @s R` | 设置 0–192000 的抵抗并重新按阈值选阶段，用于测试；正常恢复仍按滞后规则 |

营养 N 独立于苹果皮显示的原版 saturation。营养面板只显示 N、P、F、V、糖抵抗五行；原版饱和度请用状态命令或苹果皮核对。数值会随服务器正常 tick 代谢，微量营养每 tick 减 1；对照食用前后差值时需考虑经过的 tick。

## A：双资源、食物数值与界面

1. 清除药水效果，设置 S=N=0，吃面包应增加 **8 饱食、2 营养**；再清空双资源吃熟牛肉，应增加 **10/10**。不得恢复原版快速饱和回血。
2. 同样检查熟猪排 8/8、熟鳕鱼 6/6、熟羊肉 6/6、苹果 2/1、鸡蛋 1/3、蘑菇煲 2/4。低等级会受容量限制。
3. 0 级新建玩家 S=N=6，升到 5 级容量变 8，但不自动补充；已有高值降回 0 级时，两项都限制为 6。
4. 背包/JEI 悬停显示 S/N、微量营养类别及实际糖抵抗增量。按 E 打开背包，点击配方书按钮右侧的**饱和效果图标**，应出现营养面板，只有 N、P、F、V、糖抵抗五行，显示 `当前值/上限 (整数百分比%)` 与提示中的精确数值；N 的上限随等级，P/F/V 为 160000，糖抵抗为 192000。执行 `/mite food set nutrients @s 159654 160000 112998` 后，P/V 应分别接近 99%/70%，正常 tick 下数字继续微量下降。
5. 在营养面板分别按 Esc、E、点击“返回”，都应回到原背包。拿起任意物品使其跟随鼠标，打开/返回面板后检查物品仍在原拖拽状态，不丢失、不复制、不意外扔出；主手/副手任意持物也应能打开按钮。切换 GUI 缩放、宽/窄窗口、打开/关闭配方书，并保留 JEI 搜索与结果面板一起测试。窄屏展开配方书时隐藏营养按钮与品质条；背包品质条位置为相对 (136,49)，不得和营养按钮或槽位互抢点击。再检查快捷栏蛋白/植物条、副手、攻击指示器、空气/坐骑生命/选中物品名互不遮挡。
6. 服用药水、水瓶与灾厄瓶应维持各自功能，不误补食品营养。蜂蜜和紫颂果的现代功能保留，数值适配单列在目录。

## B：摄入限制、蛋白与植物营养

1. 设置 S=N=20，普通食品应无法吃；金苹果和奶桶保留满值可用的来源例外。
2. S=20、N=1 时，普通面包仍会拒绝：原作不只是看任一条没满就允许。S=20、N=0 时可吃具有营养的食品；牛奶 S=0 的食物值允许补低营养而不加饱食。
3. 设置 S=N=20，P=0、F=160000、V=160000。熟肉可以食用补蛋白，即使双资源满值；苹果不能替代缺失蛋白。将 V=0、P=160000 后，苹果可以补植物营养。
4. 小麦种子只补原版饱和度，按以下步骤独立测试；先清除恶心并以空中右键食用，避免种植消耗：

   ```mcfunction
   /effect clear @s
   /mite food set reserves @s 4 3
   /mite food set saturation @s 0
   /mite food set nutrients @s 0 0 0
   /mite food status @s
   ```

   吃一份后应为 **S4/N3/原版饱和度1**，P/F/V 仍为 0；不得出现 S+1、N增加或脂肪+2000。再次吃可累加饱和度，但最高为当前 S4。将 S/N 设为 0/3 后，已有饱和度应被压到 0，再吃种子仍为 S0/N3/饱和度0。把两项都清到 0 时，种子不能恢复双资源能量或替代 N。历史 R196 S1/N0、F=true、脂肪2000仅为来源记录，当前不执行。

   再清空双资源并吃熟牛肉，N10 补蛋白 80000，不补另外两项。
5. 单独 F=0、P/V满值不会显示营养不良；蛋白或植物值为零会显示，并使代谢更快、自然回血更慢。
6. 恶心会阻止食品和牛奶摄入，牛奶不能借清效果绕过。玩家眼睛浸水时不能摄入本批食品和牛奶，包括有水肺；未将药水/水瓶改为食品，未额外实现未注册的饮食诅咒。

## C：32 tick、取消和鸡蛋投掷

1. 对空中右键食用，20 TPS 下约 1.6 秒。中途松开右键，应不消费、不补状态；副手也应一致。
2. 普通右键鸡蛋应吃掉一枚并增加 1/3，不生成投掷实体；Ctrl＋右键则只投一枚，不加 S/N。先松开取消进行中的食用，再切 Ctrl 投掷。
3. 满 S/N 或恶心时普通吃蛋失败，Ctrl 投掷仍可用；主手和副手分别测试，不能两手都扣、扣两枚或先吃后投。
4. 刚切换热栏/刚转视角后投掷，应来自当前手持槽并沿当前视角。鸡蛋提示应显示 Ctrl 操作。

## D：容器、奶、蛋糕与食物效果

1. 四份蘑菇煲吃一次剩三份，增加一空碗；最后一份换一个空碗，不能整叠消失或双返。满背包时空碗掉落；创造模式不额外生成空碗。
2. S=N=0 时喝一桶奶：只补 N4，不加 S，退一个铁桶；正负药水效果清除。饮用前若有恶心，应无法饮用且不清效果、不扣奶。
3. 蜂蜜 32 tick 完成，现代 6/6、保留解毒，退一个玻璃瓶；两份只产生两个瓶。
4. 放蛋糕，设置双资源为空后吃一片，应即时增加 2/2，不开始 32 tick 手持食用。每片含蛋白和 166 糖；反复清空双资源后吃到第六片，方块应消失。
5. 未吃蛋糕破坏可取回一蛋糕，吃过任一片后再破坏不能取回；手持蛋糕仍放置而非直接吃。
6. 腐肉/生鸡肉的中毒有概率，几次没触发不代表失败。蜘蛛眼必定中毒 I 100 tick；毒马铃薯 60% 中毒 I 100 tick；红蘑菇还导致长恶心。金苹果不应叠加现代默认伤害吸收效果。

## E：糖抵抗、代谢、疾跑和制造

1. 清除效果并设置抵抗 0，吃一个苹果或一份糖，应积累约 **4800** 抵抗；饼干 **1200**，蛋糕每片 **796**。期间每有效 tick 下降 1。
2. 可用命令测试 48000/96000/144000 的轻/中/重度显示。正常下降存在滞后，轻度不会一低于 48000 就消失，归零才清状态。
3. 中/重度再吃糖食会少加饱食，自有提示应按当前抵抗显示调整后的饱食值；已有抵抗下继续加糖可恶心，重度另中毒。为单独验证响应，可设置双资源为空并用命令清效果；这只限测试副本。
4. S=0、N=1 仍可疾跑、正常采集和继续制造；两者都为 0 才无法疾跑、采集强度除 5、制造暂停。再次补其中一项应恢复，不能仍按单食物条判断。
5. N=0 时即使饱食满也会缓慢饥饿伤害；正常模式保持至少 1 点生命，困难允许致死。满微量、N6、离床时自然回血一生命约 1924 有效 tick，不使用原版 10/80 tick 回血。
6. 设置 S4/N3、原版饱和度1 后等待消耗：exhaustion 达到 4 时，应先扣 1 点原版饱和度，S/N 暂时保留；之后的消耗恢复双资源原逻辑。其它食品不会无故清空已有饱和度，但 S 下降仍会钳位。原版饱和度不启用快速回血，也不替代 N；单独 N=0 的慢饥饿伤害仍应发生。
7. 长时等待可 `/tick rate 200`，结束恢复 `/tick rate 20`；湿冷、入水与营养不良提高基础代谢。饥饿积压每 tick 只扣一次，不清空全部积压。

## F：保存、死亡、联机与兼容范围

保存退出重进，检查 S/N、原版饱和度、微量营养、糖抵抗与阶段；普通死亡和保留背包死亡都重新建立 S=N=6，微量营养与糖抵抗不清除；末地返回保留原双资源与微量状态。用两位玩家分别食用，状态互不串号；独立服务器重启和 JEI/Jade/AppleSkin 等模组实际共存需用户测试。

旧单食物条存档首次迁移：保存的食物值作为 S/N 两项起点，原版饱和度不当作营养；缺失微量状态初始化为满值。持久化版本为 1，整数/float 代谢进度都存储。保留现代动作造成的额外 exhaustion 与和平模式自身回血/补食物；没有声称所有移动/战斗/采集消耗、再生附魔、锦标赛睡眠惩罚已按 R196 替换。普通有效模式的基础代谢、摄入和慢恢复使用本批来源公式。
