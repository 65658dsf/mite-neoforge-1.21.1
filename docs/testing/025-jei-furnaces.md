# 025 熔炉 JEI 兼容与显示调整测试

开发者：NingMeng123。客户端由用户手动验收，本批通过前不提交 GitHub。服务端自动检查可以核对配方和实际烧炼规则，JEI 标签页、图标、提示与点击操作仍需要客户端实测。

## 准备

由用户重新启动测试客户端，继续现有带作弊的测试存档即可，不需要新生成地形。`run/mods` 中保留 `jei-1.21.1-neoforge-19.57.0.451.jar` 及已有开发辅助模组；不用移动或删除辅助模组。若之前加速过游戏，先执行 `/tick rate 20`。

把鼠标移到 JEI 中的物品上按 **R** 查看制作配方，按 **U** 查看用途。矿石的烧炼属于用途，先按 U；查看锭的获取方式则按 R。JEI 中切换顶部设备分类，查看对应炉体图标、原料、产物和燃料。

## 1. 去掉两处额外显示

打开任意熔炉，包括没有放材料的空炉。界面外部不再出现截图中的黑底“炉温：0 / 1”和“放入材料以查看所需炉温”面板。

在背包或 JEI 中分别悬停橡木原木、煤、纸和岩浆桶。普通物品提示不再出现“燃料热级：……，燃烧时间：……秒”。检查已有的品质、工具耐久和其它原本的物品提示仍正常。

## 2. 矿石应列出实际能使用的炉体

对以下矿石按 U，或对相应锭按 R，分别检查普通矿石和深板岩矿石：

| 原料 | 应出现的设备 | 不应出现的设备 |
| --- | --- | --- |
| 铁矿、铜矿、金矿、银矿 | 圆石熔炉、黑曜石熔炉、地狱岩熔炉、高炉 | 三种低温炉、烟熏炉 |
| 秘银矿 | 黑曜石熔炉、地狱岩熔炉 | 圆石熔炉、高炉、三种低温炉、烟熏炉 |
| 艾德曼矿 | 地狱岩熔炉 | 其它七种设备 |
| 远古残骸 | 地狱岩熔炉 | 包括高炉在内的其它七种设备 |

每个设备标签页应带对应炉体图标或名称。点击标签页和炉体图标，JEI 不应只展示一个泛用“熔炉”入口，也不应出现暗示秘银或艾德曼能用原版高炉加工的旧页面。

检查原料、产物数量和可用燃料：铁矿每个产 1 铁锭，低温木炭不能出现在铁矿的可用燃料中；秘银页面要提供热级 3 的岩浆桶，在地狱岩炉中还可使用烈焰棒；艾德曼页面只能提供热级 4 燃料。金属岩浆桶应在适用页面中正常显示。

煤矿只需低温，但它是大件：大黏土炉、砂石炉、圆石熔炉、黑曜石熔炉、地狱岩熔炉和高炉应有页面，小黏土炉和烟熏炉应没有。青金石和红石矿每个应显示 4 个产物。

## 3. 沙子和砂石的特殊加工

对沙子、红沙按 U：

- 低温页显示 **4 沙子 → 1 砂石**；红沙对应红砂石。燃料只提供低温燃料。
- 较高温度页显示 **4 沙子 → 1 玻璃**，可用燃料必须足够热。不要把木炭与玻璃结果组合在同一页。
- 小黏土炉不应有任何沙块加工页面。

对砂石、红砂石按 U，应显示圆石熔炉、黑曜石熔炉和地狱岩熔炉中的 **1 砂石 → 1 玻璃**，不应显示低温炉页面。

顺便在圆石熔炉实际测试 **红砂石＋木炭**：不能点火，也不能产出玻璃；换成煤后可以正常烧出玻璃。这修正了前一批红砂石漏掉热级 2 限制的问题。

## 4. 砖、食物和燃料数量

对黏土球按 U，六种普通炉都应有烧砖页面。页面分别显示每批 **1～4 黏土球 → 同数量砖**。烟熏炉和高炉不应混入这些普通烧砖页面。

对生牛肉、生猪肉、面团、大鱼查看烧炼：六种普通炉和烟熏炉可加工，高炉不可加工。普通炉每批 **10 秒**，烟熏炉和高炉每批 **5 秒**，对应默认 20 TPS 下的 200 刻和 100 刻。

牛肉页面中的纸应显示普通炉每批需要 **8 张纸**，烟熏炉每批需要 **4 张纸**；木棍分别需要 **2 根**和 **1 根**。这是连续燃烧所需数量，燃烧中断仍会清空加工进度。小黏土炉页面不能提供原木或煤，较大的低温炉可以提供原木。

## 5. 操作与可选模组检查

打开新炉体界面，再用 JEI 查看相关配方。JEI 应能正常展开、关闭、切换分类，不能遮住炉内的输入、燃料和成品槽。若 JEI 提供放入材料按钮，尝试点击并检查没有凭空增加物品；仍不足以烧炼时，炉子不得消耗不合法燃料。没有放入按钮的页面，按显示数量手动放入即可。

可选检查：在单独的测试客户端实例暂时不加载 JEI，模组仍应正常启动，炉体和实际烧炼规则仍可使用。本批服务端自动检查也会在没有 JEI 和 JEI API 的环境运行，不要求用户修改现在使用的测试实例。

## 自动验证与验收状态

新增 GameTest 核对所有展示原料与燃料组合是否匹配真正的烧炼批次，并用实际方块实体逐刻检查矿石、短燃料、砖输出空间，以及红砂石的低温拒绝和高温成功。另检查全部八种设备、深板岩变体、普通与现代设备耗时及没有 JEI 的服务端环境。

2026-10-13 自动检查通过：1071 项 JUnit、340 项服务端 GameTest，失败、错误与跳过均为 0。新增 11 项集成检查包含全部展示原料与燃料组合、独立矿物数值预期、真实炉体逐刻烧炼及红砂石修正；服务端实际没有加载 JEI，且 `mezz.jei.api.IModPlugin` 不在运行类路径中。

构建只使用锁定版本的 `compileOnly` API。模组元数据不声明 JEI 前置，发布 JAR 不含 JEI API、JEI 实现或测试类。不安装 JEI 时没有新增的配方分类，但现有炉体、燃料和烧炼机制仍可用。2026-10-13 用户确认已经测试完毕，并明确要求提交；仅记录整体通过，不补写未逐项反馈的操作结果。
