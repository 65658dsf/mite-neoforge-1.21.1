# 032：R196 动物 AI 测试入口

开发者：NingMeng123。原作：Avernite。本批来源为本地 R196 发布包；独立规则和逐类方法索引见 [来源规格](../../spec/animals-source-032.json) 与 [源码证据](../animals-032-evidence.md)。

本批覆盖牛、蘑菇牛、猪、羊、鸡的养殖需求与生产，以及来源狼、恐狼、豹猫/猫、马及现代拆分马种、普通蝙蝠和鱿鱼的专属行为。地狱犬只接入其实际注册的游泳、出水和出熔岩，不继承狼的驯化、食物与繁殖。原来已有的吸血蝙蝠、巨型吸血蝙蝠和夜翼捕食判定供动物避险使用。

## 开始测试

保存后自行退出并重新启动测试客户端，让最新编译的模组代码生效。使用开启作弊的新测试世界或存档副本，避免为了试验而修改正常存档中的动物。自动验证使用独立目录，没有操作你的游戏窗口。

需要等待时使用 `/tick rate 200`，测完恢复 `/tick rate 20`。动物成长、资源更新、生产和冷却依赖实际游戏刻，不能用 `/time set` 代替。观察寻路和动画时保持 20 TPS。

## 推荐手测顺序

1. **牛、猪、羊、鸡的觅食饮水**：在开放草地摆放食源和开放水，降低动物对应资源，观察寻找并停留补充；再测试顶盖、拥挤和屋内环境。操作及数据指令见 [牲畜手测](032-livestock.md)。
2. **喂食与繁殖**：伤牛后第一口小麦回血，满血健康后下一口才进入恋爱。缺水、拥挤或繁殖冷却不能靠无限喂食绕过；幼体不接受普通繁殖食物。测试 16000 刻父母冷却、-64000 刻新生年龄与危急食水停止成长。
3. **生产与保存**：耗尽牛奶后等待健康生产，给羊剪毛再吃草，观察鸡蛋/羽毛和粪便；保存重进，资源、牛奶、羽毛库存、生产计数和排粪倒计时不能刷新。蘑菇牛现代炖菜共用牛奶库存，剪毛转换保留资源。
4. **受伤与避险**：攻击牛或猪后应停止繁殖并逃离；同类收到攻击者警告，其他附近牲畜可以通过可见且可到达的受惊动物传播惊吓。放野生成年狼、僵尸、蠹虫或来源凝胶怪附近，观察动物避捕食者；驯服狼不触发野狼捕食判定。
5. **宠物和马**：按 [专属动物手测](032-special-animals.md) 测狼/恐狼骨头驯化、来源鱼诱引豹猫、跟随/坐下、马进食与骑乘、繁殖属性及保存行为。
6. **水生和飞行**：测试鱿鱼深水追逐、接触缓慢、船撞击；普通蝙蝠在负 Y 洞穴中飞行和倒挂，玻璃下不能挂。步骤见专属手测文档。
7. **消失保护与保存**：来源计时、视线、橡木栅栏、被攻击/吃食后的保护及现代命名/驯服保护见 [消失规则手测](032-animal-despawn.md)。先用存档副本和临时动物测试，不要直接修改正常养殖场。

## 共用行为的边界

同级任务使用来源构造顺序：掉落食物、避火、牲畜食源/水源/自由度/避险，再接物种任务。食水任务与繁殖的竞争不会由现代构造顺序意外改变。空/水炼药锅中被顶盖挡住的幼体，即使一次成长越过成年边界，也停在年龄 -1；移开顶盖后继续长大。

口渴牲畜可以留在水或雨中补水；玩家正在控制骑乘、来源亡灵马不使用出水呼吸任务。坐下的伤宠物不主动走向掉落食物，但接触到正确食物仍可吃；生命超过一半的驯服宠物拒绝这一主动资源路径。正常恐慌持续 100～199 刻。攻击者 UUID、记忆、逃离判定和惊吓截止时间保存；来源 Goal 内的恐慌倒计时及完成标记在重新加载时重置。

## 现代适配及保留范围

- 使用 1.21.1 的世界高度、加载区块和寻路器，允许负 Y；不承诺 1.6.4 同种子路径或随机序列一致。
- 旧猫身份映射到现代豹猫与猫；现代猫额外毛色、狼变种、牵引、狼铠、马库存与骷髅陷阱保留。马驴骡与亡灵马沿用来源马类别的共用规则。
- 蘑菇牛的花朵炖菜、剪毛转换与现代草蔓延保留，接入来源资源成本/状态。猪骑乘沿用现代 travel 和已实现的材料钓竿规则。
- 现代草/蕨的双格植物作为旧短草的适配食源；践踏状态使用草方块附加属性保存，不新增草方块注册身份。
- 现代额外生物没有来源动物身份时保留自己的 AI；实际正在攻击来源动物的现代捕食者会进入避险查询。来源豹猫虽捕鸡，却没有 `preysUpon` 覆写，不凭目标 Goal 虚构这一谓词。
- 保留已由字节码确认的 R196 马繁殖实际行为和豹猫第二种鱼诱引引用行为，具体说明见专属手测文档。
- 宠物驯化冷却、普通蝙蝠飞行目标及防立即倒挂机时在本实现中跨重载保存，作为现代实体恢复适配：避免重新登录绕过冷却，维持飞行恢复状态。R196 的这些临时字段没有写入原 NBT，不能把本实现的保存行为称为原版来源行为。攻击者记忆等来源本来保存的字段单独保留；恐慌与宠物威胁凝视仍按来源临时状态处理。
