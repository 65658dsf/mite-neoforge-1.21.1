# 028 门、栅栏和装饰品手测

开发者：NingMeng123。自动验证由统一 028 记录维护；这份说明不代表手测已经通过。

## 金属门

1. 用 JEI 搜索铜门、银门、金门、远古金属门、秘银门、艾德曼门。也可 `/give @s mite:silver_door`、`/give @s mite:golden_door`、`/give @s mite:ancient_metal_door`、`/give @s mite:mithril_door`、`/give @s mite:adamantium_door`。
2. 在石头地面搭两格高的石头侧柱，门必须靠柱放置。先在空地尝试，应拒绝无侧框放置；门两侧都用泥土柱也应拒绝。
3. 有框的门右键不能手动打开；放红石火把、按钮或拉杆供电后上下两半同时开关。拆掉铰链侧上层框，整扇门掉一件物品。
4. 尝试左右并排的双门，两端各有两格高实体侧框。查看开关、贴图朝向和碰撞是否正常。原版铜门及氧化、打蜡铜门同样只用红石开关。
5. 合成形状为 2×3 的6个同材锭，产出1扇门；相应材料或更高等级工作台才可制作。

## 金属栅栏

1. `/give @s mite:copper_bars`、`mite:golden_bars`、`mite:ancient_metal_bars`、`mite:mithril_bars`、`mite:adamantium_bars`。
2. 放成十字、拐角、贴墙，检查连通、碰撞、背面及透明贴图；用水桶测试新版含水行为。
3. 合成为3×2的6个同材锭，产出16个；物品最多堆叠16。
4. 铜活板门保留原版功能、氧化和打蜡；为避免与铜栏杆冲突，6铜锭在3×3网格摆为：第一行3铜锭、第二行铜/空/铜、第三行空/铜/空，产出2个，需要铜工作台或更高级台。
5. 生存空手和低级工具不能采集高级材料。铜/金栏杆需要铜等级镐，远古需要铁/远古镐，秘银需要秘银镐，艾德曼需要艾德曼镐。

## 花

1. `/give @s mite:dahlia`。其余使用原版橙色郁金香、蓝色兰花、绒球葱、滨菊。
2. 暖平原、森林可种大丽花和郁金香；冷针叶林不能种。绒球葱只在沼泽/红树林沼泽，兰花需要比平原更热的气候，例如丛林；滨菊不能种在丛林。露天或光照至少8。
3. 每朵花可以转1个对应染料，大丽花产粉色；不需要工作台。花最多32一组。
4. 将大丽花放进原版花盆，再取出，检查植物贴图和归还物品。找新生成的暖地区块，确认大丽花能在自然地表取得；原有已生成区块不会补花。

## 凋零灌木和地狱沙砾

1. `/give @s mite:nether_gravel`、`/give @s mite:witherwood_bush`。灌木只能种在地狱沙砾上，普通沙砾/沙子不行；黑暗中仍可种。
2. 切生存后触碰灌木，应获得约10秒凋零I；短暂离开再碰可延长，但已有凋零II不会被覆盖成I。使用低等级玩家测试时先备好治疗/食物，避免测试死亡。
3. 剪刀或丝触采集应得灌木自身；普通破坏只有50%概率得1木棍。拆掉底下沙砾，应掉1灌木，不能复制。
4. 检查紫色粒子及旧资源包贴图；灌木堆叠32，地狱沙砾4。
5. 进入新生成的下界区块，检查表层和矿脉沙砾都显示地狱沙砾，表面有凋零灌木，现代地形仍在。采集后仍是地狱沙砾身份，不随维度改变。普通砾石树中铜/银/秘银/艾德曼替换为金粒，宝石碎片替换为石英碎片，燧石分支保持。
6. 灌木有0.2的来源缓冲值：只在落点有凋零灌木时接入源小数公式。其余地面不改变现有摔落机制；这项已有自动测试，手测可用较高生命等级对比落伤。
