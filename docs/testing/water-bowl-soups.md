2026-10-16：数据生成、构建、1455 项 JUnit 和 1512 项服务端 GameTest 全部通过，日志为 `build/verification/water-bowl-soup-build-final.log`。用户手动测试后反馈“没有问题”，并授权提交；未操作用户客户端，也不补写逐项手测记录。

重新启动客户端加载本次代码，使用生存模式和 MITE 工作台。水碗可用空碗对水取水，也可执行 `/give @s mite:water_bowl 4`。

| 产物 | 每批材料（无序放置） |
| --- | --- |
| 甜菜汤 | 6 个甜菜分别占 6 格 + 1 个水碗 |
| 蘑菇煲 | 红蘑菇 + 棕蘑菇 + 水碗 |
| 兔肉煲 | 熟兔肉 + 烤马铃薯 + 胡萝卜 + 红或棕蘑菇 + 水碗 |
| 迷之炖菜 | 红蘑菇 + 棕蘑菇 + 1 朵小花 + 水碗 |

1. 按表逐项制作，确认配方有产物；把水碗换成空碗，应无该汤产物。
2. 每格准备两份材料，普通点击结果一次，应只完成一碗汤、剩下一份材料；制作时不额外返还空碗。Shift 点击仍可连续制造。
3. 分别使用红、棕蘑菇制作兔肉煲，两种均成功；任意调整材料位置仍可制作。
4. 分别用蒲公英和罂粟制作迷之炖菜，食用后应获得对应的饱和、夜视效果。材料多放一朵花、一个水碗或无关物品应不能制作。
5. 吃完任一种汤，正常获得一个空碗。需要先消耗饱食值以允许食用。
6. 安装 JEI 时，查看上述四种汤的配方，应显示水碗；迷之炖菜可以查看不同小花对应的效果，不应出现旧空碗配方。参照配方手动放入材料，再实际制作。

蘑菇煲与迷之炖菜的材料能放进背包 2×2 合成格，也应按相同规则工作。甜菜汤和兔肉煲需要更大的合成格。
