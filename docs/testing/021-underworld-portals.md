## 启动与准备

这次增加了维度和方块注册，请自行关闭并重新启动测试客户端；已运行的客户端不会加载新的Java注册。开发客户端仍使用项目的 `run/mods`。可运行项目根目录的 `gradlew.bat runClient`，或使用构建产物 `build/libs/mite-0.1.0.jar` 安装到自己的NeoForge21.1.259实例。

创建新的创造测试存档，开启作弊，保持 `/tick rate 20`。以下坐标命令用于这个测试存档。执行：

```mcfunction
/gamemode creative
/give @s minecraft:flint_and_steel
/give @s minecraft:obsidian 64
```

## A. 地底地形与新版主世界

先在主世界查看新版洞穴、山地和Y=-64附近；观察地形时切旁观模式，可以从传送坐标所在的岩石中穿出：

```mcfunction
/gamemode spectator
/execute in mite:underworld run tp @s 0 160 0
```

创造飞行查看Y144以上的石质洞穴，Y120..143的部分水域、蛛网及部分菌丝/蘑菇，Y255顶部基岩。下层Y0..119按R196是实心岩层和基岩分层，**并不是另外一层巨大空洞**。Y0各列应为发光地幔。切回主世界：

```mcfunction
/execute in minecraft:overworld run tp @s 0 80 8
/gamemode creative
```

预期：地底没有天空、日夜太阳和降雨；主世界保留新版本地形。地底首次生成可以有等待，移动后持续正常出区块。

## B. 主世界底部门 → 地底 → 回程

在主世界依次执行：

```mcfunction
/fill 0 -63 0 3 -63 0 minecraft:bedrock
/fill 0 -62 0 3 -58 0 minecraft:obsidian
/fill 1 -61 0 2 -59 0 minecraft:air
/tp @s 1.5 -61 2
```

用打火石点燃门内底部。进入门，预期到地底世界，自动生成的门保持2×3内框。走出门、等至少一秒再进入，预期回到主世界来源门附近。背包数量与品质等组件应保留。

切生存模式时，连续站在普通门内约4秒才传送。离开门不能累积离线等待。创造模式立即传送。

## C. 地底底部门 → 下界 → 回程

先切创造，到地底后执行：

```mcfunction
/execute in mite:underworld run fill 32 2 0 35 2 0 mite:mantle
/execute in mite:underworld run fill 32 3 0 35 7 0 minecraft:obsidian
/execute in mite:underworld run fill 33 4 0 34 6 0 minecraft:air
/execute in mite:underworld run tp @s 33.5 4 2
```

点火并进入。预期到现代下界，保留下界原有群系；走出门等待后进入，预期回到地底。下界任何普通门都通往地底。

新下界区块Y0应为地核，上方屋顶原有基岩部分显示地幔。这项只修改新生成的区块，已有下界区块不会批量改写。

## D. 高位普通门与尺寸限制

在主世界Y80建立标准门：预期把玩家送往主世界的世界出生点附近，保持同维度；它不直通下界。目的地选可站立位置。

在地底Y160建立标准普通门：预期通往主世界，自动回程门返回地底。高处人为摆放基岩/地幔并贴门不能绕过底部高度判定。

扩大内框为3×3或2×4：预期不能点亮。在末地搭2×3黑曜石框点火也不能激活。骑猪、骑船等骑乘状态不能通过普通或符文门。

## E. 符文制造与符文门

在创造栏搜索“符文石”，应看到两类各16个符号，图标和放置侧面与所选符号相符。顶部、底部使用现代黑曜石纹理；侧面使用用户提供材质包中的原始符文纹理。

给出材料和工作台：

```mcfunction
/give @s mite:mithril_nugget 16
/give @s mite:mithril_crafting_table
/give @s mite:adamantium_nugget 16
/give @s mite:adamantium_crafting_table
```

在对应工作台放置：中心1块黑曜石，上下左右各1粒相应金属。右键输出在Nul、Quas等16种符号间循环；预览切换不消耗材料。左键加工一次，Shift左键连续加工，制造的符号应与预览一致，数量无重复。弱工作台不能制造。

用四块同金属符文替换标准黑曜石门的四角，其他边保持黑曜石，点火：预期在**当前维度内**传送。四个Nul目标X/Z为0/0附近；改变角上的符号应改变目标，同一组合在同一世界可重复到达相同区域。秘银范围较近，艾德曼较远；混用两种金属角不能形成符文门。

移除四角后应恢复该位置的普通门规则；在底部门上测试可确认不会错误保留瞬时同维度路由。落点不安全且找不到附近安全位置时保持原地，不能删除基岩、地幔或容器强行落地。

挖下/中键选取非Nul符文，预期符号保留；铁砧不能改名。爆炸毁坏符文时只可能产生黑曜石碎片，不额外掉完整符文。

## F. 地幔、水与床

在地底搭安全站立区域，切生存并接触Y0..2地幔：预期受热伤，持续干燥接触约10刻后着火；火焰保护及抗火按现代伤害/附魔路径生效。远离地底底部的人工地幔不作为直接伤害陷阱；下界地核底部/屋顶接触也会烫伤。

用原版水桶和任意MITE金属水桶对地幔/地核上方倒水：预期消耗桶内水、留下空桶且不产生水源。让旁边水流流过：地幔上方不能被淹，普通石头上方仍能流入水。附近木材可能着火；核心纹理应有动画。

在地底、下界放床并点击：预期中文拒绝睡眠提示，床与周围地形保持，不爆炸、不重设重生点。

## G. 保存与重进

背包留几件有品质/损伤的工具，经过普通门进入地底，再自行保存退出并重进。预期玩家仍在地底，区块地形、菌丝、符文符号和门路由保留。重复B、C中的回程，确认没有进入错误维度、丢失或复制背包物品。

若使用独立服务器，再由两名玩家分别入门、重连及重启服务器后重复回程。本轮无窗口GameTest不能替代双客户端网络实测。

## 范围与差异

- 地底原有未复刻怪物与Longdead/LongdeadGuardian地牢，后续随相应实体和战利品补入。现有原版实体使用已核实的地底刷怪表子集。
- 地底装饰中的地下泉水候选、其余父级群系装饰尚未全量移植；水层、蛛网、菌丝和棕色蘑菇已实现。
- 本轮保留现代维度时钟体系；R196的各维度独立时钟、首次访问标志及无人时暂停逻辑仍需后续移植。灰雾公式已接入当前时钟，固定天角不依赖时钟推进。
- 世界底部坐标适配到主世界minY=-64；水平边界采用现代WorldBorder。普通门安全建造和符文安全落点保护属于现代适配。
- 当前只搭矿物生成基础，不表示已生成秘银、艾德曼等新增矿脉。
