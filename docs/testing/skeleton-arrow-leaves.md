# 骷髅箭穿过树叶

开发者：NingMeng123。

2026-10-16：本批构建、1455 项 JUnit 和 1574 项服务端 GameTest 全部通过。用户手动测试后反馈“好了提交吧”，授权提交；不补写逐项手测结果。

普通、流浪者、沼骸、凋灵及 MITE 骷髅射出的箭可以连续穿过树叶，仍能命中叶后的实体，并被树干、石头等实心障碍物截停。材质箭及药水效果继续生效，树叶不会被破坏。

发射者类型随箭同步并保存。远处客户端未跟踪发射者、发射者死亡或箭重载后仍保留穿叶行为；重新指定非骷髅发射者会清除这一行为。升级前已插在树叶里的箭保持插入状态，请用新发射的箭测试。

R196 的箭使用带有概率截停的穿透射线。本次针对骷髅箭无法穿叶的问题修复，不声明还原旧版的全部箭矢随机碰撞规则。玩家、发射器和其他生物的箭保持现有行为。

## 手动检查

1. 重新启动客户端，保持 `/tick rate 20`。夜间让持弓骷髅隔着数层树叶射击，箭应穿叶命中玩家。可用创造模式搭场景，测试命中时切回生存。
2. 在同一路径上加原木或石墙，箭应插在障碍物上。没有实体和实心障碍物时应穿过全部树叶，树叶本身完好。
3. 分别测试原版骷髅、流浪者及 MITE 远古骷髅。流浪者穿叶命中后仍有迟缓。
4. 与另一位玩家联机时，在远处只观察射来的箭，检查箭通过树叶的表现与实际命中一致。

自动测试覆盖骷髅实际射箭、多层树叶、起点位于树叶内、斜射、实体与实墙、全部树叶标签、药水箭，以及实际实体数据包编解码和存档边界。服务端自动测试不代替客户端验收。
