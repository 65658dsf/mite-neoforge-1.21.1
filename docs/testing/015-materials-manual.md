```mcfunction
/experience set @s 0 levels
/experience set @s 0 points
```

右键后用 `/data get entity @s XpTotal` 读累计经验。钻石从0开始应为500点、等级8；副手同样支持；R196创造模式也消耗献祭宝石。当前测试副本关闭了自然恢复，便于确认献祭本身不会治疗。
