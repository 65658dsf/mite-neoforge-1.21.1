## A：材质与名称

1. 查看铜工具、银/远古/秘银/艾德曼工具、碎片和九种台的背包图标与手持外观。
2. 预期：包内对应原图，无紫黑缺失材质、无额外着色把原图染错；铜锭、铜粒仍是此前外观。
3. 木棒头部应向上；注意第一人称、物品栏都要看。旧材质包图的方向与此前人工图不同，模型变换已相应调整。

## B：工作台配方与门槛

1. 背包按“燧石、线 / 木棍、原木”摆 2×2。左键结果开始，等制造完成，应得到新燧石台；用筋替代线再测一次。
2. 四木板不能合成原版工作台。命令得到的旧台无法正常放置/打开；已有旧台拆掉后应获得新燧石台。
3. 在燧石台按“铜锭、皮革 / 木棍、木板”做铜台。背包同形状应不允许制作。
4. 铜镐：三铜锭铺顶排，中、下排中心各一木棍。在燧石台不应有可制造结果；铜、银、金台均应允许。
5. 用铁锭替换铜锭测试铁镐：铜台不足，铁台可以。按同一原则检查更高级工具。
6. 将燧石台或黑曜石台放合成格拆解，完成后得到对应小刀，并退一块橡木原木；输入格叠两个台、背包满时也不得吞刀或木头。

## C：合成耗时与取消

1. 铜台中放三套铜镐原料，普通左键点结果。完成一个周期只产出一把，剩两套原料；额外等待两个周期也不再制造。再用 Shift＋左键点结果，应逐批制造剩余两把，每把都需要完整周期。进行中反复点击不能追加批次或跳过等待。
2. 制造中右键结果取消，或移动一个材料、关闭界面。材料不消耗；重新开始从零计时。
3. 按数字键/快速反复点击结果，不能跳过时间，也不能多产物品。
4. 让饱食度降为 0 后，制造应暂停；补食物继续。升级后制造速度提高，最高不快于每批 25 tick。
5. 界面上方应有服务端制造进度条，暂停和取消提示正确。原木加工仍出原数量的木板，现在需要等待。
6. 高级材料等待较长时可临时 `/tick rate 200`；完成后恢复 `/tick rate 20`。挖掘速度与耐久比较保持 20 TPS。
7. 背包合成格放三块燧石，普通左键拆分应只消耗一块、产出四片燧石碎片，余下两块保持原位；Shift＋左键才会继续逐批拆完。工作台放三块橡木原木，普通左键应只消耗一块并产出四块木板，而不是只产一块木板。
8. Shift 开始后，在下一批完成前右键取消，再普通左键重新开始；应只制作一批然后停止，不继承上次连续模式。

## D：工具功能与精确磨损

新工具不要附魔，使用正常品质；每次确认目标确实破坏后读取“耐久”提示。以下数值是本批明确核对的样例：

| 操作 | 预期 |
| --- | --- |
| 铜镐刚取得 | 最大耐久 4800 |
| 铜镐挖一块普通石头 | R196 硬度 2.4，消耗 240，剩 4560 |
| 普通无附魔铁镐挖一块黑曜石 | 消耗 240，9600 → 9360；连续两块累计消耗 480 |
| 铜斧挖一块原木 | 最大 4800，消耗 120，剩 4680 |
| 燧石短斧挖一块原木 | 最大 400，消耗 160 |
| 铜锄/鹤嘴锄成功耕一次地 | 消耗 50；对不能耕的方块不扣 |
| 剪刀成功剪一次羊 | 消耗 50；羊已剪过且未长毛时不扣 |
| 铁剪刀剪一株普通短草 | 消耗 5，并保留剪取掉落 |
| 铁镐 / 秘银镐 / 艾德曼镐初始 | 最大 9600 / 76800 / 307200 |
| 锈铁镐初始 | 默认劣质，最大 3600 |

再试剑、匕首、战斧、战锤攻击并查看磨损；银武器对亡灵有加成，战锤对骷髅有加成。保留现代攻击冷却，需要蓄满后再比较。普通无效方块操作和创造模式不应正常扣耐久。原版钻石与下界合金工具继续保留功能；它们的耐久数值是已注明的现代映射，不冒称旧版存在同款装备。

## E：品质、维修与护甲

1. `/function mite:test_durability_016` 的普通铁镐应为 9600，优良铁镐为 14400；保存退出后重进，品质和当前损伤不变。
2. 在铁台合并两把损伤各 6000 的普通铁镐，应得到剩余 7200/9600 的铁镐，没有额外 5% 奖励。同品质且均损坏、无附魔才可普通合并；异品质不能合并。
3. 铁头盔、胸甲、护腿、靴最大耐久分别为 80、128、112、64。
4. 比较新铁胸甲、损伤 96 的胸甲、损伤 127 的胸甲：三者都应提供 6 护甲、1.25 韧性；只剩 1 耐久的胸甲普通受击不会直接消失，并继续提供完整防御。火和熔岩有源规则例外，不用来测这个普通受击案例。
5. 给工具附耐久 V，重复同类操作后平均磨损应明显减少；这是随机免耗，不要求每一次固定减少 75%。工具在耐久耗尽时会损坏，护甲普通损耗保留最后一点。

## F：自动合成与返回物

1. 原版合成器继续可合成（其配方中的工作台已换为燧石台）。
2. 让合成器加工铜镐：没有相邻材料台或仅邻接燧石台应拒绝，邻接铜/银/金或更高台才开始，等待后一次红石请求产出一把。
3. 制造中移除工作台或替换输入，不能消耗旧输入或产出旧结果。重新触发需要重新完整计时。
4. 无设备门槛的粒锭兑换使用合成器自身基础能力；拆金属块仍得到 9 锭，进箱子为 8+1，不丢失也不复制。
