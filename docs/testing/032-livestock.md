# 032：R196 养殖动物 AI 手动测试

开发署名：NingMeng123。来源为本地 R196 的 `EntityLivestock`、`rq`（鸡）、`rr`（牛）、`rw`（蘑菇牛）、`ry`（猪）、`rz`（羊）及 `rp`、`nk`、`pn`。完整独立提取见 `spec/animals-source-032.json`。

本批把牛、蘑菇牛、猪、羊、鸡的真实资源、觅食、饮水、拥挤、成长、繁殖和生产连起来。食物、水分、自由度分别为 0～1；全部至少 0.25 才是健康状态。这里的健康状态影响繁殖、生产和肉掉落，不是新药水效果。

每 100 刻有 90% 概率更新资源：靠近食源加食物 0.1，否则减 0.005；靠近水源加水分 0.1，下雨但无水源加 0.01，否则减 0.005；开阔且不拥挤加自由度 0.1，否则减 0.005。资源不足 0.5 开始寻找，低于 0.25、0.05 分别扩大搜索范围。资源加到超过 0.95 才停止在资源旁等待。

## 测试准备

保存退出客户端并重新启动后，使用有作弊权限的新测试世界。摆放草地和围栏，给动物留足空间。在测试动物旁运行以下指令查看实际服务器数据，以牛为例：

```mcfunction
/data get entity @e[type=minecraft:cow,sort=nearest,limit=1] NeoForgeData.mite_native_loot_state_031
```

其中 `food`、`water`、`freedom` 是当前资源；`milk` 是牛的 0～100 牛奶库存；`production_counter` 是生产积累；`manure_countdown` 是下一次粪便计时。旧 031 的保存字段继续使用，没有另存一套掉肉判定。

需要等待时可用 `/tick rate 200` 加速；结束后 `/tick rate 20`。等待不受 `/time set` 代替；动物成长和生产需要实际游戏刻。

## 觅食、饮水和自由度

1. 牛和蘑菇牛：旁边放短草、蕨或蒲公英。草方块本身不是牛的食源；这是 R196 牛的实际覆写。牛每次资源更新时有 1% 概率吃掉检测到的食源。关闭 `mobGriefing` 后不破坏植被。
2. 猪、羊、鸡：草方块、短草和蕨是环境食源。把牛的 `food` 改为 0.1，再放开通路，观察它寻找植被并在旁等待，数值逐步回升。
3. 动物脚下和头部附近的开放水、雪层、雪块、非空且够得到的水炼药锅均可补水。水面上覆盖实体方块后不再能喝；动物不会抽走水方块或消耗炼药锅水位。
4. 手持水碗给缺水的猪、羊或鸡右键，水分增加 0.25；水桶增加 1.0 并钳制到 1。生存模式归还原来的空容器，创造模式不消耗容器。
5. 三只动物紧贴在 2 格水平、半格垂直范围会拥挤；两只不会。玩家不计入这项数量。把动物关在封闭屋子也会下降自由度；自由度不足后会尝试找开阔位置。

例如快速制造缺水条件：

```mcfunction
/data modify entity @e[type=minecraft:pig,sort=nearest,limit=1] NeoForgeData.mite_native_loot_state_031.water set value 0.1f
```

## 喂食、繁殖和成长

牛、蘑菇牛和羊接受小麦；鸡接受小麦种子；猪接受胡萝卜和棕色蘑菇。手持诱惑使用相同列表，猪也跟随原版及 MITE 的胡萝卜钓竿。

1. 伤害成年牛后喂一口小麦，恢复最多半条生命上限，同时加食物 0.5；这一口先检查繁殖条件再回血，因此不会立刻冒爱心。恢复满血后再喂一口，三资源都健康才冒爱心。
2. 成年动物食物已满、但缺水或太挤时，继续喂小麦不能治好缺水或拥挤，也不会反复消耗材料。处于繁殖冷却或已经爱心状态时同样拒绝普通喂食。
3. 繁殖成功，父母各冷却 16000 刻，幼体起始年龄 -64000。幼体的每项资源取对应父母的较小值。
4. 幼体食物或水分低于 0.05 时停止成长；恢复后继续。R196 幼体不能靠玩家反复喂食直接加速成长，可通过环境食源和饮水供给。小羊吃草会额外成长 300 刻。
5. 马、驴、骡及来源亡灵马使用同样新生儿年龄；幼体马每 200 个带实体偏移的刻批量成长 200，而非每刻更新。兔子等新版额外动物保持其原有成长行为。
6. 幼体在被实心顶盖封住的水炼药锅中不能长成成年模型；移除顶盖后正常成长。

## 牛奶、羊毛、羽毛、鸡蛋和粪便

1. 牛奶初始 100。一碗花 25、一桶花 100，耗尽后拒绝继续挤。健康成年牛每次成功资源更新恢复 1 点牛奶；幼体不生产。喂食、饮水、肉掉落和挤奶都读取同一份资源。
2. 蘑菇牛保留 1.21.1 蘑菇汤和棕色蘑菇牛花朵迷之炖菜，作为现代适配：健康且满血的成年牛每碗消耗同一库存 25 点牛奶。没库存时不会消耗碗或清除已喂入的花朵效果。用剪刀转成普通牛时保留资源、牛奶和生产计时。
3. 羊吃草动画 40 刻，第 36 刻咬下植被或草方块时恢复羊毛、加食物 0.5。没真正吃到东西只播放咀嚼，不凭空长毛。受惊、逃跑或刚受伤会停止吃草；关闭 `mobGriefing` 后不破坏草，也不免费恢复羊毛。
4. 羊连续累计受到 6 次火伤后毛被烧掉；没着火时每 100 刻减少 1 次累计。火伤累计是 R196 的瞬时字段，重开清零；已烧掉的羊毛状态继续保存。凝胶生物或酸、消化液伤害会破坏羊毛。
5. 鸡羽毛库存初始 1～2，与死亡掉落共用；健康积累达到 100 后，每次生产检查有 1/500 概率恢复一根，库存满则掉落一根。成年鸡偶尔自然掉毛但至少留一根；普通物理攻击可掉掉最后一根。
6. 鸡积累达到 200，且没有先触发羽毛生产时，每次检查有 1/20 概率产一枚蛋，消耗 200。旧原版的无条件鸡蛋倒计时已停用；不健康的鸡不能用它绕过养殖条件。
7. 成年且食物至少 0.05 的动物排粪。牛周期 24000、猪和羊 48000、鸡 384000 刻；实际每次计时重置为半个周期加 0～不足一个周期的随机值。幼体不排粪，饿到绝望会暂停排粪计时。

## 保存与联机

让缺水动物正在寻路、让一只鸡已有生产积累、让牛已消耗牛奶，然后保存重开。资源、鸡羽毛、生产计数、牛奶、排粪计时应保持；不会刷新成初始满状态。多人同时取最后一份牛奶或汤时只能成功一次。

自动 GameTest 覆盖真实实体 NBT、来源资源阈值、生产随机顺序、实体互动、出生事件、羊吃草、马批量成长、蘑菇牛汤和转换。客户端动画、寻路观感与多个扩展模组一起运行由你手动确认；本批不自动操作你的游戏窗口。
