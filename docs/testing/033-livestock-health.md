# 033：R196 动物生病与康复手测

开发者：NingMeng123。原作：Avernite。来源规则见 [033 证据](../livestock-health-033-evidence.md) 和 [来源规格](../../spec/livestock-health-source-033.json)。

R196 的病态由食物、水分、自由度任意一项低于 25% 决定，全部恢复到至少 25% 就康复。它不等于生命值受伤，也没有另一份传染计时。032 已实现相应资源、生产和繁殖判定；033 补齐普通牛、猪、羊、鸡的身体病态纹理，并独立验证整条生病与恢复流程。

四张贴图使用用户提供资源包的原始字节，64×32，匹配 1.21.1 的基础模型纹理尺寸。正常状态继续由原渲染器和用户材质包选择；病态羊只改变身体，羊毛颜色及猪鞍具保留。蘑菇牛也有健康判定，但 R196 的独立蘑菇牛渲染器没有病态贴图分支，因此红/棕蘑菇牛保持正常外观。

## 快速检查外观

保存后自行重新启动测试客户端，使用有命令权限的存档副本。测试期间保持 20 TPS，在无水、无雨的测试地放一只成年牛：

```mcfunction
/summon minecraft:cow ~ ~ ~ {NoAI:1b}
/data modify entity @e[type=minecraft:cow,distance=..6,sort=nearest,limit=1] NeoForgeData.mite_native_loot_state_031.water set value 0.20f
```

牛应显示来源病态身体贴图，灰暗且出现斑点。`NoAI` 在这里便于观察，不代表正常生存需要关闭 AI。正常动物仍按原有寻路寻找食水和开阔环境。

恢复水分：

```mcfunction
/data modify entity @e[type=minecraft:cow,distance=..6,sort=nearest,limit=1] NeoForgeData.mite_native_loot_state_031.water set value 1.0f

```

如果食物和自由度也至少 25%，应恢复正常外观，不需等待另一个康复倒计时。调试命令重新加载 NBT 后，等待实体同步刷新；不把命令执行当成一次正常喂水。

将上述实体类型换成 `minecraft:pig`、`minecraft:chicken`、`minecraft:sheep` 分别重复。羊先用剪刀剪毛再看身体，避免羊毛遮住病态皮肤；染色羊恢复后，毛色应保留。已有猪鞍不会因生病消失。

## 分开验证三种原因

1. 将 `food` 设为 `0.20f`，其余两项保持 `1.0f`，应病态；给正常成年、可进食的牛喂小麦，食物恢复后即可康复。
2. 将 `water` 设为 `0.20f`，食物和自由度保持 `1.0f`；喂一水碗可增加 0.25 水分。反复给小麦不能替代补水。
3. 将 `freedom` 设为 `0.20f`，其余保持 `1.0f`；开放空间、解除拥挤后，真实资源更新会恢复自由度。喂食和喂水不会直接补自由度。
4. 任意一项仍低于 25%，只补另一项不能康复。三项恰好为 `0.25f` 是健康边界；无供应的环境会在随后资源更新时再次跌破边界，因此稳定观察用 `1.0f`，或提供正常环境。
5. 伤害一只三资源充足的动物，它不应仅因扣了生命就出现病态纹理。病态也不额外降低移动速度、最大生命或持续扣血。

需要长时等待可以 `/tick rate 200`，结束恢复 `/tick rate 20`。动物所在区块要正常模拟；`/time set` 不能代替真实资源更新。当前节拍每 100 实体刻有 90% 概率更新资源，康复时间取决于供应和缺失量。

## 生产、繁殖与既有库存

测试正常寻路和羊吃草长毛前，将观察样本恢复 AI，或另生成正常动物。例如：

```mcfunction
/data merge entity @e[type=minecraft:sheep,distance=..6,sort=nearest,limit=1] {NoAI:0b}
```

- 生病成年动物停止增加生产计数，不能新进入繁殖爱心状态；康复后重新允许。已进入的恋爱状态不因资源刚跌破边界立即清空。
- 牛库存已有的奶仍可挤；生病不是清空牛奶或拒绝所有挤奶。耗尽后，病态期间没有健康生产积累补回奶量。鸡也可能消耗此前已经积累的生产计数再产蛋或羽毛。
- 病态鸡、牛/蘑菇牛、猪、羊死亡不掉来源肉类；皮革、羽毛、羊毛和鞍具仍按各自规则处理，不是全部掉落消失。
- 病态仍可自然回血。羊可剪毛、吃草长毛；幼体只有食物或水分低于 5% 才停止成长，不能把所有低于 25% 都理解为成长冻结。

## 保存和联机

让动物病态后保存重进，三资源和外观应一致；康复后再次保存也不应回到病态。另一名玩家同时观察同一只动物，生病和恢复应一致，由已有资源同步决定，不由各客户端分别计算缺食倒计时。
