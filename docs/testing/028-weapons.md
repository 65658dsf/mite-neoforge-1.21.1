# 028 武器手测

开发者：NingMeng123。建议用可开指令的测试存档；测试客户端由你操作，本批不会自动重启或接管窗口。

## 强化弓

1. 执行 `/give @s mite:ancient_metal_bow`、`/give @s mite:mithril_bow` 和 `/give @s mite:mithril_arrow 16`。两弓应有各自待机图标；对准安全空地右击拉弓，分别观察开始、约 13 刻、约 18 刻的三段贴图。换铜箭、银箭、艾德曼箭测试箭头颜色是否对应，松开后恢复待机。
2. 生存模式满拉发射应消耗一箭、弓损耗一点；满拉箭有暴击粒子。同拉满条件下远古金属弓速度比普通弓快 10%，秘银快 25%。空包无箭不能拉弓；创造模式可以正常用原生备用箭。
3. 确认普通品质远古弓 64 耐久、秘银弓 128 耐久。使用对应金属工作台按 JEI 或三木棍、三线、中心金属锭配方制作；更低阶工作台不允许。品质制造能力由现有经验/等级系统验证，选择高品质时要有足够经验。
4. 在远古金属或更高铁砧用远古金属粒维修远古弓；在秘银或更高铁砧用秘银粒维修秘银弓。原版铁砧不应维修这两弓；金属锭不是源维修材料。维修不花原版经验等级，但仍检查源品质维修能力。
5. 在附魔台或铁砧测试原版力量、冲击、火矢及耐久附魔；不需要 JEI。原版木弓、弩和此前的材料箭应仍能使用。

## 五色投掷球

依次获取下面物品，生存模式在空地右击。每次消耗一个，出现对应颜色的飞行物；创造模式不消耗。

```mcfunction
/give @s minecraft:slime_ball 16
/give @s mite:ochre_jelly 16
/give @s mite:crimson_blob 16
/give @s mite:grey_gelatinous_sphere 16
/give @s mite:black_pudding 16
```

原绿色球仍保留黏性活塞等原版用途；四种新颜色没有新增合成配方，原怪物自然来源在后续生物批次接入。

1. 向动物投球，绿色、褐色、红色、灰色、黑色的实际未防护投掷伤害分别为 2、3、4、4、5。命中出现碎片和成功伤害嘶声；不应额外施加中毒。
2. 放置蜘蛛网，任何颜色都应直接去除且不掉物。
3. 放置羊毛、地毯、蛋糕，用灰色或黑色球投掷应直接去除；绿色、褐色、红色命中羊毛只冒蒸汽，不会立刻去除。不要把“400 周期”理解为球命中后延时自动删除。
4. 用酸球从顶部命中草方块/菌丝，应变成泥土；从侧面命中草方块应保持草方块。普通石头、完整原木、金块不应被去除；铁块、铜块、银块只冒蒸汽。
5. 丢出球后保存退出再进入，确认存档正常；多人分别投球，其他玩家应该看到对应颜色飞行物和命中结果。

异常反馈请包含物品 ID、使用模式、目标方块、是否带附魔、当前等级以及截图；测试过程中发现具体问题再修复，不将客户端视觉结果和自动逻辑测试混为一项。
