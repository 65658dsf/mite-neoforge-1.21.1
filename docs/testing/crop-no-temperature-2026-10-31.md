# 农作物取消生长温度要求

开发者：NingMeng123

日期：2026-10-31

## 行为

- 小麦、胡萝卜、马铃薯、洋葱、甜菜根及南瓜／西瓜茎移除生长率中的温度修正，各温区使用原最适温度倍率。
- 甘蔗移除温度随机门槛，保留独立的 80% 随机减速；蓝莓统一采用原最适温度下的 2.5% 生长概率。
- Jade 不再生成“温度不适，停止生长”诊断，中英文语言项同步移除。旧快照中的 `TEMPERATURE` 仍可解码，但归一为未知条件，保留年龄、健康和土壤事实，不虚报当前可以生长。
- 水分、光照、肥力、布局、湿度加成、植物生境、病害、耕地蒸发及自然降雪各按原有机制执行。西瓜与南瓜的生长检定参考值仍分别为 2、2.5，不额外调整已有随机周期。

## 验证

| 检查 | 结果 | 记录 |
|---|---|---|
| JUnit | 2,043 项通过，0 失败、0 错误 | `build/verification/crop-no-temperature-tests.log`、`build/test-results/test` |
| 服务端作物回归 | 79 项通过 | `build/verification/crop-no-temperature-tests.log`、`build/verification/crop-no-temperature-final.log` |
| Jade 15.10.6 接口与数据包 | 真实 API 检查通过，含旧温度快照迁移、方块／位置／维度一致性和语言提示检查 | `build/verification/crop-no-temperature-jade-audit.json` |
| 构建与产物 | 保持工作区已有版本 0.2.19；包内生产类与实际编译输出一致，无 GameTest 类 | `build/verification/crop-no-temperature-acceptance.json` |

生长回归直接修改测试位置的真实生物群系并调用方块随机更新，验证粮食作物在冰冻山峰、沙漠、平原与丛林实际增长，瓜茎和甘蔗在寒冷、炎热环境增长；同时确认干旱和光照限制仍有效。蓝莓在森林、桦木森林和繁花森林验证 2.5% 概率的接受／拒绝边界。甘蔗额外验证仅消耗一次非温度随机抽样。

Jade 检查不启动游戏窗口：使用真实 Jade 接口和数据包解码路径验证提示组件，不记录为图形客户端画面验收。首次新增旧包提示检查误用了禁止访问世界的测试 accessor，已改为检查真实解码结果生成的提示行；生产逻辑未因这一测试夹具问题作额外修改。

测试通过独立运行目录与定向测试源集执行。数据生成输出到 `build/verification/crop-no-temperature-generated`，未改写既有生成资源。两种语言 JSON 均验证无重复键，JAR 中也不包含被移除的温度提示项。

## 使用

产物：`build/libs/mite-0.2.19.jar`。替换后重启客户端；联机时服务端也需更新同一构建。没有修改本轮开始时的模组版本号、创建版本标签或发布。
