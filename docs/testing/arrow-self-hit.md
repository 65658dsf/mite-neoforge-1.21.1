# 箭矢回落卡在玩家头顶

开发者：NingMeng123。日期：2026-10-17。

2026-10-17 用户回复“提交吧”，授权提交本次修复；未另行提供逐项手动复测记录。

## 原因与修复

R196 `uh` 的实体碰撞在速度低于 1 格/tick 时不造成箭矢伤害；项目的 `R196RangedRules.impactDamage` 已保留这个门槛。但现代 `AbstractArrow.onHitEntity` 在伤害失败时会将速度反向并衰减，重力又让箭落回玩家碰撞箱，导致低速箭反复弹起，看起来悬停在头顶。正常箭在无敌帧内被弹回后也可能进入此状态。

本次采用现代碰撞适配：普通燧石箭及九种材料箭低于该伤害门槛时，跳过实体碰撞，继续按原版重力、空气阻力及方块碰撞运动，落地后按原有规则拾取。速度达到 1 格/tick 的实体命中继续使用原有伤害处理。此改动不复刻 R196 的整套反弹实现；药水箭、光灵箭和三叉戟保持现有行为。
