# 026 工作台等级 JEI 兼容

开发者：NingMeng123。本批按当前服务端已实现的 R196 制造规则提供可选 JEI 展示，不新增制造权限或修改成长门槛。用户于 2026-10-13 明确要求完成后直接提交 GitHub，本批在自动验证后提交；未操作用户游戏，客户端视觉与交互尚未实测。

## 内容与规则

JEI 新增九种材料工作台分类，以及单独的“背包合成（2×2）”分类。每个工作台图标仅关联它实际能加工的静态配方；原料格保留有序形状、空格、标签替代和数量。原版工作台不作为新分类加工设备。

| 工作台 | 加工能力 |
| --- | ---: |
| 燧石 | 1 |
| 黑曜石 | 2 |
| 铜、银、金 | 4 |
| 铁 | 8 |
| 远古金属 | 16 |
| 秘银 | 64 |
| 艾德曼 | 256 |

每条配方所需能力取 `WorkbenchRules.required(output)` 与 `CraftingQuality.rule(...).requiredCapacity()` 中较大值。背包配方还须能放进实际 2×2 网格，且不能产出木板。制造工作台本身按前一阶段解锁，不能错误地要求已有同种台才能制造。

耗时来自现有 `TimedCraftingRules`，明确标注 **0级、默认品质**。玩家等级和所选品质变化时，实际制造界面显示最终时间与经验消耗。未接入制造计时的现代配方显示“即时合成”；JEI 不凭空增加技能或经验门槛。符文石结果提示可在制造界面切换符文。

食品自定义配方同样按它的 manufacturing 数据筛选。奶酪各槽提供七种牛奶桶替代，允许混用，并将 63 个相同功能的来源配方合并为每种数量一个页面；九种台各有 1～9 桶批次，背包只有 1～4 桶批次。拆解燧石/黑曜石台同时展示小刀与返还的橡木原木。拆金属块仍显示每批 9 锭，不因锭的堆叠上限 8 而截断。

仅隐藏已成功纳入这些分类的原 JEI 合成页面，保留修理、染色、地图、烟花等动态特殊配方，以及其它模组的专用分类和未知配方子类扩展。空标签或无法匹配示例原料的配方不接管。数据包重载或重新进入世界时，由 JEI 的配方更新生命周期重新读取当前配方；不修改服务端 RecipeManager。

本批提供查看配方和用途，没有注册自动填料按钮。现有工作台客户端菜单没有同步加工能力，直接注册通用搬料会错误判断等级；以后增加可靠的菜单能力同步后再接入。普通点击一批、Shift 点击连续制造、品质选择和经验不足拒绝制作继续使用既有服务端逻辑。

JEI 依旧只通过 `compileOnly` API 编译；元数据不声明 JEI 前置，发布 JAR 不打包 JEI 或测试代码。

## 手动验证

由用户自行重启测试客户端并进入原测试存档；保留 `run/mods` 中的 JEI 和已有辅助模组。对物品按 **R** 看获取方式、按 **U** 看用途。鼠标悬停分类图标可查看工作台名称。

1. 对铜镐按 R，应有铜、银、金、铁、远古金属、秘银、艾德曼台；不能出现背包、燧石或黑曜石台。铁镐从铁台开始，秘银镐仅秘银/艾德曼台，艾德曼镐仅艾德曼台。
2. 对九种台分别按 U，检查它们能加工的配方范围。铜、银、金应同级；高等级台能加工低等级配方。对铜台按 R 应允许燧石台，对铁台按 R 从铜/银/金开始，对秘银台按 R 从远古金属开始，对艾德曼台按 R 从秘银开始。
3. 对燧石台按 R，应有背包 2×2 页面；四个原料格为燧石、线或筋、木棍、原木，现代木种正常轮换。对橡木板按 R，不应出现背包合成分类；原版工作台、木镐、木斧的禁用配方不能重新出现。
4. 对铜镐分别查看铜台和铁台页面：0级默认品质基准应显示 14.65 秒和 13.6 秒。高等级玩家或选择高品质后，实际制造时间以制造界面为准。对符文石悬停结果，确认切换符文说明。
5. 对奶酪按 R，检查同一工作台每个批量只有一个页面，原料槽可轮换七种桶；五桶批次需五个单独槽，不能显示为一槽五桶。按页面混用不同牛奶桶制作，成品数量与返还桶应正常。
6. 查看拆解燧石/黑曜石台页面，确认显示对应小刀和橡木原木；实际拆解应拿到刀，输入槽返还原木。拆铜、铁、金块页面应显示 9 锭，实际产物分成合法的 8+1 堆。
7. 检查熔炉分类、普通修理/染色等已有 JEI 页面仍可查看；书签、关闭重开、退出重进正常。新工作台页面本批按显示原料手动摆放。原有制造一次/连续和品质收费行为保持正常。
