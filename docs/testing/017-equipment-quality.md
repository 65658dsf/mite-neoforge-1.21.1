## 本批变化

- 合成结果支持八档品质，在材料上限内选择；经验不足也能预览高品质，实际开始制造仍须满足经验资格。空闲时右键结果切换，也可点击结果下方的左右箭头；悬停查看范围、费用与预计时间。
- 品质直接改变最大耐久，优良以上增加制造难度、耗时和经验费用。普通或更低品质不收品质费，不额外降低耗时。品质不直接增加基础攻击和挖掘速度。
- 服务器在完成一批时扣费。取消、关闭、换原料不会提前收费；中途经验不足时停止原品质的制造。普通左键一批、Shift 连续；按照 R196，收取品质费的制造即使用 Shift 也只完成一批后停止。
- 同品质维修、线/筋修补皮甲、染色、铁砧、砂轮、锻造升级保留品质；维修按装备完整制造难度检查能力。维修/染色免品质费，现代铁砧本身的等级费用仍保留。
- 弓接入品质与 R196 普通耐久 32；怪物自带的未附魔木/皮装备品质降低一档，僵尸猪灵与凋灵骷髅初始武器为劣质；捡起的玩家装备不被降质。
- 按用户要求取消 200 级玩法上限，200 级以后沿用累计 `5L²+15L`；采集等级加成继续增长。保存、重生、命令和制造扣费共用同一经验余额。

规则来源见 [品质证据](../quality-017-evidence.md)、[装备行为证据](../quality-equipment-evidence.md)、[经验适配](../experience-adaptation.md)。尚未实现的职业、笨拙诅咒和其他生物完整生成规则不会被本批伪装成已上线；R196 默认关闭职业，当前品质调用使用无诅咒状态。现代石/钻石/下界合金装备采用明确的适配难度，登记在 `quality-equipment-017.json`，不是原作存在这些配方的声明。完整高级铁砧和剩余物品仍是后续工作。

## 准备

请自行重启测试客户端加载本次 Java 代码；F3+T 不能更新逻辑。使用允许命令的测试副本，先存好随身物品并留出背包空位。开发客户端可领取下列物资，函数只发物品，不清包、不改世界、不改经验；背包不足时会掉在脚边。

```mcfunction
/reload
/function mite:test_quality_017
/gamemode survival
/tick rate 20
```

物资函数只在开发运行环境存在，不打入发布 JAR。保持饱食度大于 0，必要时吃面包。按 F3+H 或物品提示查看耐久；也可主手持物后 `/data get entity @s SelectedItem` 查看 `mite:quality` 和损伤。组件中的 `minecraft:max_damage` 保存基础值，实际耐久以游戏提示为准，不能把基础值当成品质失效。

每次需要精确设置总经验时依次执行以下三条，把最后的数值替换为该步骤要求的经验点：

```mcfunction
/experience set @s 0 levels
/experience set @s 0 points
/experience add @s 500 points
```

## A：切换、经验门槛与耐久

1. 放置铜工作台。顶排三铜锭，第二、第三排中间各一木棍，得到铜镐预览。
2. 总经验为 0、499、500、999、1000 时都能切换普通、优良、优秀。空闲右键结果或箭头依次切换，超过最高档回到普通。铜工具最高优秀，多给经验也不能选精良。优良需要 500 点、优秀需要 1000 点；不足时品质与费用标红，左键/Shift 左键不得开始、不得扣料扣经验，也不得给出预览物品。保持已选优秀并补足到 1000 点，再点击才可制造，无须重新切品质。
3. 500 点经验选择优良，悬停应显示 500 点费用，左键启动。进行中查看进度，完成前不扣材料和经验；完成后得到优良铜镐、经验归零，最大耐久 7200。
4. 重新设置 1000 点，制作优秀铜镐，费用 1000，最大耐久 9600。普通铜镐为 4800，不收品质费。品质提高不会直接改变基础伤害或采集速度。
5. 制造进行中右键结果是取消，空闲右键才是切换。取消后原料和经验应不减少；重新点击从零开始。更换原料或关闭界面也取消，重新放配方默认普通。
6. 在 JEI 开启、原版配方书开关、不同 GUI 缩放和窄窗口下查看品质控件。不得遮住实际结果格、无法点击、显示紫黑材质或中文缺字。该项需要用户客户端实测。

## B：连续制造与途中变化

1. 设置 2000 点经验，铜台放三套铜镐原料，选优良后 Shift＋左键。完成后只得一把，剩 1500 点经验和两套原料；继续等待不应再扣费。
2. 选择普通，普通左键只做一把；剩余原料用 Shift＋左键逐批做完。每批都必须等进度，不得重复产出。
3. 500 点启动优良制作，关闭界面应无消耗。重新启动后在服务器命令环境将经验减至 499，原优良批次应停止并清零进度，预览保留优良；不能自动改普通后产出，也不能出现负余额或复制物品。补回到 500 点不会自动恢复制造，重新点击后才从零开始。
4. 空食物条时制造暂停，补食物继续；暂停阶段不收费。高材料制作等待较长可 `/tick rate 200`，结束恢复 `/tick rate 20`。

## C：合并维修、皮甲修补与染色

1. 领取的两把优良铁镐各损伤 10000、最大耐久 14400。设置 979 点经验，在铁工作台把两把放入合成格，应不能制造维修结果；980 点时允许。
2. 完成维修后品质仍为优良，损伤 5600（剩余 8800），经验仍为 980。不能再加原版合并维修奖励，也不能把耐久倍率重复计算成 21600。混合不同品质不得合并。
3. 普通皮胸甲损伤 15，配 8 根线：完成消耗 7 根、损伤变 1；再用 1 根线修到满。此维修免品质费。
4. 优良皮胸甲损伤 7、最大耐久 24：总经验 319 时不能修补，320 时配 8 个筋，完成消耗 2 个、损伤变 1，仍保留优良品质，经验不扣。原有附魔/命名/染色也应保留。
5. 用未损坏的优良皮胸甲加红染料，0 点经验也能染色；完成后仍为优良、耐久 24、经验 0。损坏皮甲不能借染色配方完成制造或维修。
6. 砂轮合并同品质装备应保持品质，不额外奖励耐久；不同品质不能合并。单件祛魔应保持品质。2026-10-17 调整后，鼠标悬停砂轮产物显示祛魔费用，数值为原随机经验奖励的两倍；经验不足时红字提示且不能取出，输入、经验和预览均保留。单件效率 I 铁镐费用为 2 点：0 或 1 点经验不能取出，补到 2 点后普通点击或 Shift 可取出且经验归零，不掉经验球。预览、关闭及拒绝取出不扣费，反复刷新不改变费用；双件附魔合并按两件附魔合计，无附魔维修、仅有诅咒不扣费。铁砧同样不能混品质维修；仅重命名或加附魔书不应误判为维修资格不足。铁砧自身的正常等级费另算。
7. 钻石升级下界合金保持原品质，不能把来源已乘过的最大耐久再乘一次。合成器制造装备采用普通品质，不自动支付玩家经验；染色保持输入品质，损坏装备不能用无人自动维修绕过资格。

## D：200 级以后与高阶品质

```mcfunction
/experience set @s 200 levels
/experience set @s 0 points
/experience add @s 2020 points
```

应为 **201 级**。再加 2030 点应到 **202 级**。200/201/202 级累计经验分别为 203000/205020/207050；生命与饱食上限仍遵守此前的独立规则，不随取消经验上限无限增长。

1. 保存退出、重进后 202 级及当前经验保持；拾取经验球仍正常增加。附魔、死亡/保留背包和制造扣费后按同一曲线重算。
2. 设置总经验 491840 点，应为 **312 级**，当前级内余 440 点。在艾德曼工作台摆三艾德曼锭与两木棍制作镐，可切到传奇，费用 **491840** 点。完成后经验为 0、等级为 0，传奇艾德曼镐最大耐久 **1075200**。
3. 取消高品质制作不扣经验；把结果放箱子、丢出捡回、退出重进后品质和耐久不变。
4. 高等级采集倍率继续使用 `1＋0.02×等级`，201 级为 5.02，300 级为 7；工具资格仍生效，等级不能让错误工具采集受限材料。

经验兼容原版的 32 位存储/网络字段，在整数存储范围内持续按公式计算；2147483647 点是技术存储边界，不再将 200 级或 203000 点视为玩法上限。技术边界及极值行为见经验适配文档。
