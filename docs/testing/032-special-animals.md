# 032 狼、猫、马、蝙蝠、鱿鱼专项测试

开发署名：NingMeng123。来源为本地 R196 发布包的 `sf`、`rx`、`rs`、`ro`、`sc`、`sq`，规则索引见 [animals-source-032.json](../../spec/animals-source-032.json)。本页列出手动验收办法；自动检查结果由本批验证记录填写，不代表客户端已经实测。

使用本批 JAR 启动客户端后，在单独的创造测试存档开启命令。需要观察 AI 时，实体不要带 `NoAI:1b`。长期等待可使用 `/tick rate 200`，结束后执行 `/tick rate 20`；玩家操作驯服、观察动画和碰撞时使用默认刻率。

## 狼与凶狼

1. 用 `/summon minecraft:wolf ~ ~ ~` 与 `/summon mite:dire_wolf ~3 ~ ~` 分别生成普通狼和凶狼。空手以外的骨头交互仍可驯服；普通狼与凶狼使用不同的失败和成功阈值，玩家等级提高会增加中间概率区间的成功率。
2. 骨头驯服失败后有 100 tick（默认刻率 5 秒）冷却。失败消耗一根骨头，立即重复右键不会继续消耗；冷却结束后才再次判定。侵略性失败可能攻击玩家，蓝月夜抑制这一反应。
3. 驯服前先伤害狼，记录缺少的生命值，再驯服。普通狼生命上限从 8 变成 12，凶狼从 16 变成 24，缺少的生命值保持。例如普通狼剩 3 点生命时成功驯服后剩 7 点。
4. 驯服的狼会在主人距离至少 10 格时跟随，接近至 2 格停止；无法走到主人身边时不会使用新版原版的瞬移。让狼坐下后，它不会走向地上的肉；生命不高于一半时，直接碰到它身上的肉仍会被吃掉。
5. 野狼会按 R196 的独立猎食概率选择鸡、羊、猪、牛以及骷髅或食尸鬼。猎食任务每刻有四十分之一概率重新选择可见的更近猎物；要求视线的目标在连续失视超过 60 次检查后放弃。猎物骑在可攻击的生物上时转为攻击坐骑。普通狼和凶狼不能交叉繁殖；原版狼的不同新版皮毛保留。
6. 驯服的宠物会察觉正在攻击自己或主人的敌对生物，短暂凝视威胁；狼会发出警告声音。威胁记忆持续 50～140 tick，宠物已经自己开始攻击时结束这项警戒。狼成功攻击仍存活的猎物会刷新目标倒计时。

## 豹猫与猫

1. 豹猫与猫只认鳕鱼代表的旧版生鱼和 `mite:raw_large_fish`。鲑鱼和熟鱼不属于 R196 的这份食物清单。
2. 拿大生鱼静止靠近野生豹猫，等待其诱食 AI 启动，距离小于 3 格时右键。每次判定消耗一条鱼，成功率为三分之一；失败有 400 tick（20 秒）冷却。大生鱼诱食未启动时，单纯靠近右键不会消耗鱼。
3. 这里保留 R196 的实际调用行为：小生鱼和大生鱼各有一个诱食任务，但驯服入口引用的是后注册的大生鱼任务。因此只有小生鱼正在引诱时不能直接驯服。此行为经源码确认，并非新增概率规则。
4. 旧版豹猫驯服后转换为新版猫实体，使用旧版三个猫种对应的黑猫、红猫和暹罗猫之一。已有新版猫的外观不强制替换。驯服的猫保留主人坐下交互，会跟随主人并选择封闭箱子、燃烧中的熔炉或床尾休息。
5. 受伤猫吃鱼恢复最大生命的一半；生命已经满时吃鱼才进入繁殖状态。受伤的猫首次吃鱼不会因为这次恢复到满血而同时进入繁殖。
6. 野生豹猫即使因食物进入爱心状态也不会繁殖。已驯服猫的幼崽继承母方的猫种与主人。自然生成的豹猫有七分之一机会追加两只 R196 新生幼崽；这与新版的群体幼体比例机制不同。

## 马、驴、骡与亡灵马

1. 未驯服的成年马、驴、骡在脾气为 0 时会躲避附近玩家。投掷在地上的小麦不会被马拾取食用；手持右键喂食属于独立路径。
2. 用小麦、糖、面包、干草块、苹果、金胡萝卜和金苹果喂食，依次验证恢复生命、幼崽成长和脾气增加。糖增加 150 成长 tick 和 3 点脾气；小麦增加 300 成长 tick 和 3 点脾气。亡灵马不接受这些食物。
3. 未驯服且满血的马接受食物后，会有 4000 tick（200 秒）拒绝重复喂食；受伤时可再次喂食治疗。骑乘驯服失败会增加 5 点脾气、甩下骑手，并有 4000 tick 拒绝再次骑乘。驯服后两个拒绝计时清空。
4. 驯服、成年、满血的马喂金胡萝卜或金苹果可进入繁殖。受伤时这次食物先用于治疗，不能在同一次交互里通过治疗后满血绕过原来的满血繁殖检查。
5. 幼马每 200 个偏移刻批量成长 200 tick；出生时间仍使用本批统一的 R196 动物年龄。普通马与驴交配产生骡。
6. 保留已由字节码确认的 R196 繁殖行为：繁殖时三个随机平均属性写到调用繁殖的母马，而幼崽保留构造默认值（生命 53、速度 0.225、跳跃 0.7）。花纹 80% 来自母方、20% 来自另一方，没有额外随机花纹分支。不要用新版原版的属性继承结果作为此项验收标准。

## 普通蝙蝠

1. 在封闭但有飞行空间的房间生成普通蝙蝠。出生时是飞行状态，随后会寻找底面坚实、下方为空气的天花板倒挂；玻璃不能作为倒挂天花板。
2. 靠近至 4 格内、伤害蝙蝠或拆掉天花板，会使其离开倒挂。离开后有 60 tick（3 秒）防止立即重新倒挂的计时。
3. 在主世界负数高度重复测试。飞行目标应继续在附近产生，不会因旧版 Y=1 下限而集体飞向地面。
4. 本页普通蝙蝠的倒挂逻辑与已有吸血蝙蝠、巨型吸血蝙蝠、夜翼战斗 AI 分开处理，避免替换已有战斗目标和吸血逻辑。

## 鱿鱼与船

1. 在至少两层水深的水池内生成普通鱿鱼，切换生存模式观察。浅水玩家和站在岸上的玩家不属于猎物；蓝月夜鱿鱼清空猎食目标。
2. 鱿鱼与猎物之间须有由满水方块组成的路线。石头障碍或不满的流水截断所有中心、脚部和顶部备选路线时，鱿鱼放弃这一目标。
3. 接触普通鱿鱼，验证缓慢 III 持续 200 tick（10 秒）。玩家的距离小于 1 格且未坐船时，独立的接触效果不受浅水或蓝月猎食规则影响。鱿鱼不会猎食鱼类或其他水生动物，荧光鱿鱼保留新版自身行为。
4. 夜间坐船并让普通鱿鱼锁定船上乘客。针对该乘客的鱿鱼累计碰撞船 6 次会毁船，掉落 3 块橡木木板和 2 根木棍；无目标鱿鱼不累计这项撞击。近期撞击数每 200 个偏移刻减少 1，保存重进后保留未衰减的计数。

## 自动验收范围

`NativeAnimals032GameTests` 包含独立的驯服阈值、骨头消耗与冷却、缺血量保留、食物门槛、坐下宠物接触拾食、实际伤害、命中刷新、威胁记忆、诱食选择权重与冷却、目标计时保存、目标任务注册、同类繁殖、豹猫幼崽和猫种继承、鱼类清单、马食物表和成长、拒食拒骑、繁殖属性接收者、负数层蝙蝠、满水射线、蓝月猎食与独立玩家接触缓慢以及真实船碰撞与保存测试。测试期望使用发布包提取的常量，随机输入由独立 Java Random 选择。

## 重载与现代保存适配

驯服失败后，保存退出并重进存档，剩余交互冷却继续计算，不会因为重登立即获得新的驯服判定。普通蝙蝠的飞行目标、倒挂高度和防重挂剩余计时也会在现代实体数据中恢复。测试时可在狼或豹猫冷却期间重进，检查不会重复消耗手中食物；在负数层蝙蝠飞行或倒挂期间重进，检查实体位置和状态正常恢复。

这些跨重载恢复属于本项目明确采用的现代保存适配，不是 R196 原有的 NBT 字段：`oq` 自身只写入主人和坐下状态，驯服冷却是旧版临时字段；`ro` 自身只写入蝙蝠标志和初次倒挂尝试标志，旧版飞行目标和防重挂计时同样属于临时字段。适配保留原来的概率和剩余计时数值，用于避免重登绕过交互冷却，并适应新版实体的保存恢复。目标引用相关的诱食任务绑定在实体离开世界时释放，重载后重新创建；威胁凝视记忆仍按旧版临时状态处理。

现代适配：新版实体类型拆分、寻路与碰撞体继续采用 1.21.1；猫外观和马鞍、装备、容器等新版交互保留；普通蝙蝠的高度下限采用新版维度最低高度；诱食、威胁察觉和失路呼叫使用实体随机源承接旧版部分全局随机调用，保留概率而不承诺旧版随机序列或寻路路线；威胁凝视记忆仍属于未写入存档的临时状态。自动检查不替代本页的客户端观察。
