## 硬币：经验与金属粒的存取

| 金属 | ID | 每枚保存的经验 | 铸币最低工作台 |
| --- | --- | ---: | --- |
| 铜 | `mite:copper_coin` | 5 | 铜、银或金 |
| 银 | `mite:silver_coin` | 25 | 铜、银或金 |
| 金 | `mite:gold_coin` | 100 | 铜、银或金 |
| 远古金属 | `mite:ancient_metal_coin` | 500 | 远古金属 |
| 秘银 | `mite:mithril_coin` | 2500 | 秘银 |
| 艾德曼 | `mite:adamantium_coin` | 10000 | 艾德曼 |

更高材料容量的工作台同样可用；没有铁币。

1. 先用 `/experience set @s 0 levels`、`/experience set @s 0 points` 清空经验，再 `/experience add @s 5 points`。拿铜粒，在铜工作台把1粒放入任意格，应看到1铜币。普通点击制作一次，完成后消耗1粒和5点经验；右击拿在手里的币不会免费送经验。
2. 把铜币放进背包2×2，制作后返还1铜粒和5点经验。再试2~4枚分格拆解；工作台3×3最多9枚，每格一枚参与本批，返还对应数量与经验。不能一批扣掉整叠。
3. 再次先设0等级和0点，再 `/experience add @s 4 points`；此时仍能看到铜币配方，但点击不能制造，材料与经验保持。换低级工作台时不能铸币。
4. 再次先设0等级和0点，再 `/experience add @s 20 points`，备好4铜粒：普通点击完成一枚后应停止；Shift点击继续逐批制作，直到材料或经验不足。满背包应只掉落实际已付费产物。自动合成器没有操作者，不能铸币或拆币取得经验。总经验可用 `/data get entity @s XpTotal` 检查，`experience query points` 只显示当前等级内的余量。
5. 打开JEI，查看铸币、拆币的不同工作台页面、材料数量和耗时。首次实际结算主世界地牢/沙漠神殿的宝箱战利品时，硬币按存档累计游戏时间到源第20天解锁；此前已打开结算的箱子到20天不会补币。仅 `/time set` 改变日夜不能提前解锁。

## 祛魔之瓶：饮用和铁砧

1. `/give @s mite:bottle_of_disenchanting 4`。加一个正面效果和一个负面效果，例如 `/effect give @s minecraft:speed 60`、`/effect give @s minecraft:poison 60`。右键饮用约1.6秒，所有状态效果消失，生存模式返还1玻璃瓶，身上装备附魔保持。
2. 反胃或眼睛在水下时不能饮用，也不会消耗瓶子。创造模式正常饮用不增加空瓶。
3. 铁砧左槽放已附魔装备，右槽放瓶子。输出应清除实际装备附魔（包括物品诅咒），耐久与品质保持；零经验也可取出，不磨损铁砧，瓶子完全消耗，无额外空瓶。未附魔物品及储存附魔书不凭空出现洗附魔结果。
4. 在JEI查看“水瓶＋下界疣＋煤”，尝试用其他药水代替水瓶应失败。它是饮用品，没有投掷爆炸。旧版持久玩家诅咒系统尚未实现，本批不宣称已经复刻该部分。

## 七种石桶：冷却与拆解

金属前缀为 `copper`、`silver`、`gold`、`iron`、`ancient_metal`、`mithril`、`adamantium`，ID统一为 `mite:<金属>_stone_bucket`。例如 `/give @s mite:copper_stone_bucket`。

1. 带对应岩浆桶进入水中，眼睛没入水后主物品栏与副手岩浆桶变成同材质石桶。铁岩浆桶ID为 `minecraft:lava_bucket`，其他为 `mite:<金属>_lava_bucket`。把掉落岩浆桶丢进水中也会冷却；站在水边、眼睛未没入水不能触发携带冷却。
2. 石桶不能倒岩浆或放置石头，最大堆叠1。它不能用熔炉烧成空桶。
3. 把石桶放入背包合成格，应只制作1个同材质空桶，无石头、无第二只容器；命名后的石桶拆解应保留名字。JEI在背包及各等级工作台都能查到拆解配方。
4. 掉落金属币、材料及桶遇普通火焰/岩浆按各自材料判定，普通火焰与岩浆不是同一免疫。艾德曼石桶遇岩浆时内容被毁，应只留下一个空艾德曼桶。
