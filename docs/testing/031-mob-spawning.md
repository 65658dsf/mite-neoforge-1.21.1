# 031：R196 生物、自然生成与客户端外观手测

开发者：NingMeng123。原作：Avernite。基准：本地 R196 发布包与原材质包。

这份清单供用户自己操作。**本轮没有自动关闭、重启或操作你的游戏，也没有记录为用户已验收。** 完成根任务的构建后，请先保存并退出当前客户端，再重新打开测试客户端加载新代码；仅返回标题界面或资源重载不能加载新增 Java 类。开发客户端使用 `runClient`，保留 `run/mods` 中的 JEI、Jade 等测试扩展，不需要再把开发项目 JAR 放进同一个 `run/mods`。独立安装实例使用本批最新构建的模组 JAR。

使用有命令权限的测试存档，先创造模式检查模型，再切生存模式观察攻击。来源怪物的攻击与装备可能明显超过 0 级生命容量，观察战斗时可先提高测试等级或穿相应装备。默认 20 TPS；长时间等待可使用你建议的 `/tick rate 200`，结束后恢复 `/tick rate 20`。高 TPS 会同时加快饥饿、攻击、状态和生成，测试距离/攻击间隔时恢复 20 TPS。

## 1. 注册、蛋、召唤与基础外观

在 JEI 或创造物品栏的刷怪蛋分类搜索 MITE。应有下面 29 种蛋；它们可按每堆 16 获取。逐种检查名称、蛋图标、召出身份，不能显示紫黑缺失纹理或报错退出。

```mcfunction
/gamemode creative
/give @s mite:ghoul_spawn_egg 16
/summon mite:ghoul ~ ~ ~
```

其他物种将 `ghoul` 换成表中的路径。要让默认装备和随机变体正常执行，优先使用蛋或不带额外 NBT 的召唤命令。给 `/summon` 附加 NBT 是手动指定实体数据的测试，会与默认生成完成流程不同；不要把自己指定的空装备当成默认生成装备错误。

## 2. 怨魂、骷髅装备、品质与保存

1. 召出若干怨魂，应全部成年并带四件锈铁板甲和武器。装备有磨损、品质按材料上限处理。改变世界时间到第 10、20 天附近后重复召出，战斧/战锤分别进入武器池；随机不等于每次必出现。
2. 多次召出远古骷髅，弓与剑两种变体应存在；护甲为远古锁链。射出的实体和捡回箭为远古金属箭，不是普通燧石箭。骷髅射中其他骷髅时检查来源友军免伤。
3. 对守卫，找一只初始拿弓的个体，在生存模式、可见且相对平坦的距离条件下观察：小于 5 格换短剑，大于 6 格换回弓，正好 5、6 及中间区间不反复切换。用 `/data get entity` 的 `stowed_item_stack` 记录备用武器，换回时品质/磨损/附魔不重新掷。
4. 保存退出，重开；独立服务器还要停服再启动、第二位玩家连接观察。守卫备用武器、骷髅子型、怨魂成年状态都应保留，不能丢失物品或重新生成一套装备。
5. 用原版骷髅蛋多次生成，应有来源约 25% 的木棒近战变体，其余拿弓。保存后不能因为只保留弓/近战 AI 丢失子型。下界用原版骷髅蛋或直接命令得到 type1 时应使用凋零外观、放大形状、差品质铁剑、火免疫与凋零攻击；自然池生成则可对应现代凋零骷髅实体。

死亡装备保持真实磨损。普通领主的合适手持武器与远古骷髅生成武器的掉落条件不同；单次没掉不能用作概率结论。大摔落会压低材料与装备掉落，应分别记录玩家击杀、环境击杀、是否大量摔落、抢夺等级。

## 3. 骷髅领主部队

在足够宽的平坦房间或洞穴放领主，周围要有能站立并通过路径/视线检查的空位。生存玩家与领主保持可见且不超过 16 格，给部队生成留出至少 4 格距离。普通领主召普通骷髅，远古领主召远古骷髅。

观察附近受伤骷髅和领主的每秒治疗、绿色短时狂暴及目标指派。狂暴每次刷新 20 刻，不应无上限叠加攻击；离开领主范围后应结束。保存的 `num_troops_summoned` 记录最多 6，不产生第 7 个名额；部队死亡不会立即返还该来源计数。部队自然回收与计数减少另有保护时间、玩家视线和距离条件。

可用 `/tick rate 200` 等待较长的部队消失保护，但观察战斗与距离边界时回到 20 TPS。保存重开后，领主计数和部队保护应继续保留，不可通过重连反复获得额外部队。

## 4. 吸血蝙蝠、暗翼与视野

在有天花板的暗室放小蝙蝠和巨蝙蝠，再放牛或其他可捕食动物。小蝠受伤后命中动物应按真实造成的生命损失恢复；满生命后暂停攻击动物/村民 1200 刻（20 TPS 下 60 秒），仍会攻击生存玩家。再次受伤后暂停结束；巨蝠满生命仍会捕食。伤害被阻止时不能凭空吸血。

小蝠可在一格空气的实心天花板下吊挂，巨蝠需要两格；玻璃不可吊挂。观察旧模型翅膀在飞行/倒挂两种状态是否完整、没有撕裂或错误 UV。下面负 Y 房间也要同样检查。

暗翼与暗影命中玩家后，应看到视野逐渐变暗并按刻衰减，HUD 仍清晰在覆盖上方。穿银装备后的抵抗效果另测；普通武器、银武器、魔法和阳光的接受条件分别观察。暗翼在阳光中应被来源阳光伤害销毁，低亮度时周期恢复。测试过程中被无敌/创造状态完全阻止的攻击不得给玩家追加变暗；重连/服务器重启时状态不应突然加倍或永久不消失。

## 5. 蜘蛛、胶体、元素体和蠹虫

- 蜘蛛在生存目标附近投网，恶魔蛛/着火蛛可投燃烧蛛网。分别检查落地位置、目标预测与水中行为。死亡线数量受**剩余**蛛网库存影响；已经投完的蛛不能死亡时再刷新一组库存。相位蛛起始没有网，要观察有限躲避次数、合法落地与负 Y 环境，不能传进实心方块。
- 胶体多次召出检查尺寸和分裂；灰浆怪不能出现真实尺寸 4 的大体型。准备原料、食物和装备，让腐蚀与进食在实际容器/掉落实体路径发生，核对数量、品质、耐久和返还；同一腐蚀作用不能复制物品。留意农业病害状态及其保存。
- 元素体在不同环境和材料状态下看皮肤、发光、防御、热化/冷却，黏土体硬化后不能被冷却任意回到泥体。工具攻击和银/魔法等例外要分别测，死亡方块应与实际材料状态一致。火元素在水/雨、干燥处、熔岩中分别记录实际生命变化和火焰，不能把正常透明身体当成缺失纹理。
- 蠹虫先在有可触发宿主块的房间测试受伤后延迟增援，再在空房间对照；不要用没有宿主的空房间断言增援未实现。分别看铜脊的毒、苍白的麻痹、地狱蠹虫的烟与火/水差异。

## 6. 自然生成与现代负高度

自然生成使用新版本地形。各源物种有自己的维度、深度、光照、气候和池权重，不要求 29 种在一个房间全刷出来。先确认难度不是和平、`doMobSpawning` 开启，并留出原生玩家距离与碰撞空间。自然观察应从没有被大量命令生物占满怪物名额的状态开始。

1. 主世界普通夜晚、森林/寒冷/沙漠等环境及不同洞穴深度分别观察，记录现代绝对 Y 与来源深度映射。专门去 Y<0 洞穴观察，不应因为旧 `Y>=1` 判断而整个区间不生成、不飞行或不能吊挂。
2. 地底世界通过此前已验证的传送体系进入。在合法洞穴中重复自然生成和负 Y 生物交互；不要在地幔、基岩或墙里只用命令生成就作为生成资格验证。
3. 下界普通/玄武岩等环境观察地狱生物、骷髅对应和火系状态。现代下界地形继续存在；不能因为迁移旧深度比较把全部可生成区域移到世界外。
4. 光照由现代发光方块和实际天空读取。明暗两个同构测试房对照；检查带电/雷暴、敌对难度、刷怪笼与自然生成路径的区别。
5. 检查生物群系与生成条件后，再使用加速等待；`/tick rate` 不改变时间设定指令本身。观察到的频率受生成池随机与名额限制，不承诺一小时必出现每种罕见生物。

可在专用测试存档比较普通夜、血月夜和蓝月夜。当前来源日历下，以下示例在对应日夜晚 13000 刻：

```mcfunction
/time set 13000
/time set 757000
/time set 3061000
```

它们分别用于普通夜、第 32 日血月、第 128 日蓝月。每次比较记录地形、气候、亮度和已经存在的生物数量；原规则中蓝月和血月不是同一个标志。结束后恢复所需时间和 `/tick rate 20`。没有完成真实频率采样时，不把主观“刷得更多/更少”写成全量概率验收。

## 7. 保存、重连与第二客户端

至少保留一只守卫、两种蝙蝠、一个材料/热量变化后的元素体、投过网的蜘蛛、受过腐蚀的胶体和召过部队的领主。记录 `/data get entity` 与截图，保存退出重开或停服重启后重新对比。不要使用 `NoAI` 或直接修改生命/库存的命令替代真实行为验证；它们只适合隔离外观检查。

第二位玩家观察同一实体，核对尺寸、手持武器、材质/热量、相位位置与胶体尺寸一致。让玩家跨维度再返回、重新连接，确认视觉状态与持久实体没有丢失或生成副本。战斗、拾取、死亡与中途取消的 NeoForge 事件仍应各执行一次，客户端不能自行恢复库存或追加掉落。

## 8. 反馈格式

可以按组回复，不需要一次测完全部 29 种。每组记录实体 ID、单人/服务器、维度、现代 Y、时间/月相、20 或加速 TPS、使用蛋/命令/自然生成、预期和实际结果。外观问题附正面/背面或翅膀/腿部截图；掉落/装备问题附数量、品质与磨损；生成问题附生物群系、天空/方块光照、难度和附近生物数量。

用户明确确认通过后再提交 GitHub。没有用户回报的组仍标为待手测，不能因其他组正常而全部标成已验收。

## 9. 原版生物掉落与实际库存

在单独的小房间使用原版刷怪蛋，清空其他掉落实体后分别测试；保持 `/gamerule doMobLoot true` 和 20 TPS。多次击杀才能观察随机数量，单次未出稀有物不等于故障。

1. 牛/哞菇应掉 1–3 张皮，健康初始个体至少一份牛肉；猪至少一份猪肉。羊的羊毛并非必掉，剪过或烧死不掉羊毛，同时可有皮和至少一份羊排。鸡烧死应只有一份熟鸡肉、不掉羽毛；普通鸡使用剩余羽毛，已掉出的羽毛不能死亡时重新补满。
2. 普通僵尸稀有物应是铜/银/金/铁粒；僵尸村民稀有物为种子、胡萝卜、马铃薯或洋葱，不能再附加原版稀有铁锭或第二份洋葱。无玩家近期命中的环境死亡没有来源稀有物。
3. 原版普通骷髅返还锈铁箭与骨；来源近战子型不掉箭。凋零子型/现代凋零骷髅为煤、骨及来源低概率头骨。原装备掉落应保持死前品质、附魔与磨损，不能生成第二件或重新磨损。
4. 铁傀儡用岩浆/摔落等环境击杀时不应得到铁锭或铁粒；近期玩家正常击杀才可能得到来源铁粒。大量摔落会抑制材料，不能以高空掉落代替正常击杀测试。
5. 鱿鱼近期玩家击杀固定一份墨囊，环境死亡无墨囊；烈焰人环境死亡无烈焰棒。狼掉一张皮，马还会有来源牛肉。已安装的猪鞍、马鞍和货物仍需完整返还一次。
6. 女巫可掉来源扩展池中的小刀、种子、花和药水；药水名称、饮用/喷溅形态和效果时长不能全变成同一个物品。保留新版本无旧来源身份生物的原生掉落，例如兔子、尸壳、流浪者。
7. 原版蜘蛛/洞穴蜘蛛也要实际观察投网和库存。严格距离大于 2、小于 6 格时才可能跃击；正好 2/6 格不跃。原版蜘蛛在户外亮度严格大于 0.5 时可能保持中立，洞穴蜘蛛保持敌对。已经投出的网不得死亡时再返还成线；投完后保存退出、重开再击杀，库存不能重掷。

畜牧初始健康值和掉肉条件已接入，但完整饥渴、拥挤与代谢仍在后续农业范围；请不要将本轮掉落测试通过视为整套养殖系统已完成。反馈时注明是否玩家近期命中、着火、大量摔落、已剪羊毛、此前掉羽/投网以及装备抢夺等级。

## 10. 原生蜘蛛投网、中立与来源骑乘

原版蛋仍使用 `minecraft:spider_spawn_egg` 和 `minecraft:cave_spider_spawn_egg`；新来源蜘蛛使用表中的 `mite:` 蛋。这些是不同身份，需要分别测试。

1. 在有目标且无遮挡的暗室放普通蜘蛛/洞穴蜘蛛，生存玩家保持不超过 8 格。库存可能出生为 0，先挑有库存的个体；普通蜘蛛投网周期为 500 刻（25 秒），洞穴蜘蛛为 200 刻（10 秒），首次时刻受实体偏移时钟影响，不能用出生后一秒没投断言失败。分别用水、实心墙和站在前方的另一只生物阻挡，应不会隔它们命中后方目标并扣库存；眼部受阻时可以尝试四分之一身高的通路。
2. 先用正常无火个体投网，再让蜘蛛着火后观察燃烧网。比较投射物和落地蛛网，确认已有库存减少，剩余线掉落和保存恢复使用同一份状态。20 TPS 下观察跃击时保持严格大于 2、小于 6 格；概率为每刻 1/10，并不保证每刻都会跳。
3. 准备两间明亮房，一间有完整屋顶，一间连通户外。普通蜘蛛在明亮**室内**仍应追击；户外未受玩家攻击时可能放弃玩家目标，受到玩家反击后保留该目标。洞穴蜘蛛在户外也敌对，实际造成生命损失后毒状态初始持续 24 秒，不能按原版难度变成 7/15 秒；被无敌或取消事件完全拦住、没有损失生命的攻击不追加毒。本批来源 NPC 即使有吸收生命值，正数命中仍按 R196 最少损失 1 点实际生命，此时仍可追加毒。
4. 放鸡观察原生蜘蛛/洞穴蜘蛛捕食可见鸡；玩家获取与投网检查不是同一个视线条件，蜘蛛可以发现墙后的玩家，但不能用投网穿过实心墙。
5. 在普通蜘蛛蛋/不附加 NBT 的召唤流程中分批观察骑乘。它是来源 1% 世界随机概率，100 次也不保证恰好一次；每次骑手应是持弓 type0，不能出现来源木棒近战子型。进入地底世界再重复，骑手应变成持远古金属弓的远古骷髅。保存退出、重开后检查身份、持弓装备、品质和磨损继续保留；新四种来源蜘蛛以及洞穴蜘蛛不应凭继承关系随机带普通骷髅骑手。
6. 普通蜘蛛的困难模式群组增强来源实际是速度/力量/再生；来源随机范围使隐身分支不可达。新四种来源蜘蛛和洞穴蜘蛛不继承普通蜘蛛这项随机增强，不能因为现代父类回调而出现同类随机药水。不要把其他模组主动施加的效果当成本模组随机生成。
7. 单独测试命令在下界生成普通蜘蛛时，客户端/服务端不能因骑手选择卡死。原作该路径会永远抽到凋零 type1 而无法达到只收 type0 的循环条件，本批使用最多 64 次后的来源弓装备安全回退；这是明确的现代安全适配。生成事件被其他模组取消时不能不断重试以绕过取消。

本组与前面 29 个新增身份同样待用户手测。最终自动回归数量由根任务记录确认，自动源参数/结构检查不等于骑乘外观、联机同步和真实自然生成已经人工验收。

## 11. 来源 NPC 伤害与已有马铠回归

这一组检查新统一伤害入口是否保留此前已添加的装备功能。使用单独场景与 20 TPS，不在同一只生物上连续混合不同来源的伤害；受伤无敌时间会影响连续比较。

1. 用蛋生成牛，施加抗火后分别接触普通火与熔岩：火不伤害，熔岩伤害为未施加抗火时的一半。地狱蠹虫同样只减半熔岩伤害，不因抗火药水获得熔岩免疫。对照普通未硬化黏土魔像和地狱蠹虫，普通烧着的箭仍有物理命中，不能被当作纯火全免；硬化/石体有另一套工具资格，不能与泥体混测。
2. 给牛施加吸收效果后让普通攻击命中；来源 NPC 正数伤害经过吸收仍最低损失 1 点实际生命，吸收值按来源 NPC 规则消耗。无敌、伤害事件被其他模组取消或明确置为 0 时仍不损失生命，不制造额外攻击。可用 Jade 或 `/data get entity` 记录 `Health` 和 `AbsorptionAmount`。
3. 在有头盔的来源 NPC 上对比普通攻击和落下的铁砧：普通伤害不磨损 NPC 护甲，落物会磨损头盔并执行来源的伤害调整。用 `/data get entity` 记录头盔伤前/伤后的耐久；不要把被铁砧实际砸死的尸体当成存活装备损耗对照。
4. 驯服并装上马铠的马在保存重开后仍有防护。普通物理伤害下，铜/银马铠防护 4、金 3、铁/远古 5、秘银 6、艾德曼 7；金马铠提示应为 3。使用同种攻击和同样健康初值比较，最少伤害规则仍适用。马铠保持来源不可损坏；熔岩等绕过普通护甲的伤害、绝对伤害不能被马铠挡住。现代皮革/钻石马铠保留其现代防护适配。

自动测试另外覆盖头盔耗损事件取消、伤害前事件置零、马铠实际损血和显示属性一致性。实机、多人显示和扩展模组组合仍由用户反馈。
