# 移除钻石材质装备

开发者：NingMeng123。本次按用户要求调整现代内容，不作为 R196 新来源规则。

2026-10-16：数据生成、构建、1455 项 JUnit、1589 项服务端 GameTest 全部通过。用户手动测试后反馈“好的没有问题了提交吧”，授权提交；不补写逐项手测结果。

## 范围与适配

移除 10 件物品：钻石剑、斧、镐、锹、锄、头盔、胸甲、护腿、靴子和马铠。钻石、钻石碎片、两种钻石矿石和钻石块保留；附魔台、唱片机等使用钻石材料的功能方块不受影响。

- 创造分类、创造搜索及可选 JEI 隐藏这些装备的全部组件变体。JEI 仍非前置。
- 禁用原版钻石装备配方，服务端加载和同步的配方集合也过滤钻石装备产物。原版修复、配方书及自动合成不能借此恢复已移除装备。
- 宝箱、宝库、钓鱼及装备战利品在全部全局掉落修改器执行后统一过滤；村民交易检查产物和两种输入，兼容已保存的旧交易。
- 玩家背包、盔甲、副手、末影箱、菜单与光标，生物装备、掉落实体，以及存档读取的装备都会清除。潜影盒和收纳袋递归清理其中的钻石装备，保留合法内容的数量、名字和容器槽位。已有钻石装备直接移除，不转换成其他材料。
- 原版注册 ID 保留用于兼容存档和数据加载，不通过注销注册项使旧存档无法读取。普通游戏中的获取、显示和使用入口均按上述规则限制。

9 种下界合金装备的锻造底材改为对应的**远古金属工具或板甲**，仍消耗原版下界合金升级模板和下界合金锭，保留原配方 ID 及原生组件继承。远古金属与原钻石的耐久因子、工作台容量均为 16，下界合金为 32；这是一项现代进度适配。

原版 5 项非配方进度中引用的钻石装备改为远古金属对应装备，包括护甲进度、两个显示图标和两个斧头交互列表。保留进度 ID、条件名称、父项与奖励，避免删除装备后留下无法完成的目标。

## 手动检查

重新启动客户端加载代码；本轮不自动操作客户端。

1. 搜索创造栏和 JEI：10 件钻石装备不再出现，钻石材料、矿石、碎片及下界合金装备仍可查看。
2. 在工作台摆原版钻石镐、钻石剑、钻石胸甲配方，应无产物。自动合成器也不应产出这些装备。
3. 锻造台放入升级模板、对应远古金属装备和下界合金锭，应获得对应下界合金装备；缺模板或锭、改用钻石底材均不能制作。检查自定义名称与原有品质等组件继承。
4. 用 `/give @s minecraft:diamond_sword`、`/give @s minecraft:diamond_chestplate` 检查运行时清除；装备不会保留为可使用物品。再用 `/give @s minecraft:diamond 3`，材料应正常保留。
5. 检查盔甲匠、武器匠和工具匠的高阶交易，以及末地城、堡垒和试炼宝库战利品，不应获得钻石装备；钻石材料及其他奖励正常。
6. 检查旧背包、末影箱、潜影盒、收纳袋、盔甲架和生物身上的存量钻石装备已清除，其他物品保留。已加载的未打开容器在打开或重载时生效，不进行全世界逐刻扫描。
7. 原版“远古金属护体”进度使用远古金属盔甲完成，下界合金进度仍可沿新锻造路径完成。
