# 032：来源动物消失规则

开发署名：NingMeng123。独立依据：`og.java:564～643`、`rp.java:206～220`、`sf.java:524～526`、`rx.java:57～62`、`nn.java:87/1493/1536/1586/2432`、`abw.java:1414/2134/2156/2290/2348/4042`。`og` 四条视线和 `rp` 的 800、1024、2400 边界已与原始字节码交叉核对。

只替换 R196 对应动物的消失检查，包含普通蝙蝠、鱿鱼、恐狼、地狱犬和三个新增蝙蝠种类；怪物和兔子、山羊、发光鱿鱼等额外新版动物继续使用其原有检查。

## 实际规则与现代适配

- 消失计数保存在 `NeoForgeData.mite_animal_despawn_032.counter`，按真正执行的实体刻增长，允许负数；保存重开不会清零。小于 200 时不尝试，没有符合条件的玩家时也不尝试。
- 距离使用 `dx²+dz²+(dy×系数)²`，严格大于 256 才允许继续判断。来源钟表 5 点（新版日时 23000～23999）系数为 1，其余时段为 2。
- 普通来源动物还受 `rp` 保护：计数小于 800 时拒绝；玩家实际距离严格小于 1024 格，或附近水平 ±16、垂直 ±1 范围存在橡木栅栏时重置为 0；计数不超过 2400 时也拒绝。其他木种栅栏不冒充来源 ID 85。
- 狼必须存在超过 2400 个原始实体刻、未驯服且不是女巫同伴；豹猫也要超过 2400 刻。地狱犬按真实继承链跳过狼年龄和普通动物计数保护，保留基础距离、库存与视线规则。
- 视线不要求玩家朝向动物。最多四条视线分别连接玩家眼睛与动物身体、脚部和头顶，最后一条把玩家眼睛抬高 1 格；超过 64 格时还检查来源的实体包围盒渲染范围。
- 来源视觉射线忽略液体、玻璃、冰、门、栅栏和铁栏；草、作物、花、树叶、甘蔗和藤蔓每个沿途格累积 50 阻抗，第二格达到 100 时可遮蔽。使用现代碰撞/选择形状、实体尺寸和已加载区块边界；新版额外植物和方块保留其现有形状，不声明逐像素重现旧射线。
- 看得见的普通动物把计数向下刷新到 -400，鱿鱼为 -9600。拾取食物可刷新 -2400，受伤通常 -1200，玩家攻击受害动物额外 -9600；刷新只取较小值，不能缩短已有的更长保护。
- `og.tryDespawnEntity` 外层判断失败时，会再把计数重置到 -50～49；这会覆盖内层刚执行的视线或栅栏刷新，是来源的实际执行顺序。不要把“曾执行 -9600 刷新”理解为每次检查后一定留下 -9600。
- 现有可回收箭的库存附件会阻止动物消失，保存后继续生效。装备不等于体内库存，生产计数也不冒充库存。
- 保留现代命名、持久化标记、栓绳、乘坐/载客、已驯服宠物和已驯服马的保护，作为明确适配；来源 `rs` 自己没有额外驯服马门槛。NeoForge 消失事件保持可拦截。现代服务器的消失检查位于实体刻之前，计数按真实实体刻增长，调度可与旧版相差一刻；不承诺旧版随机种子或完整刻顺序一致。

来源有一个容易误读的情况：普通动物在计数 200 进入外层检查后，因为内层还没达到 800，外层会随机重置。因此在一直有玩家的普通游玩中，它通常无法自行累积到 800；无玩家但区块仍被加载时或外部设置计数，才可能进入后续分支。这是来源行为，不把它修成新的自然消失周期。

## 手动测试

1. 用名字命名一只牛、给马驯服或给动物拴绳，离开再回来；动物应保留。兔子等新版动物的逻辑不受本批替换。
2. 对未命名的动物查看上述计数字段，等待真实游戏刻后再次查看；保存重开应保留负值和数值。可用 `/tick rate 200` 加速，结束用 `/tick rate 20`。
3. 检查来源消失条件时，用指令给计数设置高值；普通动物附近留一个橡木栅栏，应保护它；换其他木种栅栏不能作为来源保护依据。普通动物同时有“玩家 1024 格内保护”，因此近距离实验中不能只凭没消失来证明其他栅栏有效。
4. 鱿鱼/蝙蝠在距离合适时，石墙可以挡视线，玻璃墙不应当作石墙遮蔽。已有可回收箭库存的动物应继续保留。
