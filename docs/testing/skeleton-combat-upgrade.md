# 骷髅射击与双武器验收

作者：NingMeng123

本次玩家要求是在原有 R196 行为上增强骷髅射手。发射瞬间读取可见目标当前移动速度，计算带箭矢阻力与重力的初始方向；只预判水平移动的 80%，预判位移最多 4 格，目标运动速度最多按每 tick 0.35 格估算。发射后不再修改箭矢方向，横向急停、变向与掩体仍然有效。简单、普通、困难难度分别保留 5、4、3 的原生随机散布值，没有必中模式。

普通远程骷髅（SkeletonType 0）与远程远古骷髅（longdead 类型 0）可以拾取原版剑及 MITE 剑、匕首；备用武器使用原生副手槽保存。目标可见且距离小于 5 格时换近战武器，距离大于 6 格时换回弓，中间区间保持当前武器。没有活目标时恢复持弓。40 tick 缴械冷却仍然有效。已有的远古骷髅守卫私有备用武器及纯近战、凋灵、骸骨领主的装备策略保持原规则。

武器交换同时交换两个槽位的掉落概率。拾取的装备保持必掉标志和持久实体标志，原生存档保存两个完整物品及其组件。死亡结算前将原远程武器恢复到主手，避免杀死它时的交战距离意外改变 R196 主手弓掉落规则；拾取的近战武器仍按必掉装备结算。原生死亡掉落事件仍然可以统一取消掉落。

自动回归位于 `SkeletonAimRulesTest` 和 `SkeletonCombatUpgradeGameTests`：重力/阻力、横向和后退预判、预判封顶、随机散布、原生落地物拾取、按距离切换实际攻击目标、完整双武器存档、两种交战距离下的真实死亡掉落、纯近战种类隔离、真实箭矢水平预判、发射后不追踪以及实体墙遮挡。

手工复核：

1. 在平地让普通射手追击，横向匀速移动与急停变向各测试多次。射手应更善于预判，但仍有明显随机偏差；躲到石墙后不会继续向隐藏位置射击。
2. 向普通射手与远古射手脚边扔一把剑，确认拾取后弓仍在。走近到 5 格以内触发近战，退出到 6 格以外恢复射箭。隔墙移动不应触发凭空的距离追踪切换。
3. 保持近战模式保存退出并重进，再拉开距离。应恢复同一把弓，剑的耐久、附魔及品质不变。
4. 用缴械附魔触发落地掉武器，冷却期间不应立即从副手恢复；冷却结束后可重新使用备用武器。
5. 分别在骷髅持剑、持弓时击杀拾取过玩家武器的骷髅，检查装备不重复、不消失，耐久未被重置。
