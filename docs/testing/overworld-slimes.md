## 生成规则

主世界已有敌对怪物生成池中，四种史莱姆每种权重为 **100**，与当前僵尸、骷髅、苦力怕的基础权重相同。权重用于同一个候选池中的相对选择，不表示每次有 100% 概率生成；实际数量还受体型空间和共享怪物上限影响。

第一天起即可在普通夜晚的地表、黑暗洞穴生成，不要求血月、第三次血月入侵、旧版深度、石质顶棚或石质地面；也不套用原版史莱姆区块、沼泽月相或 Y 高度限制。保留正常亮度、实体碰撞、安全距离、可站立地面及液体检查。原本没有敌对怪物的安全生态仍保留，普通／血月的怪物总上限和其他地下怪物的进度规则不变。

地底世界和下界的权重、资格及来源表不变。

## 手动检查

1. 重新启动客户端，以中文搜索创造栏或 JEI，确认四种生物的刷怪蛋均使用新名字；Jade 显示的普通实体名也应同步更新。
2. 在主世界第 1 天夜间、未照明的草地或普通黑暗洞穴观察自然生成。可在允许指令的测试环境使用 `/time set 13000`；无需先触发血月或推进到第 97 天。玩家与生成位置仍需保持正常安全距离。
3. 确认四种均能自然出现，明亮区域、占用空间和水中不应因此获得额外生成特权。短时没有出现某一种不代表规则失效，可检查周围怪物是否已占满共享上限。
4. 可以分别 `/summon mite:blob`、`/summon mite:jelly`、`/summon mite:ooze`、`/summon mite:pudding` 核对名字及原有能力；召唤仅用于检查名称和行为，不作为自然生成验证。
5. 地底世界保持原有生态；其他地下怪物仍受此前的主世界进度规则限制。
