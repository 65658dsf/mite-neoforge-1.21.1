# 003：等级饱食度与疾跑

开发与记录：NingMeng123。日期：2026-10-12。

## 功能与规则

饱食度上限和基础生命上限共用等级曲线：`clamp(6+(level/5)*2,6,20)`。0–4 级 6 点（3 格），5 级 8 点（4 格），此后每 5 级增加 2 点，35 级达到 20 点（10 格）。HUD 使用新版原版纹理，保留半格、饥饿效果、抖动和右侧布局。

服务端在进食、直接赋值、等级变化及玩家生命周期应用上限；升级不自动补满，降级钳制当前值。饱和度保持 `0 <= saturation <= food <= cap`。达到本等级上限后，普通食物不能继续消耗；金苹果等允许随时食用的食物保留原有例外。

当前单食物条有剩余饥饿值即可疾跑，值为 0 时不能继续；保留飞行能力和乘骑的原版分支。客户端接收食物包时不按尚未更新的旧等级截断，避免服务端先发送食物、后发送经验包造成数据丢失。

原始容量来源见 [R196 玩家规则](../r196-player-rules.md) 中 `uf.java:550-555,1727-1740`。R196 疾跑调用为 `bex.java:119-132` → `uf.hasFoodEnergy()`，检查饱食与营养之和非零。当前暂以新版单食物值承载该条件。
