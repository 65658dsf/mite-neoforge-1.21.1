# 回家传送门地表落点修复

维护者：NingMeng123。

主世界普通回家门仍返回世界出生点附近，搜索半径仍为 8 格。旧逻辑先从天空到底部检查出生点所在整列，地表有水、岩浆或危险方块时，可能在尝试旁边的安全地表前选中该列的地下洞穴。

回家门现在使用 `MOTION_BLOCKING_NO_LEAVES` 高度图，每列只验证地表落点，再检查相邻列。碰撞、流体、危险地面与世界边界检查继续生效。附近没有安全地表时取消本次传送，保留玩家和地形。此修复不改变普通跨维度门与地底、下界符文门的洞穴搜索规则。

`HomePortalGameTests` 通过真实 `NetherPortalBlock.getPortalDestination` 覆盖三种情况：中心水面下有安全洞穴时选择邻近干燥地表；所有地表均危险时取消传送；中心地表安全时保持原落点。测试临时移动世界出生点并在结束时恢复。

手动复测：在独立测试存档将世界出生点设在水面或岩浆旁，确保下方有洞穴、8 格内有干燥地面，再进入主世界高位普通门。应落在附近安全地表；将周围地表全部改为危险地面后，应保留原位置，不挖开地形。
