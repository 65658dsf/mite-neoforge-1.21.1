# 主世界试炼地牢材料奖励调整

开发者：NingMeng123。按用户指定的现代平衡调整执行。

2026-10-16：构建、1455 项 JUnit 和 1598 项服务端 GameTest 全部通过；客户端待用户手动验收。

仅在主世界生成原版试炼密室的宝库、箱子、木桶或饰纹陶罐战利品时，绿宝石块、绿宝石、钻石的出现概率改为当前的 **1/6**。普通与不祥宝库都生效。普通与不祥刷怪笼的原版奖励不含这三种材料，无需另改。

先完成原有战利品生成，再针对三种材料分别作一次 `nextInt(6) == 0` 保留判定。同一次最终奖励中，同种材料的全部物品栈共用一次判定，避免多栈让“至少出现一次”的概率偏离原来的 1/6。保留时数量、名称等组件不变；未保留的材料不补抽其他奖励。因此这三种材料的整次出现概率和平均产量均为原来的 1/6，其他奖励的生成权重及概率不变。

如果本次材料削减导致宝库最终奖励为空，仍正常消耗钥匙并记录该玩家已领取，避免通过免费重抽绕过概率；空奖励按原版状态机结束，不生成空物品实体。原本就是空的战利品表保留原版行为，地底世界也不套用这项空奖结算。

范围同时检查主世界维度与 `minecraft:chests/trial_chambers/`、`minecraft:pots/trial_chambers/` 表名前缀。地底世界的宝库、箱子、陶罐，以及其他结构和其他命名空间的战利品不受影响。只影响之后生成的奖励，不清理玩家已获得或容器中已生成的材料。

## 手动检查

重启客户端加载代码后，可以多次开启主世界普通、不祥宝库并搜查试炼密室箱子和陶罐，对比此前材料出现频率。少量尝试不能判断概率；保留下来的单次材料数量应与此前一致，其他奖励仍正常。

也可以在主世界重复执行 `/loot give @s loot minecraft:chests/trial_chambers/reward` 与 `/loot give @s loot minecraft:chests/trial_chambers/reward_ominous`，并对比地底世界的对应宝库。地底世界沿用现有奖励规则。

若一次主世界宝库开启没有吐出奖励，钥匙仍应正常消耗、同一玩家不能再领取；宝库应正常恢复状态供其他未领取玩家使用。

自动验证应覆盖六种判定结果、三种材料独立判定、同种多栈、物品组件、维度和表名边界、真实宝库与陶罐战利品入口，以及原有钻石装备禁用规则。
