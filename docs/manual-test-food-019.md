## 准备

自行重启测试客户端加载本轮 Java 代码，F3+T 只重载资源，不能更新逻辑。使用允许命令的测试世界，准备箱子存放测试物资；每组单独领取，避免把所有物资一次塞满背包。

开发测试客户端可用以下四个物资函数，它们仅给予物品，不清空背包、不改等级/营养、不修改世界：

```mcfunction
/function mite:test_food_019_baking
/function mite:test_food_019_bowls
/function mite:test_food_019_vessels
/function mite:test_food_019_garden
```

四组分别包含 18/14/22/16 种物资。它们是开发专用资源，不打包到安装版 JAR；安装版或提示未知函数时，使用下文 `/give`，或从创造物品栏的 MITE 食物分类取物。

先执行：

```mcfunction
/gamemode survival
/difficulty normal
/experience set @s 35 levels
/effect clear @s
/mite food set reserves @s 0 0
/mite food set saturation @s 0
/mite food set nutrients @s 0 0 0
/mite food set resistance @s 0
/mite food status @s
```

35 级 S/N 上限均为 20，便于测试高数值食物不被低等级截断。每种食物前重复上述食物状态命令，避免上一种营养和糖抵抗干扰。食用过程中微量营养与糖抵抗每 tick 自然减 1，因此状态命令观察值可以略低于下面的摄入增量；摄入前后间隔和环境代谢也要记录。

长时间等待可用 `/tick rate 200`，结束恢复 `/tick rate 20`。动作、制造耗时与拾取经验测试用正常 20 TPS。涉及随机掉落/长成时应测试多次，单次没有触发不是确定性失败。

这些普通食品最大堆叠 16，吃一份用 32 tick（20 TPS 下约 1.6 秒）。洋葱对耕地右键优先种植，想吃时对空中右键。面粉和粪肥不能吃：

```mcfunction
/give @s mite:flour 17
/give @s mite:manure 17
```

各分成 16＋1；空中右键不开始食用、不补营养。蓝莓是食品，不能像甜浆果那样种植，种植须灌木物品。

回归小麦种子：S4/N3、饱和度 0、P/F/V 为 0 时吃一份 `minecraft:wheat_seeds`，S/N 不变，原版饱和度变 1，P/F/V 不增加；吃其他食物不会无故抹掉这 1 点缓冲。

运行 `_vessels`，或用以下 ID 逐种测试。每行 `/give @s <ID>`，三列分别是空桶、水桶和奶桶：

| 材质 | 空桶 | 水桶 | 奶桶 |
| --- | --- | --- | --- |

| 铜 | `mite:copper_bucket` | `mite:copper_water_bucket` | `mite:copper_milk_bucket` |

1. 各新增空桶取水源，变同材质水桶；向普通方块倒水，出现水源并退同材质空桶。再对可容水方块试一次，检查不被换成铁桶。水桶沿用现代规则，本轮不要求复现旧水源机制。

5. 对一只新成年牛先用空碗：连续最多 4 碗后无奶；另一只新成年牛用空桶：一次整桶后无奶，立即第二次失败且不耗空桶。幼牛不能挤奶。
6. 让牛附近有草/蒲公英、水和露天空间，避免过密，使用加速时间观察渐进恢复；并非等待 5 秒就有完整一桶。达到储奶 25 才能取一碗，100 才能取一桶。另检查成年有食物的牛经过较长时间能掉粪肥。

## F：洋葱、蓝莓、水果、虫子与钓鱼

运行 `_garden`，或使用：

```mcfunction
/give @s mite:onion 8
/give @s mite:blueberry_bush 4
/give @s mite:blueberries 4
/give @s mite:manure 8
/give @s mite:raw_worm 8
/give @s minecraft:bone_meal 8
/give @s minecraft:shears
/give @s minecraft:fishing_rod
/give @s mite:copper_hoe
```

洋葱：湿耕地种植后为 0 阶段，立即破坏回收 1；中间阶段不掉食物；健康成熟产 2 或 3（3 的概率25%）。拆掉其下耕地时，0 阶段仍回收 1，成熟株自掉落不产食物；成熟健康株真正旱死则产 2/3，爆炸不产。晴天光照15、湿地、合适温度时缓慢成长，连片比孤株快；露天夜间与雨天不足15时不长，光照采用实际天空扣减。粪肥右键耕地，F3 指向应看到 `mite_fertilized: true`，成长有 1.5 倍肥效，存档重进仍在；旁观或无放置权限时不施肥、不耗料。健康洋葱骨粉不直接长大；病株骨粉只清病，死株不复活。日常病害/干旱为随机事件，观察并记录环境，不把单次未触发写成失败。

想独立验证病/死材质与骨粉操作，可在测试耕地上记录一个作物坐标，使用 `/setblock <x> <y> <z> mite:onion_crop[age=3,blighted=true,dead=false]`。骨粉应清 `blighted` 而保留年龄3；将同格设为 `dead=true` 后骨粉不能救活，破坏不产洋葱。命令造病株只验证后续行为，不等于随机患病过程已经通过。

蓝莓：在森林/桦木森林/老桦木森林/繁花森林的露天地面用灌木物品生存放置，从0开始；耕地或不适合地区不可维持。骨粉加1–2级，成熟3级右键得1蓝莓并重置0；剪刀破坏回收灌木，徒手不回收，成熟破坏仍有蓝莓。接触无刺伤和移动拖慢。探索本轮新生成的森林区块，检查天然成熟灌木；已经生成的旧区块不补种。蓝莓食物本身不能种灌木。

水果：破坏自然橡树/丛林树叶多次，橡树通常对应苹果、丛林里的橡树对应橘子、丛林树叶对应香蕉；也可加速等待自然风落。掉落较稀有，放置叶片不能用来刷水果/木棍，剪刀与精准采集仍能取叶片。新版其它树种本轮保留现代规则。

虫子：非冰冻环境破坏草块，晴天无时运约1/16，雨中无时运约1/4；触发时只掉虫子并替代泥土，精准采集草块不额外产虫子。玩家放置草块可以测试这一草块机制，玩家放置树叶保护是另一条独立规则。

钓鱼：将生虫子放快捷栏，对比无饵等待速度；有饵等待更快，但咬钩后的正常反应窗口仍在。成功钓获只消耗快捷栏第一只生虫子，等待或挂实体不耗；把全部虫子移到普通背包，不再提供快捷栏饵料效果。非冻结海洋深水处可钓大鱼，钩下33×33×4范围不能含泥土/草块/砂砾；不要求每次捕获都是大鱼，现代宝物、垃圾、河豚等保留。

自然洋葱来源另测玩家击杀僵尸村民，基础约1/60概率；这不等于整个旧亡村庄/结构战利品已复刻。领取物资或命令召出食材也不能作为自然来源已经通过的记录。

## G：箱内虫子堆肥与库存守恒

普通箱子放生虫子8只、小麦8份或面粉8份，另留空格。生虫子不消耗，可堆肥食物随机减少，累计后出现 `mite:manure`；面粉每份价值0.8、小麦0.5，累计每1产1粪肥，余数继续保存。可加速等待，不是右键箱子立即合成。

换汤食物再测试，消耗后空碗留在箱子；奶碗、奶桶、鸡蛋、种子、金苹果、附魔金苹果、金胡萝卜和生虫子本身都不作为饲料。加入纸、树叶或干草块验证非食品饲料；西瓜返一份西瓜种子，南瓜返一份南瓜种子，南瓜灯还应返一根火把。把箱子装满、使全部返还物/粪肥没有位置，检查不白吃食物、不丢容器；腾出空间后继续。保存重进，虫子、食物及累计进度保留。双箱两半独立处理，普通箱、陷阱箱和金属箱均通过原生随机刻工作。

## H：自动合成器、保存与联机

自动合成器放3小麦横排并触发一次红石，需经过加工时间才出1面粉，不能瞬间反复复制。再试水桶＋面粉或奶碗奶酪，检查成品和全部容器余物。回装铁奶桶需要旁边有铁级工作台；缺少该台不能出物。处理期间改变配方/禁用格，中断不能白出成品；卸载/重启后材料仍在，但待加工进度重新开始。

保存退出重进，检查容器材质和数量、洋葱年龄/病死状态、耕地肥沃标记、牛储奶/储备、箱内累计堆肥状态。两位玩家同测不同金属桶、同牛和同工作台，观察没有重复挤奶、复制容器或营养串号；独立服务器重启也要核对保存。

JEI、Jade、AppleSkin、Sodium/Iris 等用户测试客户端模组共存时，检查配方页面、真实制造进度、营养面板、物品提示及新植物渲染；JEI 展示配方不能替代实际工作台/计时校验。反馈可按“分组编号＋物品ID＋前置＋操作＋预期/实际＋截图”发送，测试通过后再由主流程按用户约定提交 GitHub。
