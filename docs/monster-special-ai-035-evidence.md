# 035：苦力怕蓄爆与着火僵尸趋树的来源证据

开发者：NingMeng123。原作：Avernite。范围是本地 R196 发布包中实际启用的 `qs`、`EntityAIMoveToTree`，以及它们直接消费的仙人掌和环境扩火路径。此文件不表示整个怪物 AI 已全部完成，也不表示任何测试已经通过。

## 实际调用链

普通苦力怕 `tf` 构造器将 `qs` 注册到动作优先级 2，烈焰苦力怕继承它。`tw` 普通僵尸构造器将 `EntityAIMoveToTree(this, 1)` 注册到优先级 3，怨魂通过 `tw` 继承。僵尸的树目标并不是未注册工具类。

### 苦力怕

| 条件 | R196 实际行为 | 依据 |
| --- | --- | --- |
| 起始检查 | 已在蓄爆或记得附近显著仙人掌时可直接启动 | `qs.a()` |
| 目标距离 | 导航已结束为距离平方 `<16`；仍在导航且受伤为 `<9`；仍在导航且满血为 `<4.5` | `qs.a()`；`javap -c -p qs` 偏移 53–90 |
| 烈焰类型 | 上述起始距离平方乘 2 | `qs.a()`；字节码偏移 91–104 |
| 目标缓存 | 启动时停止导航并缓存当时的目标；停止时清空；运行中不自动采纳新目标 | `qs.c/d()` |
| 常规续爆 | 缓存目标非空后，检查世界全部生命大于 0 的玩家，而非只检查缓存目标 | `qs.e()` |
| 续爆半径 | 普通为 `16/clamp(health/maxHealth,.4,1)`，烈焰为 `36/clamp(...)`；距离平方允许恰好相等 | `qs.e()` |
| 续爆视线 | 苦力怕膝部（高度四分之一）或眼睛到玩家身体四分之一/四分之三位置任一路径可见；每个来源位置还限制到玩家中心的距离平方 | `qs.e()` → `of.canEntityBeSeenFrom` → 来源 vision ray |
| 无玩家或被挡 | 将蓄爆方向设为 -1；不会因为另一个非玩家目标存在就继续蓄爆 | `qs.e()` |
| 创造模式 | 续爆遍历仅检查玩家生命和视线，没有创造模式排除条件 | `qs.e()` |

`qs.a()` 的 CFR 文本有局部变量看起来未赋值的反编译歧义，实际字节码清楚地把三个距离常量之一存入同一个 float 局部变量。实现采用字节码确认的分支，没有沿用有歧义的变量排版。

现代实现为 `SourceCreeperSwellGoal`。视线复用已迁移的 `SourceAnimalDespawn032.visionRay`，保留玻璃等透明方块规则，使用 1.21.1 方块形状、世界高度和已加载区块保护。原有引爆物品、同步蓄爆方向、声音、爆炸和现代实体生命周期继续由苦力怕承载。

### 显著仙人掌

`ang.a(world,x,y,z,entity)` 只有实际伤害成功且造成死亡时，才为仙人掌柱下的普通沙地增加杀死实体次数，范围 0–7。`tf.onEntityDamaged` 在仙人掌伤害成功、该柱次数大于 1 且 `nextInt(2)==0` 时设置 120 刻记忆；计数发生在这次死亡登记之前。`tf.l_()` 每刻递减记忆；记忆大于 0 并在水平、垂直各 1 格内有仙人掌时，`qs.e()` 可无视目标和玩家而继续蓄爆。

原 `ang.updateTick` 顶端仙人掌的 50% 更新用来尝试减掉一个杀敌计数；底部仙人掌移除会清除沙地记录。现代实现通过 `CactusTrapMixin` 包装真实 `Entity.hurt` 返回结果，`CactusTrapRemovalMixin` 覆盖实际方块移除路径，`CreeperCactusMixin` 递减临时记忆。

旧版利用沙地元数据低三位保存计数。现代改用每个维度自己的 `SavedData`、版本 1、沙地坐标及计数，避免污染现代沙地变种或方块状态。底部仙人掌和支持沙地移除时清除；读取支持负 Y。临时 120 刻记忆不保存。只把该计数依赖接入现有现代仙人掌随机刻，不声称迁移完整旧仙人掌生长率、沙漠限制、整套农业或物品尖刺碰撞规则；现代沙地移动不继承另一个坐标的陷阱记录。

### 僵尸趋树与真正扩火

`EntityAIMoveToTree.a()` 先抽 `nextInt(40)==0`，然后要求实体正在着火。搜索距离 16、垂直半径 4。其实际调用的 `abw.getNearestBlockCandidates(float,...)` 先扫描原点列，随后按 XZ 方形螺旋（东、南、西、北）扫描；每列 Y 从低到高，遇到第 8 个旧原木立即返回，**没有按几何距离排序**。玩家脚部方块 Y 必须严格大于原木 Y+2、严格小于 Y+9，水平方块距离平方不超过 32；排除幽灵/已死亡等不可用玩家。到原木的路径末点距离平方必须 `<2`。成功找到路径后，设置 `increased_chance_of_spreading_fire_countdown=100`。

这个字段并非仅展示状态：`nn.l_()` 的环境扩火分支实际读取，`og.l_()` 先调用 `super.l_()`，随后递减计时，所以剩余 1 刻仍使用强化概率。普通着火实体每刻基础扩火概率为 `.00125`，强化时为 `.01`；火元素为 `.05`，熔岩土元素和烈焰人为 `.04`，不依赖普通着火标记。成功抽签后，检查脚下列从脚部至 `(int)height`：空位有 1/10 尝试依据周围可燃物放火；否则尝试熔化支撑方块。已有方块按来源火焰吞烧规则（分母 100、火龄 1）尝试燃烧，失败时检查冰雪熔化。来源 `aov` 冰变水，`aqm` 整雪块变七层雪，`arf` 雪层逐层减少。

支撑块来源不是把脚部中心下移 0.1 格：`nn.getBlockRestingOn(.1)` 实际委托 `getBlockRestingOn3()`，要求落地且没有骑乘，扫描完整脚底 AABB 涉及的方块列。只有碰撞顶面恰好等于脚底 Y 的方块可用，多个支撑按方块中心到实体 XZ 的距离取最近一个。现代实现使用实体碰撞上下文及方块的实际碰撞形状，检测脚底水平接触范围，保留相同落地、骑乘、严格高度和最近支撑语义，支持跨格边缘及负层，不会因 `.1` 参数把悬空间隙当作接触。

现代 `ZombieMoveToTreeGoal` 采用 `SourceMovement032Goal` 的已加载区块和现代导航，支持新版世界负层；候选使用 `logs_that_burn` 适配新版可燃树种，未把下界不可燃菌柄当作旧树。源子类明确覆盖路径持续条件，仅依据导航结束判断，不额外套入父类卡住超时。

`SourceMonsterFire` 持有不保存的 100 刻临时强化并直接消费到真实放火/吞烧/冰雪变化；没有新增无效的持久字段。保留现代 `doFireTick`、NeoForge `canEntityGrief`、方块的 `onCaughtFire`、火焰/灵魂火与可燃属性接口。这些世界保护及现代方块适配与旧版无保护的直接改块有所不同，不能称作逐随机数、逐体素重演旧世界。

## 验证范围

`CreeperTreeGameTests` 新增 15 项实际实体与世界交互案例，覆盖起始与续爆边界、导航/健康分支、目标缓存、非目标玩家、透明/实体墙、实际仙人掌击杀/伤害、计数保存和清除、趋树条件及真实路径、原木首 8 个候选的螺旋和逐列 Y 顺序、强化最后一刻的真实放火、保护开关和支撑冰熔化。支撑案例包含未落地、骑乘、有高度间隙、跨格边缘和最近支撑选择。它们只描述待执行案例；实际结果以主批构建和完整 GameTest 日志为准。测试不打开或操作用户游戏窗口。
