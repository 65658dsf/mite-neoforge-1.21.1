# 2026-10-24 装备韧性与武器平衡

开发者：NingMeng123。

铜银伤害及Simply Swords原生材质基数已由[最新铜银生存平衡](copper-survival-balance-2026-10-24.md)替代。护甲与韧性的当前数值见[护甲防御与盔甲韧性的现代适配](modern-armor-defense.md)。下文保留此前阶段记录，攻速和负重规则继续适用。

本轮按用户要求为防具补齐盔甲韧性，降低高级防具的基础护甲上限，并重新分配武器的单次伤害、攻击速度和持有负重。所有数值均为无附魔、无成长、无锻造的基础值；实际战斗仍受玩家等级、目标种类、攻击蓄力和已有词条影响。

## 防具

韧性按穿戴部位实际生效，减少大伤害对护甲减伤的穿透。它是属性点数，并非固定百分比减伤。表中韧性为每件的数值，完整四件可相加。

| 材质 | 头／胸／腿／靴护甲 | 每件韧性 | 全套韧性 |
| --- | --- | --- | --- |
| 皮革 | 1／3／2／1 | 0.25 | 1 |
| 锈铁板甲 | 1／4／3／1 | 0.375 | 1.5 |
| 金板甲 | 2／4／3／1 | 0.5 | 2 |
| 铜／银板甲 | 2／5／3／2 | 0.75 | 3 |
| 铁板甲 | 3／6／6／3 | 1.25 | 5 |
| 远古金属板甲 | 2／6／5／3 | 1.25 | 5 |
| 秘银板甲 | 3／7／5／3 | 2 | 8 |
| 艾德曼板甲 | 3／8／6／3 | 2.5 | 10 |
| 振金板甲 | 4／8／6／4 | 3 | 12 |

2026-10-28 铁制防具每件增加1护甲、0.25韧性，铁板甲全套为18护甲、5韧性；铁链甲头／胸／腿／靴为3／5／5／2护甲、每件1韧性，全套15护甲、4韧性。其他链甲每件韧性为同材质板甲的75%，护甲也较低。锈铁及其他材质沿用原值。海龟壳为2护甲、0.5韧性，Modern ITE的铁桶头盔按铁头盔处理。保留物品的钻石／下界合金防具分别采用18／20全套护甲、每件2／2.5韧性的兼容值，原有禁用或移除规则不因此改变。

马铠及其他动物护甲在BODY槽提供正韧性。铁马铠为6护甲、1.25韧性。马铠保留固定减伤方式，仅追加同护甲值下有韧性相对零韧性的减伤增益，避免切换伤害公式反而大幅削弱马铠。熔岩等原有绕过护甲的伤害仍遵守原来源规则。

2026-10-28 起，防具护甲与韧性不再随耐久降低，最后一点耐久也提供完整穿戴防御；耐久消耗与维修规则继续适用。旧存档中明确保存的原生基础护甲／韧性会在读取属性时更新；独立自定义属性、附魔、名称、品质、成长及锻造数据保留。韧性属于穿戴防具，手持武器不会额外提供防具韧性。

## 本体及ITE武器

按原始材质与家族的未削弱总基础伤害计算：普通金属武器乘0.8，战斧乘0.9，镰刀乘0.7，普通采集工具乘0.65，剪刀乘0.6。铜材质在此基础上再应用此前要求的0.6系数，只结算一次。木、燧石、黑曜石等开局装备沿用原值。

| 家族 | 每秒攻击次数 | 主手玩家移速代价 |
| --- | --- | --- |
| 剑 | 1.5 | 0 |
| 匕首／短刀 | 2 | 0 |
| 战斧 | 0.85 | -15% |
| 战锤 | 0.75 | -18% |
| 金属棍 | 1.1 | -8% |
| 非开局短棒 | 1.2 | -4% |
| 镰刀 | 1 | -8% |
| 斧／短斧 | 0.95／1.25 | 0 |
| 镐／铲／鹤嘴锄 | 1.05 | 0 |
| 锄／剪刀 | 1.2／1.3 | 0 |

例如铁剑基础伤害9→7.2，铁战斧9→8.1，振金剑14→11.2；铜剑在前次铜削弱后的4.8基础上降至3.84。战锤保留对骷髅的专长，并承担慢攻速和负重。工具的挖掘速度、采集等级及耐久继续按各自材质规则运行。

三叉戟普通近战基础总伤害乘0.72、攻速1、主手移速-5%；现代重锤普通基础总伤害乘0.8、攻速0.65、主手移速-15%。其原有投掷及下落攻击机制继续运行。

Simply Swords的15类武器另按家族分配预算：巨剑／巨斧／巨锤保留较高单次伤害，攻速为0.95／0.8／0.7，负重为20%／22%／25%；长矛和长柄刀以更低伤害换取距离。完整表与兼容细节见[简易刀剑平衡表](equipment-balance-simplyswords-2026-10-24.md)。

## 存档与兼容

旧武器保存的基础攻击／攻速不能绕过新平衡，额外词条保留，并在归一化后的基础数值上继续结算。旧组件中同一基础属性ID在多个槽位重复出现时，先清除全部已识别基础条目，再建立正确槽位的一条属性；原NBT不写回。重武器负重仅作用于玩家主手，使用同一个临时属性标识；切换、死亡、重生、重登、读档及跨维度不会残留或叠加负重。副手和背包中的武器不施加负重。

本轮继续使用此前用户提供的两份默认配置；数值平衡直接归入装备基础属性，不覆盖实际游戏目录的配置文件。

## 验证
