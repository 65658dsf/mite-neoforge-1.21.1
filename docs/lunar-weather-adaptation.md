# 血月白昼血雨、夜间干雷与血红天空

开发署名：NingMeng123。原作：Avernite。

本次按用户追加要求，主世界血月日 **白天下雨并打雷，晚上停雨、保留雷声和真实闪电**。这是现代玩法扩展：R196 `abw.java:5331–5332` 的实际强制事件仍是当天 `[0, 13000)`；保留原始 `LunarWeatherRules.schedule`、来源证据及其数值测试，不把新行为记成旧版原值。

## 天气与保存

- 第 32、64、96 天等血月日期，白天设置降雨和雷暴目标，夜间关闭降雨目标但维持雷暴目标；严格共用 `LunarCalendar.State.night`：`[13000, 23000]` 为夜间，`[0, 13000)` 和 `[23001, 24000)` 为白天。第 128 天仍由蓝月替代，不触发此覆盖。
- `doWeatherCycle=false` 也不能清除血月雷暴；血月期间 `/weather clear` 会在下一个正常世界天气 tick 恢复雷暴目标。
- 原版每 tick 0.01 的雨量／雷强插值保留，进入、退出约需 100 tick；客户端一进入血月夜间即停止绘制雨雪、生成落地雨滴和播放雨声，不再等待残留雨量淡出。雷声和真实闪电继续有效。使用维度定向同步，不每 tick 重发固定天气包。
- 进入血月前保存雨、雷、晴天计时和标志，使用版本 1 的 `mite_lunar_weather` SavedData。退出血月时，天气循环开启则恢复原 R196 排程；关闭则恢复血月前冻结的天气。保存重进后仍能释放覆盖，不会把雷暴永久留到普通日。
- `/time` 向前或向后跳出血月均在下一次天气更新释放覆盖。跳出后、更新前又执行的 `/weather` 命令优先于旧的冻结快照。
- 白天保留沙漠血月降水、寒冷地区降雪及屋顶遮挡；夜间没有降雨、降雪或炼药锅接雨。干雷仍使用闪电候选、合法落点和避雷针，血月禁睡保留。其它维度不套用此天气覆盖。

夜间仅解除有效雷暴强度对雨量的乘数依赖，继续使用原生雷强插值；世界的实际雨量、受雨判断及接雨逻辑仍为干燥状态。自然闪电仅在 `tickChunk` 的两个雨条件处允许夜间干雷，原生落点、避雷针和寒冷生物群系限制保留。玩家登录、重生及跨维度的初始天气快照另同步雨强与雷强，避免原版在无雨时省略雷暴同步。

SavedData 字段和版本 1 格式保持兼容，退出覆盖时同时识别白天湿雷暴和夜间干雷暴的短计时状态，恢复原天气。

## 白昼天空

主世界血月白天，天空、云和空气雾色按客户端实际雨量渐变为暗红色。新颜色公式与来源夜间光照分开：雨强为 `r`，原色为 `(R,G,B)`，天空和云的目标为 `(max(R,0.16), 0.12G, 0.12B)`，按 `r` 线性混合；空气雾不加最低红亮度，避免照亮洞穴或失明造成的黑暗。

原有血月夜间 lightmap、月盘颜色、光晕和雨量遮蔽公式保留；此白昼扩展不替换夜间色偏。入夜雨量退至零后，月盘和光晕恢复晴天的可见度，保留血月颜色。普通月相、蓝月、收获月、幻月和其它维度不增加这种白昼天空颜色。水下、熔岩和细雪雾色保留原生规则。

使用原生 `ClientLevel.getSkyColor/getCloudColor` 返回值及 NeoForge 空气雾事件接入。完全替换原生天空的光影需要实际画面检查；无界面审计仅验证接线和独立 RGB 数值，不等于已经验证光影画面。

## 血雨雨滴与夜间停雨

2026-10-25 修正：此前只染红天空、云和雾，雨幕及落地雨滴仍使用原生白色顶点；夜间只关闭服务端降雨目标，客户端还可能显示未淡出的雨量。现在血月白天将雨幕的四个顶点和落地雨滴统一乘以 `(1, 0.08, 0.08)`，形成红色血雨，保留原生透明度、光照、密度和遮挡。寒冷地区的白昼降雪保持原色，普通雨天、蓝月和其它维度不染色。

血月夜间在 `LevelRenderer.renderSnowAndRain/tickRain` 入口停止降水绘制和雨声处理，包含直接跳时和重进世界时的残留雨量。雷强、闪电实体、雷声及服务端天气保存格式继续使用原有路径。

## 手动检查

在独立测试存档、主世界无遮蔽位置执行：

```mcfunction
/gamerule doDaylightCycle false
/gamerule doWeatherCycle false
/time set 750000
```

等待约 5 秒，确认白昼雷暴、天空和云偏血红，雨幕及地面溅起的雨滴也呈红色；执行 `/weather clear` 后应自行恢复雷暴。接着设置 `/time set 762000`，确认夜间立即停止雨幕和新的雨滴／雨声，保留雷声、真实闪电及原有夜间色偏。已生成的短命雨滴和已开始播放的一次雨声音效会自然结束。闪电是随机事件，不要求立刻落雷。

边界检查：`/time set 756999` 仍为白昼血雨；`/time set 757000` 立即停止绘制降水，服务端雨量开始淡出；`/time set 767000` 仍是夜间干雷；`/time set 767001` 进入黎明，开始恢复血雨；`/time set 767999` 仍处于血月白昼降雨段。

设置 `/time set 768000`，等待雨量过渡，确认恢复血月前冻结的天气；设置 `/time set 3066000` 检查第 128 天蓝月不会被认作血月。重复在血月保存退出并重进，再跳出血月检查恢复。测试结束恢复原有时间及游戏规则。

自动回归需覆盖昼夜天气边界、三次血月及蓝月排除、干雷与真实闪电、冻结天气、前后跳时、SavedData 原生编解码、稳定天气不重复广播、白昼 RGB、其它事件／维度／夜间隔离及实际客户端 Mixin 字节码。测试执行结果由主任务统一记录。
