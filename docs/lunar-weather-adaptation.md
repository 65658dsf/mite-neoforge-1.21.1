# 血月全天雷暴与白昼血红天空

开发署名：NingMeng123。原作：Avernite。

本次按用户追加要求，将主世界血月日的强制雷暴扩展为 **当天全部 24,000 tick**。这是现代玩法扩展：R196 `abw.java:5331–5332` 的实际强制事件仍是当天 `[0, 13000)`；保留原始 `LunarWeatherRules.schedule`、来源证据及其数值测试，不把新行为记成旧版原值。

## 天气与保存

- 第 32、64、96 天等血月日期，从当天 0 到 23999 始终设置降雨和雷暴目标；第 128 天仍由蓝月替代，不触发此覆盖。
- `doWeatherCycle=false` 也不能清除血月雷暴；血月期间 `/weather clear` 会在下一个正常世界天气 tick 恢复雷暴目标。
- 原版每 tick 0.01 的雨量／雷强插值保留，进入、退出约需 100 tick；使用原版仅在强度变化时发送的维度定向同步，不每 tick 重发固定天气包。
- 进入血月前保存雨、雷、晴天计时和标志，使用版本 1 的 `mite_lunar_weather` SavedData。退出血月时，天气循环开启则恢复原 R196 排程；关闭则恢复血月前冻结的天气。保存重进后仍能释放覆盖，不会把雷暴永久留到普通日。
- `/time` 向前或向后跳出血月均在下一次天气更新释放覆盖。跳出后、更新前又执行的 `/weather` 命令优先于旧的冻结快照。
- 沙漠血月降水、寒冷地区降雪、屋顶遮挡、闪电候选、避雷针和血月禁睡沿用已有实现。其它维度不套用此天气覆盖。

## 白昼天空

主世界血月白天，天空、云和空气雾色按客户端实际雨量渐变为暗红色。新颜色公式与来源夜间光照分开：雨强为 `r`，原色为 `(R,G,B)`，天空和云的目标为 `(max(R,0.16), 0.12G, 0.12B)`，按 `r` 线性混合；空气雾不加最低红亮度，避免照亮洞穴或失明造成的黑暗。

原有血月夜间 lightmap、月盘颜色、光晕和雨量遮蔽公式保留；此白昼扩展不替换夜间色偏。全天雷暴完全形成后，月盘和光晕仍会按原雨天透明度被遮蔽。普通月相、蓝月、收获月、幻月和其它维度不增加这种白昼天空颜色。水下、熔岩和细雪雾色保留原生规则。

使用原生 `ClientLevel.getSkyColor/getCloudColor` 返回值及 NeoForge 空气雾事件接入。完全替换原生天空的光影需要实际画面检查；无界面审计仅验证接线和独立 RGB 数值，不等于已经验证光影画面。

## 手动检查

在独立测试存档、主世界无遮蔽位置执行：

```mcfunction
/gamerule doDaylightCycle false
/gamerule doWeatherCycle false
/time set 750000
```

等待约 5 秒，确认白昼雷暴、天空和云偏血红；执行 `/weather clear` 后应自行恢复雷暴。接着设置 `/time set 762000`，确认血月夜间仍有雷暴，原有夜间色偏保持；`/time set 767999` 是血月最后一刻，也应雷暴。

设置 `/time set 768000`，等待雨量过渡，确认恢复血月前冻结的天气；设置 `/time set 3066000` 检查第 128 天蓝月不会被认作血月。重复在血月保存退出并重进，再跳出血月检查恢复。测试结束恢复原有时间及游戏规则。

自动回归覆盖全天边界、三次血月及蓝月排除、冻结天气、前后跳时、SavedData 原生编解码、稳定天气不重复广播、白昼 RGB、其它事件／维度／夜间隔离及实际客户端 Mixin 字节码。测试执行结果由主任务统一记录。
