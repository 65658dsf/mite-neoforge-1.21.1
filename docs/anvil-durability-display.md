# 铁砧耐久度显示

开发署名：NingMeng123。日期：2026-10-17。

七种材质铁砧显示“耐久：剩余 / 上限”：铜、银、金、原版铁、远古金属、秘银和艾德曼。包括原版铁砧的完整/开裂/损坏三个 ID，以及新增材质的三个磨损外观。

## 显示位置

- 背包、快捷栏和 JEI 等原生物品提示入口：悬停铁砧物品时显示精确剩余耐久。
- 铁砧界面：上方显示耐久数字和进度条，正常使用时为绿，剩余不超过一半为黄，不超过五分之一为红。维修完成后使用服务端最新磨损数据。
- 安装 Jade 时：瞄准已放置铁砧显示服务端数值。没有匹配的服务端数据、目标已替换或损坏消失时不显示猜测值；Jade 的“铁砧耐久度”选项可控制该提示。

物品提示和铁砧界面不要求安装 Jade。只有 Jade 集成类依赖其可选 API。

| 材质 | 完整耐久上限 |
| --- | ---: |
| 铜、银、金 | 198400 |
| 铁 | 396800 |
| 远古金属 | 793600 |
| 秘银 | 3174400 |
| 艾德曼 | 12697600 |

## 数据来源

物品优先读取已有 `mite:anvil_damage` 数据组件。没有精确组件时，按原版铁砧损坏 ID 或已有方块状态对应的最低磨损显示，与该物品正常放置后的初始耐久一致。显示不会向物品写入组件，也不会将铁砧变成普通装备耐久物品。

界面通过原生菜单数据同步读取真实方块实体。原生容器数据包每项传输 16 位，因此剩余和上限各拆成两个 16 位值，避免艾德曼等高耐久数字被截断。菜单每次读取当前位置当前实体，支持原版铁砧换阶段时实体替换；目标消失后隐藏。数值仅由服务端发往客户端，不接受客户端申报磨损。

Jade 数据绑定维度、位置、方块身份及状态，直接读取当前已加载的真实实体，不额外加载区块，不改变磨损、物品或世界状态。原有维修耗损、创造免耗损、搬运和保存规则继续使用。

## 复测步骤

1. 悬停七种材质的新铁砧，核对上表上限。原版开裂/损坏铁砧应显示对应阶段的剩余值。
2. 使用有精确磨损的铁砧，分别查看物品提示、打开后的界面和 Jade，三处数值应一致。
3. 生存模式进行一次金属粒维修，界面数字和进度条应减少对应磨损；仅预览结果不应减少。
4. 保存重进、拆下再放置，数值应保留。原版铁砧跨越磨损阶段后，界面仍读取精确数值。
5. 使用高耐久艾德曼砧，确认百万级数字完整，未截成负数或几万。铁砧完全损坏消失后不再保留耐久条。
6. 分别在有 Jade 和无 Jade 环境检查物品提示与铁砧界面；有 Jade 时快速切换不同铁砧，提示不能串到另一位置或阶段。

需要精确样本时，可在允许命令的测试存档执行 `/give @s mite:copper_anvil[mite:anvil_damage=12345]`，应显示 `186055 / 198400`，放置后数值相同。
