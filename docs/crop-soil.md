# R196 耕地、水分与施肥

开发者：NingMeng123。

## 原始证据

基准为本地 R196 发布包反编译后的 `aof`（耕地），以及 `ItemManure`、`ItemBowl`、`yp`（药水瓶）、`wr`（桶）。普通作物和瓜茎分别对应 `anr`、`aqq`。数值按实际调用链迁移，继续使用现代原版耕地 ID、高度范围及区块方块状态保存。

## 已迁移规则

| 条件 | 行为 |
|---|---|
| 距离水的 X/Z 偏移均在 ±4，Y 为土壤或土壤上方一格 | 湿度立即补至 7 |
| 距离冰、雪层、雪块的 X/Z 偏移均在 ±1，Y 为土壤或上方一格 | 同样视为水源，补至 7 |
| 没有灌溉源、上方正在下雨 | 每次耕地随机刻仅增加 1 湿度，最高 7 |
| 没有灌溉源且没有雨 | 每随机刻以 `max(0, 基础温度 - 0.15 - (降雨量 > 0.85 ? 0.5 : 0))` 概率蒸发 1 湿度 |
| 已干燥、上方为空气且 3×3 上方没有作物或瓜茎 | 赢得干燥抽取后恢复泥土 |
| 使用粪肥 | 保存肥沃标记；再次施肥不消耗物品 |
| 正常作物成功长大一阶段 | 每次抽取 `nextInt(256)`，抽中 0 时移除已有肥料；未施肥仍消费该抽取 |
| 水碗或普通水瓶浇水 | 单格补至 7，分别返回空碗或玻璃瓶 |
| 水桶浇水 | 同高度 3×3 耕地补至 7，返回原材质的空桶 |
| 完全湿润且无可浇格 | 失败，不消耗容器，也不回落到新版水桶放水逻辑 |
| 蒸发维度浇水 | 液体蒸发并返回空容器，不提高湿度 |
| 骨粉点击耕地上表面 | 不消耗、不治疗上方作物，也不会将骨粉变成持久肥料；须直接瞄准活病株治疗 |

`mite_fertilized` 沿用原有方块属性，不引入第二份坐标存档；旧存档已施肥格的状态保留。土壤湿度变化不清除肥沃标记。普通作物的 1.5 倍肥料效果由完整生长公式计算；未接管的第三方作物仍保留对原版静态生长速度的兼容注入。

`aof.fertilize` 虽然保留骨粉转发到上方作物/瓜茎的分支，但实际骨粉物品入口 `xl.tryFertilize` 只接受草方块和 `anr` 作物，不进入耕地分支。复刻以默认启用的调用链为准，不将这条未启用分支变成新功能。

普通死作物在旧版使用独立方块 ID，因此不会作为活作物的同种邻株提供分组加成；迁移后的 `dead` 状态同样不计入这项邻接判断。活着的病株仍然计入。瓜茎原本用同 ID 的死亡位保存状态，不适用普通死作物的排除规则。

## 踩踏

`aof.a(world,x,y,z,entity,fallDistance)` 以 `random.nextFloat() < fallDistance - 0.5` 判定踩踏，无新版额外体积门槛。胶状怪物完全豁免；熔岩怪不属于该豁免。原作先处理植物，再检查土壤：湿地或已施肥的地仍然会失去被踩的植物，但不会变回泥土。只有干燥且无肥料的耕地才会被踩回泥土。

作物踩踏使用独立掉落原因，不伪装成玩家正常采收。`anr` / `aqq` 不因踩踏产出正常食物或种子；土豆 `apt` 的特殊毒土豆路径由共享作物掉落实现保留。牛踩踏不产生植物掉落。

## 现代适配与保护

- 现代浮冰、冰和蓝冰共同映射旧版冰材料；现代细雪不在旧雪材料集合中。
- 仍接纳 NeoForge 的方块水票与 `canBeHydrated` 扩展，且随机刻不会为扫描强制加载区块。
- 不复刻原作允许怪物在 `mobGriefing=false` 时先踩坏植物的顺序漏洞。非玩家踩踏在所有植物/土壤写入之前检查现代破坏授权。
- 踩踏保留 `FarmlandTrampleEvent` 取消能力，取消同时保护植物和土壤；水桶逐格检查交互和物品使用权限；物品事件取消、旁观者、冷却、禁用物品使用都不能触发处理。
- 浇水延续原有 `ItemUtils.createFilledResult` 容器转换，背包满时使用原版掉落空容器路径，不吞容器，不增加玩家食物资源。
- 现代原版固体压覆耕地、物理碰撞、摔落伤害继续由原生方块处理。

## 验证

新增 `CropSoilRulesTest` 检查低温边界、高湿减缓和沙漠每刻蒸发的原始公式实例。`CropSoilGameTests` 通过真实 FarmBlock 随机刻、原生 fallOn、真实 NeoForge 物品交互和取消事件检查灌溉边界、雨水逐格补充、蒸发、邻株维持、踩踏次序、水瓶返还、粪肥路由及不可达的耕地骨粉路径。完整运行结果由主任务构建报告记录。
