## 分级工作台

玩家背包为 2×2（`vv.java:11–12`），工作台为 3×3（`vl.java:18–19`）。工作台元数据 0–14 有效；燧石和黑曜石各四种原木外观（`arv.java:11,60–73`）。表中的耐久系数同时用于能力比较，并非工作台会消耗的使用次数。

|工具材料|元数据|能力系数|有材料要求配方的速度加成|制造该工作台要求|
|---|---|---:|---:|---|
|燧石|0–3|1|0.2|无材料门槛|
|铜 / 银 / 金|4 / 5 / 6|4|0.3|燧石|
|铁|7|8|0.4|铜同档|
|远古金属|8|16|0.5|铁|
|秘银|9|64|0.6|远古金属|
|艾德曼|10|256|0.7|秘银|
|黑曜石|11–14|2|0.2|无材料门槛|

`RecipeHelper.addRecipe`（`RecipeHelper.java:56–83`）为一般金属成品设置最硬金属要求；锭、精确类 `ItemKnife`、已有桶参与的精确桶类输出除外。木板要求木材工作台能力。制造金属台要求现有工作台材料列表中严格更弱的最高系数，且排除黑曜石，所以铜台要求燧石，而铁台要求铜档。

实际放行比较是 `要求材料.durability <= 台工具材料.durability`；非空要求还要求打开工作台。旧代码在 `awy.java:159–218` 的 GUI 路径设置 `crafting_result_shown_but_prevented`，`wd.canPlayerCraftItem`（143–170）读取该标志。这说明旧客户端参与判定，不能作为新版服务端权限模型。

`RecipesMITE.java:113–132` 注册燧石/黑曜石“刀+原木”和“材料+线或筋+木棍+原木”配方；金属台使用锭+皮革+木棍+木板。拆 primitive 台得到刀的难度是 25，且不参加最低制造难度推导；`wd.java:130–131` 调 `arv.getBlockComponent`（76–84）额外退回对应原木。

两种格子都禁用精确 `ItemKnife` 类的金属输出；不是仅背包禁用。砂岩元数据 2 在 wonder tournament 中禁用，元数据 3 在非 tournament 时禁用（`vv.java:73–81`、`vl.java:76–84`）。

## 难度、计时、品质和经验

### 难度来源与时间

`RecipeHelper.java:5–55` 把展开配方中每个非空材料的 component difficulty 累加。负值材料先尝试其已知最低生产难度；锈铁还可按同类铜物品难度×材质耐久比例回退；仍未知则记录错误并跳过，不能凭空设定统一基础值。注册后显式 `setDifficulty` 可以覆盖。物品最低生产难度取允许参与计算的配方 `difficulty/outputCount` 最小值或显式覆盖（`yc.java:1260–1275`）。

设配方难度 D、品质等级 q（average 序号 2），品质调整难度 `Dq=D×2^max(q−2,0)`；低于普通不减难度，固定品质覆盖右键选择（`CraftingResult.java:29–45`）。

基础周期 B：Dq<25 时为 25；25≤Dq≤100 时为 `Math.round(Dq)`；Dq>100 时为 `round(pow(Dq−100f,0.8f))+100`。最终周期为 `int(max(B×(笨拙?2:1)/(1f+等级×0.02f+工作台加成),25f))`（`bex.java:450–503`、`uf.java:558–562`）。没有工作台加成 0；配方没有材料要求时任何台一律加成 0.2，不能给艾德曼台套 0.7。

必须保留 Java float 运算顺序、`0.8f` 扩展成 double 后的指数、正数 round 和最终截断。最低 25 tick = 名义 1.25 秒；固定 20 TPS 只是换算，服务器卡顿会增加现实时间。

`MITEContainerCrafting.onUpdate`（61–98）仅在客户端 `crafting_proceed && hasFoodEnergy` 时增加进度；没有食物能量暂停。选品质或换结果重置；禁止制造时清除。完成一次时扣料并重置：品质经验费正值停止连续制作，0 继续。币的费用独立，因此不能单看这个字段判断“免费”。旧服务端 `ka.java:861–867` 接收客户端完成包和费用整数，这部分必须改为服务端重新验证。

### 品质和费用

|品质|序号|耐久乘数|难度乘数|D=100 的普通制造经验费|
|---|---:|---:|---:|---:|
|wretched|0|0.5|1|0|
|poor|1|0.75|1|0|
|average|2|1|1|0|
|fine|3|1.5|2|40|
|excellent|4|2|4|80|
|superb|5|2.5|8|160|
|masterwork|6|3|16|320|
|legendary|7|3.5|32|640|

品质耐久 `max(round(基础最大耐久×乘数),1)`，普通或空品质走基础耐久路径（`EnumQuality.java:7–14`、`yc.java:590–605`）。材料最高品质：皮革/木/燧石/黑曜石=fine；锈铁=poor；铜/银=excellent；金=superb；铁/远古金属=masterwork；秘银/艾德曼=legendary；地狱岩/玻璃=average；石英=fine；绿宝石=excellent；钻石=superb（`EnumEquipmentMaterial.java:5–21`）。多材质若最低上限低于普通则取最低，否则取最高，木柄不会把所有金属工具限制为 fine（`yc.java:1237–1257`）。

最低品质序号 `clamp(2+(L−(笨拙?20:0))/10,0,2)`，除法向零截断；启用职业且没有适用职业时最多 poor。最高品质在物品材料上限内倒序寻找付得起费用的普通以上品质；XP≤0 或缺职业直接退回最低；否则找不到也退回最低（`uf.java:2184–2216`）。实际 ItemStack 再限制材料上限（`ye.java:927–954`）。因此负等级 −9 仍最低 average，−10 为 poor，−20 为 wretched，不能用向下取整。

候选经验费 `round(Dq/5f)×(笨拙?2:1)`；实际只有有品质、品质高于普通且非 XP 豁免结果收费（`uf.java:2219–2224`、`wd.java:279–287`）。右键切换品质，左键启动；repair quality_override 不允许切换（`wd.java:174–211,250–287`）。维修即便免 XP，仍可要求玩家具备制造该品质的能力。

上身处于蛛网、维修失败、容器禁止标志都会阻止；非维修配方禁止损坏材料。职业仅在世界启用时参与，缺职业阻止无品质物品与护甲染色配方（`wd.java:143–170`）。材料按 `consumption`（默认 1）逐槽扣除，容器物和原木处理回收；结果进入背包，满时掉落（`wd.java:104–135`）。

### 经验币

铜 5、银 25、金 100、远古金属 500、秘银 2500、艾德曼 10000 XP（`ItemCoin.java:15–26`）。铸币要求足额 XP，成品回调另扣 `币值×产量`（`wd.java:155–156`、`ItemCoin.java:57–58`）；拆币每个占用币槽返还一次币值（`wd.java:109–135`）。`RecipesMITE.java:104–110` 注册每种 1–9 枚拆币难度 25、单枚铸币难度 100。币没有品质，所以 `crafting_experience_cost=0` 不代表铸币无费用。

## 格子维修与铁砧

`aaf.java:263–321` 格子合并要求恰好两槽同物品、每槽一个、都损坏、同品质、都未附魔，有染色时颜色也必须一致。设最大耐久 M、损坏 d1/d2，结果损坏 `max(0,d1+d2−M)`，没有原版额外百分比修复。制造难度为最低生产难度的一半，保留品质和染色，免 XP，超出玩家品质能力则失败。

皮甲+线/筋（`aaf.java:323–353`）：每份恢复 `step=M/repairCost`。先 `n=ceil(damage/step)`，若 n>1 且会过量恢复则减 1，再限制到材料数量；结果损坏 `max(damage−n×step,0)`，难度 `n×50`，固定原品质且免 XP。例如损坏25、每份10只用2份，留5；损坏5则用1份修好。

铁砧 `va.java:58–98` 两类维修：同物品/子类型/品质合并（第一件损坏，第二件未附魔；第一件未附魔时第二件也须损坏），或对应材料耗材修复。维修金属系数不得超过砧材质系数（失败码2）；超过玩家品质能力为失败码1；职业不足在职业启用时拒绝。`uy.java:99–103` 的通用输出槽点击守卫确实拒绝失败码非零，不能只按是否显示结果判定。

耗材修复每份正常 `M/repairCost`，锁链甲 `2×M/armor.getRepairCost(false)`。循环只在当前单次恢复量等于第一次恢复量时继续，因此整份修复后剩余的不足一份要下一次操作再补：损坏250、每份100、材料8→用2份留50；随后50→用1份归零（`va.java:128–145`）。工具 repairCost=部件数×2；护甲为部件数×2，再按皮革/锁链模式除2（`xj.java:260–261`、`wh.java:305–319`）。

附魔书要求首件可附魔且尚未附魔，且书中有至少一个有效附魔；有效等级按上限截断。消魔瓶清除附魔，支持重命名。`va.java:115–197` 与 `vc.java:32–68` 没有 XP 扣除和原版40级门槛，局部计算附魔稀有度变量未用于扣费。此结论只指铁砧，不涉及独立附魔台。

只有耗材维修取出结果会损伤砧（`vc.java:33–51`）：工具=实际恢复耐久×1，护甲×200，弓×200，鱼竿×22（200/9 整除）。系数由铁鹤嘴锄12800/铁靴64、秘银铲25600/秘银弓128推得，不是随机损坏率。砧最大寿命 `int(1600×31×材质耐久系数)`，累计损坏达到50%、80%进入破损阶段1、2，100%破碎（`amv.java:187–206`、`TileEntityAnvil.java:25–36`）。铁砧寿命396800，阶段阈值198400/317440/396800。两件装备合并、改名和上述书操作不进入耗材维修磨损分支。

炉存档保存物品、BurnTime/CookTime/CurrentItemBurnTime（short）及 heat（byte）（`asg.java:74–105`）。顶部输入、侧面燃料、底部输出与燃料槽；底部抽燃料只允许空桶（313–348）。技能限制在玩家容器条件路径，默认关闭（`vp.java:95–99`、`we.java:64–70`）。旧输出 XP 是玩家取货回调 `outputItem.getExperienceReward(quantityTaken)`，不是炉内按配方累积经验账本，漏斗不会调用玩家回调（`vq.java:17–21`）。

品质支付边界 D=100、材料上限legendary：XP39→average，40→fine，80→excellent，640→legendary；上限excellent的铜物品即使XP10000也不得更高。笨拙使高品质费用翻倍，维修豁免只影响实际扣费，不移除品质能力门槛。

现代设计见 [modern-adaptation.json](../spec/modern-adaptation.json)。服务器统一重新计算工作台能力、计时、材料、经验和结果；单人与独立服务器共用路径。Crafter 无操作者默认平均品质（受材料上限约束）、无职业加成；所有需要操作者 XP 的制造都拒绝 `NO_OPERATOR_XP`，包括独立回调扣费的铸币。经验储存、现代炉经验、机器加载/卸载/退款均须按现代规格明确实现，不得声称为 R196 原有行为。

未决范围：完整普通配方使用运行时注册表，格子维修属于动态规则必须另测；旧客户端权威、炉多产物容量检查只比较当前数量、非法存档燃料绕过槽检验、损坏数据导致零 repair quantum 等属于边界审计，不自动照搬为新版行为。本文不声称所有旧分支在默认世界同时启用，也不代替逐功能游戏实测。
