# R196 烈焰人与恶魂射击

开发署名：NingMeng123。

本项将原版烈焰人和恶魂的射击目标、出手节拍、水平预判、随机散布及炮口位置接入服务端 Goal。仅处理 `minecraft:blaze`、`minecraft:ghast`；现代其他怪物和第三方实体不会因为继承这两个类而被替换。原生漫游、飞行控制、模型、声音资源、火球实体及其反弹、碰撞、伤害和爆炸继续使用 1.21.1。

## 现代边界

射击 Goal 使用现有来源视线/射线服务。恶魂保留原生飞行和转身；烈焰人保留原生选敌、浮升与寻路。没有把 R196 全部旧 AI 循环替换进现代实体。

发射后仍由现代原生火球积分运动：初始速度为归一化方向乘 .1，其后使用现代原生加速、空气/液体阻力及反弹处理。R196 `uj` 的构造初速度为零，再在后续 tick 累加固定方向的 .1 加速度；本项没有替换整个火球物理引擎，因此不宣称旧版逐 tick 飞行时间、同种子 RNG 或命中结果完全一致。已迁移的来源预判参数不会自动补偿现代积分差异。

## 验证入口

- `SourceFireballRulesTest`：9 项 JUnit，独立数值向量、两类周期、遮挡衰减、范围及两层散布。
- `NativeFireballAttackGameTests`：8 项 GameTest，实际原版实体加入后的 Goal 安装、原生充能位、真实小/大火球生成、30/64/100 边界、遮挡、移动目标轨迹向量、竖直重叠近战和真实服务端玩家选敌。
- `fireball_r196.nbt` 为独立 112×24×16 空气测试区域，长距离目标仍留在本测试分配范围内，避免污染相邻测试区域。

上述 GameTest 直接推进已安装的生产 Goal 并读取实际火球加入事件。构建、9 项规则 JUnit 和 8 项真实实体 GameTest 均已通过，结果见[本轮统一验证](testing/r196-parity-implementation.md)。客户端观感、自然追逐、完整战斗及真实多人仍待用户手测。
