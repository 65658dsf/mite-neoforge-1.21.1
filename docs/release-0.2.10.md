# MITE: Modern 0.2.10

开发者：NingMeng123。发布日期：2026-10-24。

本体与Modern ITE同时升级到0.2.10。Minecraft 1.21.1、NeoForge 21.1.259和Java 21保持不变。

## 本版内容

- 主世界铜、银普通／深层矿石默认倍率4.5，煤普通／深层2.8，绿宝石仍为1.5；地底的独立倍率保留。
- 怪物绝对刷新权重支持小数；输入、保存、TOML重读、导出、服务器同步和实际抽选保留数值，范围0～1000000。
- 长矛默认每秒1次攻击；Simply Swords双手武器额外20%攻速惩罚生效，主手按家族降低15%～25%移速，换下即恢复。铜剑6、银剑6.4、铁剑7.2基础伤害保留。
- 幻灵刃满额数量为铜／银4、铁5、秘银6、艾德曼7、振金8；锈铁／金4、远古金属5。按容量均匀竖直环绕，飞行时剑尖朝向目标、拖尾位于剑柄后。旧八剑存档保留已消耗次数，切换与重登不补弹；原伤害、逐发间隔和恢复秒数保留。
- 历史最高日期第1～35天，新怪物不生成装备，骷髅弓手例外获得普通无附魔弓；第36天恢复原装备流程。旧锁定空手弓手在入场时补弓，可见自定义／拾取装备保留，内部备用出生武器不能反补。

完整参数及旧存档行为见[本轮规则](ore-spawn-weapon-tuning-2026-10-24.md)、[幻灵刃](phantom-blades-2026-10-24.md)和[出生装备](blood-moon-equipment.md)。

## 安装与配置

本体文件为`mite-0.2.10.jar`，扩展为`modern-ite-0.2.10.jar`。安装扩展时需要本体0.2.10或更新版本；两份JAR配套更新，客户端与服务器保持一致。构建产物仅含生产代码和资源，不包含测试代码、参考旧版JAR或可选模组依赖。

已有配置继续优先读取。要采用新的矿石默认值，可在对应条目点“还原”或修改配置中的六个主世界倍率字段。矿石设置仅影响新区块。

## 验证

本版功能已通过1,742项本体JUnit、38项ITE JUnit、2,488项本体GameTest、335项ITE GameTest和134项四模组合回归。客户端验证包括权重2.5真实编辑、保存、重新打开回显，以及4剑环绕和剑尖朝向目标的真实帧缓冲截图。正式版构建另核对版本、扩展最低依赖、生产类与资源一致性；具体校验和与构建检查随正式包保存。

正式0.2.10构建的两组JUnit与配套加载的3项GameTest通过。本体1,463个生产类、4,639项处理后资源，以及ITE的265个生产类、745项资源逐字节匹配构建输出；两份默认TOML也与源码一致。正式JAR与完成上述全量回归的0.2.9候选仅版本元数据不同，未混入测试、参考旧版或可选依赖类。
