# 0.2.15 正式配套版本

开发者：NingMeng123

日期：2026-10-27

## 文件与运行环境

- 本体：`mite-0.2.15.jar`，模组 ID `mite`。
- 极难附属：`modern-ite-0.2.15.jar`，模组 ID `modern_ite`，最低依赖本体 0.2.15。
- Minecraft 1.21.1、NeoForge 21.1.259 或兼容的 21.1.x、Java 21。

两仓库默认构建版本及附属的默认本体 JAR 路径统一为 0.2.15，不再需要命令行覆盖版本号。

## 本次包含

本体包含失败寻路的共享退避和错峰、近身零步计划、单次搜索内的区块与方块查询缓存，以及移动中的失败追击最短重算间隔。挖掘活动与暂停检查共用追击规划，成功路线继续及时响应目标移动。

普通首次索敌要求自身视线；矿洞近战怪可通过完整、实际可行走且终点能够攻击的通路发现附近玩家，完全封墙或残缺路径不建立首次锁定。发现后的追击记忆和反击保留，极难附属的僵尸首领主动换锁检查新目标视线。

详细实现、采样口径与范围见[寻路开销](multiplayer-path-performance.md)、[首次发现](monster-initial-visibility.md)和[验证记录](testing/multiplayer-path-performance.md)。

## 安装

退出游戏、关闭服务器后，分别替换客户端与服务端的旧本体和附属 JAR；每种模组只保留一份。极难附属与本体一起加载。正式包文件名不含测试或补丁后缀，包内版本均为 0.2.15，署名均为 NingMeng123。
