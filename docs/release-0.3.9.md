# MITE: Modern 0.3.9

November 24, 2026. Developed by NingMeng123.

## Changes

- Added the Swift Strike attack-speed enchantment and an in-game configuration menu for gravel drop rates and Underworld red-diamond ore generation. Gravel settings are synchronized with MITE: Modern ITE.
- Added configurable Better Combat support for players and hostile mobs, including live server-configurable attack-speed and damage multipliers, plus Punchy compatibility for clubs and weapon animations. Fixed Punchy 3.2b startup resource reload and custom-attack transitions.
- Reworked the settings entry and sections, added search coverage, and fixed the server difficulty setting to Hard.
- Added growing cave brown mushrooms, piglin-brute reinforcements and updated their drops. Improved sprint catch-up when chasing animals.
- Fixed food consumption order and health regeneration while resting. Added the MITE settings handoff for ITE configuration.
- Fixed Wither summon health and Jade identification for Wither Plus Inferno Wither Skeleton Skulls.

Build file `MITE-Modern-0.3.9.jar`.

Requires Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the mod on both client and server for multiplayer.
