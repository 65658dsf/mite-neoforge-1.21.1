# 028 武器来源与适配

开发者：NingMeng123。版本基准为本地 R196 归档，校验值与完整材质清单在 `spec/weapons-028.json`。

## 身份、制造与维修

新增 `mite:ancient_metal_bow`、`mite:mithril_bow`，对应 R196 1251、1048。`aam.java:12-13` 和受保护注册表配方 39、38 的形状为 ` #X / #IX / #X`；三个木棍、三根线、对应金属锭一个，产出一个弓。

| 项目 | 远古金属弓 | 秘银弓 |
| --- | --- | --- |
| 普通品质耐久 | 64 | 128 |
| 品质上限 | 大师（masterwork，6） | 传奇（legendary，7） |
| 制造难度 | 1750 | 6550 |
| 最低工作台材料 | 远古金属 | 秘银 |
| 附魔能力 | 40 | 100 |
| 玩家发射速度增幅 | 10% | 25% |
| 维修材料 | 远古金属粒 | 秘银粒 |

耐久来自 `wp.java:14-23`；品质材料选择来自 `yc.java:1237-1254`，多材料取最高上限，除非最低上限低于普通。材料数值来自 `akc` 实际注册，不能套用早期工具上限。`wp.getNumComponentsForDurability` 为一个金属组件，维修成本为两个粒；通过现有 `R196RepairMaterial` 和材料铁砧逻辑，维修相同或更高阶铁砧，恢复量与品质耐久关联。`vc.java:38` 的弓铁砧磨损比例为 200。

普通原版弓仍沿用 `minecraft:bow`、普通品质 32 耐久和精良品质上限。新弓具有原生弓能力、现代原版附魔标签；伤害取决于箭材料、速度和临界随机数，使用 027 材料箭逻辑，不赋予虚构固定弓伤害。

## 发射与渲染

`wp` 拉满 20 刻，速度曲线 `(f²+2f)/3`，不足 0.1 不发射，满拉为暴击。原生 1.21.1 弓的箭准备、取消事件、弹药、耐久、附魔和发射流程沿用，定点替换发射向量。

`uh.java:128-162` 的玩家散布为 `0.5+4.5/(0.8+(level+1)/5)²`；负等级为 `5-level*0.5`，浸在液体时翻倍；偏移每轴为独立高斯随机数乘随机符号乘 `0.0075*散布`。本地 R196 技能开关受抑制，玩家直接用等级。强化倍率仅玩家发射有效。保留新版可取消发射及特殊弹药功能。

两弓分别复制 31 张原包图片：待机、十种箭各三段。源 `uf.java:1602-1611` 拉弓图阈值为 `>0`、`>=0.65`、`>=0.9`。客户端模型属性切换到实际准备弹药对应材质；现代药水箭视觉用燧石头作为默认，药效和原生箭颜色功能保留。

原作 Quickness、True Flight 未在此批注册，不能以新版 Quick Charge 或其他附魔替代它们。现代普通弓发射使用相同 R196 散布公式，其他模组弓和弩继续调用其自身发射行为。

远古金属弓接入已有地下地牢池：`afp.chest_contents_for_underworld`，数量 1、权重 2；共用 027 原始总权重与抽取次数，避免另开池翻倍概率。秘银弓通过源配方制造。

来源 `ItemGelatinousSphere`、`EntityGelatinousSphere`、`uq`，每组最多 16。右击实际投掷，普通模式消耗一个，创造模式保留，增加 0.25 耗竭，发射速度 1.2、重力 0.07，散布同玩家等级公式但高斯没有额外随机符号。物品图标、投射物图标复制原包五色 PNG；原生 ItemStack 跟踪与 NBT 同步颜色。命中产生八个对应物品碎片粒子，成功造成伤害有蒸汽和嘶声。

源实际伤害代码用 `nb.a(this, thrower)`，伤害类型为普通 `thrown`。`getDamageType` 返回 acid/pepsin 仅供方块接触；不能因此给实体施加毒或额外腐蚀其背包装备。现代伤害事件取消有效。

## 精确方块响应

使用 `SphereCorrosionExport.java` 在独立 JVM 的现有只读安全边界内，只注册源类并调用纯 `aqz.getDissolvePeriod(0, damage)`，不调用游戏 main，不创建世界。禁止文件修改、进程、网络、原生库、线程、移除边界及无关读操作的七项自检通过。完整实际数值保存于 `spec/sphere-corrosion-028.json`。`aqz.getDissolvePeriod(world,...)` 明确传 metadata 0，源中未启用按状态改变周期。

命中面前相邻方块先接触，再接触命中方块；对命中后的方块继续原生 `onProjectileHit`。周期 0 直接移除且不掉物，周期 400 单次球只显示蒸汽，**不累计 400 刻或安排定时删除**；负数不响应。

- 胃酶立即去除蜘蛛网；羊毛、床、地毯、蛋糕、绊线只冒蒸汽。
- 酸立即去除蜘蛛网、羊毛、地毯、蛋糕、树叶、树苗、花、草、作物、火把、红石火把、甘蔗、藤蔓、睡莲、下界疣、绊线及原版对应家庭的新内容。
- 铁、铜、银及远古金属相关方块、箱子、床、木制构件等源周期 400，仅冒蒸汽。
- 从顶面命中草方块或菌丝转为泥土；侧面不转换。金、秘银、艾德曼金属耐酸；普通石头和完整原木不会因单颗球消失。

现代同家族叶片、花、羊毛等明确映射源同类行为；现代未知方块、其他模组方块默认不处理。液体、基岩、地幔及原版完整坚硬块不扩展成无依据的溶解目标。

## 范围与未完成来源

四种新颜色没有源合成配方，不能添加猜测配方。源 `EntityGelatinousCube.s()` 只有一尺寸个体掉球，不同球来自未复刻的褐色软泥、红色软泥、灰色软泥和黑色布丁怪物。此批实现物品使用和方块响应，新增颜色可通过创造栏及指令测试；其自然怪物来源待生物批次，不将原版岩浆怪偷换为源怪物。原绿色球仍由原版史莱姆掉落，保留原版合成用途。
