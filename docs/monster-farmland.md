# 怪物主动破坏耕地

开发署名：NingMeng123。R196 原作：Avernite。来源校验与本次扩展数值见 [结构化规格](../spec/monster-farmland.json)。

## 来源边界

本功能按用户明确选择加入现代扩展：怪物没有活体攻击目标时，会寻找并破坏附近耕地。**R196 没有通用的“无目标寻田破坏”任务**，本次扫描半径、间隔、工作时间和适用现代生物均不冒充 R196 原始值。

核对 R196 所有 `aqz.aF`／`aof` 引用，以及 `tm`、`on`、`og` 和各怪物构造函数的任务注册，确认原版相关路径有三种：

1. `EntityAnimalWatcher` 构造注册 `EntityAIWatchAnimal`，后者必须已有活体目标，再尝试挖挡路方块。耕地位于可挖白名单；这属于追击挖掘，不是寻找农田。普通僵尸、冤魂、食尸鬼及土元素／黏土傀儡家族实际启用此任务；僵尸猪人虽继承类层次，但 `bf()` 关闭该调度器，不能因继承关系就认为它会执行该任务。
2. `aof.a(World,x,y,z,Entity,float)` 是落地触发的被动踩踏：随机数小于 `fallDistance - 0.5F` 时处理上方植物；仅干燥且未施肥的土壤继续变泥土。湿润／施肥田仍可能失去作物。源码的 `mobGriefing` 判断位于作物处理之后，本项目已有现代保护适配在任何作物或土壤变化前检查它，本次保留该保护。
3. `EntityGelatinousCube.bl/onCollidedWithBlock` 是身体实际接触作物时致病或腐蚀，不会为此搜索整片农田。`pn` 的吃作物逻辑是动物吃草任务，不能套给所有怪物。

关键字节码已核对：`EntityAIWatchAnimal.a()` 先检查当前活体目标，非持续挖掘时还执行 `nextInt(20)==0`；`EntityAnimalWatcher.canDestroyBlock` offset 441 读取 `aqz.aF` 作为普通可挖例外；`aof` 落地方法 offset 70 调用植物踩踏，offset 112 才读取 `mobGriefing`。

## 本次现代扩展

| 项目 | 行为 |
| --- | --- |
| 生物范围 | 分类为 `MONSTER` 的 `PathfinderMob`，且具有 `GroundPathNavigation`；包含原版现代怪物与新增 MITE 地面怪物 |
| 显式排除 | 烈焰人、恼鬼和潜影贝虽然可能继承地面导航对象，但并不沿地面行走，故不安装任务；飞行导航、动物和蝙蝠也不安装 |
| 任务优先级 | 5，使用移动与观察锁；任何活体攻击目标都禁止启动并打断当前工作 |
| 搜索范围 | 水平半径 8 格圆形区域，垂直上下各 2 格；只读取已加载区块和实际世界高度 |
| 搜索间隔 | 200～299 游戏 tick；首次搜索按实体 ID 分散到 0～199 tick，不额外消耗源装备或生物 AI 的随机流 |
| 路径限制 | 按距离选最近候选，每次最多尝试 8 条真实路径；路径必须报告目标可达，不能隔墙远程清田 |
| 目标 | 裸露耕地，或上方为空气、作物、茎及其它草本植物的耕地；不以田上容器或实体方块为目标 |
| 移动 | 正常导航速度倍率 1；最多行进 200 tick，每 20 tick 仅在导航结束时尝试续路 |
| 工作 | 距目标站立点不超过 1.5 格、眼睛至土壤的物理射线未被其它方块遮挡后停下，连续工作 40 tick；有手臂动作和方块裂纹，离开工作范围重置进度 |
| 完成结果 | 单格耕地变为泥土；不会直接挖出坑，也不掉落泥土物品。湿润或施肥田也可被有意破坏 |
| 作物掉落 | 托管食物作物调用现有 `TRAMPLE` 路径；普通成熟作物不产生收获。病害／未成熟马铃薯等已有来源特殊掉落仍由原食物规则决定；其它草本植物和茎直接清除，不额外制造种子 |

一次完成仅影响一格。已拥有的追击挖掘任务和本次寻田任务互相区分：源挖掘真正拆掉土壤，掉落一份泥土；现代寻田是有意踩平，不产生土壤物品。两个任务都允许优先追击玩家及其它活体目标。

## 权限与联机

服务器独占路径选择及方块变化。搜索与工作期间均检查 NeoForge 的 `canEntityGrief`。完成前检查土壤和上方作物各自的 `canEntityDestroy`／`LivingDestroyBlockEvent`，以及 `FarmlandTrampleEvent`，全部通过后才改变任何一个方块。保护插件否决作物破坏时，下面的耕地也保持原状。监听器若自行改了目标方块，任务会重新检查并中止，避免继续使用过期状态。

存档重进按当前世界重新寻找田块，不保存临时裂纹、路径或已工作时间；加入世界时防重复安装。关闭 `mobGriefing` 会使进行中的工作取消，下次开启后仍按正常搜索间隔尝试。

## 手动测试

重启测试客户端后，在新测试区域执行 `/gamerule mobGriefing true`。准备一条平坦通路，在僵尸前方 4～6 格放一小片耕地，分别留空、种成熟小麦、浇湿并施肥。保持创造或旁观模式，使怪物没有活体攻击目标。等待约 0～15 秒首次搜索后，怪物应沿路靠近，工作约 2 秒踩坏一格，作物消失，耕地变泥土；不会一下清掉整片。

- 将农田完全围在两格高的实心墙里：怪物不能隔墙直接破坏。
- 工作中切换生存并进入怪物视野：它应停止耕地工作，优先追击。
- 工作中执行 `/gamerule mobGriefing false`：作物与土壤均保留。
- 换骷髅、苦力怕、尸壳或 MITE 地面怪物重复；牛、狼、蝙蝠和浮空怪物没有此行为。
- 长等待可用 `/tick rate 200`，测试结束恢复 `/tick rate 20`。

GameTest 另覆盖正常实体 tick 的真实行走、可达／不可达路径、39／40 tick 边界、两个方块的事件否决、追击原有耕地挖掘及掉落区别。
