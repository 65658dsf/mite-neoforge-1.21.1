# 035：R196 怪物破门与挖掘障碍来源

开发者：**NingMeng123**。来源为本地 R196 发布包，SHA-256 `fb7ad265d05749e0cd1e54938f6c36ecbe9ea1d4d90d4a04c519615e1e0218c3`。结构化来源见 [monster-obstacles-source-035.json](../spec/monster-obstacles-source-035.json)。本文记录实际来源及对 031 基线的差异，不代表现代实现或实机测试通过；未运行旧版世界。

## 两条独立路径及启用范围

`EntityAnimalWatcher` 继承怪物 `tm`，构造时注册优先级 1 的 `EntityAIWatchAnimal`，mutex 为 3。`tw` 僵尸、`EntityGhoul` 食尸鬼、`EntityEarthElemental` 土元素分别在子构造中注册优先级 1 的 `pj`（原 SourceFile：EntityAIBreakDoor）。`pm`（EntityAIDoorInteract）与 `pj` 没有设置 mutex，默认 0，所以专用敲门可以和其他任务并行。

普通僵尸和僵尸村民对应 `tw`；怨魂 `EntityRevenant` 继承 `tw`；黏土傀儡 `EntityClayGolem` 继承土元素。亡魂、隐形潜行者、暗影直接继承 `tm`，没有这组 watcher 挖掘/敲门任务。猪人 `tn` 虽然继承 `tw` 构造，但覆写 `bf()` 为 false；`of.c()` 因而走 `oldAi/bl`，不执行 `og.bi` 的 GoalSelector。不能仅凭继承链就给猪人默认启用这些 Goal。

## 专用敲木门：pj / pm

| 项目 | 实际规则 |
|---|---|
| 入口 | 已水平碰撞 `og.G`；导航存在未结束路径且 `rf.c()` 允许通过关闭木 portal |
| 寻门 | 遍历路径开头至 `min(nextIndex+2,nodeCount)` 的节点；逐个检查节点 Y+1，再节点 Y；水平到节点平方距离 `<=2.25`；最后检查自身 X/Z、Y+1/Y |
| 可敲种类 | `alg.isWoodenPortal` 只认木门 64 (`aqz.aJ`)、木活板门 96 (`aqz.bp`)、木栅栏门 107 (`aqz.bA`) |
| 打开状态 | 三者必须关闭；木门上半部递归读下半部打开位 |
| 目标限制 | 栅栏门还要求当前目标为玩家；普通木门/木活板门没有此目标类型限制 |
| 游戏规则 | 开始时检查 `mobGriefing=true`；源继续条件和最终破坏分支不重新检查 |
| 保持 | 进度 `<=threshold`、portal 仍关闭、实体到目标整数坐标平方距离 `<4` |
| 基础阈值 | **木门 1920**，木活板门/栅栏门 **480**；不是原版 240，也不能交换木门/活板门映射 |
| 元素与狂暴 | 土元素阈值先按普通黏土/硬化黏土/其他分别整数除 4/6/8；之后狂暴再整数除 2；食尸鬼没有专用门阈值的额外减半覆写 |
| 进度 | 每 tick 加 `(int)(max(sourceToolStrength,1)+.5f)`；非 `xj` 工具按 1；超过阈值截到阈值 |
| 效果 | 每 tick 刷新失踪计数到 -400；1/20 播放事件 1010 与带门标志的 2001；裂纹阶段为 `(int)(progress/threshold*10)`，变化时发出 |
| 真正破坏 | 只有进度达到阈值并且难度 `world.r==3`（困难）才移除方块。简单/普通可以敲并在满进度继续保持 |
| 双格与掉落 | 若目标是木门上半部，先把下半部设空气，flags=2，再移除目标，flags=3；播放 1012、2001。该路径没有掉门物品或调用工具破坏回调 |
| 停止与保存 | 停止广播阶段 -1；重新开始把进度设 0。`pj.i/j` 没有 NBT 保存；不能把专用门进度当通用挖掘存档续算 |

持剑、木棒和镰刀的通用禁挖条件不在 `pj` 中；它们仍可执行专用敲门。铁门、铜门、银门等不是木 portal，不走此路径；现代各种木种/竹/下界木门对应的扩展必须明确为新版本映射。

“困难才可破门”仅描述这条专用敲门路径。符合下节几何和权限条件的 watcher 也能用通用挖掘拆木门，因此不能为模拟 `pj` 的难度限制，把门从通用挖掘一律剔除。

声音编号是版本适配的一部分：R196 的 1010/1012 表示敲门/破门，1.21.1 的 1010 却是播放唱片，1012 没有对应处理。现代实现明确使用 `LevelEvent.SOUND_ZOMBIE_WOODEN_DOOR`（1019）、`SOUND_ZOMBIE_DOOR_CRASH`（1021）和 `PARTICLES_DESTROY_BLOCK`（2001），不再广播旧编号。`portalPoundingAndBreakSendDoorSoundsInsteadOfJukeboxPackets` 使用真实测试连接捕获客户端事件包，覆盖实际敲击和最终破门，禁止出现唱片事件。

## 通用挖掘权限与候选：EntityAnimalWatcher / EntityAIWatchAnimal

### 挖掘资格

基类默认可以挖；持 `zl`（剑）、`ItemCudgel`（含其子类 `ItemClub` 木棒）或 `ItemScythe` 则禁止。短剑、战斧、战锤、小刀不是这个禁止列表。

`tw.isDiggingEnabled` 另外要求聪明、狂暴或持 `xj` 工具。普通僵尸出生聪明概率 1/8，怨魂恒为聪明；被玩家实际负面影响后会变聪明，`is_smart` 保存加载。但 Goal 的入口是 `!isDiggingEnabled && !canSeeTarget(false)` 才拒绝，所以不聪明、空手但能看见目标的普通僵尸仍可能挖。

watcher 继承 `tm.isFrenzied() = world.isBloodMoon(true)`，因此本文狂暴默认是血月判定，不是仅骷髅领主专用状态。

### 可破方块

1. 方块不能是空气/未注册或液体。方块 Y 最高为脚 Y+1，向脚下挖只有手持 `ItemShovel` 才行。身体中心到方块中心的距离平方必须 `<=3.25`。
2. 开启 clipping 检查时，从主要攻击点和身体高度 1/4 的腿点分别射到方块中心；只有两条都被其他方块挡住才拒绝。局部条件虽写有 `rc.isEntity`，实际 `abw.getBlockCollisionForPhysicalReach` 固定 `performVsBlocks().getBlockCollision()`，实体分支默认不可达，不能因此额外添加实体遮挡。
3. 土元素如果方块来源最低采集等级不高于本体材质采集等级，立即允许。此 return 在同伴占用检查之前，土元素捷径不受后述独占检查。
4. 其他情况任一条件足够：来源材质不需要工具；狂暴且来源最低采集等级 `<2`；`xj.getStrVsBlock` **>0**；或下面的来源例外。
5. 例外：砂 12、泥土 3、草 2、砂砾 13、雪块 80、耕地 60、黏土 82、树叶 18、羊毛 35、海绵 19、菌丝 110、干草块 170、玻璃板 102，以及 `apy` 南瓜/南瓜灯、`apg` 西瓜；仙人掌 81 只在本体无敌或亡灵时作为此特许条件成立。
6. 不走土元素捷径时，还要求附近没有另一个 watcher 正在破坏同坐标。查询盒为本体位置 ±4 XYZ，排除自身；必须看对方实际 `is_destroying_block`，不是仅看残留 NBT。

这里的 `material.requiresTool` 是材质 `requires_tool` 或方块来源最低采集等级 >0，不等于现代 `requiresCorrectToolForDrops`。来源石头材质需要工具，不能把大部分现代石头的默认标志当成空手可挖证明。木材与玻璃材质本身不设需要工具，但 `arj` 原木、`aol` 整块玻璃、`aov` 冰在各自构造器把最低采集等级提高至 1；`aqh` 砂岩从石头 2 降到 1。木门没有该提升，仍可无工具通用拆除；玻璃板也没有整块玻璃的等级提升。负硬度/无敌方块的现代保护、加载区块和 NeoForge grief 事件应明确记录为适配，不能凭空声称旧代码已有对应检查。

### 选块顺序

- 无目标、与目标同 XYZ 方格、持禁挖武器直接拒绝。已有破坏且当前块仍可破时继续；新任务 1/20 启动抽签。
- 到目标距离 >16 拒绝。距离平方 >2 时，先沿目标 X/Z、目标脚下一格向下扫描到自己的脚 Y，尝试挖目标脚下支撑。
- 剩余候选距离最高 8；如果头顶视点（眼 Y+1）无遮挡并可直达目标眼睛，用 8；否则狂暴用 6，平时 4。
- 计算 16 格到目标路径后，当前导航仍未结束就不启动；已经能近战命中也不挖。
- 先尝试从眼/攻击点到目标身体中心上方 1 格的射线（目标头顶需可通行），再到目标身体中心；每次从命中块的 Y+1 向下扫至自身脚 Y。
- 最后尝试腿点到目标中心的命中块，且其上方可通行或会下落；该最终候选调用 `setBlockToDig(...,false)`，不再复查 clipping。
- 木栅栏 `aoh` 是受限射线候选：只有拿有效工具或目标玩家才选。此筛选不是所有木材，也不是所有门。
- `qa` 近战还有额外入口：不能直接击中且目标取整 Y 高于自身时，尝试目标脚下方块；因此不能仅复刻主 Goal 的随机入口就宣称来源选块完整。

### 时长、交互与终止

通用初始 cooloff=40、阶段=-1。阶段动作前若 cooloff==10 挥手；每 tick 先减 cooloff，降到 0 时重置为当前块阶段间隔并执行阶段动作。动作先 `++progress`，达到 10 才真正破块，所以从 -1 开始需 **11 次动作**。同块重复设置不重置阶段；换块时重置阶段，但 `setBlockToDig` 本身不重置当前 cooloff。

阶段间隔依次为：`(int)(300f*来源metadata硬度)`；狂暴整数除 2；土元素整数除 4/6/8；若持 `xj` 则 `(int)(cooloff/(1f+strength*.5f))`；食尸鬼覆写在父计算结果上再整数除 2。非有效工具 strength=0，不能把原版默认 speed=1 强塞进公式而产生错误提速。允许 0 间隔，下一 tick 即可执行下一动作。

每次动作刷新失踪计数 -400；挖仙人掌且物品不保护手时承受 1 点接触伤害。正常阶段发裂纹，并播放 2001；玻璃材质使用独立打碎声和最终效果。真正破块显式构造 `BlockBreakInfo.setHarvestedBy`，执行来源掉落，再设空气，最后调用手持物品 `onBlockDestroyed`，物品耐久遵循已有工具规则。

完成后不只是简单向上换块：上方为 falling block 时继续原坐标并暂停 10；上方非空且不应下落时，按脚层与可挖性选择向上或向下继续；还有头顶狭窄时转向下层的分支。上方为 `BlockUnderminable` 会触发 `tryToFall`。存在上方下落风险时，附近 `(3,1,3)` 范围有近战 `qa` 的生物把近战压制和攻击冷却提高至至少 10。

继续条件会递减对应近战 cooldown；如果此时可近战命中，立即执行近战并停止挖掘。暂停最后一刻若寻路能至少靠近目标 2 格以上则停止；每 10 个 offset tick，如果路径终点距目标 <=1 且从终点到目标中心没有障碍，也停止。目标消失、同格、换禁挖武器、目标块不可达等均停止。`player_attacks_always_reset_digging=false` 是实际常量，不能把每次受击都设为固定重挖；死亡会取消裂纹。

通用 NBT 只在正在破坏时保存 active、XYZ、progress、cooloff；**pause 不保存**。取消时 active=false、progress=-1、cooloff=40，并发阶段 -1。

## 031 基线的明确缺口

| 领域 | 当前 031 实现差异 |
|---|---|
| 专用敲门 | 仍依赖现代 Zombie 默认门任务/随机开关；亡魂 finalizeSpawn 固定开启，但缺来源 1920/480、木活板门/栅栏门、力量、血月、无掉落/无耐久等完整规则；食尸鬼/土元素未装对应任务 |
| 启用 | `R196DiggerGoal.watcher` 仅继承链；缺普通僵尸聪明状态、可见绕过、血月和猪人 oldAi 不启用审计 |
| 权限 | 现代工具 speed>1 与原版掉落工具标志替代来源规则；缺精确来源等级/材质判断、狂暴等级<2、土元素跳过独占、仙人掌伤害 |
| 候选/结束 | 缺8/6/4视点范围、上方/腿射线和受限木栅栏筛选、近战支撑入口、路径变好/可命中时终止 |
| 时序 | 已有初始40和11动作；缺挥手、血月减半；基础hardness仅现代局部映射；换块当前直接重置cooloff为40，不同于来源 |
| 后续/互助 | 当前只尝试向上；缺落块原位等待、转向下层、周围近战压制及BlockUnderminable关联 |
| 保存/取消 | 已有位置/阶段/cooloff保存与懒恢复；源码pause不保存；现代退出条件和真实占用者状态仍需校验，死亡不能留裂纹 |

以上是实施前基线审计，后续生产修复和现代适配应在验收文档记录。农业落块体系、完整怪物目标选择和旧版随机序列等关联内容不能被本批小功能默认为全部完成。
