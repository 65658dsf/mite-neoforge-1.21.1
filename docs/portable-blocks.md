# R196 便携方块

开发署名：NingMeng123。这里的“便携”是拆卸速度、工具资格及免工具磨损，不是将任意容器内容打包进方块物品。现代容器仍使用自己的正常掉落和内容处理。

源入口为 `uf.java:787–833` 和 `xj.java:177`。先调用方块 `isPortable(world, player, position)`；便携时忽略手持工具及效率附魔，从 `4×hardness` 起算，依次应用急迫、挖掘疲劳、水中无水下速掘、离地、食物能量、等级倍率；最后再限制最低 `4×hardness`。因此负等级、空腹、空中、水中都不能比最低搬运速度慢；正等级可以更快。零硬度仍按原进度入口立即破坏，不可破坏方块仍不能拆卸。

来源不是“所有 BlockEntity 都便携”。默认 `aqz.java:1687` 为 false；`amw.java:35`、`BlockDirectionalWithTileEntity.java:33`、`BlockMountedWithTileEntity.java:43` 及具体覆盖形成如下名单：

| 来源类别 | 当前明确覆盖 |
|---|---|
| `amv / arv` | 材料砧、铁砧及材料工作台 |
| `anb / aoy / are / anj` | 床、梯子、TNT、炼药锅及其装液状态 |
| `ank / aod` | 普通箱子、陷阱箱、末影箱；保险箱另看主人 |
| `any / aoa / aot` | 发射器、投掷器、漏斗 |
| `app / aow / ana / ans` | 音符盒、唱片机、信标、阳光探测器 |
| `BlockFurnace* / aoc / and` | 来源各炉型、附魔台、绿宝石附魔台、酿造台 |
| `aqj / aqk / aob` | 告示牌、头颅、龙蛋 |

`api.java:41` 对刷怪笼明确返回 false。现代刷怪笼、试炼刷怪笼、宝库、木桶及潜影盒没有因为具有 BlockEntity 而自动获得便携属性。现代适配仅延伸明确家族：新颜色床、新木种告示牌/悬挂告示牌、装液炼药锅、烟熏炉和高炉。

`BlockStrongbox.java:75–80` 只给主人便携资格。现代继续以已有保存的 UUID 判主人，未归属及其他玩家保险箱仍需原有材料门槛；Generic ChestBlock 继承不能绕过它。所有工具（含新版下界合金及第三方工具）经实际 `ItemStack.mineBlock` 入口免便携磨损；来源工具既有免损逻辑继续共用同一判定。

自动验证入口：`PortableBlockRulesTest`、`PortableBlocksGameTests`，覆盖等级/环境顺序、来源白名单和负例、实物下界合金镐零磨损、持工具不加速、主人/非主人区别。其他模组取消 BreakSpeed 或设为零依然优先生效；便携计算对正数进度应用来源公式。

手动验收：0级空手拆床、箱子、漏斗、炉子、梯子，应能拆；换高级工具不额外加速、不扣该工具耐久。50级在地面正常能量时应比0级快一倍。0级在空中/水中应有最低速度。其他玩家保险箱、刷怪笼与试炼方块不能获得便携豁免；箱子内容维持原生散落。
