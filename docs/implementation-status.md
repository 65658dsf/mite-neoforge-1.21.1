## 发布规则

- 原始 ZIP、反编译源码、开发存档、日志和本机路径不得混入游戏发布包。
- 每个功能以用户手动游戏验证为提交门槛：提供步骤和预期，用户反馈通过后再推送；未获用户明确要求时不操作、重启或关闭游戏。
- 提交采用类型前缀与中文说明：新增功能为 `feat:`，问题修复为 `fix:`；正文分条记录变更与验证，署名为 NingMeng123。
- 记录明确的遗留项目；工程启动成功不代表 R196 全量复刻完成。
