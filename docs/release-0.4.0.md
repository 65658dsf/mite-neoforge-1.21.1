# MITE: Modern 0.4.0

November 26, 2026. Developed by NingMeng123.

## Changes

- Added material-specific shield-break cooldowns and corrected monster growth, melee reach and Nether spawning behavior.
- Added detection and configurable blocking of shaders and resource packs that reveal entities, with in-game settings and chat feedback. The Punchy and Better Combat integration now loads only when both mods are installed.
- Restored bare-hand breaking for vanilla blocks such as glass, and made overworld night skipping follow the configured sleep percentage.
- Kept gamma brightness at its minimum according to the gameplay rule.

Build file `MITE-Modern-0.4.0.jar`.

Requires Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the mod on both client and server for multiplayer.
