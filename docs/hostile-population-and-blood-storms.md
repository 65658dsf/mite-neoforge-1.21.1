# 怪物数量与血月全天生成

开发署名：NingMeng123。

本次属于用户指定的现代玩法调整。R196 原始怪物权重、群系栖息地和第 97 天永久解锁规则继续保留；不把新增数值描述为 R196 原数值。

## 数量上限

Minecraft 1.21.1 的 `MONSTER` 类别基数为 70。现在普通日使用 1.5 倍，即 105；主世界血月全天使用 2 倍，即 140。其他维度没有血月日期，使用普通日基数。

实际维度总上限向下取整：

```text
普通日 = floor(105 × 有效玩家区域区块并集数量 / 289)
血月日 = floor(140 × 有效玩家区域区块并集数量 / 289)
```

单个玩家贡献以所在区块为中心的 17×17 区域，共 289 个区块。沿用现有选择器：外圈 64 个区块计入区域面积，内圈 225 个区块参与位置采样。多人区域取并集，重叠部分只计算一次；这并不保证区域中的所有区块已经加载或每刻都能生成怪物。

地下和地表继续分两轮寻找位置，但共享同一维度的怪物总量上限。旧版地下额外翻倍不再应用。深层一轮成功加入的怪物会立即扣减本刻共享额度，浅层只使用余额；同一群怪也不能突破剩余上限。普通蜘蛛的骑手与蜘蛛共同扣除怪物额度，剩余额度不足时回滚整组；预先加入世界的骑手不重复触发加入事件。怪物统计仍沿用项目现有规则，包括命名怪物，不影响刷怪笼自己的限制。

玩家包围盒向水平各 32 格、垂直各 8 格扩展后，旧地表拥挤阈值通常只有 8～12，容易提前让整个玩家区域停止生成。阈值现在至少为普通日 105、血月日 140，避免旧门槛掩盖提高后的总量。原深度和要塞计算结果仅在高于这个最低阈值时保留。多人聚集时仍有局部拥挤保护。

动物、环境生物和水生生物的数量算式与调度周期保持原规则。

## 血月全天

血月白天的雷雨也允许地表亡灵生成。普通日白天继续禁止地表亡灵生成。夜间原有的户外抽选保持不变，血月夜仍使用二选一放行。

白天放行只读取当前血月日期，血月结束后立即恢复限制，第 97 天永久解锁不会永久开启白天生成。这个限制同时覆盖旧版亡灵、新版亡灵变种和自然生成时附带的骷髅骑手；普通日雷雨也不能绕过。地下洞穴仍按原有光照等条件生成，刷怪笼继续使用自己的规则。

生成限制按实体类型标签 `mite:daylight_restricted_undead` 分类，不逐个判断怪物名称。该标签包含原版 `minecraft:undead` 和来源 `UNDEAD` 家族，数据包可追加其他模组的亡灵；原版亡灵标签与战斗、治疗规则保持原样。

日间限制使用专用地表判定：向上检查实际遮蔽，树叶、树枝原木和纯液体不算地下顶盖。因此浓密沼泽树冠、树枝阴影和浅水不会让沼骸等亡灵绕过普通白天限制；洞穴中的实体岩层仍保留地下生成资格。判定不使用固定 Y 高度，也不因洞口距离很近而把有岩层顶盖的位置改判为地表；地下仍须满足原有光照、碰撞等条件。夜间原有户外路径与随机抽选保持原样。

树枝通过原木方块标签识别，只有原木屋顶的棚屋也按地表处理；上方确有石、泥等实体地层的地下空间仍按地下处理。

新版生物的自然生成还须独立通过原版生成位置资格及完整实体包围盒的方块碰撞检查。光照/难度谓词和生成事件本身不包含这两项检查；漏掉它们会让沼骸直接在草块、树干、石头中出生，并把身体所在的实体块误当地下顶盖。此检查按原版生成类型统一覆盖新版生物，允许合法暗洞中的生成，不逐个特判沼骸。

以前仅血月夜放宽的深度门槛扩展到整个血月日期，包括食尸鬼、怨魂和骷髅领主。亡魂在高层仍要求冰冷群系，暗影在高层仍要求沙漠；其他栖息地、方块、光照、碰撞和距离要求继续判定。

远古骷髅、远古骷髅领主等第 97 天追加的内容不会提前加入主世界。第 97 天永久解锁也不会因为血月结束或时间倒退而被取消。

## 刷新频率

普通情况下，深层和浅层怪物生成轮的每刻启动概率分别为 10% 和 17%，再乘已有动态修正。血月全天额外乘 2，分别为 20% 和 34%；动态修正仍然生效，最终概率不超过 100%。例如动态修正为 2 时，血月为 40% 和 68%。

这里增加的是每轮调度启动概率，不承诺实际怪物数量固定翻倍。位置、光照、群系、现有数量、距离和群聚限制仍会让某一轮生成失败。环境生物和水生生物的 400 刻周期没有加速。

## 验证与手动检查

自动测试覆盖独立数值算式、地下与地表共享额度、整日血月选择器、保留群系限制，以及真实玩家周围 20 个怪物不会再触发旧的低拥挤门槛。集成测试使用原生已加载实体区块和真实怪物计数。

在单独测试存档中，可比较第 160 天的白天和夜间。该日期已超过第 97 天，又属于血月：

```mcfunction
/time set 3822000
/time set 3834000
```

第一条是血月当天 6000 刻，第二条是当天 18000 刻。关闭创造模式飞行并在无遮挡、无人工照明的位置等待，白天应能看到亡灵新生，不再只有蜘蛛等非亡灵。暗影需要在沙漠检查；亡魂需要在冰冷群系检查。营地照明、地形、已有怪物和附近其他玩家都会影响实际数量。

随后执行 `/time set 3846000` 切到第 161 天普通白天，户外亡灵应停止自然生成，即使入侵已永久解锁或仍有雷雨。观察新增怪物即可，已有亡灵不会因这条生成限制被清理。

将普通日与血月的数量比较时，应使用相近地形和相同玩家数量，等待自然刷新稳定。达到 105 或 140 是完整单玩家有效区域的总量上限，包含地下怪物，不是玩家视野内必定出现的数量。
