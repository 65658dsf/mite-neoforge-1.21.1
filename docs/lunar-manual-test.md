# 月相机制与手动测试

开发者：NingMeng123。原作：Avernite。日期：2026-10-15。本轮基于本地 R196 实际调用链，使用新版主世界地形。用户在核对绝对时间指令后反馈“没有问题了提交吧”，确认当前交付正常并授权提交 GitHub；本清单保留供复测，不补写未提供的逐项结果。

后续追加的[血月白昼降雨、夜间干雷与血红天空](lunar-weather-adaptation.md)属于现代扩展，昼夜天气修正等待本次独立验收；此前用户确认不代替新增行为的手测。

## 本次变化

- 统一八阶段月相、血月、蓝月、黄月（收获之月）和月晕日历；月盘、原图光晕、月光明暗及夜间环境色偏接入实际客户端。
- 接入来源天气排程、血月沙漠降雨及闪电概率、血月睡眠限制。
- 血月夜感染接入已有作物病害；修正活的染病马铃薯固定掉一枚毒马铃薯，死亡和爆炸不掉落。成熟作物仍会收到病害随机刻。
- 沿用已有血月怪物生成、狂暴及蓝月动物规则；修正蓝月钓鱼与鱿鱼捕食的昼夜边界，补齐恐狼额外低吼。
- 按用户要求添加彩色聊天通知。这是现代适配：进入特殊日期，或玩家首次加入该特殊日期的主世界，提示“今天是第 X 天，丰收之月”等；同日停留、重登、死亡不会重复刷屏。普通日期不提示。

来源日期为 `dayTime / 24000 + 1`，与原版 `/time query day` 的零起始数值相差一。第 128 天蓝月替代血月；第 120 天月晕替代收获月。来源夜间为当天 `13000..23000`，包含两端。

## 月亮和聊天提示

用可执行命令的独立测试存档，在主世界无遮蔽平地测试。由你手动运行更新后的客户端；本轮开发没有启动、重启或操作游戏窗口。

先执行：

```mcfunction
/gamerule doDaylightCycle false
/gamerule doWeatherCycle false
/weather clear
```

等先前雨量消退后，依次设置下列绝对时间。每次看天空、聊天栏及周围地面；靠近火把再比较一次。

| 命令 | 月亮及环境预期 | 聊天提示 |
| --- | --- | --- |
| `/time set 186000` | 第 8 天普通白色满月，无特殊光晕 | 无特殊提示 |
| `/time set 90000` | 第 4 天新月，月盘暗，月光较弱 | 无特殊提示 |
| `/time set 570000` | 第 24 天金黄色收获月，地面偏暖，无额外光晕 | 金色“今天是第 24 天，丰收之月” |
| `/time set 762000` | 第 32 天血月夜雨量逐渐消退，仍有雷声与真实闪电；月盘和光晕保留血月颜色，无遮挡低方块光处偏红 | 红色血月提示 |
| `/time set 2874000` | 第 120 天白色满月和蓝灰色圆环，地面无额外色偏 | 浅蓝色月晕提示 |
| `/time set 3066000` | 第 128 天蓝色月盘、大光晕，地面偏蓝 | 蓝色蓝月提示，无血月提示 |

这些指令设置的是绝对总时间。执行后不要再使用 `/time set night` 或 `/time set 13000`：它们会把总时间重置到第 1 天，而非只调整特殊日当天的时刻。聊天里的旧月相提示作为历史消息保留，当前月盘以当前总时间为准。用户本轮截图中的日期重置已核对，未据此修改正确的日历或着色公式。

进入地下或火把方块光达到 8 时，特殊夜间色偏应减弱至消失。普通日没有特殊颜色。月晕圆环随月亮升落淡入淡出，不是整天都能看见。

在同一特殊日等待、重登或死亡，不应反复收到提示；推进到另一特殊日应出现新的提示。先在下界停留时切换到特殊日期，不应在那里收到主世界月相提示；返回主世界后可收到尚未提示的当日消息。

先关闭光影包检查基础画面，再按自己的模组组合检查。完全替换天空或光照图的光影可能采用自己的显示路径；无界面审计只验证原生渲染接线，不代表已验证光影画面。

## 天气和睡眠

```mcfunction
/gamerule doWeatherCycle true
/time set 750000
```

这是第 32 天白天：等待约 100 刻，应逐渐进入来源强制雷暴。沙漠也能下雨、接雨的炼药锅可积水；实心屋顶仍能遮雨。雪地保持雪，不被强行变成降雨雷击气候。闪电是随机事件，不要求每个测试点立刻落雷。

白天应看到血红天空和云；执行 `/time set 757000`、`/time set 762000` 后，雨幕和雨声应在约100刻内消退，夜间仍可打雷并生成真实闪电，露天炼药锅不再接雨。13000～23000（包含端点）共用原月相夜间定义；`/time set 767001` 进入黎明，恢复降雨目标，`/time set 768000` 进入下一天才释放血月覆盖。尝试使用床，应有血月不能入睡的提示，仍能设置重生点。第 128 天 `/time set 3066000` 的蓝月夜可正常睡眠；普通怪物距离和床本身的原生限制仍有效。测试实际跳夜时需重新开启 `doDaylightCycle`。

自然天气循环开启时，`/weather` 会被来源排程重新设置；非血月需要固定晴天看月亮时可关闭 `doWeatherCycle`。血月即使关闭天气循环，`/weather clear` 也会在下一次正常天气更新被雷暴覆盖；退出血月后恢复原来的冻结天气。天气排程的世界创建时间种子适配为现代世界种子，具体雨日不宣称与旧版相同种子一致。

## 作物、生物与钓鱼

- **单人集成服务器**：先种有水的小麦、胡萝卜、马铃薯或洋葱，包含成熟作物；到血月夜观察随机染病。来源为每次相关随机刻 25%，不是每刻、也不保证所有作物同时感染。密封实心遮蔽可保护；玻璃和树叶不等于实心不透明保护。骨粉能治尚未死亡的病株，不能复活死株。活病马铃薯收获为一枚毒马铃薯，死亡和爆炸没有收获。
- **独立服务器**：R196 原始实现明确关闭血月额外 25% 感染，保留这一模式差异；已有其他病害来源仍有效。本轮没有重写普通原版作物的完整气候、旱死及健康未熟马铃薯产出。现代甜菜作为当前 `CropBlock` 共享病害适配纳入，不假称旧版已有甜菜。
- 血月夜现有怪物生成及狂暴继续有效；蓝月夜减少户外敌对生成，但不会清除已有怪物，也不禁止遮光地下怪物。蓝月动物生成仍受动物上限、距离及场地资格约束。
- 恐狼蓝月夜停止额外随机主动攻击和低吼；已有复仇不被清除。普通狼的失败驯服不会因蓝月额外反击，但不保证驯服成功。蓝月鱿鱼停止来源猎物路径，白天恢复；不能据此断言鱿鱼任何接触均无伤害。
- 在合格水域钓鱼，蓝月夜的来源咬钩分母为 600，之后仍计算降雨、钓鱼幸运和快捷栏虫饵；不是立即咬钩或保证高级战利品。边界和概率由自动回归验证。
- 收获月没有源码支持的额外产量或加速生长，不添加此奖励。

若需长时观察，可临时 `/tick rate 200`，结束恢复 `/tick rate 20`。测试后恢复原来的时间、天气和游戏规则。此前交付已由用户确认；本次夜间停雨保留雷暴的改动待实机复核。多人分别观察、实际关服重进和逐项光影/扩展模组组合结果未另行提供，后续仍可按本清单复核。
