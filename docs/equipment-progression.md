# 武器、工具与防具成长

开发者：NingMeng123。适用 Minecraft 1.21.1 / NeoForge 21.1.259。

## 成长规则

物品初始为0级，等级、级内经验和成长副词条独立保存于 `mite:gear_progress` 数据组件，包含格式版本和物品UUID。成长不消耗、不替代玩家经验。创造和旁观模式不获取成长经验。

当前等级为L时，升到下一级所需经验为 `100 × (L + 1) × (1 + floor(L / 5))`。0→1需100点，4→5需500点，5→6需1200点，10→11需3300点，20→21需10500点；0→25累计122500点。经验按千分之一点保存，一次奖励可以连续升级，每级独立随机抽取一条奖励。满级不再积累经验。

| 材质或系列 | 等级上限 |
| --- | ---: |
| 铜、银、锈铁、金、皮革、木、石、燧石、黑曜石 | 5 |
| 铁、远古金属 | 10 |
| 秘银、Simply Swords钻石系列 | 15 |
| 艾德曼、下界合金、符文系列、三叉戟、重锤 | 20 |
| 振金、Simply Swords独特武器 | 25 |

强化弓、盾牌与链甲按实际材质；普通弓、弩按木质5级。已移除的原版钻石装备不会恢复。钓竿、鞘翅和马铠不参与本系统。

## 经验来源

| 行为 | 奖励 |
| --- | --- |
| 武器击杀非玩家生物 | 目标最大生命值向上取整，包括动物和村民 |
| 适用工具实际破坏未标记为玩家放置的方块 | `ceil(2 × H × (1 + T / 2))`，H为现有采掘有效硬度，T为最低采集等级；H≤0无奖励 |
| 锄头或镐锄成功把方块变为耕地 | 每块12点，自己铺土和踩回泥土后重复锄地也可获得 |
| 玩家有效承受伤害 | 盾牌和无敌帧处理后、护甲减伤前伤害×4，按受击时穿戴的可成长防具均分 |
| 盾牌成功格挡 | 实际格挡伤害×2，奖励给执行格挡的盾牌 |

普通锄头严格只通过耕地升级；镐锄可以挖掘和耕地；斧、短斧、战斧、战锤和MITE镰刀可以采集和击杀。剑、匕首、棍棒、Simply Swords武器及弓弩、三叉戟、重锤通过击杀升级。采集检查工具适用性和方块真实移除结果，预测、取消和失败不奖励。

护甲完全吸收仍按减伤前伤害奖励，盾牌全挡不奖励护甲；取消、无敌和冷却拒绝不奖励护甲。均分余数按头、胸、腿、脚顺序分配，满级护甲的份额丢弃。远程击杀通过UUID定位原武器，切换手持物不转移经验；库存中找不到原弓弩或存在重复UUID时跳过奖励。可回收长矛和三叉戟直接更新实体携带的真实武器。能明确追溯至同一玩家原武器的短时延迟死亡可结算；宠物、其他实体补刀不借用此前武器。

## 独立副词条

每升一级，等概率抽取该物品适用的一条附魔，并给相应副词条增加一级。诅咒和经验修补不进入副词条池，普通附魔中的经验修补保持原有行为；其他宝藏附魔可抽取，已有普通附魔和副词条不限制候选互斥关系。适用性包含当前附魔书规则中的皮革耐久特例。词条等级可以超过原附魔最高等级。原版与MITE现有附魔接入效果桥；未知第三方自定义效果需要显式适配后才能进入随机池。

普通附魔与副词条分别计算属性后相加，绝不将非线性效果直接按等级之和计算。效率III的+10和成长效率II的+5合计+15。基础值只计一次；两来源概率之和最多100%，只进行一次触发判断。开关行为执行一次，燃烧和状态等数值先相加再应用一次。精准和时运可共存，掉落保持已有精准优先规则。

副词条不写入普通 `minecraft:enchantments` 组件，附魔台、附魔书、铁砧费用与磨损、砂轮和祛魔瓶仍只处理普通附魔。悬停信息独立显示等级、经验和副词条。

## 保存与维护

成功放置的方块来源记录保存在区块附件中，支持多方块放置、活塞和下落搬运，方块移除后清理记录。已有矿石的 `PLACED` 标记继续生效。其他旧存档中已经放置但没有历史记录的方块无法追溯，按未标记方块处理。限制排除所有玩家放置的方块，不能通过另一名玩家代放绕过。

修理、改名、染色、盾牌装饰、砂轮和祛魔保留成长；两件装备合并只保留第一件成长，不合并副词条。锻造和振金升级继承成长，按新材质上限继续升级，不重新抽取已有等级。不可用附魔ID作为原始ID保留，暂不产生效果，不重抽或删除。

仅成长数据变化时保持手持姿态与连续采掘；换槽、改名、耐久、普通附魔等其他变化仍按原行为处理。发射后的投射物保留发射时附魔快照，后续升级不倒改已发射投射物效果。

## 验证

纯规则测试覆盖经验台阶、材质上限、伤害精度与溢出、非线性概率叠加；GameTest覆盖真实成长、数据与网络往返、维护菜单、独立候选、实际原版/MITE附魔效果，以及采集、耕地、护甲、盾牌、远程和延迟击杀。可通过 `build`、`runGameTestServer` 和客户端审计运行验证，成长专用GameTest命名空间为 `mite_gear`；自动审计不替代实际客户端视觉体验确认。
