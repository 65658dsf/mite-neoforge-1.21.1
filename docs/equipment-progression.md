# 武器、工具与防具成长

开发者：NingMeng123。适用 Minecraft 1.21.1 / NeoForge 21.1.259。

## 成长规则

物品初始为0级，等级、级内经验和成长副词条独立保存于 `mite:gear_progress` 数据组件，包含格式版本和物品UUID。成长不消耗、不替代玩家经验。创造和旁观模式不获取成长经验。

装备经验使用 MITE-ITE 2.0.28 的线性公式，以当前等级L计算。工具为 `基础值＋L×增量×(武器?2:1)`，基础值不翻倍；防具为 `(基础值＋L×增量)×部位系数`，头、胸、腿、脚分别乘2、4、3、1。

| 材质 | 工具基础 / 增量 | 防具基础 / 增量 |
| --- | --- | --- |
| 铜、银 | 100 / 50 | 16 / 8 |
| 金 | 125 / 60 | 18 / 9 |
| 铁、远古金属 | 150 / 75 | 20 / 10 |
| 秘银 | 200 / 100 | 24 / 12 |
| 艾德曼 | 200 / 120 | 28 / 14 |
| 振金 | 200 / 150 | 32 / 16 |
| 其他现代材质、皮革、木、石等 | 150 / 75 | 150 / 75 |

保存仍以千分之一点为单位以兼容原有数据，但新奖励只入账整数经验。一次入账最多升级一级，达标后级内经验直接清零，超出部分不保留；每次实际升级在有候选时必抽一阶副属性。旧存档等级和经验原样保留，不补发或重算历史等级。等级上限仍遵守本次用户要求，不移植旧版耕地可绕过上限的漏洞。

| 材质或系列 | 等级上限 |
| --- | ---: |
| 未安装 Modern ITE 的所有可成长装备 | 25 |
| 安装 Modern ITE 的工具、武器及现代适配装备 | 15＋锻造等级 |
| 安装 Modern ITE 的防具 | 材质最低采集等级×3＋锻造等级 |

本体没有锻造台，所有已支持装备直接拥有25级成长上限，不需要锻造解锁。安装 Modern ITE 后通过已有扩展策略读取其锻造组件；本体不依赖 ITE 类。已移除的原版钻石装备不会恢复。钓竿、鞘翅和马铠不参与本系统。

## 经验来源

| 行为 | 旧版来源奖励（锻造加成前） |
| --- | --- |
| 武器对非玩家生物的真实主近战命中并扣血 | `floor(min(目标最大生命, 实际扣血×倍率))`；战斧攻击大地元素倍率10，其他1 |
| 镐及泛用工具有效采集 | 方块原始材质最低采集级；常见石质与矿石为2，不能使用矿物自身的采集门槛代替 |
| 斧、短斧、战斧有效采集 | 原木2；其他`max(材质最低采集级,1)` |
| 铲、镐锄、镰刀有效采集 | 分别3、2、1 |
| 锄头有效收获成熟作物 | 8；其他普通路径0 |
| 锄头或镐锄成功耕地 | 1 |
| 实体来源攻击触发护甲实际随机磨损分配 | 每个选中护甲的随机portion分别入账2，再由护甲外层乘2；未锻造时最终4点/portion |

剑、匕首、小刀、战斧、战锤使用旧武器判据；Simply Swords、三叉戟、重锤的主近战按现代同类适配。普通斧、短斧、镰刀、棍棒不因攻击获得经验。没有击杀额外奖励、投射物/延迟死亡奖励或盾牌格挡奖励；弓弩和盾牌保留已有成长数据，但不再人为添加旧版不存在的经验来源。

采集要求真实破坏成功、有效工具、正硬度、非便携拿取且非剑家族。玩家放置的方块照样参与经验奖励；取消、预测及破坏失败不结算。现代成熟作物已有正硬度，因此锄头成熟8点分支可用，零硬度初始幼苗仍无采集经验。副属性“地质学”的放置矿石经验限制独立保留。

护甲沿用原版随机损耗分配，同一次受击可能多次选中同一件，每个portion分别入账，空槽不奖励，不按穿戴件数均分。旧版的 `result.healthLost` 在这个调用时点尚未写入，为0，经过 `floor(clamp(0,1,4))×2` 得到原始输入2；不能用最终实际掉血替代。环境伤害无责任实体、取消/无敌拒绝、未实际走护甲损耗路径均不奖励。非旧材质的现代护甲在原生护甲损耗事件中按实际被损耗件适配一次。

未安装ITE时无锻造经验加成。安装ITE后，工具实际入账 `int(float(raw整数经验)×(1＋bonus))`，`bonus=(0.05f＋锻造等级×0.05f)×锻造等级÷2`；护甲在上述整数截断完成后再乘2。保留旧float运算与截断顺序，例如锻造1阶的60点输入得到62点，不使用double近似得63点。零锻造护甲每portion最终4点；锻造4阶为6点。

## 独立副词条

新升级使用 MITE-ITE 2.0.28 的独立修饰池：工具8项、防具9项，名称、权重、属性等级上限与部位限制均按参考JAR。每级直接抽取一次，不再执行25%基础概率加每级3个百分点的成功判定，也不再枚举附魔注册表。抽中概率为该项权重除以当前有效候选总权重；已有未满级项仍可抽中并加一阶，没有优先新词条或稀有保底。满级项立即退出；同一件防具的普通、火焰、爆炸、弹射物保护彼此互斥。每次升级重新构建候选池，空池仍可正常升级。完整表见 [副词条权重](equipment-affix-weights.md)。

新修饰使用 `mite:modifier/tool/*`、`mite:modifier/armor/*` ID，保存在既有 `gear_progress.affixes` 映射中，数据格式仍为version 1。与历史附魔ID完全隔离；旧装备已有附魔型副词条和未知ID原样保留，通过既有效果桥继续生效，不自动转换、删除、重抽或补发历史奖励。后续升级只添加独立修饰。普通附魔不占用新修饰上限，也不影响保护修饰组的互斥。

旧附魔型副词条与普通附魔继续分别计算后相加；新修饰通过独立的战斗、采掘、耐久和状态效果入口生效。例如新“急速”的每阶0.25加在材质采集效率上，不按原版效率附魔公式计算；新“耐久”减少实际损耗，不增加耐久上限。新修饰不受附魔启停/最高等级配置控制。

副词条不写入普通 `minecraft:enchantments` 组件，附魔台、附魔书、铁砧费用与磨损、砂轮和祛魔瓶仍只处理普通附魔。悬停信息独立显示等级、经验和副词条。

## 保存与维护

盾牌成功格挡的累计伤害或次数达到当前材质的上限时，会强制破盾100tick（5秒）并清空负荷。铜、银、锈铁为基础档，每提高一个材质档位，次数上限增加2次，伤害上限按次数同比例增加：`25 × 次数上限 / 3`，计算保留小数。

| 盾牌材质 | 累计伤害上限 | 格挡次数上限 |
| --- | ---: | ---: |
| 铜、银、锈铁、金 | 25 | 3 |
| 铁、远古金属 | 125/3（约41.67） | 5 |
| 秘银 | 175/3（约58.33） | 7 |
| 艾德曼 | 75 | 9 |
| 振金 | 275/3（约91.67） | 11 |

原版 `minecraft:shield` 按铁盾处理；未适配材质的第三方盾牌使用基础档。阈值按盾牌材质选择，不随经验等级、品质或附魔改变。两项阈值独立，任一达到即触发；低于3点的小伤害也计次，取消、后方命中和零格挡伤害不计。触发阈值的这次攻击仍正常格挡、消耗耐久，随后盾牌暂时不可用；格挡不再提供装备经验。玩家和持盾怪物均适用；玩家所有金属盾一起冷却，不能在破盾后切换材质绕过。普通放下、重新举盾、换手不会清空同一面盾的负荷，计数随物品保存和维修；旧版已保存的负荷原样保留，保存格式继续使用version 1。斧头造成的原有破盾仍生效并清空负荷。悬停提示保持隐藏，不添加相关翻译。

成功放置的方块来源记录保存在区块附件中，支持多方块放置、活塞和下落搬运，方块移除后清理记录。已有矿石的 `PLACED` 标记继续生效。其他旧存档中已经放置但没有历史记录的方块无法追溯，按未标记方块处理。该记录继续供其他机制使用，旧版装备经验不再排除玩家放置方块。

修理、改名、染色、盾牌装饰、砂轮和祛魔保留成长；两件装备合并只保留第一件成长，不合并副词条。锻造和振金升级继承成长，按新材质上限继续升级，不重新抽取已有等级。不可用附魔ID作为原始ID保留，暂不产生效果，不重抽或删除。

仅成长或盾牌负荷数据变化时保持手持姿态，连续采掘仅忽略成长变化；换槽、改名、耐久、普通附魔等其他变化仍按原行为处理。发射后的投射物保留发射时附魔快照，后续升级不倒改已发射投射物效果。
