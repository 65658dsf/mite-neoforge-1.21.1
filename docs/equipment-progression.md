# 武器、工具与防具成长

开发者：NingMeng123。适用 Minecraft 1.21.1 / NeoForge 21.1.259。

## 成长规则

物品初始为0级，等级、级内经验和成长副词条独立保存于 `mite:gear_progress` 数据组件，包含格式版本和物品UUID。成长不消耗、不替代玩家经验。创造和旁观模式不获取成长经验。

装备升级门槛采用用户批准的Excel新梯度：工具和盾牌为`100＋50L`，武器为`150＋100L`，防具为`(20＋10L)×部位系数`，头、胸、腿、靴分别乘2、4、3、1。不乘材质门槛倍率，也不再使用0.2.4每五级跳档的统一阶梯曲线。2026-10-21 将护甲受击原始总经验由有效伤害×4改为×1；2026-10-22 再按用户要求，将所有装备新获取的成长经验在当前基础上统一削减50%。千分精度、余量连升、每级必抽独立副属性及本体25级／ITE锻造等级上限约定保留，不重算旧存档经验或改变升级门槛。

这里的L是装备当前等级，初始为0；经验条右侧分母是本级升至下一级所需的点数，不是玩家等级、累计升级总经验或内部保存的千分单位。判定升级和悬停显示共用同一个按类别及护甲部位读取的入口，同类别不同材质门槛相同。

| 类别 | 本级门槛 | 0→1 | 24→25 | 0→25累计 |
| --- | --- | ---: | ---: | ---: |
| 工具、盾牌 | `100＋50L` | 100 | 1300 | 17500 |
| 武器 | `150＋100L` | 150 | 2550 | 33750 |
| 头盔 | `(20＋10L)×2` | 40 | 520 | 7000 |
| 胸甲 | `(20＋10L)×4` | 80 | 1040 | 14000 |
| 护腿 | `(20＋10L)×3` | 60 | 780 | 10500 |
| 靴子 | `20＋10L` | 20 | 260 | 3500 |

弓、弩、棍棒和Simply Swords武器使用武器门槛；普通斧、短斧和本体镰刀使用工具门槛。经验门槛分类独立于副属性候选池的武器判据，不改变已有候选、权重或采掘动作。

经验按千分之一点保存，奖励和护甲均分保留小数整经验。升级扣除本级门槛并保留余量，同一次入账可以连续升级；每级都重新构建候选池，有候选时必抽一阶独立副属性。只有达到等级上限后才清空剩余经验。旧存档等级、经验和副词条原样保留，不补发或重算历史等级。

| 材质或系列 | 等级上限 |
| --- | ---: |
| 未安装 Modern ITE 的所有可成长装备 | 25 |
| 安装 Modern ITE 的工具、武器及现代适配装备 | 15＋锻造等级 |
| 安装 Modern ITE 的防具 | 材质最低采集等级×3＋锻造等级 |

本体没有锻造台，所有已支持装备直接拥有25级成长上限，不需要锻造解锁。安装 Modern ITE 后通过已有扩展策略读取其锻造组件；本体不依赖 ITE 类。已移除的原版钻石装备不会恢复。钓竿、鞘翅和马铠不参与本系统。

## 经验来源

| 行为 | 当前奖励（未安装ITE） |
| --- | --- |
| 合法武器击杀非玩家生物 | `ceil(目标最大生命)÷2`；归属实际攻击武器，单次死亡只奖励一次 |
| 有效工具成功采集未被玩家放置的方块 | `ceil(2 × 有效硬度 × (1＋采集门槛÷2))÷2`，除法保留小数；采集门槛取方块要求，不使用原始材质级代替 |
| 锄头或镐锄成功耕地 | 6 |
| 玩家受击完成 | 原按有效伤害×1均分，再将每件入账减半，保留千分经验 |
| 盾牌成功格挡 | 实际格挡伤害×1 |

减半只在统一入账入口执行一次：先按原公式计算千分单位，经可选ITE锻造加成后再整除2，舍去不足0.001点的部分，不按整数经验点截断。所有来源共用这一步，玩家经验不受影响；已有等级、经验、UUID和副词条不变。

击杀沿用0.2.4的近战、远程及投掷武器归属。投射物记录发射时的原武器UUID；玩家换手后不会把奖励转给当前手中物品。环境造成的延迟死亡只在100 tick内仍有原版玩家击杀归属、且能唯一找回原武器时奖励，其他生物或宠物不借用玩家的历史命中。普通未致死近战不单独按扣血发经验。

采集要求真实破坏成功、有效工具和正硬度；玩家放置的方块、取消、预测及破坏失败不结算。不同工具不再使用低版固定1／2／3／8点分支，成熟作物按同一硬度公式计算，零硬度初始幼苗无采集经验。副属性“地质学”的放置矿石限制继续独立保留。

护甲经验与随机耐久portion分配分开。有效伤害取格挡和无敌帧处理后、护甲减伤前的伤害，不是最终实际扣血；完成受击后先按有效伤害（×1）构成原始经验池，再按参与成长的人形护甲件数均分，每件入账时应用各自的ITE加成并统一减半。原始分配的千分单位余数按头、胸、腿、脚的顺序补齐。已满级但仍属可成长类型的护甲继续计入均分件数，其份额由满级检查丢弃，不转给其他部位。取消或无敌拒绝的受击不奖励，不读取旧版尚未写入的 `result.healthLost` 或对每个耐久portion重复发奖。

例如零锻造、同时穿四件可成长护甲，每次有效伤害5点时，原始经验池为5点，最终每件获得0.625点。升级门槛未改，头、胸、腿、靴从0到25级分别约需11200、22400、16800、5600次这样的受击。该估算保留满级件继续占分母的现有规则，不假设靴子满级后会加速胸甲升级；击杀、采集、耕地和盾牌格挡也统一减半。

未安装ITE时无锻造经验加成。安装ITE后，保留0.2.4的double公式 `原始千分经验 × (1＋0.025×锻造等级×(锻造等级＋1))`，仅截去不足一个千分单位的部分，不截去小数整经验；工具和护甲使用相同加成，护甲不额外乘2，再统一将最终入账减半。例如锻造1阶原始1点最终得到0.525点、原始60点得到31.5点，10阶原始1点得到1.875点。此前新增的锻造经验加成悬停行仍已撤销。

## 独立副词条

新升级使用 MITE-ITE 2.0.28 的独立修饰池：工具8项、防具9项，名称、权重、属性等级上限与部位限制均按参考JAR。每级直接抽取一次，不再执行25%基础概率加每级3个百分点的成功判定，也不再枚举附魔注册表。抽中概率为该项权重除以当前有效候选总权重；已有未满级项仍可抽中并加一阶，没有优先新词条或稀有保底。满级项立即退出；同一件防具的普通、火焰、爆炸、弹射物保护彼此互斥。每次升级重新构建候选池，空池仍可正常升级。完整表见 [副词条权重](equipment-affix-weights.md)。

新修饰使用 `mite:modifier/tool/*`、`mite:modifier/armor/*` ID，保存在既有 `gear_progress.affixes` 映射中，数据格式仍为version 1。与历史附魔ID完全隔离；旧装备已有附魔型副词条和未知ID原样保留，通过既有效果桥继续生效，不自动转换、删除、重抽或补发历史奖励。后续升级只添加独立修饰。普通附魔不占用新修饰上限，也不影响保护修饰组的互斥。

旧附魔型副词条与普通附魔继续分别计算后相加；新修饰通过独立的战斗、采掘、耐久和状态效果入口生效。例如新“急速”的每阶0.25加在材质采集效率上，不按原版效率附魔公式计算；新“耐久”减少实际损耗，不增加耐久上限。新修饰不受附魔启停/最高等级配置控制。

副词条不写入普通 `minecraft:enchantments` 组件，附魔台、附魔书、铁砧费用与磨损、砂轮和祛魔瓶仍只处理普通附魔。悬停信息独立显示等级、经验和副词条。

## 保存与维护

盾牌成功格挡的累计伤害或次数达到当前材质的上限时，会强制破盾100tick（5秒）并清空负荷。铜、银、锈铁为基础档，每提高一个材质档位，次数上限增加2次，伤害上限按次数同比例增加：`25 × 次数上限 / 3`，计算保留小数。

| 盾牌材质 | 累计伤害上限 | 格挡次数上限 |
| --- | ---: | ---: |
| 铜、银、锈铁、金 | 25 | 3 |
| 铁、远古金属 | 125/3（约41.67） | 5 |
| 秘银 | 175/3（约58.33） | 7 |
| 艾德曼 | 75 | 9 |
| 振金 | 275/3（约91.67） | 11 |

原版 `minecraft:shield` 按铁盾处理；未适配材质的第三方盾牌使用基础档。阈值按盾牌材质选择，不随经验等级、品质或附魔改变。两项阈值独立，任一达到即触发；低于3点的小伤害也计次，取消、后方命中和零格挡伤害不计。触发阈值的这次攻击仍正常格挡、消耗耐久，随后盾牌暂时不可用；成功格挡先按实际格挡伤害×2计算原始经验，再统一减半入账，未安装ITE时最终为伤害×1。玩家和持盾怪物均适用；玩家所有金属盾一起冷却，不能在破盾后切换材质绕过。普通放下、重新举盾、换手不会清空同一面盾的负荷，计数随物品保存和维修；旧版已保存的负荷原样保留，保存格式继续使用version 1。斧头造成的原有破盾仍生效并清空负荷。悬停提示保持隐藏，不添加相关翻译。

成功放置的方块来源记录保存在区块附件中，支持多方块放置、活塞和下落搬运，方块移除后清理记录。已有矿石的 `PLACED` 标记继续生效。其他旧存档中已经放置但没有历史记录的方块无法追溯，按未标记方块处理。该记录供装备采集经验及其他来源限制使用，玩家放置方块不奖励采集经验。

修理、改名、染色、盾牌装饰、砂轮和祛魔保留成长；两件装备合并只保留第一件成长，不合并副词条。锻造和振金升级继承成长，按新材质上限继续升级，不重新抽取已有等级。不可用附魔ID作为原始ID保留，暂不产生效果，不重抽或删除。

仅成长或盾牌负荷数据变化时保持手持姿态，连续采掘仅忽略成长变化；换槽、改名、耐久、普通附魔等其他变化仍按原行为处理。发射后的投射物保留发射时附魔快照，后续升级不倒改已发射投射物效果。
