# 怪物随日期成长

开发者：NingMeng123。日期：2026-10-16。

## 计算公式

令 `D` 为存档曾经到达的最高主世界天数，从第 1 天开始；各维度读取同一日期。令 `N = max(D - 1, 0)` 为从新存档出生起经过的完整天数。调回时间不会降低进度。

```text
q = floor(N / 32)
r = N % 32
生命倍率 = 1.16^q × (1 + 0.005 × r)
基础攻击倍率 = 1.08^q × (1 + 0.0025 × r)
最终生命上限 = min(1024, 未计日期成长的生命上限 × 生命倍率)
近战基础攻击 = 原始本体基础攻击 × 基础攻击倍率
本次近战攻击 = 先使用成长后的基础攻击，再加入当前手持武器与其余原生修饰
```

每 32 天重新确定基准，段内按固定基准线性增加：生命每天增加该段基准的 0.5%，基础攻击每天增加该段基准的 0.25%。一段结束分别增长 16% 和 8%，下一段使用这份新数值。周期按经过天数计算，包括蓝月日期，不取决于实际血月次数。1024 是 1.21.1 原生最大生命属性的限制。

低血量骷髅例外：初始生命不变，增长量以至少 20 点生命为基准。令 `H0` 为未计日期成长的当前生命上限，骷髅使用 `min(1024, H0 + max(H0, 20) × (生命倍率 - 1))`。普通 6 血骷髅即 `6 + 20 × (生命倍率 - 1)`；虚拟的 20 点增长基准也随每段结算增长。此规则不改变其攻击伤害基准。

| 最高天数 D | 已过天数 N | 基础 20 血怪物 | 初始 6 血骷髅 | 基础攻击倍率 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0 | 20 | 6 | 1 |
| 33 | 32 | 23.2 | 9.2 | 1.08 |
| 65 | 64 | 26.912 | 12.912 | 1.1664 |
| 97 | 96 | 31.21792 | 17.21792 | 1.259712 |
| 321 | 320 | 88.22870 | 74.22870 | 2.158925 |

例如本体基础攻击为 3，当前武器增加 6：经过 32 天后为 `3 × 1.08 + 6 = 9.24`；经过 64 天后为 `3 × 1.1664 + 6 = 9.4992`。武器增加的 6 不会加入下一段的成长基准。其他属性、状态、附魔及目标护甲、韧性、抗性继续按原生流程处理。

原生 `Mob.doHurtTarget` 在独立属性副本中先成长本体基础值，再读取含当前装备与其他修饰的结果。作用域结束后恢复，不修改实际基础属性或装备属性；该次伤害也不会在公共入口再次放大。因此直接查看原生攻击属性仍看到未计日期成长的属性值。其他攻击，如怪物射出的箭、法术、有明确怪物归属的爆炸及不经过该原生近战方法的接触伤害，在 `LivingIncomingDamageEvent` 减伤前使用自己的本次伤害乘基础攻击倍率。这些伤害不把手持工具的近战属性加入基准。环境伤害、无归属爆炸、玩家和动物造成的伤害不增加。无攻击者归属的后续着火、毒素等状态伤害保留原处理。

## 生效和保存

- 范围包括原版和 MITE 的 `MONSTER` 分类，以及 MITE 的敌对蝙蝠。原版蝙蝠、普通动物、凶狼、村民和玩家不参与。
- 加入世界时立即计算生命，每只存活怪物每 20 刻检查一次日期变化。已有个体会继续成长。
- 用一个固定 ID 的最大生命乘法修饰符，与首领属性等原有生命修饰组合。重复更新、重载和跨维度不叠加倍数。
- 生命上限提升时保留原有生命比例；新生满血仍满血，受伤个体不会因此变成满血。存档首次接入此规则也按原生命比例处理。
- 实际攻击使用攻击发生时的最高历史日期，不等待下一次生命更新。
- 日期、版本和生命修饰符随原生 NBT 保存。血月装备材质依旧只在新生时选择，和本节的存活个体属性成长是两套规则。

## 手动测试

请先在新测试存档观察早期个体，再推进日期；最高历史日期不能通过调回时间降低。

1. 第 1 天生成一只没有首领属性的普通僵尸，记录其生命和无护甲目标受到的伤害。
2. `/time set 774000` 到第 33 天白天（经过 32 天），在阴影下观察原有目标，约一秒内生命上限应成长。基础 20 生命的个体应为 23.2；Jade 可能按显示设置取整。
3. 此时本体攻击倍率为 1.08。给同一怪物换上武器，武器增加的伤害不乘 1.08；护甲减伤仍照常。
4. 打伤目标后记录当前生命比例，保存重进；同一天当前生命不应重置或重复成长。推进到更晚日期，生命上限提高并保持伤情比例。
5. 查看骷髅箭和苦力怕爆炸造成的伤害随日期增加；爆炸方块破坏半径不会因本节的伤害倍率自动增加。
6. 另开新存档在遮光处生成普通骷髅，确认初始为 6 血；`/time set 774000` 后约一秒内应为 9.2 血，再 `/time set 1542000` 到第 65 天（经过 64 天）应为 12.912 血。初始 6 血不变，只有增长量使用 20 的基准。
