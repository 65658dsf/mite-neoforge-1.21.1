# 0.2.16 追击与怪物装备修复

开发者：NingMeng123

日期：2026-10-27

## 文件与兼容

- 本体：`mite-0.2.16.jar`，包内模组 ID 为 `mite`，版本为 0.2.16。
- 配套附属继续使用 `modern-ite-0.2.15.jar`。其本体依赖范围为 `[0.2.15,)`，兼容本次版本，既有装备扩展 API 保留。
- Minecraft 1.21.1、NeoForge 21.1.259 或兼容的 21.1.x、Java 21。

## 本次修改

- 卫道士、劫掠兽等原版地面近战怪物接入增强追击，保留物种原有攻击任务、冷却与开门能力。
- 已在追击的怪物受到另一名合法玩家有效伤害时可转火，取消旧目标尚未命中的攻击，保留已消耗的攻击恢复时间。
- 卫道士主动索敌范围基础值至少 32 格，旧存档也修复；更大的自定义范围、原有修正与首次视线要求保留。掠夺者失去弩后可使用近战，重新持弩后恢复原生远程任务。
- 完全取消早期出生禁装备，保留各物种原生装备、生成概率和隐藏备用武器。旧禁装标记在入场时退役，仅修复明确缺失的弩、铁斧或真实弓手的普通弓，保留已有装备及缴械状态。

详细规则见[追击路线](zombie-route-ai.md)、[索敌与转火](monster-targeting-melee-035-evidence.md)及[装备规则](blood-moon-equipment.md)。

## 验证

行为修复已通过 1,770 项 JUnit；普通模式、Better Combat 2.4.0 模式各 206 项必需 GameTest；实际 Modern ITE 0.2.15 下 18 项自然索敌、真实旧档加载与装备兼容 GameTest。日志及场景见[本次验证记录](testing/gameplay-adjustments-2026-10-27.md#后续取消禁装备与主动索敌验证)。

正式 0.2.16 已重新完成构建及 1,770 项 JUnit。与上述已验收修复包逐项比较，所有游戏类和资源完全一致，仅 `META-INF/neoforge.mods.toml` 的本体版本从 0.2.15 更新为 0.2.16；31 个改动后的主类及内部类与实际编译输出一致，未混入 GameTest 类。

正式产物为 `build/libs/mite-0.2.16.jar`，9,891,190 字节，SHA-256 为 `086683f00d4c531e54d005b9090298b080ca40f9ab5cc75a1ad767e9c1672260`。构建日志及逐项校验记录在 `build/verification/release-0.2.16/`。未进行实际客户端双人联机手测。

## 安装

退出游戏并关闭服务器后，替换旧本体为 `mite-0.2.16.jar`；客户端和服务端使用相同本体版本，每种模组只保留一份。已安装的 Modern ITE 0.2.15 可继续使用。
