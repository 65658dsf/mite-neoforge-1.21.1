# 篝火燃料与生存规则

开发者：NingMeng123。此项为用户指定的现代篝火调整，同时适用于普通篝火和灵魂篝火，不作为 R196 来源规则记载。

2026-10-16：最终构建已通过 1455 项 JUnit、1560 项服务端 GameTest。用户对包含篝火和液体桶调整的交付版本反馈“可以了提交吧”，授权提交；本页保留复测步骤，不补写逐项手测结果。

## 燃料、点火与烤肉

| 项目 | 行为 |
| --- | --- |
| 新放置 | 熄灭、0 点燃料 |
| 最大储量 | 3 点，包含正在燃烧的一点 |
| 每点寿命 | 最多 900 刻，即正常 20 TPS 下 45 秒；空烧也计时 |
| 每点产量 | 最多烤熟 2 块肉；计时到期或烤满 2 块，先满足者消耗当前一点 |
| 烹饪 | 同时最多 2 块，每块 300 刻，即 15 秒 |
| 打火石 | 消耗一次工具耐久，点燃并补至最多 3 点；满且已燃烧时不消耗 |
| 普通/灵魂火把 | 消耗一根，补 1 点并点燃；红石火把不适用 |
| 木制燃料 | 原木、木板、木制方块、木棍、木碗和可燃木工具等，每次消耗一件、补 1 点，不自动点燃 |
| 熄灭后 | 添加木制品只储存燃料，须用打火石或火把重新点燃 |
| 补燃 | 不刷新当前一点的剩余寿命和已使用的烤肉配额 |

例如，3 点燃料完全空烧最多维持 135 秒；持续同时烤两块肉，则每 15 秒消耗一点，最多烤 6 块。单块先后烤制也共享同一点的两块配额，不能通过反复取放、灭火、补燃或重载刷新。

支持原版牛肉、猪肉、羊肉、鸡肉、兔肉、鳕鱼、鲑鱼，以及 MITE 大鱼和虫子。动物性食材仍须有有效的篝火烹饪配方且炉温要求不超过 1。土豆、面团、海带、矿石等不能在篝火加工；熔炉和烟熏炉的既有规则不变。可通过 `mite:campfire_meats` 标签接入其他模组的生肉/鱼。

原版烹饪配方的实际显示时间也改为 300 刻，非肉篝火配方被禁用，因此 JEI 不会继续展示篝火烤土豆、面包或海带。JEI 与 Jade 均保持可选扩展。

## 熄火与环境

- 暴露于雨水立即熄灭；有有效屋顶遮雨时不受影响。浸水、铲灭、燃料耗尽同样会中断烤肉。
- 未完成的肉按原物品与原组件掉落，烹饪进度归零；肉已在篝火内按生肉存储，不会先转换为熟肉再倒退。剩余燃料及其已用配额保留。
- 燃烧亮度为 10，熄灭为 0；普通冰不会被篝火本身的光照融化。霜冰的原版自然消退规则保留。
- 3 格内每秒清除玩家冻结积累，作为现有粉雪冻结机制下的保暖效果；没有新增体温条。
- 周围 1 格内存在可燃木材或干草时，每秒有 `1/60` 的引燃尝试概率。在可燃物相邻、可放火的空气格生成原版火焰，遵守 `doFireTick`、雨水和区块加载条件，后续蔓延遵守原版规则。
- 16 格内可见火光会吸引使用普通寻路 AI 的闲置怪物；它们走到火外约 2 格停留。有战斗目标、正在着火、浸水或火源熄灭时不继续调查。不会因此额外生成怪物。
- 原版篝火烟雾继续安抚蜜蜂。精准采集不再获得完整篝火：普通篝火掉 2 木炭，灵魂篝火掉 1 灵魂土，爆炸仍遵从原版爆炸掉落概率。

燃料状态随方块实体保存并同步。旧格式、已燃烧篝火首次加载得到最多 3 点初始燃料；新版燃料耗尽后的存档不再回补。结构自然生成的燃烧篝火也只获得这一次初始储量。发射器打火石保留原版点火能力，但不额外补充燃料；零燃料篝火不能因此持续燃烧。

## 手动测试

重新启动客户端加载代码，正常测试保持 `/tick rate 20`。建议在石头平台进行烹饪测试，避免起火影响木制建筑。

1. 放置两种篝火，应均为熄灭状态。右键放入一块木板，应只增加 1 点而不点燃；用打火石右键，应点燃且补至 3 点、扣一次耐久。Jade 可查看燃料、当前一点剩余秒数及还能烤的肉数。
2. 放入两块生牛肉，第三块应放不进去。15 秒后得到两块熟牛肉，燃料由 3 变 2，制作过程中无额外物品。另试只放一块，之后再放一块，仍合计消耗一点。
3. 燃料耗尽后，木板不会使其复燃。用一根火把重新点燃，只获得 1 点；不放肉，45 秒后熄灭。重复使用满燃料篝火不应消耗材料或打火石耐久。
4. 放入肉后立即铲灭或浇水，应掉回原生肉。无屋顶时 `/weather rain` 应立即浇灭；遮雨屋顶下保持燃烧。结束用 `/weather clear` 恢复天气。
5. 尝试放土豆、面团和矿石，应拒绝。JEI 显示肉类篝火配方耗时 15 秒，不再显示非肉篝火配方。
6. 在粉雪冻结时靠近燃烧篝火 3 格内，冻结积累应清除；熄火后不再保暖。相邻普通冰不应被其光照融化。蜂箱下的燃烧篝火仍应安抚蜜蜂。
7. 在可破坏的测试区域放邻近木板/干草并等待，有概率起火；`/gamerule doFireTick false` 时不应引燃，结束恢复。不要以短时间未触发判定随机风险失效。
8. 使用创造或旁观模式观察附近没有战斗目标的僵尸等怪物，应靠近可见火源并停在火外；熄火后取消调查。使用精准采集工具拆篝火，应获得材料而非完整篝火。
9. 烤熟一块肉后保存退出，再进入；当前燃料的剩余时间和一块烤肉配额应保留。燃尽后保存重进，燃料应仍为 0。

客户端由用户手动操作；服务端自动测试不代替上述实机验收。
