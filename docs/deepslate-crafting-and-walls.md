# 深板岩制造耗时与圆石墙产量

开发者：NingMeng123。

圆石墙和苔石墙的六方块配方现在每批产出 8 个墙，分别对齐 R196 注册配方 order 273/274。工作台材料、形状和原有整批 difficulty 1200 保持一致。覆盖由 `DecorativeRecipes` 生成原版配方 ID，重新运行 `runData` 会保留修正。

`mite/timed-crafting-deepslate.json` 为全部 16 个深板岩合成网格配方补充计时，包括深板岩圆石、磨制深板岩、深板岩砖和深板岩瓦的半砖、楼梯、墙，以及磨制、制砖、制瓦、雕纹四个加工配方。

深板岩属于现代新增材料，耗时采用本项目已有石材工序的整批基准。表内 `source_order` 指工序基准的来源，不表示 R196 存在深板岩。等级 0、无诅咒时的耗时如下，等级和工作台加速继续使用现有公式。

| 工序 | difficulty | 背包公式 tick | 基础工作台 tick / 秒 |
|---|---:|---:|---:|
| 雕纹 | 100 | 100 | 83 / 4.15 秒 |
| 半砖 | 600 | 244 | 203 / 10.15 秒 |
| 四块磨制、制砖、制瓦 | 960.00006 | 323 | 269 / 13.45 秒 |
| 楼梯、墙 | 1200 | 371 | 309 / 15.45 秒 |

背包公式列仅说明耗时，实际可用配方仍受 2×2 网格限制。深板岩各配方原有材料与产量不变。服务端菜单、快捷键提取、连续制造、自动合成器和 JEI 通过同一 `TimedCraftingRecipes`/`CraftingQuality.rule` 入口取得规则。熔炼与切石使用各自原版机制；本表限定合成网格，不改变这些工作站。

`VanillaCraftingTimingGameTests` 核对两种圆石墙整批产量，枚举全部已加载深板岩合成产物，在实际菜单中检查完成前一 tick 与完成 tick 的物品数量，并核对连续制造、快捷提取、背包加工、JEI 时间和红石自动合成器路径。实际执行结果由本轮验证输出记录。
