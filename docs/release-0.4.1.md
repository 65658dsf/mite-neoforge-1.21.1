# MITE: Modern 0.4.1

November 28, 2026. Developed by NingMeng123.

## Changes

- Added the Mossy Dungeon Eye and its shapeless four-corner recipe.
- Added lemon crops and foods, zombie fruit and vegetable drops, and nutrition values in food tooltips.
- Added live gravel drop-rate and mineral-distribution displays to JER's native pages.
- Adjusted shield guard thresholds and durability, and fixed ordinary durability loss so it can fully wear out armor.
- Fixed redstone duplication and clay-furnace cooking, and adjusted dried kelp behavior.
- Restored R196 fire elemental hit and water-vessel rules, and fixed Simply Swords silver weapons being recognized in melee and thrown combat.

Build file `MITE-Modern-0.4.1.jar`.

Requires Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the mod on both client and server for multiplayer.
