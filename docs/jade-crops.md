# 作物状态与 Jade 兼容

开发署名：NingMeng123。

安装 Jade 1.21.1 NeoForge 15.10.6 后，准星指向作物可查看 MITE 作物状态。Jade 是可选扩展，不打包进 MITE，也不是启动前置。未安装 Jade 时，种植机制照常运行。

## 显示内容

- 小麦、胡萝卜、马铃薯、甜菜根和洋葱：健康、生病或枯死，生长进度及成熟状态；病株提示使用骨粉治病，死株提示无法治愈。
- 耕地及其上的普通作物、瓜茎：湿度和是否施肥；直接查看耕地还能看到附近是否存在有效灌溉来源。
- 未成熟的普通作物、瓜茎和蓝莓：根据已实现的规则，显示干旱、光照不足或符合当前生长条件等状态。生长不再要求合适温度；蓝莓自身的森林种植环境仍会检查。连接着果实的瓜茎显示已有果实。
- 可可、下界疣：实际生长阶段及可确认的生长条件。
- 普通食用作物和瓜茎：显示服务端真实剩余生长时间，按 `时:分:秒` 更新；瓜茎计至茎长成，不包含随机结果的等待。蓝莓、可可和下界疣保留随机生长的预计剩余时间。
- 蘑菇：大型化阶段及当前是否满足大型化条件。此阶段不是采收成熟度。
- 甘蔗、仙人掌：当前整株高度及自然生长上限。

原版甜浆果和其他未由 MITE 接管的作物保留 Jade 自带提示。普通作物死亡后不再显示可收获的“成熟”提示。Jade 设置中的“MITE 作物与耕地状态”选项可以关闭整组扩展提示；关闭后恢复 Jade 自带的生长进度提示。

## 数据与显示边界

`CropInspection` 独立于 Jade，统一生成只读状态快照和文本。Jade 插件只读取快照，不施肥、不催熟、不消耗随机数，也不修改世界。

健康、年龄和耕地自身状态来自已经同步的方块状态。完整环境诊断由服务端计算，通过 Jade 自有数据通道发送，不需要给作物新增方块实体。客户端只接受位置、方块 ID、维度和完整方块状态均匹配的数据；快速切换目标或作物刚发生变化时，旧数据不会套用到新目标。

环境数据会随 Jade 的刷新节奏更新，可能短暂落后于周围光照、水源或天气。尚未收到匹配数据时，只显示当前方块自身可确认的状态，不猜测周围土壤、光照或灌溉情况。服务端未安装 Jade 时同样使用这一回退方式。旧版温度停长快照会保留健康和生长阶段等事实，但不再显示已经取消的温度警告。

“正在生长”表示当前已检查的条件允许进入生长流程，不代表下一刻一定长大；实际生长仍受随机刻、概率及其他模组事件影响。成熟作物不显示无关的生长阻碍。仙人掌仅提供高度信息，不把其额外概率分支误报为完整生长诊断。特殊作物不凭空增加普通作物病害状态。

2026-11-02 根据用户进一步确认，将普通食用作物及瓜茎改为真实持久化生长计时：无加成 60 分钟，所有种植优势叠加后最快 35 分钟。Jade 直接读取区块中保存的工作量，不再从随机阶段猜测、也不因持续看着同一株而虚扣时间。新种作物即使随机运气好或提高随机刻速度，也不能突破 35 分钟。

倒计时随服务端实际工作量减少，切换目标、离开再看和重启都会延续已保存的进度。光照不足、干旱、生病、环境不适或关闭随机刻时暂停；区块停止运行及离线时间不补算。改变肥力或布局后，会按保存的工作量和新速度更新剩余时间。生长时间已满但被其他模组事件阻止时提示等待生长更新，只有真实成熟状态才显示成熟。显示以正常 20 TPS 为基准，低 TPS 时现实等待更久；60/35 分钟均为累计有效生长时间，停长阶段另计。

蓝莓、可可和下界疣仍按其现有的 1/40 随机增长概率及随机刻速度计算期望时间，只在阶段或环境变化时重新估算，不伪造逐秒递减的确定时钟。它们不套用普通耕地作物的 60/35 分钟规则。

没有匹配的服务端数据时不猜测成熟时间。新增时间字段兼容原有版本一快照：旧包没有该字段时继续显示原有作物信息。带时间的服务端快照超过 5 秒会回退，避免网络中断后一直把旧的生长条件当成当前状态。蘑菇、甘蔗、仙人掌和其他未接管植物不套用普通成熟倒计时。

Jade 原有的成熟度行通过其公开 UID 移除，避免重复显示。末尾回调仅在本插件确实生成了提示行时清理原版行，兼容用户自定义排序，也不会在关闭插件选项时误删原版信息。Jade 的精简模式可能折叠这些普通详情，按其“显示详情”按键即可展开。

## 手动测试

1. 用本轮 JAR 重启测试客户端，保留 `run/mods` 中的 Jade。进入存档，将准星指向不同年龄的小麦、胡萝卜、马铃薯、甜菜根和洋葱，检查健康及生长阶段，只出现一套进度。
2. 按 `crop-manual-test.md` 生成病株和死株。病株应显示生病及骨粉治病提示；使用骨粉后变为健康，年龄不变。死株应显示枯死且无法治愈，不显示成熟可收获。
3. 查看湿润、干燥、施肥和未施肥耕地，再查看其上的作物。用水瓶或现有容器灌溉、用粪便施肥后，等待 Jade 刷新，检查状态随实际方块变化。
4. 对同一种未成熟作物分别测试白天、夜间、冻结山峰与沙漠。湿耕地上的日间作物应显示可生长，不因冷暖停长；干耕地或夜间显示对应原因。提示不保证立刻生长。
5. 查看普通瓜茎、已连接果实的瓜茎和枯死瓜茎，检查阶段、已有果实及死亡状态；再查看蓝莓、可可和下界疣，确认阶段准确且没有虚构的病害提示。
6. 查看不同大型化阶段的蘑菇，以及多层甘蔗、仙人掌；高度应指整株高度。原版甜浆果、火把花及其他非受控植物应保留原来的 Jade 显示。
7. 在两株不同状态的作物间快速移动准星，在查看时治病、收获或切换维度，确认不会把上一株的健康、年龄或环境诊断显示到下一株。
8. 在 Jade 插件设置中关闭“MITE 作物与耕地状态”，检查扩展信息消失、原版生长进度保留；重新打开后恢复扩展。精简模式中展开详情后也应可见。
9. 可选兼容检查：在独立测试实例移除 Jade，MITE 应仍可正常启动和种植。不要在游戏运行时替换模组文件。
10. 持续查看湿润、日照充足的未成熟作物，预计时间应逐秒减少；切换到夜间应暂停，再切回白天应继续。改变肥力、布局或 `randomTickSpeed` 后检查估算刷新；将其设为零应提示停长。已成熟、死株和未收到服务端数据时不应出现正在递减的成熟时间。

接口依据：[Jade 1.20–1.21.5 官方开发文档](https://jademc.readthedocs.io/en/latest/plugins20/getting-started/)，并对照本地 Jade 15.10.6 JAR 的实际签名。
