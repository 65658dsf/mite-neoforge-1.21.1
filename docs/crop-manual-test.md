# 作物机制手动验收

开发署名：NingMeng123。先使用测试存档并重新加载本轮构建的模组。测试期间由用户操作客户端，自动测试不会接管或重启游戏。

## 一、生长和收获

选择平原，在露天放置一片九乘九耕地及水，种小麦、胡萝卜、马铃薯、洋葱、甜菜根。先设 `/time set 6000`、`/weather clear`。可以临时 `/gamerule randomTickSpeed 100` 或 `/tick rate 200` 加速观察；检查挖掘速度时恢复 20 TPS。

1. 健康苗逐步成长；骨粉点击健康苗不催熟、不消耗。并排种植与单株的生长率有区别，施粪便的耕地外观改变并提高生长率。
2. 设 `/time set 18000` 或用实心屋顶挡光，作物不会像白天那样继续成长。夜间不是必然立即生病。
3. 生存模式破坏新种小麦得一粒种子；破坏中期小麦无产物；成熟小麦得一个小麦、不额外掉种。成熟根菜为两份或三份，中期马铃薯为一个毒马铃薯。
4. 打开背包、JEI 后再回到世界，植物状态及材质正常，无新增缺失材质。

## 二、病株、死株和骨粉

先在脚下放湿耕地，再用命令准备病株，避免等待低概率自然事件：

```mcfunction
/setblock ~ ~-1 ~ minecraft:farmland[moisture=7]
/setblock ~ ~ ~ minecraft:wheat[age=4,mite_blighted=true,mite_dead=false]
```

站开后观察病株外观，用骨粉直接点它：只治病，年龄仍是 4。重新放病株并在附近放健康胡萝卜或马铃薯，加速观察传播或死亡；它们是概率事件，可多放几株。若自动刻太快，先恢复 `/gamerule randomTickSpeed 3` 再检查。

死株可以直接准备：

```mcfunction
/setblock ~ ~ ~ minecraft:wheat[age=4,mite_blighted=true,mite_dead=true]
```

死株外观应与活病株不同，骨粉不能救活，破坏后无产物。洋葱使用 `mite:onion_crop[age=4,blighted=true,dead=false]`；甜菜根最大 `age=3`，也应能感染、治病和保存。

## 三、灌溉、旱死和践踏

1. 在远离水的耕地上种几株苗，临时提高随机刻。耕地逐步干燥，作物可能旱死；成熟株旱死时有来源收获掉落。
2. 耕地同层或上一层四格内放水，应该补满湿度；相邻一格内的冰、雪也能灌溉。雨天耕地逐级增湿。
3. 用水碗或水瓶对准耕地上表面或其作物，为单格补湿并正确返回容器；水桶为三乘三范围。检查物品数量没有复制或丢失。
4. 跳落踩踏时，作物可能先损坏；湿润或施肥的耕地受到土壤保护，不能因此认定苗也绝对不会被踩坏。
5. 用流水冲毁健康幼苗，普通种子不返还；中期马铃薯仍是一个毒马铃薯。

## 四、瓜茎与其他植物

- 南瓜、西瓜茎在适合气候和湿地上成长，骨粉不催熟；结瓜后有概率枯死变色，移除果实不会复活死茎。西瓜普通破坏固定四片，精准采集得到整块；爆炸瓜类得到一个对应种子。
- 甘蔗需要完整日光和上方透天，最多长到三格；仙人掌生长更慢，天然最大高度由种子与位置决定，人工堆叠也不超过三格。
- 可可种植需要天然丛林树叶冠，骨粉不能催熟；成熟产一或二豆。下界疣在下界正常生长，其他维度会失效。
- 褐蘑菇需要室内阴暗适合底材；湿润施肥耕地上的褐蘑菇能培养菌丝。合适环境用粪便推进巨型化，前两次有效处理保存进度，第三次才尝试生成。红蘑菇需要靠近露天而被遮阴的草地，详见特殊植物说明。
- 如需快速检查农业附魔，手持锄执行 `/enchant @s mite:harvesting 5` 或 `/enchant @s mite:fertility 5`。丰收额外产物是概率，肥沃 V 正常成熟采收和有效耕地时应补肥；镰刀只对小麦适用这些效果。

## 五、保存和恢复设置

保存退出后重进，确认病株、死株、施肥耕地、死瓜茎、蘑菇生长阶段还在。真实多人联机可再检查第二个客户端看到同一状态。

结束恢复 `/tick rate 20` 和 `/gamerule randomTickSpeed 3`。若测试前是其他数值，以自己的原值为准。反馈时说明作物、年龄、环境、操作及实际掉落，便于定位。
