# 成长副词条权重与上限

开发者：NingMeng123。新升级使用 MITE-ITE 2.0.28 的独立副属性候选池；每升一级在有候选时必抽一次，没有额外成功率、稀有保底或优先新属性。`P(属性)=权重/当前候选总权重`。满级项排除；每次抽取后重建候选池，一次入账最多升级一级，溢出经验清零。候选池耗尽时装备仍正常升级。

## 独立效果与保存

新ID为 `mite:modifier/tool/*` 和 `mite:modifier/armor/*`，与附魔注册ID隔离。沿用 `mite:gear_progress` version 1 的映射格式，旧等级、经验、UUID、附魔型副词条和未知ID均保留。新升级只添加独立修饰，不对历史物品执行转换、补发或重抽。原有附魔效果桥继续处理历史ID。副属性不是普通附魔，不写入 `minecraft:enchantments`，不受附魔启停或最高等级配置控制。

每阶参数必须结合实际效果解释：急速加在材质采掘效率上；喜水在水中或雨中加采掘效率并解除水下速掘惩罚；耐久按比例降低损耗；锋利每阶加1伤害；织网按等级施加缓慢；超自然按材质与方块采集等级差加速；恶魔之力在非主世界增伤25%；地质学按熔炼经验生成额外经验。保护类加护甲点；稳定按穿戴件逐项减少击退；神圣在受到亡灵攻击时加防御；免疫每阶缩短负面药水时长15%。坚毅不倒忠实保留参考实现：只检查是否持有，四阶使用同一组血量阈值增伤倍率，不人为修正为按等级增伤。

本体所有已支持装备直接拥有25级成长上限；安装 Modern ITE 后由其锻造组件决定，非护甲15＋锻造等级，护甲材质采集级×3＋锻造等级。经验来源、线性升级曲线和单次入账最多一级、溢出清零同样按低版本改造，完整来源及现代边界见 [装备成长](equipment-progression.md)。
