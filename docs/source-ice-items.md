# R196 冰雪物品融化

开发署名：NingMeng123。来源：本地 R196 发布包；下文旧行号相对于 `.reference/r196/decompiled/`。本文件记录实现和待验收范围，不宣称客户端已实测。

`jv.java:559–566` 每实际玩家刻检查主库存；`ss.java:110–113` 每掉落物刻检查物品栈。`yc.java:1543–1544` 的概率为 `(温度−1)×0.0001`，非正概率不抽取随机数。`ye.java:1036–1045` 对原栈的每一件独立抽取一次，扣除成功件数。玩家正在着火时，主库存按温度 20 计算，概率为 0.0019；地面物品只读取群系温度，普通火焰伤害仍经过原生物品伤害流程。

`SourceIceItemMelting` 只处理来源材料对应的冰、雪球、雪层物品和雪块。每刻实际更新36格主库存/快捷栏，排除盔甲、副手、鼠标携带栈和打开的其他容器；不递归容器内容。生存和创造共用来源消耗，现代旁观者和死亡玩家不参与。掉落物最后一件融化后移除实体，否则用原生同步实体数据发布新数量；主库存变化走原生库存同步。没有新计时数据，保存重进不会重置已有栈的额外进度。

温度使用 `SourceIceMeltingRules` 的 **R196 数值**，不是直接将现代 `Biome.getBaseTemperature()` 带入概率。例如现代沙漠的2.0映射为来源沙漠1.6，现代丛林的0.95映射为来源丛林1.2。海洋/河流/末地0.5、平原/沼泽0.8、森林0.7、山地0.4、针叶林0.05、冰雪群系0、海滩1、地底1、下界2。旧沙漠河1.4、丛林河1和旧丘陵变种的数值也保留于纯规则表。

现代群系按既有 `R196MobSpawning.biomeId` 的族映射选择来源温度；恶地归沙漠，另外明确把现代稀树草原家族归沙漠1.6。没有旧身份的森林/山地等族按已有映射；其余未知群系回退平原。保留现代当前位置的三维群系，不增加高度、天气、光照修正，也不凭相邻地貌创造旧版三种特殊河流身份。此为现代群系适配，不宣称逐坐标重建旧世界气候。浮冰、蓝冰和细雪桶是现代物品，当前不扩展来源四类材料的消耗范围。

验证入口：`SourceIceMeltingRulesTest` 核对温度、概率、严格小于边界和逐件抽取；`SourceIceItemMeltingGameTests` 使用真实群系持有者、实际服务器玩家事件和变换后的原生 `ItemEntity.tick`，检查沙漠/丛林数值、着火消耗、主库存边界、冷区保存与最后一件移除。上述验证均已执行通过，实际结果见[本轮统一验证](testing/r196-parity-implementation.md)。

全量测试曾发现原落点对齐到区块中心后可能离开低处模板，原生碰撞脱困会提前消耗实体随机数，零刻还可能与残留雪堆合并，令“第一抽融化唯一一件”前提不稳定。夹具现使用保存并恢复的高空净空，明确校验真实落点气候、碰撞与初始数量；测试物品用原生永久拾取延迟隔离拾取/合并，仍真正调用 `ItemEntity.tick` 并严格要求最后一件融化后移除。该修正不改变生产概率或削弱移除断言。

手测可在独立存档携带多组雪球、冰、雪层和雪块前往沙漠或丛林，按正常刻持续观察数量随机减少；平原中保持不着火时不应减少。着火时主库存融化明显加快，副手及鼠标携带栈不受这条规则影响。地面冰雪的融化和原生火烧销毁应分别观察。单件的低概率不能用几秒未减少判定失效。
