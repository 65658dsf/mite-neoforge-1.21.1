# MITE: Modern 0.3.8-bugfix1

November 21, 2026. Developed by NingMeng123.

## Changes

- Fixed a startup resource reload failure with Punchy 3.2b that could cause Minecraft to deselect enabled resource packs. MITE clubs can now use the active sword animations again.
- Updated the transition between custom weapon attacks for Punchy 3.2b.
- A summoned Wither now finishes charging at its actual maximum health. With MITE: Modern ITE installed, it enters combat at 1300/1300 HP.
- When Jade and Wither Plus are installed, looking at a placed Inferno Wither Skeleton Skull shows its item name and its mod, Wither Plus. This works for standing and wall-mounted skulls.

Verified with Punchy 3.1b and 3.2b using the Polaris 1.4 resource pack. Both clients entered a test world and passed animation selection checks for 52 weapons, covering both new and saved item stacks.

Build file `MITE-Modern-0.3.8-bugfix1.jar`.
