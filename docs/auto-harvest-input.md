# R196 左右键自动采集

开发者：NingMeng123。依据本地 Minecraft 1.6.4 MITE R196 发布包。实现直接位于现有 `main` 分支。

2026-10-17 扩展了 AUM、两种模式的绿色背景/边框及物品补货，当前新增操作与适配见 [自动使用与物品补货](auto-interaction-r196.md)。下文保留原 AHM 独立实现的范围和历史验收。

## 操作与范围

先单独按住攻击键（默认鼠标左键），再按住使用键（默认鼠标右键），并让准星对准要挖的方块。先松开右键再松开左键后，准星仍指向同类方块时会继续挖掘。持续移动准星到同类方块，可以接着采集。

这对应原作的自动采集模式，不会自动连打生物，也不会锁定右键使用物品。松开鼠标后，瞄准空气、实体或不匹配的方块时暂停，超过现实时间 5 秒没有符合条件的继续采集便结束；回到匹配方块会刷新这个计时。仍实际按住攻击键并进入原生持续破坏入口时，即便没有造成方块损伤或暂时没有命中，也会按原作刷新计时。`/tick rate` 不会改变这 5 秒。

再次单独按攻击键可退出自动采集，当前手动攻击仍正常生效；单独按使用键也会退出。先松左键而右键仍保持按住，会被视为单独使用键并取消，因此正常开启时应先松右键。两键从松开状态同时按下而没有经过一次单独攻击键的准备，不会直接开启。

使用游戏中绑定的攻击键与使用键判断组合，因此重绑定后仍然使用同样顺序。自动继续只补充原生持续破坏流程，原有采集工具、触及距离、速度、碰撞、进度及服务端校验继续生效。

## 新版适配边界

方块类型与必要的状态匹配由客户端适配层提供，纯 Java 状态机只管理按键准备、捕获、暂停、续期及取消。旧版橡木、云杉、白桦、丛林的原木、树叶、木板、树苗分别曾共用各自的方块 ID，因此各类别中的这四种树种也可互相接续；旧羊毛、彩色地毯、染色陶瓦、砂岩、石砖、圆石墙、石英及对应半砖变体按旧共用 ID 分组。新加入、没有旧共用 ID 对应的方块保持各自类型。现代红石矿的点亮与未点亮状态已合并为同一方块，两种状态均能互相接续；普通方块朝向等状态继续按原作忽略 metadata 的原则处理。

状态机不把模拟按下写回原生按键状态，物理释放事件仍正常处理。计时使用新版 `Util.getMillis()` 的单调实时时间，替代旧版 `System.currentTimeMillis()`，避免系统时钟校准改变剩余时间；时限与游戏刻速度仍相互独立。原生持续破坏入口在实际按住攻击键、上下文允许且未使用物品时，通过 `recordAttempt()` 记录继续尝试；已清理的模式不会因此重新激活。

为避免菜单返回或切换世界后误挖，新版在打开界面、失焦、死亡、睡眠、切换世界及能量耗尽时立即完全清理；任意方式切换快捷栏也立即清理，包括滚轮及数字键。R196 原作仅在这些场景阻止继续挖掘，部分场景允许在旧 5 秒计时结束前恢复；数字键换栏没有像滚轮那样显式取消。这里采用统一立即取消的新版行为。

原作的 imposed 聊天可在采集时保持输入；新版打开聊天界面同样会取消，不恢复旧版边聊边自动挖的特殊入口。手持物使用和实体攻击不加入本次自动采集功能。

## 用户手动验收

1. 使用生存模式，在可正常挖掘的石头或泥土前，单独按住左键开始挖，再按住右键。先松右键，再松左键，继续瞄准方块：它应继续破坏；转向附近同类方块仍可继续。
2. 自动采集石头时先看空气或木头，再在 5 秒内看回石头：暂停后应可继续。重新开启后看空气超过 5 秒再看回石头：不应自动恢复。游戏刻加速时仍按现实 5 秒判断。
3. 开启后再单独按一次左键，随后松开：只剩这次正常手动操作，不能继续自动挖；也检查单独右键能取消。仅同时按下左右键、没有先单独左键准备时，不应直接开启。
4. 用泥土开启，转向草方块，以及反向操作，均应可继续。用不同方向放置的橡木原木开启，转向云杉、白桦或丛林原木应可继续，这四种在旧版共用一个原木方块 ID；转向新版樱花原木等非旧共用 ID 的树种应暂停。
5. 开启后打开背包、聊天或暂停菜单，再关闭；切出窗口再返回；切换快捷栏、死亡重生或切换世界。各场景应立即取消，返回后不会自行挖方块。
6. 将攻击、使用键改为其他鼠标按钮或键盘按键，按先攻击后使用的顺序重复开启与取消；恢复默认按键后也应正常。
7. 准星瞄准怪物或空气时尝试组合操作，不应自动连打或挥手；单独正常攻击、放置、吃喝、拉弓和容器操作不应因此重复触发。
8. 独立服务器或局域网中重复同类方块挖掘，确认挖掘速度、工具门槛、距离及实际掉落仍与普通手动挖掘一致。
