# 原版石材制作计时补全

开发者：NingMeng123。日期：2026-10-30。版本保持现有0.2.18。

## 范围与结果

对照本地Minecraft 1.21.1原始配方，石材建筑与加工范围共有152个工作台制作配方：此前61个已有明确计时，本次补齐其余91个。服务端测试再按实际已加载的配方管理器核对，避免仅凭资源文件存在就认为生效。

覆盖25种原版墙，以及相关楼梯、台阶、抛光、砖块、錾制、柱形和基础石材混合配方。材质包括圆石/苔石、石头/石砖、花岗岩/闪长岩/安山岩及抛光型、深板岩各型、凝灰岩各型、砂岩/红砂岩各型、砖/泥砖、海晶石各型、下界砖/红下界砖、黑石各型、末地石砖、紫珀、石英、玄武岩与滴水石。包含黑石按钮和压力板、制作这些石材的黏结/混合步骤，以及海晶石碎片体系的海晶灯；不扩展到木材、玻璃、羊毛、铜建筑和装备配方。

`timed-crafting-stone-family.json` 只补缺项。每条记录注明现有参照配方、倍率与加工操作；加载采用 `putIfAbsent`，已有明确难度和工作台要求优先。原始证据文件与已有深板岩、三种现代墙补充规则保持不变。

## 难度推导

这里是现代石材移植策略，并非声称低版本已经存在凝灰岩或海晶石的原始配方。难度按整批制作计算，不按一次点击固定计时，也不将所有石材统一成一个数值。

| 新增操作 | 整批难度 | 参照与理由 |
|---|---:|---|
| 普通岩石、现代密实石材及砖类：3块做6台阶 | 600 | 现有圆石台阶 |
| 同类：6块做4楼梯或6墙 | 1200 | 现有圆石楼梯/墙；墙保留其真实产量 |
| 砂岩、红砂岩墙 | 480 | 各自现有6块楼梯配方，保留砂岩较低加工权重 |
| 石砖、苔石砖墙 | 900 | 同材质现有楼梯配方 |
| 石头楼梯 | 1440.00012 | 现有石头3块台阶难度720.00006的两倍 |
| 4块抛光、凝灰岩/黑石/末地石砖加工 | 960.00006 | 现有4石头制作石砖/深板岩抛光批次 |
| 两台阶做錾制块、紫珀柱 | 100 | 现有錾制砂岩/深板岩 |
| 四原料合成泥砖、海晶石、紫珀块 | 840 | 现有四砖块原料黏结批次 |
| 九原料合成海晶石砖、暗海晶石、海晶灯 | 1890 | 四原料砖批次840乘9/4 |
| 红下界砖 | 850 | 现有四原料下界砖批次；原料中的两个替换为下界疣 |
| 石英砖 | 14400 | 四个石英块，每块沿用现有3600权重，保留原有石英体系较高时间 |
| 砂岩/红砂岩基础压制 | 320 | 现有四原料切制砂岩批次 |

## 制作入口与切石机边界

普通取出、Shift连续制作、背包2×2可容纳的配方、红石合成器和工作台JEI页，均通过已有 `CraftingQuality.rule` 读取同一配方难度，沿用已有制作控制器。完成前不得扣料或交付，完成后一次交付完整真实批次；连续制造每批重新完整计时。

切石机使用独立 `RecipeType.STONECUTTING`、`StonecutterMenu` 及其结果槽。目前项目没有切石机计时控制器、进度同步或对应JEI计时类别，仍保留原生即时单原料加工；熔炉烧制亦继续走自身系统。本次没有把工作台耗时硬套到切石机ID，也没有显示其实际上不存在的等待。若要切石机也等待，需要单独实现槽位提取、服务端任务、换料取消、进度同步与显示，而非仅补这张工作台表。

## 回归验证入口

- `StoneCraftingDataTest`：91条新增规则不覆盖已有规则，所有难度与公开参照/倍率一致，材质和操作保持差异，范围不扩展到木/玻璃/羊毛/铜。
- `StoneCraftingCoverageGameTests.everyLoadedStoneCraftHasATimedRuleAndMatchingJeiPage`：基于实际墙、非木非铜楼梯/台阶类型及基础石材，遍历真实已加载制作配方；要求每项有正难度、JEI同时间同产量，校验25种墙和全部新增ID。输出 `build/verification/stone-crafting-coverage.json`，同时列出独立切石配方数量和即时策略。
- `VanillaCraftingTimingGameTests.everyNewStoneShapeWaitsForNormalAndShiftManufacturing` 与 `everyNewStoneProcessingRecipeWaitsForNormalAndShiftManufacturing`：对全部91项新增配方，各自用真实菜单检查普通与Shift、N-1刻不扣料不出货、完整批次、连续制作终止；黑石小型控件另查背包2×2速度。
- `redstoneCrafterCannotBypassTheNewGraniteWallPeriod` 与 `redstoneCrafterUsesTheShorterSandstoneWallPeriod`：真实红石脉冲合成器分别检查普通岩石和较短砂岩时间、整批交付及单脉冲不重复消耗。

这些GameTest沿用既有 `mite_crafting_audit` 命名空间和空模板，未迁移其他测试。精确复跑上述五个方法，并保留已有圆石墙、深板岩和原版制作入口测试即可；本分工未运行Gradle，编译与运行结果以最终构建记录为准。
