# 试炼密室天然方块掉落限制

开发署名：NingMeng123。

按用户要求，主世界 `minecraft:trial_chambers` 和地底 `mite:underworld_trial_chambers` 新生成的天然方块可以破坏，但不掉落方块物品、材料、陶片或方块经验。玩家挖掘、精准采集、时运、TNT、苦力怕爆炸和失去支撑后的破坏使用同一来源判定。

仅限制真实生成过的方块，不按房间包围盒禁掉落。玩家在密室内另外放置的方块正常掉落；天然方块拆掉后，在原位置重新放置的同种方块也正常掉落。

## 陶罐与奖励

按用户后续要求，**饰纹陶罐内的物品和尚未生成的战利品正常掉落**。仅禁止天然陶罐本体、砖和陶片；破坏时仍沿用原版容器处理生成并弹出内容物，不额外抽取第二份奖励。

宝库插钥匙后的奖励、试炼刷怪笼通关奖励、箱子/木桶正常打开取物、玩家手动扔出物品均保留。其他天然容器被破坏时按本次“不掉落任何东西”的规则处理，需先正常打开取出内容物。玩家放置的容器仍按原版掉落。

## 来源记录与存档范围

`StructureStart.placeInChunk` 只对上述维度和结构建立生成作用域，在模板最终落块成功后写入来源。临时屏障、模板外的邻居形状修复、结构之外的矿石及一般地形不参与标记。

来源记录在 `mite:natural_trial_blocks` 区块附件中，包含版本号和实际坐标；随生成区块晋升、区块保存和重载保留。掉落查询只读取已加载区块，不遍历房间或强制加载结构起点。

铜氧化、刮削、上蜡、除蜡以及门、活板门、灯泡的属性变化保留来源。拆除或真正替换后立即清理，玩家新方块不会继承旧来源。破坏过程中另保留短暂的来源快照，避免原版“先移除方块，再计算玩家掉落”的顺序导致漏判。

活塞仍能正常推拉，来源随每一块真实移动的方块转移，包含移动中保存和粘性活塞回拉，不会把同一推送链里的玩家方块误标。模板内的天然砂转为掉落方块实体时也保存来源，正常落地后继续限制；落地失败或超时不能变成可拾取材料。玩家砂保持普通行为。

**已有生成完成、没有来源记录的旧密室不追溯禁掉落。** 无法从旧存档判断一块相同材质的方块是否曾被玩家替换，因此不按范围或当前材质猜测。更新后探索新区块，或在测试存档通过 `/place structure` 新生成房间即可验证；不需要重建整个存档。

## 用户手测

请自行重启开发客户端加载新代码。本轮未操作游戏窗口。2026-10-15 用户反馈“好的没有问题，提交吧”，确认当前交付正常并授权提交；逐项画面及真实多人结果未另行记录。

1. 在测试存档中寻找更新后才生成的主世界试炼密室和地底试炼密室。地底可用：

   ```mcfunction
   /execute in mite:underworld run locate structure mite:underworld_trial_chambers
   ```

   已探索的旧房间不作为本功能的禁掉落测试样本。也可在测试存档的空旷位置执行 `/place structure minecraft:trial_chambers`；在地底使用 `/place structure mite:underworld_trial_chambers`。

2. 使用满足采集要求的工具，生存模式分别破坏铜块、凝灰岩、铜楼梯/活板门/灯泡。方块应消失，但不出现方块物品或经验。精准采集和时运不能绕过。
3. 在同一房间里自行放置铜块并挖掉，预期正常掉落；把天然铜块挖掉后，在原位置重新放铜块再挖，预期正常掉落。
4. 分别点燃 TNT、让苦力怕爆炸，确认天然块实际被摧毁且没有材料掉落。旁边玩家放置的铜块仍按普通爆炸规则掉落，默认衰减可能使个别方块不掉落。
5. 打碎装有战利品的天然饰纹陶罐：罐内战利品正常出现，陶罐本体/陶片不出现。另用爆炸验证一次；正常开宝库和打开箱子取物也应正常。
6. 对天然铜块进行上蜡/除蜡或刮除氧化，再破坏，预期仍无材料。用活塞将天然块和玩家块一起移动后再破坏，仍应只掉玩家块；天然砂落地后也不应变为可获取材料。保存退出重进后，再检查剩余天然块和玩家方块，结果应保持一致。

自动验证记录见 [试炼天然方块验证](testing/trial-block-drops-automated-results.md)。
