# 铜银武器、生存基准与原版本对照

开发者：NingMeng123。日期：2026-10-24。

本轮按用户最新要求，以铜剑总基础伤害 **6**、铁剑 **7.2** 为锚重新计算。此前“铜额外乘0.6”的要求已被替代。本文件更新此前装备平衡记录中的铜伤害，以及 Simply Swords 原生铁、金仍沿用较低基数的描述。

下方SS攻速表已同步后续修正：长矛降至每秒1次，双手武器实际承担一次20%攻速代价，保留既有主手移速惩罚及全部伤害预算。最新机制与验收记录见[矿物、刷怪与武器调节](ore-spawn-weapon-tuning-2026-10-24.md)。距离、双手判定与特殊技能路径继续使用既有实现。

这里的“总基础伤害”包含玩家原生1点，不含等级、品质、成长词缀、宝石、锻造、附魔、暴击、攻击冷却折损或目标减伤。伤害单位为生命值，2点为1颗心。没有修改两份已验收默认配置，也没有修改怪物数值。

R196普通物种的源基准来自 `src/main/resources/mite/mobs-031.json`、`R196VanillaMobRules`，其物理属性由 `R196VanillaMobEvents.attributes` 将原生ARMOR设为0；自定义R196物种也在 `R196MobRules.attributes` 明确设0。特殊天然防御是另一条路径，如亡魂骷髅1、守卫2、地狱苦力怕2、土元素4，并非所有怪物都没有防御。

Modern ITE自定义僵尸家族的 `ExtremeMobs.attributes` 使用 `Zombie.createAttributes()`，保留其原生2点护甲；`MobAbilities.attributes`没有清除它。普通 `minecraft:zombie` 则已经过本体清0，不会仅因ITE普通属性覆盖而凭空多出2点。铁桶头盔、普通日期装备、领主振金套装等是额外装备防御；南瓜头不是护甲。已有持械怪物防御／缴械机制与默认开关也保持有效，不能仅按生命除以武器面板值断言固定击杀次数。

当前用户默认成长设置为：总倍率／生命倍率／攻击倍率均1，生命基准与攻击基准0表示保留实际物种原值，生命每日0.5%，攻击每日0.25%，骷髅生命首周期参考20，周期及血月公式均为 `base + reference * rate * days`。`MonsterGrowthRules` 从第1天经过0天开始，第33天以完成第32天血月后的新值重设基准，第65、97天继续递推；第128天是蓝月，跳过该次血月重设。与旧ITE按固定初始值加day/16、day/24的线性曲线不同，现代会在完成血月后复利递推。

日期使用服务器所记录的最高世界天数及怪物已保存天数，降低时间不会逆向削弱它。刷新以剔除旧成长修正后的原基准重算，保留受伤比例，不是每tick重复乘成长。僵尸队长出生生命修正、效果或额外装备会改变实际基准，以上表格不是所有个体的固定血量。

`MonsterDayScaling.handles` 排除末影龙、凋零及真实 `Tags.EntityTypes.BOSSES` 标签。ITE领主等使用的 `modern_ite:boss` 持久标记只提高生命上限，当前没有对应bosses标签，因此仍在专种生命曲线外接受统一成长；不能笼统称所有“BOSS”均不成长。ITE `enhance_limit=366`仍只按其现有逻辑限制专种曲线，黑皮苦力怕等读取原始日期的专种例外也保留。本轮没有修改这些机制。

铜剑从前轮3.84恢复为6后，面对20生命无防御目标的理想满冷却命中估算从6次降到4次；面对ITE第1天15生命普通僵尸从4次降到3次。实际战斗还受上述护甲、防御动作、等级、血月成长及冷却等影响。材料差距仍在：铜6，银6.4，铁7.2；重武器靠单次打击、骨架专长或范围取舍，而长距离武器继续承担较低伤害和较慢节奏。
