# 草、蕨与枯灌木的采集证据

开发者：NingMeng123。依据本地 MITE 1.6.4 R196 发布包、实际注册表和原始字节码。本文记录原作事实与已决定的现代适配，不声明本轮构建或游戏实测已完成；固定验收值见 [结构化规格](../spec/r196-grass-mining.json)。

## 实际硬度不是零，也不是统一 0.04

| R196 方块 | 实际注册 | 有效子类型 | 硬度 | 最低采集等级 | portable |
| --- | --- | --- | --- | --- | --- |
| 草 / 蕨 | `aqz.ac`，ID 31，`aqv` / BlockTallGrass | 1 草、2 蕨 | 0.02 | 0 | false |
| 枯灌木 | `aqz.ad`，ID 32，`ant` / BlockDeadBush | 0 普通、1 Witherwood | 0.02 | 0 | false |
| 草方块，作为区别对照 | `aqz.z`，ID 2，`aon` / BlockGrass | 0 | 0.5 | 0 | false |

`aqz.java:2291–2292` 的两个注册都直接设置 `0.02f`。`aqz.<clinit>` 字节码在偏移 **1453 / 1492** 均加载 `0.02f`，随后 **1456 / 1495** 调用硬度 setter；运行时导出的 ID 31、32 的 `aqz.cG` 也都是 0.02。`BlockHardness.java:30` 虽声明 `deadBush=0.04f`，该常量没有用于这两个实际注册，不能把它当作发布包的枯灌木硬度。

`aqv.java:42–48` 明确草、蕨的有效 metadata 为 1、2；纹理数组中的 metadata 0 名称不能证明它是默认有效的第三种草。枯灌木子类型见 `ant.java:45–51`。旧名字 `tallgrass` 指单格草 / 蕨，不等同于现代双格 `minecraft:tall_grass`。

硬度读取链为 `abw.java:278–279 → aqz.java:654–655`。`aqv → BlockPlant → aqz` 与 `ant → ane → BlockPlant → aqz` 都没有覆写 `isPortable`；最终 `aqz.java:1687–1688` 返回 false，字节码为 `iconst_0; ireturn`。因此这些植物不走 portable 分支。一般 portable 的 `S_min=4H` 与最终 `max(S,S_min)` 是**强度下限**，能把缓慢情况限制到最多 128 次有效累加；它不是所有便携物必须等待 128 tick 的规则，更不是这次草过快的原因。

## 空手、木棒、剪刀与镰刀

草与枯灌木构造器都使用 `akc.l`（vine，`akc.java:648`），无需工具才能破坏。`uf.java:774–828` 先读取手持物强度；若小于 1，递归改用空手分支。普通物品的 `yc.getStrVsBlock` 返回 0（`yc.java:559–560`），无需工具的方块空手强度为 1。因此“拿着物品”不会自动获得工具效率，也不会让这些草不可破坏。

木棒继承 `ItemCudgel` 的有效材料列表（`ItemCudgel.java:8`），不包含 vine；`xj.java:125–138` 判定无效后返回普通物品强度，再由玩家回退为空手。草、蕨、枯灌木上的木棒基准强度都是 **1**，不是木棒对玻璃板等有效目标的 2。

剪刀 `yx.java:8,19–20` 明确对 vine 有效，基础效率 4，再乘 `xj.java:65–103` 的材料效率。铁剪刀（`yc.java:104`）为 `4×2=8`；铜 / 银 / 金为 7，锈铁为 5，秘银为 10，艾德曼为 12，古代金属为 8。最低采集等级 0 不挡住这些剪刀。

镰刀 `ItemScythe.java:8` 只把 `aqz.ac`（草 / 蕨）与 `aqz.aE`（小麦）加入有效方块列表；并未把所有植物或 vine 加入列表。草 / 蕨使用与剪刀相同的金属基础效率，枯灌木则回退为空手强度 1。另有剪刀右键剪取路径 `yx.java:70–90`，不能将它与本文左键持续采集进度混为一谈；本轮不移植旧右键剪取、旧掉落或镰刀。

## 原始浮点进度与固定预期

以下数值针对生存、落地、无水下惩罚、无药效、无附魔；除表内食物与等级外没有其他修正。原作有食物能量指 `satiation + nutrition != 0`（`uf.java:1735–1736`）。无能量先 `S/=5f`，再乘 `1f + level*0.02f`，之后按原有顺序计算：

```java
relative = H / S;
progress = relative < 0.0029296875f ? 1f : (1f / relative) / 512f;
```

不能合并成实数近似或改变浮点运算次序。证据为 `uf.java:825–862`：`getCurrentPlayerStrVsBlock` 字节码 **380 fdiv → 393 fadd → 394 fmul**；`getRelativeBlockHardness` **82 fdiv → 87 阈值 → 91 ifge**（严格小于才瞬破）；`getRelativeStrVsBlock` **34 fdiv**；`getDamageVsBlock` **12 fdiv**。

所有草目标使用 `H=0.02f`（位型 `0x3ca3d70a`）。

| 工具 / 状态 | 最终强度 S | 每次进度的 float 位型 | 达到 1 的有效累加次数 | 20 TPS 理论累加时长 |
| --- | ---: | --- | ---: | ---: |
| 空手、普通物、木棒；0 级，有能量 | 1 | `0x3dc80000`，0.09765625 | 11 | 0.55 秒 |
| 铁剪刀；0 级，有能量 | 8 | `0x3f800000`，1 | 瞬破分支 | 首次点击可完成 |
| 锈铁剪刀；0 级，有能量 | 5 | `0x3efa0001` | 3 | 0.15 秒 |
| 铜、银、金及更高效率剪刀；0 级，有能量 | ≥7 | `0x3f800000`，1 | 瞬破分支 | 首次点击可完成 |
| 铁剪刀；0 级，无能量 | 1.600000023841858 | `0x3e200001` | 7 | 0.35 秒 |
| 铁剪刀；−40 级，有能量 | 1.6000003814697266 | `0x3e200003` | 7 | 0.35 秒 |
| 铁剪刀；−40 级，无能量 | 0.3200000822544098 | `0x3d000003` | 32 | 1.60 秒 |

镰刀仅在草 / 蕨套用相应金属行；对枯灌木，0 级有能量均为 11 次。草**方块**的空手基准 `H=0.5f,S=1` 为 `1/256`，需 256 次、12.8 秒，不能与草植物混称。

−40 级倍率的实际 float 为 `0.20000004768371582`（`0x3e4cccd0`），不是精确的 0.2，因此“0 级饥饿”与“−40 级有食物”的剪刀进度位型不同。次数均由逐次 float 累加到 `>=1` 得出，未把 `ceil(1/progress)` 当作可替代的一般实现。

次数是有效进度更新次数，不是从输入按下到服务端确认的严格总 tick。`bdc.java:141–160` 在首次点击只对 `progress>=1` 立即破坏，否则将累计值设为 0；`bdc.java:190–203` 在后续持续采集时累加，并在完成后设置 5 tick 连挖冷却。实际客户端测试应另外记录初次输入、连挖冷却与服务端确认。

## 本轮现代适配边界

1. 只把五种原版植物的**有效挖掘硬度**设为 0.02：`short_grass`、`fern`、`dead_bush`，以及明确作为现代扩展的双格 `tall_grass`、`large_fern`（上下半部一致）。不修改全局注册硬度、爆炸抗性、其他零硬度方块或 portable 规则；不把 Witherwood 映射为现代普通枯灌木的新功能。
2. 原版 `minecraft:shears` 对这五种植物的基础挖掘强度改为 8，采用 R196 铁剪刀基准；之后仍应用现代附魔、环境，以及已实现的食物和等级修正。其它目标保留原剪刀 Tool 规则，其他工具保留现代速度；不新增镰刀。
3. 食物仍按本项目现有的现代 `foodLevel>0` 判定能量，是双资源食物系统完成前的明确适配。创造 / 旁观、取消事件、非正强度的现有处理不在本轮扩大修改。
4. 保留现代植物掉落、双格联动、剪刀耐久与交互；这些不因速度数值一致就算完成 R196 全植物复刻。第三方植物与剪刀不自动套用五种原版对象的规则。

现代过快的直接原因可以从固定版本源码定位：`Blocks.java:776–816,3712–3739` 为上述植物设置 `instabreak()`，而 `BlockBehaviour.Properties.instabreak`（1114–1115）等于 `strength(0f)`；原有纯 R196 进度公式对 `H==0` 正常返回 1。仅改通用公式不能恢复旧硬度。现代 `ShearsItem.java:27–37` 对这五种植物原本走默认强度 1，所以只补硬度会让现代剪刀也变为 11 次；本次额外设置铁剪刀强度 8，避免该偏差。

验收应分别覆盖五类植物的空手、木棒、剪刀，双格两半，剪刀的四组食物 / 等级向量，以及草方块、花、藤蔓、树叶等非目标回归。本文件只给预期，不代替自动测试或真实客户端记录。
