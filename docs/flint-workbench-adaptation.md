# 燧石工作台与木板加工门槛（014）

开发者：NingMeng123。依据本地 MITE 1.6.4 R196 发布包，区分原作规则与本轮现代适配。本文件不声明构建或游戏验证已经通过；固定输入、输出与验收预期见 [结构化规格](../spec/r196-flint-workbench.json)。

## 原作可以在背包制造第一张工作台

直接配方为以下固定 2×2 排列，每格消耗一个物品，产出一张燧石工作台：

| 燧石 | 线或筋 |
| --- | --- |
| 木棍 | 原木 |

左右镜像也有效，即上排“线或筋、燧石”，下排“原木、木棍”；不支持旋转、上下翻转或随意交换材料。放入 3×3 网格时允许整个 2×2 图案平移，其余格必须为空。

`RecipesMITE.java:113–118` 分别注册线和筋两种配方，模式均为 `"FS","s#"`。`arv.java:70–82` 把工作台 metadata 0–3 映射到燧石工具材质，并要求同 metadata 的 `aqz.O` 原木。原木依次为橡木、云杉、白桦、丛林（`arj.java:7`）；因此有四种原木外观 × 两种绑定材料，共八条直接配方。运行时记录 order **311–318** 均为 2×2、产量 1、难度 270、`bench_material=null`、`skillsets=null`，不会再要求一张现成工作台。

绑定材料**不能离开图案自由放置**。`aai.java:38–48` 实现平移和左右镜像；`aai.java:53` 的自由线 / 筋分支只列八种燧石、黑曜石工具，没有工作台。原始匹配方法字节码偏移 0–101 只检查这八个工具 ID，未命中时偏移 108 设 false，并于 126 跳到普通匹配路径 416。因此本轮可将两条固定配方合并为一个“线或筋” Ingredient，但不能复用短斧的任意绑定格枚举规则。

原作另有“燧石刀在原木上方”的 1×2 配方和拆解工作台的配方（`RecipesMITE.java:116,119`）。拆解产出燧石刀，并由 `wd.java:130–131 → arv.getBlockComponent` 返还对应原木。本轮不增加刀、刀配方或拆台返还逻辑；常规破坏工作台仍按现代方块掉落处理。

## 原木出四块板，但一格配方也需要工作台

`aaf.java:66–69` 为四种原木分别注册“1 原木 → 4 同种木板”。运行时 order **503–506** 都是 1×1 配方，产量 4、难度 `120.00001`、CARPENTRY 标记 128，且 `bench_material=wood`。

门槛来自 `RecipeHelper.java:71–72`：凡输出旧 `aqz.C` 木板的配方，设置 `akc.d`（木材）作为工作台工具材质检查要求。字节码在偏移 **519** 读取 `aqz.C`，**529** 读取 `akc.d`，**532** 写入工作台要求。它不是根据配方格数判断能否徒手加工，也不是要求背包里带着木板或工具。

正常界面路径 `awy.java:172–191` 要求使用 `vl` 工作台容器，并比较所需材质与该台工具材质的 durability。木材为 0.5、燧石为 1（`EnumEquipmentMaterial.java:6–7`），所以第一张燧石工作台已经足够加工木板；不需要先做铜台。`wd.java:143–163` 的取出判定消费 `crafting_result_shown_but_prevented` 标记。这里记录正常操作门槛，不把旧界面侧标记机制当作现代服务端安全校验的范本。

原作职业字段不等于默认职业锁；`atv.java:156` 标记职业关闭，独立服务器 `is.java:86–87` 读取设置后强制 false。本轮不引入木工职业、加工耗时、品质或经验成本。

## 本轮现代方案

- 沿用 `minecraft:crafting_table` 注册 ID 和 Minecraft 1.21.1 工作台材质，中文名称为“燧石工作台”。旧存档中的该方块仍使用同一 ID；不按原木种类增加四个方块或旧外观。
- 用上述固定 2×2 直接配方替换原四木板工作台配方。材料为燧石、木棍、线或 `mite:sinew`，以及现代 `#minecraft:logs`。所有符合标签的原木、木块、去皮变体、菌柄 / 菌核都产出同一工作台，这是现代材料扩展。
- 固定 1.21.1 的 `#minecraft:logs` 不含竹块和去皮竹块，它们属于单独的 `#minecraft:bamboo_blocks`。本轮按所选 logs 标签解释，不暗中增加竹块配方；数据包改变该标签时，材料范围随标签变化。
- 在原版玩家背包的 2×2 制造网格中，禁止取出所有结果属于 `#minecraft:planks` 的制造产物；普通 3×3 工作台允许，现代自动合成器 Crafter 也作为基础加工设备允许。判定对象是产出木板，不是只封一条橡木配方。
- 保留现代原版木板配方及其产量。普通原木配方仍为 4 板；现代竹块配方为 2 竹板，不强改成 4。竹板属于 PLANKS，所以即使竹块不作工作台材料，它的木板加工仍受背包门槛。
- 原版配方书、普通取出、快捷取出等入口应遵循同一服务端结果限制；第三方自定义容器是否作为加工设备留给后续明确接入，不宣称已经完整覆盖全部模组容器。

这形成“现有燧石短斧取得原木 → 背包直接制造燧石工作台 → 工作台加工木板”的闭环。不移植高级工作台、完整制造时间 / 经验体系、旧便携方块规则、旧工作台堆叠与拆解系统；也不把本轮描述为完整金属或采矿进度已经完成。

## 固定验收预期

| 场景 | 预期 |
| --- | --- |
| 背包中标准 2×2 / 左右镜像，分别用线与筋 | 产出 1 工作台，各消耗 1 燧石、1 绑定材料、1 木棍、1 原木 |
| 同一图案在 3×3 内四个位置平移 | 均可制造；左右镜像仍有效 |
| 旋转、绑定移到图案外、重复绑定或额外材料 | 不匹配工作台配方 |
| 四木板 2×2 | 不再产出工作台 |
| 背包中原木→板，包括配方书与快捷取出 | 不得获得木板，不得消耗原料 |
| 放置工作台后原木→板 | 按原版产量及种类输出，普通原木为 4 |
| 竹块→竹板 | 背包禁止；工作台与 Crafter 保留原版产量 2 |
| Crafter 实际接受并执行木板配方 | 正常加工，不能以“无人操作”为由额外职业封锁 |
| 木棍、燧石碎片、筋、短斧等非木板结果 | 保持各自现有规则 |

服务端限制、实际容器取出和自动合成器执行须由独立测试验证；上表是预期，不是已通过记录。
