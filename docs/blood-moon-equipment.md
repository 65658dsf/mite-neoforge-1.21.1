# 普通日与血月的怪物装备成长

开发署名：NingMeng123。2026-10-18 按用户确认，普通日使用同一最高日期所解锁的血月材质档位和材质分布，穿甲及空手补装备的概率取血月的一半。精确数值与独立有理数夹具见 [结构化规格](../spec/blood-moon-equipment.json)。

## 日期与生成概率

最高日期保存在主世界，不随回调时间、蓝月或跨维度回退。血月计数为 `highestDay / 32 - highestDay / 128`，蓝月不推进档位。第 64 天起，普通日和血月使用相同材质分布；普通日不再等待每 128 天缓慢提升一档。

| 最高日期 | 主要材质档 | 普通日穿甲率 | 普通日空手补装备率 | 血月每槽穿甲率 | 血月空手补装备率 |
| --- | --- | ---: | ---: | ---: | ---: |
| 64～95 | 皮革 | 40% | 35% | 80% | 70% |
| 96～159 | 锁链 | 41% | 36.5% | 82% | 73% |
| 160～191 | 金 | 42% | 38% | 84% | 76% |
| 192～223 | 铜／银（同级） | 43% | 39.5% | 86% | 79% |
| 224～287 | 铁 | 45% | 42.5% | 90% | 85% |
| 288～319 | 远古金属 | 46% | 44% | 92% | 88% |
| 320～351 | 艾德曼 | 48% | 47% | 96% | 94% |
| 352 及以后 | 振金 | 49% | 48.5% | 98% | 97% |

普通日先抽一次穿甲，成功后给空护甲槽补同材质；血月四个空护甲槽独立抽穿戴和材质，可缺件和混搭。因此每个空槽的穿戴率及某种材质的实际概率是血月的一半，整只怪物“至少穿一件”的概率因抽签方式不同而不直接折半。

第 64 天以前，普通日使用 30% 的旧护甲入口，第一次血月使用 60%；两者沿用早期材质池和部分护甲停止规则。已有的固定武器及其他原生装备生成流程继续生效；表中手持概率专指后续对空主手的补充抽签。

## 材质分布

保存索引依次为：皮革 0、锁链 1、金 2、铜 3、银 4、铁 5、远古金属 6、秘银 7、艾德曼 8、振金 9。铜银共享一个权重等级并平分其权重，原有索引不改变。

普通日与血月均以当前主等级权重 1 为基准，每低一级乘 0.35，每高一级乘 0.4，再归一化。所有十种材质均有非零概率；“振金主档”表示概率最高的档位，并非保证生成振金。第八次血月（320 天）的振金条件概率为 `512000000/2480787323`，第九次起为 `25600000000/39381511261`。

空手的适用近战亡灵补充剑、镐、铲或斧，各占成功结果的 25%；优先跟随本轮第一件新护甲，其次识别已有护甲，没有护甲再独立抽同阶段材质。皮革和锁链使用锈铁工具，振金使用已注册的振金工具。盾牌保留既有出生抽签和材质匹配规则。

## 附魔、掉落与保存

新生怪物装备的普通附魔概率与强度随最高日期提高，见 [日期附魔成长](mob-enchantment-progression.md)。怪物自带的秘银、艾德曼、振金装备固定不掉落；低阶自带未附魔装备在原死亡条件后保留三分之一，附魔装备再减半。拾取装备保持原掉率，见 [怪物装备掉率](monster-equipment-drops.md)。

装备决策保存格式仍为版本 3，旧索引和已保存结果兼容。已有护甲、已有武器、空结果及旧版本实体均不因日期变化补发或重抽。特殊亡灵保留固定装备下限，只在创建新装备时使用同日期材质分布。

## 验证与手测

独立夹具由 `python tools/specs/generate_blood_equipment_fixture.py` 使用 Python `Fraction` 生成，不调用生产 Java 概率实现；覆盖材质归一化、累计边界、普通日与血月同材质、精确二分概率和日期阈值。实际 GameTest 覆盖材质物品、手持匹配、普通日与血月生成、日期附魔及 NBT 重载不重抽。本轮结果见 [装备平衡验证](testing/monster-equipment-balance.md)。

在独立存档按日期递增测试：第 320 天第八次血月可用 `/time set 7662000`，第 321 天普通日可用 `/time set 7686000`；第 352 天第九次血月可用 `/time set 8430000`，第 353 天普通日可用 `/time set 8454000`。生成新的无自定义装备怪物比较材质，并保留一只旧怪物跨日期和保存重进，确认其装备不变。少量刷怪不能估算稀有概率。
