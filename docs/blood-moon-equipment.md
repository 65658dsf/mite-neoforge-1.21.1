# 普通日与血月的怪物装备成长

开发署名：NingMeng123。以下是用户指定的现代扩展，精确数值与独立有理数夹具见 [结构化规格](../spec/blood-moon-equipment.json)。

振金追加在艾德曼之后，保留已有材质索引 0～8，振金使用新索引 9。沿用既有日期成长、归一化权重、装备生成、品质、磨损、附魔与保存机制；旧怪物的已完成决策不会重抽。

## 普通日的连续成长

第 64 天启用成长装备，64～128 天保持初始分布；此后每天按最高到达天数增加进度，每 128 天增加一档。艾德曼所在的进度 8 仍对应第 1152 天，再延长 128 天，于第 1280 天达到振金进度 9。最高日期保存在主世界，不随回调时间、蓝月或跨维度回退。

```text
progress = clamp((highestDay - 128) / 128.0, 0, 9)
armorChance = (50 + 5 * progress)%
emptyHandSupplementChance = (40 + 5 * progress)%
```

普通日仍然先抽一次穿甲，成功后给所有空护甲槽补同材质；手持补充独立抽签。封顶穿甲率为 95%，空手补工具率为 85%。材质分布按相邻的归一化档位线性混合，振金作为高阶尾部从成长启用时就具有很低概率，实际穿戴概率逐日上升；不增加另一套独立随机规则。

## 手持、盾牌与保存

原有适用生物、固定装备排除、来源掉落规则和主手保留规则继续生效。空手的适用近战亡灵补充剑、镐、铲或斧，各占成功结果的 25%；优先跟随本轮第一件新护甲，其次识别已有护甲，没有护甲再独立抽同阶段材质。皮革和锁链依然使用锈铁工具，振金使用实际注册的振金工具。匹配振金武器的盾牌沿用既有 15% 出生抽签，生成振金盾，不额外提高盾牌概率。

保存记录仍是版本 3，原索引 0～8 不改变，新索引 9 仅写入新决策。已有护甲、已有武器、空结果及旧版本实体均不补发、不升级、不重抽；保留原有品质、附魔、磨损和掉落率。

## 验证

独立夹具由 `python tools/specs/generate_blood_equipment_fixture.py` 使用 Python `Fraction` 生成，不调用生产 Java 概率实现。包含十个基准档位、二十组分布、十种材质与十七个日期字面量锚点。单元测试逐一验证精确分数、归一化、每个累计抽取边界、每日高阶尾部不回退、振金实际概率逐日严格增长及新旧日期阈值。

实际 GameTest 覆盖第八／九次血月、振金护甲物品、十材质手持匹配、振金盾匹配、普通日封顶和 NBT 重载不重抽。测试运行状态见 [本轮振金成长验证](testing/vibranium-progression.md)。

手测时使用新的无自定义装备怪物，先按日期从小到大推进。第 320 天第八次血月可用 `/time set 7662000`，第 352 天第九次血月可用 `/time set 8430000`；普通日第 1153 天为 `/time set 27654000`，第 1281 天为 `/time set 30726000`。保留一只既有怪物跨日期和保存重进，确认其装备不变。少量刷怪不能估算稀有概率，以精确分数测试为准。
