# 血月进度与怪物护甲

开发署名：NingMeng123。以下概率是用户确认的现代扩展，不是 R196 原始数值。

主世界到达过的最高日期持久保存，所有维度共用。血月次数为 `最高日期 // 32 - 最高日期 // 128`；第 128、256 等蓝月日不算血月。回调时间、保存重进、死亡或跨维度都不回退装备进度。当前额外提升只在主世界实际血月当天生效，普通日也保留已经解锁的护甲档位。

公式：当前主档为 `s`，目标档为 `t`，最高档为 `8`。`t < s` 的概率为 0；`s ≤ t < 8` 为 `(1-r) × r^(t-s)`；艾德曼吸收最后的几何尾部，为 `r^(8-s)`。因此第 2 次血月就已经存在极小概率艾德曼，后续逐渐提高。最高主档时，成功穿甲后必定为艾德曼。

## 范围与保存

- 普通僵尸、僵尸村民、僵尸猪人、尸壳、溺尸，以及普通骷髅、凋灵骷髅、流浪者、沼骸，和尸鬼、亡魂、暗影、隐形潜行者四种源人形怪，均可使用这套进度护甲。
- 怨魂、远古骷髅、远古骷髅守卫、骷髅领主、远古骷髅领主保留原固定套装，不因新规则降级。蜘蛛、苦力怕等不增加不可见的护甲。
- 仅新怪物进行一次装备抽签，包括“没穿甲”的结果；每个实体的 `mite:blood_moon_equipment` 版本化标记随 NBT 保存。旧存档加载不重新发甲，旧实体以后跨维度也不补发。
- 使用已有 `R196MobEquipment.generated` 统一生成品质、磨损与附魔，不加第二次现代护甲附魔；武器、特殊固定装备和已有掉落概率保持原逻辑。不是保证掉出整套新甲。

## 手动检查

使用新测试存档。`/time set 1518000` 到第 64 天血月白昼，反复生成普通僵尸、骷髅或尸鬼，确认可出现同材质护甲四件套，也会有不穿甲的结果；切至 `/time set 1530000` 检查夜间。`/time set 6000` 回到普通日后，后续新怪物仍按已经达到的皮革主档生成，穿甲和高阶概率降低。

`/time set 17646000` 到第 736 天（第 18 次实际血月），成功穿甲的新怪物应为艾德曼；普通日仍可能不穿甲。保存重进并观察原怪物，不应重抽或更换护甲；用指定护甲的召唤 NBT 检查已有位置被保留。固定套装特殊怪和蜘蛛／苦力怕不应被此规则改装。高阶稀有事件不适合仅靠少量手动召唤估算，精确分布由独立规格夹具和边界测试验证。
