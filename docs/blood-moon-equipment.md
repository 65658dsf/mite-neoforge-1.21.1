# 血月进度、怪物护甲与手持工具

开发署名：NingMeng123。以下是用户确认后调整的现代扩展，不是 R196 原始概率。数值来源为 [结构化规格](../spec/blood-moon-equipment.json)，包含独立有理数计算的常量夹具。

主世界到达过的最高日期持久保存，所有维度共用。血月次数为 `最高日期 // 32 - 最高日期 // 128`，蓝月不计入。时间回调、保存重进、死亡或跨维度不会倒退装备进度；血月额外提升仅在主世界血月当天生效。

## 第一阶段

第二次血月之前保留来源装备路径。第一次血月将走旧随机护甲入口的怪物穿甲率提高到 60%，仍可能只穿部分护甲，材质池为皮革、锈铁锁链、铜锁链、锈铁板甲和铜板甲。该阶段普通日总穿甲率仍是 `15% × 区域紧张度`，新增怪物和现代变种继续各自旧路径；本次新手持抽签从第二次血月开始。

## 手持剑、镐、铲和斧

普通僵尸、僵尸村民、僵尸猪人、尸壳、溺尸和尸鬼、亡魂、暗影、隐形潜行者在来源初始化完成后，仅为空主手补充工具。四种工具等权，各占成功补充结果的 25%。

优先沿用本轮新生成护甲的实际材质；没有新生成甲时识别已有护甲；没有可识别护甲时，另按同阶段材质分布抽取。皮革和锁链没有对应工具，两者使用锈铁工具；金、铜、银、铁、远古金属、秘银和艾德曼使用对应工具。显式保留的护甲可能与新生成槽位混搭。

弓骷髅保留弓，所有已有主手（包括弓、弩、三叉戟、钓鱼竿及来源自带武器）保留。蜘蛛、苦力怕和特殊固定装备生物不新增工具。普通骷髅等仍可参与护甲成长，手持补充只用于适用近战生物。

工具统一使用已有来源生成入口，具有品质、磨损和一次附魔处理，实际战斗和既有挖路 AI 继续按物品能力工作。生成装备不会额外提高掉落率；各生物继续使用已有掉落路径，包括现有不掉装备的来源亡灵。

## 保存与旧实体

护甲和手持分别记录一次结果，包含空结果。新实体使用 `mite:blood_moon_equipment` 版本 2，护甲先初始化、手持在加入世界时完成；重复加入不重新抽取或消耗随机数。版本 1 的旧记录、磁盘加载的旧实体和早期已完成初始化的实体都不补发工具，避免重进或跨维度刷装备。旧装备不会被自动换装。

## 手动验收

使用新的作弊测试存档，由用户重启客户端。先执行 `/gamemode creative` 和 `/gamerule doDaylightCycle false`。

1. `/time set 1518000` 到第 64 天第二次血月，再使用生物蛋或不带自定义 NBT 的 `/summon minecraft:zombie` 生成一批僵尸。应能看到同材质护甲、不同种类工具，也会出现无甲持械或空手怪物。
2. `/time set 6000` 调回普通日，最高进度保留，普通日穿甲率为 50%，空手补工具率为 40%，比血月低。
3. `/time set 17646000` 到第 736 天第 18 次血月。艾德曼最常见，但秘银、远古金属及更低阶装备仍可出现；并非所有穿甲怪物都是艾德曼。普通骷髅仍持弓，守卫、领主等保留固定装备。
4. 挑选几个穿甲持械、无甲持械和空手怪物，用命名牌防止自然消失，保存重进后主手与护甲应不变；旧怪物不补发。已生成的怪物不会因为调时间而换装，必须生成新怪物观察新阶段。

少量召唤无法可靠估算极稀有低阶或高阶概率，分布常量、抽样边界、实际物品、保存和来源初始化顺序由自动测试覆盖。
