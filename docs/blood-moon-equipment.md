# 普通日与血月的怪物装备成长

开发署名：NingMeng123。以下是用户指定的现代扩展，不是 R196 原始概率。数值与独立有理数夹具见 [结构化规格](../spec/blood-moon-equipment.json)。

普通日按世界最高到达天数成长，血月按每次血月升级。这里调整的是材质档位、穿甲率和空手补工具率；R196 的劣质、普通、精良等物品品质、磨损及附魔机制沿用原规则。

## 普通日：独立按天数成长

普通日只读取主世界最高到达日期，不读取血月次数，也不要求玩家经历某次血月。第 64 天起启用成长装备，64～128 天保留初始皮革分布；第 128 天后按天平滑增加材质进度，每 128 天推进一档，第 1152 天达到最高进度。最高日期持久保存，调回时间、重进或跨维度不回退。

```text
progress = clamp((highestDay - 128) / 128.0, 0, 8)
armorChance = (50 + 5 * progress)%
emptyHandSupplementChance = (40 + 5 * progress)%
```

小数进度按相邻两档的归一化材质分布线性混合。例如第 200 天进度为 9/16，穿甲率 52.8125%、空手补工具率 42.8125%；第 201 天进度和概率继续增加，不需要等到下一次血月。普通日目前仍为一次穿甲抽签，成功后向空护甲槽补同材质套装。

## 血月：每次升级、四部位独立

第一次血月保留旧 R196 随机护甲路径：已有入口穿甲率提高到 60%，可能只穿部分护甲；旧材质池为皮革、锈铁锁链、铜锁链、锈铁板甲和铜板甲。第 64 天之前的普通日也保留原装备规则。

第二次血月开始以皮革为概率峰值，此后每次升一档。蓝月不计入血月次数，第 128、256 等天跳过。第十次血月（第 416 天）起达到艾德曼主档。

头盔、胸甲、护腿、靴子分别进行一次穿戴抽签，成功后各自再抽材质；四个部位可以缺件、混搭。表内的“每部位穿戴率”不能当作整套概率，四件全空为 `(1-p)^4`，四件齐全为 `p^4`。这里的四件齐全允许不同材质。

## 手持工具与适用生物

空手补工具率针对来源初始化后主手仍为空的适用近战怪物，不能当作所有怪物的最终持械率。普通僵尸、僵尸村民、僵尸猪人、尸壳、溺尸，以及尸鬼、亡魂、暗影、隐形潜行者可以补充剑、镐、铲或斧，四类各占成功结果的 25%。

材质优先参考本次新生成的第一件护甲（头盔、胸甲、护腿、靴子顺序），没有新甲时识别已有护甲；没有可识别护甲则独立抽取同阶段材质分布。皮革和锁链对应锈铁工具，其余使用相应材质。因此血月混搭护甲不会把四件强制改为同材质，没穿甲也可能持械。

已有主手、骷髅弓和固定套装生物保留。普通骷髅族仍可参与护甲成长；蜘蛛、苦力怕等不获得隐形护甲。来源统一生成装备品质、附魔与磨损，不额外提高掉落率，包括保留现有不掉装备的来源亡灵规则。

## 保存

新实体 `mite:blood_moon_equipment` 版本为 3，保存最高日期、连续进度、普通／血月标志、各部位材质和已填槽位；手持结果独立保存。空结果也保存，重复加入、重进、跨维度不会重抽。版本 1、2 的旧记录及已加载旧实体保留原装备，不升级或补发工具。

## 手动测试

由用户重启客户端，在新的作弊测试存档按时间从小到大测试。使用生物蛋或不带自定义 NBT 的 `/summon minecraft:zombie`，每步生成新怪物，旧怪物不会自动换装。

1. `/time set 1518000`：第 64 天第二次血月。四个护甲部位可以缺件，材质可以混搭；检查手持工具及已有武器保留。
2. `/time set 2286000`：第 96 天第三次血月，锁链成为概率峰值；不再等到第四次。
3. `/time set 4782000`、`/time set 4806000`：第 200、201 天普通日，按日历小数进度生成，不随血月次数整档跳升。一天差异很小，精确概率由数值测试验证。
4. `/time set 9966000`：第 416 天第十次血月，艾德曼主档，仍可缺件和混搭低阶甲；弓骷髅及特殊固定装备保持原规则。
5. `/time set 27654000`：第 1153 天普通日已封顶，穿甲率 90%、空手补工具率 80%，仍低于血月基准。保存重进检查同一怪物，已有装备和空结果都不变。

少量刷怪无法可靠估计稀有概率；独立部位抽取、混搭、日历插值、保存与新旧版本兼容由自动测试覆盖。
