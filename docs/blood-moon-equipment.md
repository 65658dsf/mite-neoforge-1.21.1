# 普通日与血月的怪物装备成长

开发署名：NingMeng123。2026-10-18 按用户确认，普通日使用同一最高日期所解锁的血月材质档位和材质分布，穿甲及空手补装备的概率取血月的一半。精确数值与独立有理数夹具见 [结构化规格](../spec/blood-moon-equipment.json)。

## 日期与生成概率

2026-10-27 按用户最新要求，完全取消早期出生装备禁用。此前前35天、随后前16天的禁装备规则均为历史行为；从第1天开始，普通怪物、领主和Boss沿用各自原生装备、已有生成概率与日期材质成长，不再全局清空盔甲、主副手或隐藏备用武器。原有概率仍可能生成空槽，并不强制每只怪物穿满装备。

`spawnEquipmentLocked` 公共兼容入口保留并始终返回 `false`。`mite:early_equipment_exempt` 标签及角色查询仍保留给扩展使用，但不再控制出生禁装备；Modern ITE 等扩展可以按各自规则生成装备。真正的弓手和近战骨架仍按实际角色处理，不把近战骷髅或Boss统一改成弓手。

旧版已保存 `early_equipment_locked` 的怪物在入场时移除此标记并记为已有实体，不重新抽装备。仅修复明确缺失的原生战斗武器：空主手原版掠夺者补普通弩、卫道士补铁斧，真实弓手保留补普通弓并重装射箭任务的兼容处理；掠夺者副手已有 `CrossbowItem` 时不重复补弩。已有主手、自定义／拾取装备、被缴械状态和隐藏备用武器均保留，其余特殊角色不猜测补装；没有旧锁标记的空手旧怪物也不因此重抽。

最高日期保存在主世界，不随回调时间、蓝月或跨维度回退。血月计数为 `highestDay / 32 - highestDay / 128`，蓝月不推进档位。第 64 天起，普通日和血月使用相同材质分布；普通日不再等待每 128 天缓慢提升一档。

普通日先抽一次穿甲，成功后给空护甲槽补同材质；血月四个空护甲槽独立抽穿戴和材质，可缺件和混搭。因此每个空槽的穿戴率及某种材质的实际概率是血月的一半，整只怪物“至少穿一件”的概率因抽签方式不同而不直接折半。

第1～63天，普通日使用30%的旧护甲入口；原有第一次血月60%入口及早期材质池、部分护甲停止规则不变。各物种的固定武器与其他原生装备生成流程从首日起继续生效；表中手持概率专指后续对空主手的补充抽签。

## 材质分布

保存索引依次为：皮革 0、锁链 1、金 2、铜 3、银 4、铁 5、远古金属 6、秘银 7、艾德曼 8、振金 9。铜银共享一个权重等级并平分其权重，原有索引不改变。

普通日与血月均以当前主等级权重 1 为基准，每低一级乘 0.35，每高一级乘 0.4，再归一化。所有十种材质均有非零概率；“振金主档”表示概率最高的档位，并非保证生成振金。第八次血月（320 天）的振金条件概率为 `512000000/2480787323`，第九次起为 `25600000000/39381511261`。

空手的适用近战亡灵补充剑、镐、铲或斧，各占成功结果的 25%；优先跟随本轮第一件新护甲，其次识别已有护甲，没有护甲再独立抽同阶段材质。皮革和锁链使用锈铁工具，振金使用已注册的振金工具。盾牌保留既有出生抽签和材质匹配规则。

## 附魔、掉落与保存

新生怪物装备的普通附魔概率与强度随最高日期提高，见 [日期附魔成长](mob-enchantment-progression.md)。怪物自带的秘银、艾德曼、振金装备固定不掉落；低阶自带未附魔装备在原死亡条件后保留三分之一，附魔装备再减半。拾取装备保持原掉率，见 [怪物装备掉率](monster-equipment-drops.md)。

装备决策保存格式仍为版本 3，旧索引和已保存结果兼容。除上述旧锁缺失武器的兼容修复，已有护甲、已有武器、空结果及旧版本实体均不因日期变化补发或重抽。特殊亡灵保留固定装备下限，只在创建新装备时使用同日期材质分布。

## 验证与手测

独立夹具由 `python tools/specs/generate_blood_equipment_fixture.py` 使用 Python `Fraction` 生成，不调用生产 Java 概率实现；覆盖材质归一化、累计边界、普通日与血月同材质、精确二分概率和日期阈值。实际 GameTest 覆盖材质物品、手持匹配、普通日与血月生成、日期附魔及 NBT 重载不重抽。本轮结果见 [装备平衡验证](testing/monster-equipment-balance.md)。

更新后的 `EarlyMobEquipmentGameTests` 六项覆盖第1、8、16、17、35天保留可见／隐藏装备、首日灾厄村民真实武器、真实NBT旧锁移除且已决定抽签不重复、旧锁缺失弩／铁斧／弓的有限修复、副手弩和自定义装备保护，以及五种本体弓手实际发射有速度的箭。命名空间仍为 `mite_equipment_progression`；`LordEquipmentCompatibilityGameTests` 同步检查真实Modern ITE普通怪物和领主从早日起保留装备。

最终普通模式和 Better Combat 2.4.0 模式各 206 项必需 GameTest 全部通过，包含装备进度与上述取消限制回归；实际加载 Modern ITE 0.2.15 时，18 项自然索敌、旧档迁移及普通怪物／领主兼容测试全部通过。日志分别为 `build/verification/native-aggro-20261027-verified-runtime.log`、`native-aggro-20261027-verified-bc-runtime.log`、`native-aggro-20261027-verified-ite-runtime.log`；扩展专用命名空间仅在 ITE 模式运行。独立构建及 1,770 项 JUnit 亦通过，发布包逐类核对见 `build/verification/native-aggro-20261027-acceptance.json`。

在独立存档按日期递增测试：第 320 天第八次血月可用 `/time set 7662000`，第 321 天普通日可用 `/time set 7686000`；第 352 天第九次血月可用 `/time set 8430000`，第 353 天普通日可用 `/time set 8454000`。生成新的无自定义装备怪物比较材质，并保留一只旧怪物跨日期和保存重进，确认其装备不变。少量刷怪不能估算稀有概率。
