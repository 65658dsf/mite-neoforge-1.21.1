# 016 装备耐久证据与适配

开发者：NingMeng123。依据为本地 R196 发布包、`reference-data/runtime-registry.json`、CFR 输出及 `javap -c -p`。源码位置相对 `.reference/r196/decompiled/`。结构化规格 [r196-durability.json](../spec/r196-durability.json) 包含 11 条规则、115 件原工具和 68 件原护甲的注册耐久库存；按已确定的废弃项排除 8 种金属小刀后，本批工具范围为 107 件。库存不等于所有装备已实现。

## 最大耐久与品质是真实调用结果

`xj.java:20–40` 构造工具时直接把 `(int)(4F * 部件数 * 材料durability * 100F)` 写入基础最大耐久。字节码按三次 `fmul` 后 `f2i` 执行，不是普通材料常量展示。护甲 `wh.java:18–40` 使用 `部件数 * 材料durability`，非锁链再乘二，最后截断；**护甲没有工具的 ×400**。

工具部件数：镐/斧 3，战斧/鹤嘴锄 4，短斧/铲/短剑/小刀/短棒 1，锄/剑/镰刀/剪刀/木棒 2，战锤 5。护甲头/胸/腿/脚为 5/8/7/4。因此铁镐基础耐久 9600，燧石短斧 400，木棒 400；铁护甲为 80/128/112/64，铁锁链为 40/64/56/32，皮革为 10/16/14/8。

品质倍率依次为最差 0.5、劣质 0.75、普通 1、优良 1.5、优秀 2、精良 2.5、大师 3、传奇 3.5。`yc.java:590–608` 实际最大耐久调用 `Math.round(base * multiplier)`，最低一；字节码偏移 67 乘、68 round、72 max。`xj/wh.hasQuality()` 返回 true，职业默认关闭不影响这一调用。

**未写品质的旧物品不是一律普通。** `ye.java:927–954` 将 null 品质补为 `yc.getDefaultQuality()`，后者在 `yc.java:1253–1255` 取材料上限与普通中较低者。所以锈铁默认劣质：基础 4800 的锈铁镐，默认实际最大耐久 3600；不能让缺失组件绕过上限。现代使用持久化和网络同步的 `mite:quality` 整数组件，查询仍按材料上限夹取。制造界面的品质选择、经验资格及耗时另项实现。

## 挖掘、攻击与工具操作

`xj.java:149–192` 的方块损耗为：

```java
if (hardness == 0F) return 0;
float decay = 100F * baseRate;
return Math.max(Math.max((int)(hardness * decay), (int)(decay / 20F)), 1);
```

外层要求服务端、可损坏、非便携方块、非创造、硬度正数、工具对目标的强度大于 1。错误工具或级别不足不能仅因“拿着工具”就扣耐久。现代入口使用当前 `MiningProgress.effectiveHardness` 和工具实际破坏速度；需要正确工具掉落的目标还检查 `isCorrectToolForDrops`，避免弱镐虽有速度加成却不合格时扣耐久。保留之前局部硬度适配，不更改世界方块爆抗；完整旧材质门槛仍取决于各工具/方块映射。

2026-10-28 补齐有明确旧版对应的 [方块有效硬度映射](r196-block-hardness-audit.md)。R196 黑曜石实际注册硬度为 2.4（`aqz.java:2309`，运行时 `aqz.cG=2.4`），镐每块耗 `2.4×100=240`；普通铁镐从 9600 剩 9360，可挖 40 块。先前回退现代硬度 50 导致每块扣 5000，现已修正。普通石头也使用实际注册的 2.4，镐每块耗 240。黑曜石既有 188 tick 的计时分支继续读取现代硬度 50；它与损耗使用的有效硬度分别取值。不能使用未接入注册的 `BlockHardness.obsidian=8` 作为损耗依据。

2026-10-31 现代镰刀近战适配：本体镰刀和 Simply Swords 战镰的每次成功命中统一耗 50 点，与剑一致；锋利、吸血不再改变这份普通损耗。上表的镰刀 400/200/100 仅保留为 R196 来源记录，现代运行值已替换。此前普通铜镰基础耐久 3200，只能成功命中 8 次，铁镰 6400 也只能命中 16 次；修正后分别为 64、128 次。各材质最大耐久、品质、耐久附魔及副词条减耗继续沿用原规则；割草和成熟小麦仍各耗 2 点。

这里 `aqz.V` 是砂岩，不能误写成蜘蛛网。现代红砂岩、楼梯等变体是明确扩展。小刀目标对应旧 `akc.n/k/l`（布/植物/藤蔓）；镰刀特例是 `aqz.ac/aE`（草/小麦），不是所有作物或藤蔓。初始移植时吸血附魔尚未注册，上述优先级仅用于来源对照；现代镰刀普通命中损耗不再依赖锋利或吸血。

固定例：硬度 1.2 的原木，短斧耗 160、普通斧耗 120；硬度 0.02 的有效草目标，剪刀仍耗最低 5、剑最低 10、木棒最低 1。剪羊和耕地各耗 50（`yx.java:47–63`、`yb.java:74–80`）；它们不是普通的每次挖掘公式。原版锄与剪羊在特定动作入口改为 50，现代剪刀封顶植物等额外功能保持自己的原动作费用，不把所有 `hurtAndBreak(1)` 全局换成 50。

现代 ItemStack 挖掘/攻击入口保留原统计；新 `Profiled` 工具仍执行自己的物品回调，其中调用共享耐久逻辑，避免屏蔽收割等副作用或重复耗损。原版及旧短斧/木棒等非 `Profiled` 受管物品在 ItemStack 层替换旧固定耗损。

工作台 `arv.isPortable=true` 已映射到原版 `CraftingTableBlock` 和本模组材料工作台，挖台不磨损。旧铁砧、容器基类、床、炼药锅、龙蛋、梯子、TNT、方向/悬挂方块实体，以及仅对所有者便携的保险箱尚未完整映射。不能将“所有含方块实体的方块”直接视为便携，也没有在本批补回完整便携采集时间。

## 耐久附魔与破损

`ye.java:256–279` 对每个整数损耗点独立抽一次 float，满足 `random < (level / 5F) * 0.75F` 才免除。`aau.getNumLevels()` 为 5，耐久附魔 `aas` 不覆盖它，因此 I–V 名义免耗率为 15/30/45/60/75%，并非现代的 `level/(level+1)`。III 的计算结果位为 `0x3ee66667`，略高于字面 `0.45F`；严格小于比较及该浮点顺序有独立测试。

现代只替换受管装备的耐久附魔效果，其他附魔仍走原管线，不再二次抽现代耐久。原来每次新建 `Random`，现代采用服务端 RNG；不追求同随机序列。异常命令等级夹在 0–5，自然上限 V 由附魔数据定义。

工具达到最大损坏值就损毁。普通穿戴护甲先应用耐久附魔，再限制最大损坏为 `max-1`；不能把限制放在附魔之前，否则概率结果不同。原酸/胃酸可毁、皮革火伤可毁、岩浆分支可毁且金属耗损乘十；装备腐坏诅咒在耐久附魔前乘二（`ye.java:282–343`）。本批接入现代火/岩浆和火免疫，旧酸、胃酸、腐坏诅咒另项。工具沿用现代破损通知、统计和物品组件。旧读档超损值夹到 `max-1`（`ye.java:166–175`）没有被泛化为所有现代异常 NBT 的自动修复。

## 护甲损耗与磨损后的防护

旧皮革/锈铁/铜/银/金/铁/远古/秘银/艾德曼的基础防护分别为 2/6/7/7/6/8/8/9/10，锁链再减二。每件基础防护为 `部件数 * 材料防护 / 24F`。普通保护附魔再增加本值的 `(等级/4F)*0.5F`，最后乘磨损系数（`wh.java:43–76`）。

R196 玩家磨损系数为 `min(2F - damage/max * 2F, 1F)`；最大耐久大于一且只剩最后一点时直接为零。`wh.java:202–213` 对非玩家原本固定返回 0.5。这些仍是来源算术证据。2026-10-28 的现代适配已取消玩家穿戴属性的磨损衰减：玩家与 NPC 的护甲、韧性均使用完整材质属性，剩一耐久仍然有效。来源磨损系数仅继续用于既有耐久预算和银甲特殊抗毒等独立规则。

护甲损耗总预算为 `min(当前旧式护甲防护, 来袭伤害)`，截断整数、最低尝试一点（`Damage.java:204–209`、`ud.java:579–610`）。求和后先执行 `ls.tryFitToNearestInteger(total,1e-4F)`：全铁逐件 float 相加得到 7.9999995，必须归整成 8 才能正确截取预算。

每轮随机选四槽，若仅装备一件且选中它就分配所有剩余预算；否则再抽 1 至剩余预算的部分。**空槽也消耗随机预算**，不会自动把损耗全部集中到唯一护甲。完整四件铁甲承受足够伤害时一共分摊 8 点，并非每件扣 8，也不是现代每件 `damage/4`。分到最后一点的普通护甲不会消失，并继续提供完整护甲与韧性。

玩家和人形怪物的实际减伤使用 1.21.1 护甲与韧性公式，材质使用现代平衡属性；`ARMOR` 和 `ARMOR_TOUGHNESS` 不再随磨损改变。默认属性不会额外重复计入保护附魔，保护和抗性由原生魔法层处理。旧式防护数值仅用于耐久分摊，不替换现代实际减伤。详见 [现代护甲修正](modern-armor-defense.md)。玩家受击入口保留 NeoForge `ArmorHurtEvent` 的取消/修改及物品伤害免疫；受管与非受管混穿时，非受管装备仍按现代单件损耗。属性变化跟随装备组件更新。

## 现代装备与维修边界

现代石工具暂用燧石材料系数 1；钻石工具用旧钻石材料系数 16，但 R196 没有对应工具族；下界合金用明确推导值 32，保留现代能力及火免疫。钻石/下界合金护甲分别用 16/32，耐久预算的防护档为 9/10。旧 `wh` 没有钻石防护分支，这两个值是现代适配，不是原始证据。

海龟壳、盾、鞘翅、三叉戟、刷子和未接管物品继续现代机制；本批不能宣称它们已有 R196 原值。新旧工具纹理由另行资源清单说明，本规则没有复制纹理或执行资源包程序。

普通合并维修按 `aaf.java:263–322`：同物品、两件均已损坏、品质相同、两件都无附魔、染色状态和颜色相同。两件剩余耐久相加并封顶，**无现代额外 5% 奖励**。受管装备保留品质和匹配染色，结果存储未乘品质的基础最大值，防止合并后再次放大。带诅咒也属于附魔，不能借普通合并洗掉；不影响现代铁砧处理附魔。

完整 R196 铁砧材料数量、修理费用、工作台/砧材料门槛、制造时间和品质经验资格仍未实现。铁砧保持现代可用与组件复制；本批并未宣称整个维修制造体系完成。

## 验证交接

`EquipmentDurabilityRulesTest` 提供独立字面向量：基础最大值、品质取整、各工具耗损、附魔逐点抽取与严格边界、护甲随机预算、最后一点、防护归整和无奖励合并。`EquipmentDurabilityGameTests` 提供品质 NBT/网络往返、原版 RepairItemRecipe、匹配品质/染色/无附魔限制、真实玩家受击、护甲属性刷新、最后一点、事件取消和工作台免耗的集成测试源码。

本提取代理只做静态源码工作，没有构建、启动或操作游戏；测试执行与最终实测结果由主线程记录。未完成部分包括其他便携目标、旧特殊伤害与诅咒、非玩家固定护甲系数、旧格挡、完整高级维修/品质制造，以及目录剩余装备。
