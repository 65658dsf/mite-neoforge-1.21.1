# 035：怪物 AI 接入与共同规则

开发者：NingMeng123。原作：Avernite。版本依据为本地 R196 发布包，SHA-256：`fb7ad265d05749e0cd1e54938f6c36ecbe9ea1d4d90d4a04c519615e1e0218c3`。

本批补全 031 已注册怪物中的新 AI 调度、障碍处理及直接关联行为；不代表每一种怪物、Boss、女巫诅咒或新版独有怪物的全部机制已经完成。仍使用 1.21.1 地形、负高度、实体生命周期和方块寻路形状。

## 实际启用

`R196MonsterAi` 在服务端实体加入世界后安装来源任务。普通/村民僵尸、怨魂、尸鬼、亡魂、隐形潜行者、暗影、土/火元素、骷髅、苦力怕和女巫按实际来源构造器接入；现代尸壳、溺尸、流浪者等不因 Java 继承关系自动获得旧版能力。来源猪人 `tn.bf()` 返回 false，其继承的观察者任务并不实际运行，不安装挖掘和木门任务。

原版僵尸的随机破门开关和 240 刻破门 Goal 被关闭，由独立来源敲门任务接管；普通/村民僵尸、尸鬼和土元素实际安装此任务，暗影不获得木门穿路标记。泛用挖掘与敲门是两个同时存在的来源系统，不能只把原版破门时间改长。

## 智能、狂暴与远程

| 来源 | 实际规则 | 实现/验收 |
| --- | --- | --- |
| `tw` 构造与伤害路径、`EntityRevenant` | 僵尸初始智能概率 1/8；怨魂始终智能；实际受到玩家正伤害后变聪明。智能状态保存，不能用无伤害挥击触发 | `R196MonsterAi.smart/damage`；`MonsterIntegrationGameTests` |
| `tw.isDiggingEnabled` | 排除剑、木棒/棍棒、镰刀后，智能、狂暴或持工具可开启挖掘感知；具体挖掘任务另有可见目标分支 | `diggingEnabled`；障碍来源文档 |
| `tm.isFrenzied`、`tr.isFrenzied`、`tg` | 主世界血月夜间狂暴；蓝月例外。骷髅也可受骨领主短暂狂暴；二者取逻辑或。末影人覆盖返回 false | `frenzied`；血月/白昼/蓝月/骨领主边界测试 |
| `tm` 攻击计算 | 额外增加未修改攻击基础值的 50%，不会因两个狂暴来源叠加两次 | 单一临时属性修饰符；真实骷髅属性测试 |
| `pf.c`、旧 `on.bl` | 狂暴移动乘 1.2 | 现代适配使用单一移动速度总乘数；结束后移除，不改基础属性 |
| `qn` 构造、`tr` 持弓任务 | 普通骷髅名义射程 15，实际距离平方为 `15²×4=900`；固定最大间隔 60 原始刻，不用距离插值得到的较短间隔 | `SourceRangedAttackGoal`；真实箭生成验证 |
| `qn.e` | 初始倒数为 −1，第一次更新装入完整间隔；间隔归零且视线/距离满足才射击。狂暴使用 `int(interval×.67)`，60 变为 40 | 初始 60 次更新尚未射箭、第 61 次射出；间隔边界测试 |
| `qn.e` | 到目标眼睛的穿刺预判被挡后，再查目标 25% 高度；连续看见 20 刻且在范围内停止移动，否则继续接近 | 真实障碍射线与来源 Goal |
| `Raycast.setForPiercingProjectile(null)`、`isFullyImpeded(11)` | 射击预判无投射物 originator，树叶始终不阻挡，也不抽随机数；金属栏杆、藤蔓、甘蔗和打开的栅栏门可穿过，玻璃及玻璃板阻挡 | 树叶随机序列守恒、玻璃板与铁栏对照；实际飞行箭仍由既有投射物处理 |
| `qn.e`、`sb`、`tv` | 射出前自身眼部必须是空气或可通过处；雪傀儡名义 10、间隔 20、速度 1.25；女巫名义 10、间隔 60、速度 1 | 安装对应来源 Goal；现代眼部可通行用碰撞形状适配 |

`SourceRangedAttackGoal` 与普通/新增骷髅的武器切换使用同一入口。重新装备弓或近战武器不会重新装回原版的距离插值射击 Goal。

## 来源与适配边界

- 敲门、泛用挖掘、材料等级、推进间隔、工具耗损与保护规则见 [障碍证据](monster-obstacles-035-evidence.md) 和 [结构化来源索引](../spec/monster-obstacles-source-035.json)。敲门最终破坏只在困难，但泛用挖掘可以单独在普通难度拆除符合规则的障碍。
- 寻敌、复仇、坐骑、协作、UUID 保存及近战见 [目标与近战证据](monster-targeting-melee-035-evidence.md)。所有目标判定在服务端执行，沿用原版实体同步，客户端不能自行决定目标或破坏方块。
- 苦力怕、仙人掌陷阱、着火趋树与真实扩火见 [特殊 AI 证据](monster-special-ai-035-evidence.md)。该分支未迁移整套旧仙人掌农业和碰刺规则。
- 方块破坏和环境扩火服从 NeoForge 怪物破坏保护；扩火同时遵守 `doFireTick`。这是明确的现代保护适配。无额外永久加载区块，来源 UUID 仅查附近已加载实体。
- 智能状态保存到 ForgeData；挖掘沿用 031 存储并在 Goal 启动前延迟恢复；目标和仙人掌 SavedData 含版本号。敲门进度、临时目标引用、趋树强化、骨领主倒数和仙人掌短时记忆不保存。
- 血月速度用现代属性合并规则表达 1.2 倍，保留其他扩展的属性修饰。旧版寻路器、逐随机数轨迹及同种子行为不作为相同承诺。

本批代码不改客户端界面、不添加前置模组。实际构建、回归数量及尚未完成的手测状态见 [自动验证](testing/035-automated-results.md)；用户操作见 [手测清单](monster-ai-035-manual-test.md)。
